# 교과 수업 덱 약속 (학생 대상 — 과목 공통)

`공통.md`, `docs/슬라이드_제작_가이드라인_범용.md`와 함께 읽는다. 고등학교 화학 3과목 묶음에서 실제 수업으로 다듬은 약속 가운데 과목과 상관없는 부분을 일반화했다. 과목마다 다른 것(표기, 기호, 색의 교과 뜻, 범위 제한)은 이 파일을 복사해 `<과목>_약속.md`로 만들고 그 절에 적는다.

## 1. 덱 정보

| 항목 | 정할 것 |
|---|---|
| 주제 | 교과·학년·단원·소단원(덱 하나 = 소단원 하나 또는 1–2차시) |
| 대상 | 학년, 학급 특성(선택 과목, 수준) |
| 시간 | 차시 수 × 분(보통 45·50분) |
| 목표 | 성취기준 코드와 문장(교육과정 원문) + 이 덱의 학습 목표 2–4개 |
| 자료(선택) | 교과서·지도서 PDF와 쪽 — **교과 수업이면 쓰는 것을 권한다.** 덱목록에 `textbook`, `bookPages`, `pdfOffset` |

- 성취기준은 **교과 수업이면 넣는다**(교육과정 문서를 선생님이 주면 그 원문, 없으면 묻는다). 자유 주제 수업이면 학습 목표만.
- 교과서를 쓰면 교과서의 개념·활동·예제·문항을 **빠짐없이** 다룬다(교과서 대조). 교과서 그림은 복사하지 않고 직접 그린다. 교과서 문장을 길게 베끼지 않는다.

## 2. data-sec·id

| 장 | 꼴 | 예 |
|---|---|---|
| 표지 | 대단원 번호·이름 | `Ⅱ. 물질의 구조` |
| 학습 목표 | 소단원 두 자리 번호 + 이름 | `02 분자의 구조` |
| 도입 | `<번호 이름> · 도입` | `02 분자의 구조 · 도입` |
| 개념 | `<번호> · <개념 이름>`(교과서 소제목) | `02 · 전자쌍 반발` |
| 활동 | `<번호> · <활동 이름>` | `02 · 탐구` |
| 문항 | `<번호> · <문항 묶음 이름>` | `02 · 확인하기` |
| 끝 | `<번호 이름> · 마무리` | `02 분자의 구조 · 마무리` |

id 접두어는 덱목록 `idPrefix`(과목 머리글자 + 단원 번호, 예 `ph111-`, `cm222-`).

## 3. 표식
표식 글은 **교과서 이름 그대로**(탐구, 해 보기, 확인하기, 생각 열기 …). 클래스는 성격으로: 활동·탐구·읽기 `tag` · 연결·다시 보기 `tag alt` · 확인·문항 `tag q` · 예제·연습 `tag ex` · 정리 `tag ink`. 반드시 이행할 활동(성취기준 탐구 활동 등)은 표식 뒤에 `<span class="small c-muted">[필수 활동]</span>`.

## 4. 덱 구성 (권장 순서)
표지(오른쪽 상징 그림) → (단원 도입: 그 단원 첫 덱만) → 학습 목표(성취기준 `.std` + `ol.goals` + 오늘의 흐름 `.flow`) → 도입(예측 질문 S6) → 개념 장들(새 개념 앞 '왜 필요한가' S5, 구체 → 그림 → 기호 S10) → 탐구·활동(S7, 안전 S9) + 실험실 → 예제·연습(판서 공간 + 단계 정답, S8) → 확인하기 → 읽기 자료 → 이 소단원 문항(**한 장에 한 문항**, 그림 + `.board` + 가운데 정답, S2) → 스스로 정리(개념 지도 빈칸) → 스스로 점검하기.

## 5. 탐구·활동과 필수 활동 (S7·S9·S11·S12)
- 탐구 하나 = 3–6장: ① 목표(·성취기준 탐구 문장 `.std`) ② 준비물·안전 ③ 과정(단계 카드) ④ 결과 표(빈칸, 예시 값) ⑤ 정리·결론(단계 공개) + 필요하면 ⑥ 실험실.
- **반드시 이행할 활동**(성취기준 <탐구 활동> 등 — 덱목록 `requiredActivity`)은 실험실 + 활동 장 묶음 둘 다로. 활동 문장의 동사(측정하기, 그래프로 나타내기, 비교하기, 설계하기 …)마다 실험실 조작·출력이 있어야 한다. 교과서가 일부만 다루면 덱이 채운다.
- 실제 실험이 가능한 활동이면 실험실은 대신하지 않고 **예측 → 수업 실험 → 데이터 정리·비교** 도구로 쓴다.
- 실험 영상·모의실험·스프레드시트 활동은 실험실로 대신하고 원래 활동 이름을 표식에 남긴다.

## 6. 문항과 덱 끝 마무리
- **확인 문제**: 한 장에 한 문항(S2), 그림 + `.board` + 가운데 정답, 서술형은 예시 답안과 채점 요소. 여러 짧은 문항을 한 장에 모을 때는 `data-tpl="check"`.
- 끝에서 둘째 장 **스스로 정리**: 개념 지도·빈칸에 이 소단원 몫만 채운다(단계 공개). 다른 덱 몫은 흐린 점선 상자.
- 마지막 장 **스스로 점검하기**: 지식·이해 / 과정·기능 / 가치·태도 체크 칩 + 항목마다 점검 질문과 단계 공개 답 + 다음 시간 도입 질문.
- **단원 마무리 덱**(`…-M`): 단원 개념 정리 전체 → 모든 문항(이미 소단원 덱에 넣은 문항은 대응표 한 장, 안 쓴 문항만 한 장씩) → 글쓰기·프로젝트 활동(지시 + 예시 결과).

## 7. 분량
소단원 덱 25–40장(2–3쪽짜리 소단원은 18–28장). 40장을 넘으면 `…a`/`…b` 두 덱으로 나누고 둘째 덱 첫머리에 앞 덱 요약 1장. 단원 마무리 덱 20–28장.

## 8. 표기·기호
- 교과서 표기(용어, 띄어쓰기, 기호)를 그대로. 처음 나올 때 "용어(기호)".
- 수식은 가이드라인 2.2(M1–M13), 상수·기준 값은 plan.md 0절에 한 번(M11) — 문항이 다른 값을 주면 문항 값.
- 화학식이 나오면 `\ce{}`(C1). 다른 교과의 전용 표기(수학 기호, 음악 기보, 지도 기호 …)는 `<과목>_약속.md`에 정한다.

## 9. plan.md 검산 절
```
## 계산·정답 검산
| # | 슬라이드 | 문항 | 다시 푼 값 | 교과서·지도서 정답 | 결과 |
## 필수 활동 이행
| 활동 id | 원문(성취기준) | 교과서 활동(쪽) | 실험실(장) | 활동 장 | 동사별 대응 | 덱이 채운 부분 |
## 교과서 대조
| 교과서 쪽 | 개념·활동·예제·문항 | 슬라이드 | 빠짐 없음 |
```
교과 전용 검산(반응식의 원자 수, 단위 환산 등)은 과목 약속에 꼴을 정해 덧붙인다.
