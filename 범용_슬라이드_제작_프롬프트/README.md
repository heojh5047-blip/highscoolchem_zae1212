# 범용 슬라이드 제작 프롬프트 묶음

AI(Claude Code)와 함께 **교사 연수, 수업, 학부모 설명회, 발표용 슬라이드**를 만드는 묶음입니다. 고등학교 화학 수업 슬라이드를 만들며 실제 수업에서 다듬은 엔진·규칙·점검 도구를 주제와 상관없이 쓸 수 있게 정리했습니다.

- 결과물은 **덱(슬라이드 묶음) 하나 = HTML 파일 하나**입니다. 두 번 누르면 브라우저에서 바로 열리고, **인터넷이 없어도** 보입니다.
- 화면은 16:9 고정이라 어느 프로젝터에서나 줄바꿈이 같습니다. 단계별로 하나씩 나타내기, 판서 펜, 목차, 화면 가리기, 실습 타이머를 쓸 수 있습니다.
- 지금 「교사 연수 — 과학실 안전과 교구 관리」 2차시(1차시 실험실 안전 교육, 2차시 2022 개정 교육과정 교구 관리)가 덱 목록에 들어 있습니다. 아직 만들지는 않았습니다 — `프롬프트_모음.md` 0절의 요청문으로 만드세요.

## 준비물

| 준비물 | 왜 필요한가 | 확인 |
|---|---|---|
| **Claude Code** | 슬라이드를 쓰고, 만들고, 점검하는 AI | 데스크톱 앱 또는 터미널 |
| **Python 3** | 빌드(`build.py`), 캡처 모음 | `python --version` |
| **Node.js 20 이상** | 점검·캡처·완성본 만들기 | `node --version` |
| **Chrome 또는 Edge** | 점검 도구가 화면을 찍어 봄 | 보통 이미 있음 |
| 인터넷 | 만들 때만(본문 글꼴을 받아 파일에 넣음). 완성본을 열 때는 필요 없음 | |

프로그램이 없으면 AI가 알려 줍니다. Python 패키지 `pillow`(필수), `pymupdf`(PDF 자료를 줄 때)는 AI가 설치를 물어봅니다. Firebase(웹사이트)는 쓰지 않습니다 — 웹에서 고치는 사이트가 필요하면 원본 화학 묶음을 참고하세요.

## 처음 시작하는 법

1. 이 zip을 원하는 곳에 풉니다(예: `문서\범용_슬라이드_제작_프롬프트`).
2. Claude Code에서 그 폴더를 엽니다.
3. 이렇게 말합니다:
   > **AI에게_먼저_읽히기.md를 읽고, 덱목록.json의 「교사연수」 1차시 덱을 만들어 줘.**

   새 주제라면:
   > **AI에게_먼저_읽히기.md를 읽고, [주제] 연수 덱을 만들어 줘. 대상은 [ ], 시간은 [ ]분, 목표는 [ ].**

4. AI가 구성안(`plan.md`)을 쓰고 **확인이 필요한 점**을 묻습니다. 답해 주세요(학교 사정, 실제 연락처, 자료 위치 등).
5. AI가 슬라이드를 만들고 스스로 점검·검토한 뒤 **완성본 파일 경로**를 알려 줍니다.

복사해서 바로 쓰는 요청문은 **`프롬프트_모음.md`**에 있습니다.

## 폴더 설명

```
범용_슬라이드_제작_프롬프트/
├─ README.md                     이 파일(사람용)
├─ AI에게_먼저_읽히기.md          AI가 맨 먼저 읽는 작업 순서
├─ 프롬프트_모음.md               복사해서 쓰는 요청문
├─ docs/
│  └─ 슬라이드_제작_가이드라인_범용.md   핵심 규칙(조판·색·흐름·부품·점검)
└─ 차시자료/
   ├─ 완성본/<묶음>/<덱>.html     ★ 받아서 쓰는 파일(오프라인 단일 HTML) — 만들면 생김
   ├─ <묶음>/<덱>.html            점검용 빌드본 — 만들면 생김
   ├─ 목록.html                   (선택) 덱 목록 한 장 — site_index.py로 만듦
   └─ _소스/
      ├─ AUTHORING.md             엔진 쓰는 법(AI용)
      ├─ 묶음설정.json             꼬리말(표지 왼쪽 아래 「제작: …」) 등
      ├─ 작업지시/
      │  ├─ 공통.md               작업 절차([구성안]·[제작]·[검토]·[수정])
      │  ├─ 덱목록.json            만들 덱 목록(교사연수 2차시가 들어 있음)
      │  ├─ 약속_예시/             대상별 약속: 교사연수·교과수업·학부모설명회·발표
      │  └─ 검토/                 AI가 쓰는 검토 기록
      ├─ content/<묶음>/<덱>/      덱 원본(plan.md, slides.html …) — AI가 여기서 고침
      ├─ engine/                  슬라이드 엔진(고치지 않음)
      ├─ tools/                   빌드·점검 도구(고치지 않음)
      └─ vendor/katex/            수식 글꼴(KaTeX, MIT 사용 허락) — 완성본에 들어감
```

## 결과물을 보는 법

- **완성본**: `차시자료/완성본/<묶음>/<덱>.html`을 두 번 누르면 열립니다. USB·메일·클라우드로 옮겨도 그 파일 하나만 있으면 됩니다.
- 조작: **→ / 스페이스 / 클릭** 다음, **←** 이전, **F** 전체 화면, **O** 목차, **P** 판서 펜(**X** 지우기), **B** 화면 가리기, **H** 도움말, **Ctrl+P** 인쇄(모든 단계를 펼쳐 한 쪽에 한 장 — 연수 자료집).
- 덱이 여러 개면 AI에게 「목록.html도 만들어 줘」라고 하면 덱 링크를 모은 한 장이 생깁니다(`완성본` 폴더와 함께 옮기세요).
- 「빌드본」(`차시자료/<묶음>/…`)은 점검용이라 인터넷이 있어야 수식이 보입니다. 받아 쓰는 것은 완성본입니다.

## 자주 묻는 것

**Q. 슬라이드 글자를 조금 고치고 싶어요.**
A. AI에게 「5번 장 제목을 ○○로 바꿔 줘」처럼 말하면 원본을 고치고 완성본을 다시 만듭니다. 완성본 HTML을 직접 고치면 다음에 다시 만들 때 사라집니다.

**Q. 인터넷 없는 연수실에서 써도 되나요?**
A. 됩니다. 완성본에는 수식 글꼴과 본문 글꼴이 들어 있습니다. 만들 때 인터넷이 안 되어 본문 글꼴을 못 받으면 AI가 알려 주고, 그때는 컴퓨터 기본 글꼴(맑은 고딕 등)로 보입니다.

**Q. 파워포인트(.pptx)로 바꿀 수 있나요?**
A. 이 묶음은 HTML로 만듭니다. 나눠 줄 자료가 필요하면 완성본을 열고 Ctrl+P → PDF로 저장하세요.

**Q. 사진이나 화면 갈무리를 넣고 싶어요.**
A. 파일 경로를 알려 주면 AI가 덱 폴더 `img/`에 복사해 넣습니다(완성본 파일 안에 들어감). 다른 사람의 사진·그림은 사용 허락을 확인하세요. 학생 얼굴·이름이 보이는 화면은 넣지 않습니다.

**Q. 표지 아래 「제작: …」 문구를 바꾸려면?**
A. `차시자료/_소스/묶음설정.json`의 `credit`을 고치거나 AI에게 바꿔 달라고 하세요. 덱 하나만 바꾸려면 그 덱의 `meta.json`에 `"credit"`을 넣습니다.

**Q. 법령 이름이나 기준 수치가 맞나요?**
A. AI는 선생님이 준 자료나 공식 출처에서 확인한 것만 화면에 넣고 출처를 적게 되어 있습니다. 확인하지 못한 것은 물어봅니다. 그래도 연수 전에 출처 표시를 한 번 훑어봐 주세요.

**Q. 수업(학생용)이나 학부모 설명회에도 쓸 수 있나요?**
A. 네. `약속_예시/`에 교과수업·학부모설명회·발표 약속이 있습니다. 교과 수업이면 교과서 PDF와 성취기준을 주면 더 정확해집니다(선택).

**Q. 맥(Mac)에서도 되나요?**
A. 됩니다. 명령이 `python3`일 수 있고, Chrome이 `/Applications`에 있으면 점검 도구가 찾아 씁니다.

## 알아 둘 점

- 묶음 폴더 이름(`교사연수` 등)과 덱 폴더 이름은 한국어로 써도 됩니다. 띄어쓰기 대신 `_`를 씁니다.
- 덱목록.json의 내용은 **계획**입니다. 실제 사실은 자료로 확인합니다.
- 원본 화학 수업 묶음의 웹사이트 기능(Firebase 배포, 웹 수정 화면, 관리자 로그인)은 이 묶음에 넣지 않았습니다. 필요하면 원본 묶음을 참고하세요.
- 이 묶음에는 본보기 덱이 들어 있지 않습니다. 처음 완성한 덱이 다음 덱의 본보기가 됩니다.
