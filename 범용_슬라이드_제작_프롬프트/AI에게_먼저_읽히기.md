# AI에게 먼저 읽히기 — 범용 슬라이드 제작 묶음

이 묶음으로 교사 연수, 교과 수업, 학부모 설명회, 발표 등 **어떤 주제든 16:9 HTML 슬라이드 덱**을 만든다. 결과물은 **덱 하나 = HTML 파일 하나**(완성본)이고, 선생님은 그 파일을 받아 두 번 눌러 연다. 아래 순서대로 한다. 명령은 AI가 직접 실행하고, 선생님이 해야 할 일이 생기면 그때 짧게 알린다.

## 1. 처음 한 번 (작업 환경 준비)

1. 이 파일, `README.md`, `docs/슬라이드_제작_가이드라인_범용.md`, `차시자료/_소스/AUTHORING.md`, `차시자료/_소스/작업지시/공통.md`를 읽는다.
2. **덱 정보 네 가지 — 주제·대상·시간·목표**를 정한다. `차시자료/_소스/작업지시/덱목록.json`에 그 덱이 있으면 거기서 읽고, 없으면 선생님에게 네 가지를 한 번에 짧게 묻고 덱목록에 항목을 추가해 보인다(`_필드` 설명과 「교사연수」 항목이 본보기).
3. **대상에 맞는 약속 파일**을 고르고 전부 읽는다(`차시자료/_소스/작업지시/약속_예시/`).

   | 대상 | 약속 파일 |
   |---|---|
   | 교사 연수·워크숍 | `교사연수_약속.md` |
   | 교과 수업(학생) | `교과수업_약속.md` |
   | 학부모 설명회 | `학부모설명회_약속.md` |
   | 일반 발표 | `발표_약속.md` |

   **교과 수업이면 선택**으로 더 쓰는 것: 교과서·지도서 PDF(쪽별 텍스트), 성취기준·필수 활동 대응, 화학식 `\ce{}`(화학이 나올 때) — 교과수업_약속.md. 그 밖의 덱에서는 쓰지 않아도 된다.
4. 프로그램 확인: `python --version`(3.x — Windows가 아니면 `python3`일 수 있다), `node --version`(20 이상), Chrome(또는 Edge) 실행 파일. Python 패키지 `pillow`가 없으면 설치한다(`pip install pillow`, PDF 자료가 있으면 `pymupdf`도). Chrome이 기본 경로(Windows Chrome·Edge, macOS `/Applications/Google Chrome.app`, Linux `google-chrome`·`chromium`)에 없으면 실행 파일을 찾아 환경 변수 `CHROME`으로 쓴다. 설치·권한이 필요하면 선생님에게 알린다.
5. **꼬리말**: `차시자료/_소스/묶음설정.json`의 `credit`이 모든 덱 표지 왼쪽 아래에 들어간다. 선생님이 다른 문구를 원하면 그 값만 바꾼다(덱 하나만 바꾸려면 그 덱 meta.json에 `"credit"`).
6. **자료(있으면)**: 선생님이 준 PDF·문서·그림을 덱 폴더 `차시자료/_소스/content/<묶음 키>/<덱 폴더>/자료/`(그림은 `img/`)에 **복사**한다(원본은 그대로). PDF는 `차시자료/_소스/tools`에서 `python extract_pages.py "<PDF>" "<덱 폴더>/자료/<이름>_추출.txt"`로 쪽별 텍스트를 만든다. 빠진 자료가 있으면 목록으로 알린다. 자료가 없어도 덱은 만들 수 있지만, 사실(법령·기준·숫자·사례)은 지어내지 않는다.
7. 동작 확인(처음 한 번): `차시자료/_소스/tools`에서 아주 짧은 시험 덱(예: `content/_시험/0_시험/`에 표지 1장 + 수식 1장)을 만들어 `python build.py _시험/0_시험 --offline` → `node render.mjs "../../_시험/<file>.html" "../_render/_확인"` → `node verify_offline.mjs "../../완성본/_시험/<file>.html"`이 오류 없이 끝나는지 본다. 확인한 뒤 `content/_시험`, `차시자료/_시험`, `차시자료/완성본/_시험`, `_render/_확인`을 지운다.

## 2. 덱 하나 만들기 (덱마다 반복)

선생님이 `<묶음 키>/<덱 폴더>`(예: `교사연수/1_실험실_안전_교육`) 또는 새 주제를 말하면 `공통.md`의 절차를 이 순서로 따른다.

1. **[구성안]** `plan.md` 작성 — 0절(주제·대상·시간·목표, 장수와 시간 배분, 덱 공통 약속 표), 장마다 **화면 문장 전문**·단계 공개·그림·실험실 명세, **목표 이행 절**(덱목록 `goals`가 어느 장에서 이루어지는지), **출처 절**(화면의 사실마다 출처), **시간 점검 절**, **확인이 필요한 점**. 끝나면 선생님에게 확인이 필요한 점만 짧게 묻는다.
2. **[제작]** `meta.json`·`slides.html`·(필요하면)`labs.js`·`extra.css`·`img/` 작성 → 빌드 → **render.mjs 자동 점검 0건·콘솔 오류 0건** → 캡처를 `sheet.py` 모음으로 눈으로 보기(필요한 장은 원본) → **`motion_check` 문제 0**·**`ask_check` 0건** → 실험실·타이머는 임시 스크립트로 단추 동작 확인.
3. **[검토+수정]** 내용·화면 두 관점으로 스스로 엄격하게 검토하고 **검토 json**(`차시자료/_소스/작업지시/검토/<묶음 키>_<id>_content.json`, `…_visual.json`)을 저장한 뒤 고친다. 고친 뒤 다시 0건·0건, 캡처 모음으로 전체 최종 확인.
4. **완성본**: `python build.py <묶음 키>/<덱 폴더> --offline` → `node verify_offline.mjs "../../완성본/<묶음 키>/<file>.html"`이 OK(외부 요청 0, 점검 0)인지 본다.
5. **보고**: `공통.md` 5절 형식(장수, 점검 건수, motion·ask, 완성본 경로·크기, 목표 이행, 출처 확인, 선생님 확인 필요, 엔진·도구 문제).

## 3. 지킬 것

- **고치지 않는 것**: `차시자료/_소스/engine/*`, `차시자료/_소스/tools/*`, `차시자료/_소스/vendor/*`, 다른 덱 폴더. 엔진·도구 문제는 고치지 말고 보고한다.
- 고치는 것: `차시자료/_소스/content/<묶음 키>/<덱 폴더>/` 안의 파일, `작업지시/덱목록.json`(새 덱 항목), `작업지시/검토/` 검토 파일, (선생님이 원할 때) `묶음설정.json`. **빌드본·완성본 HTML은 손으로 고치지 않는다**(다음 빌드 때 사라진다).
- **사실은 지어내지 않는다**(가이드라인 S15): 법령·지침·기준 이름과 번호, 수치, 날짜, 기관, 연락처, 사고 사례는 선생님이 준 자료나 공식 출처에서 확인한 것만 쓰고 화면에 출처를 적는다. 확인하지 못한 것은 "확인이 필요한 점"으로 묻는다.
- 그림은 직접 그린 SVG 또는 선생님이 준 그림만. 남의 그림·사진을 복사하지 않고, 자료 문장을 길게 베끼지 않는다.
- 학생·교사의 개인 정보(이름, 사진, 연락처, 성적)를 넣지 않는다. 연락처는 선생님이 준 공용 연락처만.
- 대상에 맞는 말투와 분량(약속 파일). 본문 19px 아래로 내리지 않는다.
- 선생님이 할 일(자료 주기, 프로그램 설치 허락, 내용 판단)이 생기면 그때 알리고, 그 밖의 명령은 직접 실행한다.

## 4. HTML 파일로 내보내기 (완성본) → 받기

이 묶음은 웹사이트 배포를 하지 않는다. 결과는 HTML 파일이다.

1. 덱마다 `차시자료/_소스/tools`에서 `python build.py <묶음 키>/<덱 폴더> --offline` → `차시자료/완성본/<묶음 키>/<덱 폴더>.html`. 수식 글꼴(KaTeX)과 **이 덱에 쓰인 글자만 담은 본문 글꼴**, `img/` 그림이 파일 안에 들어가 **인터넷 없이 열린다**(보통 1–1.5 MB).
   - 본문 글꼴을 받는 동안만 인터넷이 필요하다. 받지 못하면 경고가 나오고 컴퓨터 기본 글꼴(맑은 고딕 등)로 보인다 — 인터넷이 될 때 다시 만든다.
2. `node verify_offline.mjs "../../완성본/<묶음 키>/<file>.html"` → `OK`(외부 요청 0, KaTeX 오류 0, 점검 0)를 확인한다. 묶음의 모든 덱을 한꺼번에: `python build.py <묶음 키> --offline`.
3. (선택) 덱이 여럿이면 `python site_index.py` → `차시자료/목록.html`(덱 링크를 모은 한 장. `완성본` 폴더와 함께 옮겨야 링크가 산다).
4. 선생님에게 **받을 파일의 전체 경로와 크기**를 표로 알린다. 받는 법: 파일을 USB·메일·클라우드로 옮겨 두 번 누르면 브라우저(Chrome·Edge·Whale)로 열린다. 조작: → 다음, ← 이전, F 전체 화면, O 목차, P 판서 펜, B 화면 가리기, Ctrl+P 인쇄(모든 단계를 펼친 자료집).
5. 다시 고치면 1–2를 다시 하고, 선생님에게 **새 파일로 바꿔 쓰라고** 알린다(파일 이름은 같다).
