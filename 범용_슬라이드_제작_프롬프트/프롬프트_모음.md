## 1. 새 덱 만들기 (주제별 틀)

### 1-1. 교사 연수
```
AI에게_먼저_읽히기.md를 읽고 그 순서대로 해 줘.
새 덱을 만들어 줘. 덱목록.json에 항목을 먼저 추가해서 보여 줘.
- 주제: [예: 생성형 AI로 수행평가 채점 기준 만들기]
- 대상: 교사 [학교급·교과·인원]
- 시간: [50]분 × [1]차시
- 목표: [끝나고 할 수 있게 될 것 3–4개]
- 실습: [실습 이름과 결과물, 활동지 유무]
- 자료: [파일 경로 또는 "없음"]
약속 파일은 교사연수_약속.md. [구성안]부터 해서 확인이 필요한 점만 물어봐.
```

### 1-2. 교과 수업
```
AI에게_먼저_읽히기.md를 읽고 그 순서대로 해 줘.

- 교과·학년·단원: [예: 고1 통합과학 Ⅱ-1 물질의 규칙성]
- 시간: [50]분 × [2]차시
- 성취기준: [코드와 문장 — 모르면 "교육과정 문서에서 찾아 줘" + 문서 경로]

```

```
자료의 그림은 복사하지 말고 직접 그린 그림으로 바꿔 줘. 화면 아래에 출처(자료 이름·쪽)를 적어 줘.
```

## 3. 덱목록 만들기 (여러 덱을 계획할 때)
```
덱목록.json의 「교사연수」 항목 꼴(_필드 설명 참고)을 본떠서 새 묶음을 추가해 줘. 아직 덱은 만들지 마.
- 묶음 키: [예: 디지털연수_2027]
- 묶음 이름(label): [ ]
- 대상: [교사/학생/학부모/일반], 약속 파일: [ ]
- 차시: [1차시 제목 / 2차시 제목 / …], 차시당 [50]분
각 덱에 folder, title, header, idPrefix, minutes, slides(대략 장수), goals(3–4개), structure(약속 파일의 세션 구성에 분 배분), practice, materials, checkFacts를 채워서 보여 줘.
```

## 4. 여러 덱 이어서 만들기 (한 덱씩)
```
덱목록.json의 「[묶음 키]」 덱을 순서대로 한 덱씩 만들어 줘.
덱마다 [구성안] → 확인 질문 → [제작] → [검토+수정] → 완성본 → 보고(공통.md 5절 형식)까지 끝낸 뒤 다음 덱으로 가.
앞 덱의 용어·색·표식·꼴을 다음 덱이 이어받게 해 줘. 덱 사이에서 한 번씩 멈추고 내 "다음"을 기다려.
```

## 5. 검토 요청
### 5-1. 내용 검토만
```
[묶음 키]/[덱 폴더]를 공통.md의 [검토-내용] 절차로 검토해서 검토 파일만 저장해 줘(파일은 고치지 마).
특히 화면의 모든 사실(법령·기준 이름, 숫자, 날짜, 사례)을 자료·출처와 하나씩 대조해 줘.
```
### 5-2. 화면 검토만
```
[묶음 키]/[덱 폴더]를 공통.md의 [검토-화면] 절차로 검토해 줘. 모든 캡처를 원본으로 보고, 겹침·잘림·빈 공간·글자 크기·색 뜻을 확인해서 검토 파일로 저장해 줘.
```
### 5-3. 검토하고 고치기
```
[묶음 키]/[덱 폴더]를 [검토+수정] 해 줘. 내용·화면 두 관점 모두, 덱을 처음 보는 사람의 눈으로 엄격하게. 끝나면 완성본을 다시 만들어 줘.
```

## 6. 부분 수정 요청 (예시)
```
[묶음 키]/[덱 폴더]에서 다음을 고쳐 줘. 고친 장만 캡처해서 확인하고, 끝나면 전체 점검과 완성본까지.
- 5번 장: 제목을 「[ ]」로 바꿔 줘.
- 8번 장: 글이 많으니 두 장으로 나눠 줘(뒤 번호가 바뀌면 알려 줘).
- 11번 장: 대응 절차를 3단계 카드로 바꾸고 차례로 나타나게 해 줘.
- 실습 시간: 12분 → 15분(타이머도).
- 표지 꼬리말: 「[제작: ○○학교 ○○○]」 (모든 덱이면 묶음설정.json의 credit, 이 덱만이면 meta.json)
- 이 그림을 넣어 줘: [그림 파일 경로] → [몇 번 장 어디] (덱 폴더 img/에 복사)
```

## 8. 결과 파일 받기 (완성본)
```
[묶음 키]의 모든 덱을 완성본(오프라인 단일 HTML)으로 다시 만들고 verify_offline으로 확인해 줘.
```
