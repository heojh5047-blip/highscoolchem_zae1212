## 1. 교재 구조
- 단원 〔Ⅰ 〔이름〕(〔쪽〕) …〕 → 소단원 〔 〕. (중학교 교과서는 중단원 없이 대단원 → 소단원인 경우가 많다 — 교과서대로.)
- 쪽 구성: 단원 도입 〔 〕 → 소단원(〔학습 목표 · 생각 열기 · 본문 · 탐구 · 개념 확인 …〕) → 단원 끝 〔단원 정리 · 단원 평가 · 창의 융합 활동 …〕.

### 1.1 덱목록 짜는 법
1. 차례를 표로 적고 쪽 offset을 확인한다.
2. **덱 하나 = 소단원 하나 = 1–2차시**(교과서 4–6쪽, **18–30장**). 탐구가 큰 소단원은 탐구만 따로 덱으로 떼어도 된다(`note`에 「탐구 차시」).
3. 단원마다 마무리 덱(`<단원>-M`, 15–22장).
4. 덱 id `<단원>-<소단원>`(중단원이 없으면 두 자리, 예 `2-3`), folder `<id>_<제목>`, `area` 한 영역(대부분).
5. 선생님에게 표로 보여 확인받는다.

### 1.2 성취기준 붙이기
교과서 소단원 학습 목표·지도서 성취기준 표시로 코드를 찾아 `standard`에. 학습 목표 장 `.std`는 원문 그대로, `ol.goals`는 학생 말투로 짧게.

## 3. 수준 조정 (S14 — 중학교 전용)

| 항목 | 약속 |
|---|---|
| 글 양 | 한 장 4–5줄 이하, 문장 하나 40자 안팎. 한 장 개념 하나 |
| 어휘 | 교과서 용어만. 처음 나오는 용어는 쉬운 말로 한 줄 풀이(예: "마찰력: 물체가 움직이지 못하게 막는 힘"). 한자어 줄임·전문 용어 금지 |
| 식 | **말 식 먼저**("속력 = 이동 거리 ÷ 걸린 시간"), 기호 식은 교과서가 쓴 만큼. 단위는 이름과 함께("뉴턴(N)") |
| 질문 | 관찰·비교·예측 중심("어느 쪽이 더 빨리 떨어질까?"), 한 장 질문 하나. 계산 문항은 한 단계 계산까지(교과서 수준) |
| 그림 | 생활 장면 → 모형 순서(S10). 모형 그림에는 "실제 모습을 단순하게 나타냄" |
| 단계 공개 | 3–4단계 이하. 답 바로 앞에서 질문 강조(6.5) |
| 실험실 | 조작 1–2개(슬라이더 2개 이하), 결과는 큰 글씨 + 한 문장 해석 |
| 활동 | 모둠 활동 지시는 번호 3–4개, 시간 표시(예: 「5분」) |
| 문항 | 객관식은 보기 4–5개, 서술형은 채점 요소 2–3개 |

## 7. 문항 배분
- 소단원 문항 〔개념 확인〕 → 그 덱 끝. 단원 평가·창의 융합 → 마무리 덱.
- 정답은 〔지도서·교과서 부록〕 + 직접 검산.

## 8. 실험실 기준 (탐구 활동 처리)
- 성취기준 <탐구 활동>(덱목록 `requiredInquiry`)은 실험실 + 탐구 장. 실제 실험을 하는 탐구는 실험실을 "예측 → 실험 → 결과 입력·비교" 도구로.
- 안전(S9): 중학교는 안전 장을 **그림 한 장**(보안경·장갑·가열 주의 아이콘 + 문장 3줄)으로 매 실험 탐구 앞에 둔다.
