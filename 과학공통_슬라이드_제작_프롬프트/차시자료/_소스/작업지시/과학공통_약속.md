# 과학 공통 덱 약속 (통합과학1·2 · 중학교 과학1·2·3 · 확장 과목)

공통.md와 함께 읽는다. 과목 약속(`<과목>_약속.md` — 틀: `통합과학_약속_틀.md`, `중학과학_약속_틀.md`)은 이 문서를 따르고 과목·출판사마다 다른 것만 적는다. 덱 plan.md 0절의 "덱 공통 약속"은 이 두 문서를 따르고 덱에서 새로 정하는 것만 덧붙인다. 영역별 표기·그림 규칙은 가이드라인 10장(물리·화학·생명과학·지구과학 팩).

## 1. 파일·폴더·id·화면 이름

- 과목 키(`<과목>_<출판사>`)가 폴더 이름이다: 내용 `SRC/content/<과목 키>/<folder>/`, 빌드 `python build.py <과목 키>/<folder>`, 결과 `ROOT/차시자료/<과목 키>/<folder>.html`, 캡처 `SRC/_render/<과목 키>/<folder>/`.
- `meta.json`: `{"title": "<title>", "file": "<folder>", "header": "<header>"}` — 덱목록.json 그대로.
- **화면에 출판사 이름을 쓰지 않는다.** 표지 meta 줄은 「고등학교 통합과학1 12–17쪽」·「중학교 과학2 34–41쪽」, header는 「(고등 통합과학1 12–17쪽)」·「(중학 과학2 34–41쪽)」. 과목 키·폴더 이름에는 출판사를 남겨 둔다(나중에 다른 출판사 교과서를 함께 넣을 수 있게). 사이트 탭 이름(`label`)에도 출판사를 쓰지 않는다.
- id 접두어는 덱목록 `idPrefix`: 통합과학1 `is1`, 통합과학2 `is2`, 과학1 `ms1`, 과학2 `ms2`, 과학3 `ms3`(확장: 물리 `ph`, 화학 `cm`, 생명 `bi`, 지구 `es`) + 덱 id 숫자 + `-`(예: 통합과학1 1-2-1 → `is1121-`, 마무리 덱 `…9-`). 덱 전용 CSS `.is1121-…`, 실험실 이름 `is1121run`, SVG `<defs>` id `is1121-p07-ss`(D5).
- 덱 하나 = 소단원 하나(또는 1–2차시 분량). `split`이 있으면 40장(중학 30장)을 넘을 때 `…a`/`…b`로 나누고 둘째 덱 첫머리에 앞 덱 요약 1장.

## 3. h2 표식

표식 글은 **교과서 이름 그대로**(과목 약속 3절 목록). 클래스는 성격으로: 활동·탐구·읽기 `tag` · 연결·융합·다시 보기 `tag alt` · 확인·문항 `tag q` · 예제 `tag ex` · 정리 `tag ink`. 성취기준 필수 탐구는 표식 뒤 `<span class="small c-muted">[필수 탐구]</span>`. 개념 번호는 `<span class="no">1</span>`.

## 4. 색 (D7 — 한 덱 안에서 한 색은 한 뜻)

엔진 색 이름: `ink #16233D` · `plus #D7263D` · `minus #1F6FD1` · `field #2E9E6A` · `equi #E08A2C` · `bfield #7B4FC8` · `ox #C2410C` · `rd #0E7490` · `grav #8C99A6` · `muted #5B6B7F` · 형광펜 `#FFE45C`.

| 주제 | 뜻 → 색 | 메모 |
|---|---|---|
| 힘 | 무게(중력) `minus` · 외력·당기는 힘 `plus` · 수직 항력·장력 `ink` · 마찰력·공기 저항 `equi` · 알짜힘 `field` | 길이 비례(D9·D12), 힘 이름 라벨 |
| 운동 | 속도 `bfield` · 가속도 `field` · 이전 위치 `grav` 점선 | |
| 전기 | 전류 $I$ `plus` · 전자 이동 `minus` · (+)/(−)전하 `plus`/`minus` · 자기장 `bfield` | 극은 라벨로 |
| 에너지 | 에너지 흐름·열 `equi` · 손실 `grav` | 막대 길이 비례 |
| 입자 | 원자 칠 = `data-atom` 원소 색 · 양이온 `plus` · 음이온·전자 `minus` | 원소 기호 라벨·범례 |
| 반응 | 정반응 `field` · 역반응 `bfield` · 산화 `ox` · 환원 `rd` | |
| 생명 | 지시선 `muted` · 강조 이름표 `field` · 산소 많은 혈액 `plus` · 적은 혈액 `minus` · 에너지(ATP) `equi` | 소기관 칠은 가이드라인 10.3 실제 색 |
| 지구 | 고온·난류·따뜻한 공기 `plus` · 저온·한류·찬 공기 `minus` · 판 이동 `bfield` · 부정합면 `ox` · 태양 복사 `equi` | 암석 칠은 무늬 + 실제 색(10.4) |
| 그래프 | 축·눈금 `muted`, 격자 `#E2E7EC`, 주 곡선 `ink`, 비교 곡선 `field`/`plus`, 측정 이력 `grav` 점선 | 축 라벨 기호 [단위] |
| 실험 기구 | 유리 테 `#7E8B98`, 물 `#DDEEF8`/테 `#9FC3DD`, 눈금 `muted` | |

한 장에 같은 색이 두 뜻으로 겹치면(예: 무게 `minus`와 전자 `minus`) 한쪽을 라벨·선 모양으로 바꾸고 plan.md 0절에 적는다.

## 5. 크기·축척 (덱 안에서 같은 것은 같은 크기)

- 원자 반지름(폭 470–600 viewBox, 1:1): H 18 · 2주기 24 · 3주기 29 · 금속 Na 32, Mg 29, Al 27 · 이온 Na⁺ 19, Cl⁻ 32. 배경 용매 O 12 · H 8(라벨 없음).
- 힘 화살표 축척: 덱마다 "1 N = k px"를 plan.md 0절에 정하고 모든 힘 그림에 같은 값(본보기 5 px/N).
- 세포·천체 모식도는 "크기 비례 아님"을 그림 아래 `.small`로.
- 그래프 눈금은 덱 안에서 같은 양이면 같은 범위.

## 6. 표기 (가이드라인 2.2 + 영역 팩)

- 단위: SI, 수와 단위 사이 한 칸, `\text{}`. 중학교는 단위 이름을 처음 한 번 "뉴턴(N)"처럼.
- 화학식은 `\ce{}`(생명·지구 장에서도). 유전자 기호 기울임. 학명 기울임.
- 기호 겹침(속력 $v$ ↔ 부피 $V$, 질량 $m$ ↔ 미터 m, 무게 $W$ ↔ 와트 W, 주기 $T$ ↔ 절대 온도 $T$)은 처음 나올 때 뜻을 적고 plan.md 0절에.
- 계산 풀이(S8): 주어진 것 → 구할 것 → 관계식 → 계산(`aligned`) → 단위·유효 숫자.
- 용어 띄어쓰기는 교과서 그대로(과목 약속 3절에 목록).

## 7. 상수 (M11 — plan.md 0절에 다시 적고, 문항이 다른 값을 주면 문항 값)

중력 가속도 $g$ = 교과서 값(9.8 또는 10 $\text{m/s}^2$) · 빛의 속력 $3\times10^{8}\ \text{m/s}$ · 1 기압 = $1013\ \text{hPa}$ · 물의 비열(교과서 값) · $N_\mathrm{A}=6.02\times10^{23}$ · 0 °C, 1 기압 기체 1몰 22.4 L · 반감기·연대 값은 문항 값.

## 8. 탐구 장과 필수 탐구 (S7·S9·S11·S12)

- 탐구 하나 = 3–6장: ① 목표·필수 탐구 문장(`.std`) ② 준비물·안전 ③ 과정(단계 카드) ④ 결과 표(빈칸, 예시 값은 지도서 예시·직접 계산) ⑤ 정리·결론 + 필요하면 ⑥ 실험실.
- 교과서 탐구 단계 이름은 h3·작은 표식(예: 탐구 목표 · 준비물 · 탐구 과정 · 결과 정리 · 결론 도출 · 생각해 보기 — 출판사마다 다르니 과목 약속 3절).
- **필수 탐구(덱목록 `requiredInquiry`)는 실험실을 반드시 만든다.** 실험실은 탐구 문장의 동사를 모두 구현하고 결과 표가 실험실 조작으로 채워지게 한다. 실제 실험이 가능한 탐구는 실험실이 "예측 → 수업 실험 → 데이터 입력·비교" 도구가 된다. 조사·토의 탐구는 활동 지시 + 예시 결과 장.
- 실험 영상(QR)·모의실험·스프레드시트 활동은 실험실로 대신하고 원래 활동 이름을 표식에 남긴다.

## 9. 덱 끝 마무리

- 끝에서 셋째부터: 이 소단원 몫 문항(과목 약속 문항 배분) — 한 장에 한 문항(S2), 그림 + `.board` + 가운데 정답, 서술형은 예시 답안과 채점 요소.
- 끝에서 둘째 「스스로 정리」(교과서 정리 쪽 이름이 있으면 그 이름): 개념 지도·빈칸(단계 공개). 다른 덱 몫은 흐린 점선 노드.
- 마지막 「스스로 점검하기」: 지식·이해 / 과정·기능 / 가치·태도 체크(`.chips.col1 .chk`) + 점검 질문과 단계 공개 답 + 다음 시간 도입 질문.
- 단원 마무리 덱(`…-M`): 개념 정리 전체 → 문항(이미 소단원 덱에 넣은 문항은 번호·덱·정답 대응표 한 장, 아직 안 쓴 문항만 한 장씩) → 단원 활동(프로젝트·토론·글쓰기 — 활동 지시 + 예시 결과).

## 10. 분량

- 고등 소단원 덱 25–40장(2–3쪽짜리 소단원 18–28장), 중학 소단원 덱 18–30장. 넘으면 plan.md에 이유를 적거나 `split`대로.
- 단원 마무리 덱 고등 20–28장, 중학 15–22장.

## 12. 교과서·지도서 오류를 발견했을 때

덱에는 **바른 값**을 쓰고, 그 장 아래에 작은 글자로 교과서 값을 함께 적는다: `<span class="small c-muted">(교과서 ○○쪽에는 「…」로 되어 있음)</span>`. plan.md 「확인이 필요한 점」에 근거(계산·자료 출처)를 적고 보고에 올린다. 판단이 갈리는 것(표기 차이, 반올림)은 교과서 값을 따르고 확인 필요에만 적는다.
