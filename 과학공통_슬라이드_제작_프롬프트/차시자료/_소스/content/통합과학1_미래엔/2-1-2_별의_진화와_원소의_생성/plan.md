### 실험실 `is1212comp` (22장)
- 왼쪽: 원소 버튼 12개(철·산소·규소·마그네슘·니켈·황·칼슘·알루미늄·탄소·수소·질소·인). 누르면 그 원소의 지구·사람 질량비와 유래(빅뱅 직후 / 별 내부 핵융합 / 질량이 큰 별 내부 핵융합 / 초신성 폭발)가 나오고 기록 표에 쌓임. 「정리하기」 → 지구·사람 상위 4개 순서 비교 문장과, 기록한 원소들의 유래 묶음.
- 오른쪽 그림: 원소별 가로 막대 두 줄(지구 `ox`, 사람 `field`, 4.6 px/%). 자료에 따로 없는 값(기타에 포함)은 막대 없이 「–」. 고른 원소 줄을 형광 띠로 강조, 아래에 유래 띠(빅뱅 → 별 → 큰 별 → 초신성) 중 해당 칸 강조.
- 유래 판정(교과서 모형: 수소·헬륨은 빅뱅, 탄소는 별의 헬륨 핵융합, 탄소~철은 질량이 큰 별의 연속 핵융합, 철보다 무거운 원소는 초신성 폭발): 수소 → 빅뱅 / 탄소·질소 → 별 내부 핵융합 / 산소·마그네슘·알루미늄·규소·인·황·칼슘·철 → 질량이 큰 별 내부 핵융합 / 니켈(원자 번호 28 > 철 26) → 초신성 폭발.
