이 덱의 쓰임

[본보기]실제 수업 덱이 아니라, 과목 덱을 만들 때 그림·단계 공개·실험실·문항 장의 꼴을 맞추려고 보는 덱이다. 성취기준 코드는 과목 덱에서 교육과정 원문을 그대로 쓴다.
  1. 물리 힘 화살표(길이 비례, 라벨), 운동 그래프를 계산값으로 그리는 실험실, 회로도 부품 data-circuit
  2. 화학 원자 모형 부품 data-atom으로 그린 입자 모형과 원자 수 검산, 화학식 \ce{}
  3. 생명과학 세포 모식도의 이름표와 지시선, 교배표와 가계도 기호
  4. 지구과학 지층 단면의 무늬·기호와 지사 해석, 반감기 그래프

1끌려가는 상자가 받는 힘

질량 $2\ \text{kg}$인 상자를 거친 수평면에서 줄로 끌었다. Q 상자가 받는 힘을 모두 그리면 알짜힘은 얼마일까?

줄이 당기는 힘 $12\ \text{N}$, 마찰력 $4\ \text{N}$, 중력 가속도 $g=10\ \text{m/s}^2$

연직 방향: 무게와 수직 항력이 크기가 같고 방향이 반대 → 연직 방향 알짜힘 0

수평 방향: 오른쪽 $12\ \text{N}$, 왼쪽 $4\ \text{N}$ (화살표 길이는 힘의 크기에 비례)

알짜힘 $8\ \text{N}$ (오른쪽) → $a=\dfrac{F_\text{알짜}}{m}=\dfrac{8\ \text{N}}{2\ \text{kg}}=4\ \text{m/s}^2$

실험실힘과 질량을 바꾸며 가속도 측정하기

알짜힘 $F$
질량 $m$
이론값 가속도 $a$ [$\text{m/s}^2$]
번$F$ [N]$m$ [kg]측정 $a$ [$\text{m/s}^2$]

그래프는 $v=at$를 계산해 그린다(손으로 그린 곡선이 아님). 측정값에는 실제 실험처럼 작은 오차(고정 시드)가 들어간다. 이전 측정은 회색 점선으로 남는다.

2회로에 흐르는 전류

Q 전압이 $6\ \text{V}$인 전지에 저항 $3\ \Omega$을 이었다. 전류계에 흐르는 전류는 몇 A일까?

전류는 전지의 (+)극에서 나와 저항을 지나 (−)극으로 들어간다.

전자는 전류와 반대 방향으로 도선을 따라 움직인다.

$I=\dfrac{V}{R}=\dfrac{6\ \text{V}}{3\ \Omega}=2\ \text{A}$

3수소와 산소가 만나 물이 될 때

수소 분자 2개와 산소 분자 1개가 반응한다. Q 반응 뒤 원자의 종류와 개수는 어떻게 될까?

$\ce{2H2 + O2 -> 2H2O}$
원자반응 전반응 후
$\ce{H}$4개4개
$\ce{O}$2개2개

→ 원자는 새로 생기거나 사라지지 않고 배열만 바뀐다. 반응 전후 그림의 원자 수도 같아야 한다.

확인 문제 01암모니아가 생기는 반응

질소 분자 1개와 수소 분자 3개가 모두 반응하여 암모니아($\ce{NH3}$)가 된다. Q 생기는 암모니아 분자는 몇 개일까?

2개
$\ce{N2 + 3H2 -> 2NH3}$ — $\ce{N}$ 2개 = 2개, $\ce{H}$ 6개 = 6개

4동물 세포와 식물 세포

Q 식물 세포에만 있는 구조는? → 세포벽, 엽록체, (크게 발달한) 액포 — 초록 이름표

오개념 주의 식물 세포에도 미토콘드리아가 있다. 엽록체가 있어도 세포 호흡은 미토콘드리아에서 일어난다.

5잡종끼리 교배하면

둥근 완두(대립유전자 $A$, 우성)와 주름진 완두($a$, 열성)의 잡종 $Aa$끼리 교배한다. Q 자손의 표현형 비는?

생식세포$A$$a$
$A$$AA$$Aa$
$a$$Aa$$aa$

유전자형 비 $AA : Aa : aa = 1 : 2 : 1$

표현형 비 둥근 것 : 주름진 것 $= 3 : 1$

6지층 단면 읽기

Q A–E가 만들어진 순서는?

  • 지층 누중 아래 지층이 먼저 쌓였다 → A, B, C 순서
  • 관입 D가 A–C를 뚫었으므로 D는 C보다 나중
  • 부정합 굽은 침식면이 C와 D의 윗부분을 잘랐다 → 융기·침식 뒤 E가 쌓임
A → B → C → D → 융기·침식 → E

확인 문제 02방사성 원소로 나이 알아내기

반감기가 1억 년인 가상의 방사성 원소 $\mathrm{X}$가 화강암에 들어 있다. 지금 처음 양의 $25\ \%$가 남아 있다면, Q 이 화강암은 몇 억 년 전에 만들어졌을까?

2억 년 전 $100\ \% \rightarrow 50\ \% \rightarrow 25\ \%$ : 반감기 2번
