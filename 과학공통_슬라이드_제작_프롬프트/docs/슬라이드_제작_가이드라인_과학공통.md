# 수업용 과학 슬라이드 제작 가이드라인 (물리·화학·생명과학·지구과학 공통, 2022 개정)

이 문서는 고등학교 화학 4과목 90덱을 만들며 다듬은 하우스 규칙(처음에는 물리 전기 단원에서 시작)을 **물리·화학·생명과학·지구과학이 섞인 과목** — 고등학교 「통합과학1」·「통합과학2」, 중학교 「과학1」·「과학2」·「과학3」 — 에 쓰도록 일반화한 최상위 규칙입니다. 고등학교 물리학·생명과학·지구과학 선택 과목도 같은 규칙에 영역 팩만 골라 쓰면 됩니다.

- AI(Claude Code)에게 슬라이드 생성을 맡길 때 시스템 지침으로 넣습니다(`AI에게_먼저_읽히기.md` → `작업지시/공통.md` → 이 문서).
- 엔진에서 **어떻게 구현하는지**는 `차시자료/_소스/AUTHORING.md`에 있습니다. 이 문서는 **무엇을 지켜야 하는지**를 적습니다.

> **번호 체계**: 모든 규칙에는 번호가 붙고, 빌드된 덱 머리 주석·자동 점검 메시지와 같은 번호를 씁니다.
> - 공통: 조판 **T1–T6**, 수식 **M1–M13**, 도식 공통 **D1–D11**, 수업 흐름 **S1–S14**

>
> **(검증)** 표시가 없는 공통 규칙과 화학 팩은 실제 수업 피드백으로 다듬은 것입니다. 물리 팩의 회로·힘 규칙도 물리 덱에서 검증되었습니다. **생명과학·지구과학 팩은 이 묶음에서 새로 정한 것**이라, 수업에 써 보며 부록 A에 사례를 쌓아 고칩니다.

## 1. 목표와 범위

### 1.1 도구가 해결할 문제
교사가 교과서(·지도서) PDF와 교육과정 문서를 주면, 수업에 바로 쓰는 **16:9 HTML 슬라이드 덱**이 나와야 합니다.

1. 한국어 조판이 바를 것(어절 단위 줄바꿈, 수식과 조사가 붙어 있음)
2. **식·단위·기호·화학식이 정확**할 것(교과서 기호, 단위, 유효 숫자, `\ce{}`)
3. **그림이 과학적으로 맞을 것**(힘의 크기 비례, 원자 수 보존, 세포 구조 이름, 지층 순서, 그래프는 계산값)
4. 교실 운영에 맞을 것(단계 공개, 질문 먼저, 판서 공간, 판서 펜, 실험실, 인쇄)
5. 교사가 코드를 몰라도 고칠 수 있을 것(Firebase 사이트의 웹 수정 화면)

### 1.3 결과물 두 가지

| 방식 | 무엇 | 언제 |
|---|---|---|
| **① Firebase 사이트(기본)** | `차시자료/`가 그대로 웹사이트. 덱 목록(index) · 수업 화면(view) · 관리자 수정 화면(edit, 구글 로그인) | 여러 학급·여러 단원, 교사가 웹에서 글자·수식을 고칠 때 |
| **② 오프라인 HTML(선택)** | `python build.py <덱> --offline` → `차시자료/완성본/<과목 키>/<덱>.html`. KaTeX·mhchem·본문 글꼴을 파일 안에 넣은 파일 하나 | 인터넷이 불안한 교실, USB로 옮길 때 |

사이트 덱은 KaTeX를 밖(CDN)에서 불러 가볍게(덱당 약 100–300 KB), 오프라인 파일은 안에 넣어 약 1–1.5 MB입니다. 두 방식은 **같은 원본**(`_소스/content`)에서 나옵니다.

## 2. 공통 하우스 규칙

도구는 이 규칙을 기본값으로 적용하고, 어기면 자동 점검(8장)이 경고합니다.

### 2.1 조판 (T)

| 번호 | 규칙 | 구현 |
|---|---|---|
| T1 | 줄바꿈은 **어절 단위**(본문·표·목록·제목) | `keep-all` + 엔진 `keepWords()` |
| T2 | 수식·화학식은 중간에서 줄이 바뀌지 않고, 뒤의 조사("$v$는", "$\ce{H2O}$를")와 떨어지지 않음. 긴 식은 블록(`.formula`)으로 | `.katex{white-space:nowrap}` + U+2060 |
| T3 | 여러 식은 세로로 쌓고 간격을 둠. 식이 칸보다 넓으면 1단 | |
| T4 | 표 칸은 가능하면 한 줄. 넘치면 ① 문장 줄이기 ② 20px ③ 자간 −0.02em | `table.tight` |
| T5 | 번호 있는 제목은 번호–제목 간격 일정, 제목 글자 사이가 벌어지면 안 됨 | 제목을 flex로 만들지 않음 |
| T6 | 여러 줄 유도·계산은 등호 맞춤 | `\begin{aligned} … &= … \end{aligned}` |

### 2.2 수식·단위 (M)

| 번호 | 규칙 | 예 |
|---|---|---|
| M1 | 모든 양의 기호·화학식은 LaTeX. **그림 속 라벨도 LaTeX**(`text.tex`) | 유니코드 첨자 `v₀`, `m/s²`, `H₂O` ✗ → $v_0$, $\text{m/s}^2$, $\ce{H2O}$ |
| M2 | 단위 곱은 `\cdot`(가운뎃점 · 금지) | $\text{N}\cdot\text{m}$, $\text{J/(kg}\cdot{}^\circ\text{C)}$ |
| M3 | 단위는 그 양에만. 식 뒤 `[N]` 대신 `.unit` 줄 | "$F$의 단위: N" |
| M4 | 변수는 기울임, 숫자·단위·설명 첨자는 바로 선 글꼴 | $v_\text{나중}$, $E_\mathrm{k}$, $K_\mathrm{w}$ |
| M5 | 본문 속 물체·지점·물질 이름이 기호면 수식 | "물체 $\mathrm{A}$", "지점 $\mathrm{P}$", "원소 $\mathrm{X}$" |
| M6 | 수식 안 괄호 크기 맞춤 | `\left(\dfrac12\right)^n` |
| M7 | 벡터 기호는 교과서 꼴 하나로(굵은 글씨 또는 화살표). 중학교는 벡터 기호를 쓰지 않고 "크기와 방향" 말로 | $\vec F$ 또는 $\mathbf F$ |
| M8 | 곱셈 `\times`, 큰 수·작은 수는 **과학적 표기** | $3.0\times10^{8}\ \text{m/s}$ ✓ / `3x10^8`, `3e8` ✗ |
| M9 | 수와 단위 사이 한 칸, 단위는 `\text{}` | `9.8\ \text{m/s}^2`, `25\ {}^\circ\text{C}`, `1\ \text{atm}` |
| M10 | 변화량 `\Delta`, 처음 값 첨자 0 | $\Delta t$, $v_0$ |
| M11 | **상수·주어진 값은 plan.md 0절에 한 번 정의**하고 모든 문제·실험실이 그 값을 씀. 교과서 값(유효 숫자 포함) 그대로 | $g=9.8\ \text{m/s}^2$(교과서가 10이면 10) |
| M12 | **유효 숫자**: 계산 답의 자릿수는 교과서 정답 꼴을 따름. 측정값 표는 측정 기구의 최소 눈금 다음 자리까지(어림 한 자리) | 자 눈금 1 mm → $12.3\ \text{cm}$ |
| M13 | 부호 규약(방향 +, 에너지 부호, 극의 (+)/(−))은 단원 첫 사용 장에 적고 plan.md 0절에 기록 | "오른쪽을 (+)로 한다." |

**단위 표기 공통(SI)**: 길이 m·cm·mm·km, 질량 kg·g, 시간 s·min·h, 온도 °C·K, 힘 N, 에너지 J·kJ·cal(교과서가 쓸 때), 일률 W, 압력 Pa·hPa·atm, 전류 A, 전압 V, 저항 Ω, 진동수 Hz, 넓이 $\text{m}^2$, 부피 L·mL·$\text{cm}^3$, 밀도 $\text{g/cm}^3$. 중학교는 교과서가 쓰는 단위 이름(예: "뉴턴(N)")을 처음 한 번 함께 적습니다.

### 2.3 도식 공통 (D1–D11)

| 번호 | 규칙 |
|---|---|
| D1 | 회로가 있는 그림(전기 회로, 전기 분해, 화학 전지, 전자기 유도)은 🟢 `data-circuit`. 전지 긴 판 = (+)극, 분기점 ●, 계기 A·V |
| D2 | **화살표에는 무엇인지 라벨**: 힘 이름, 속도, 전류 $I$, 전자 이동, 에너지 흐름, 물질 이동, 바람, 해류 |
| D3 | 대칭인 것은 그림도 대칭(분자, 렌즈, 궤도, 대칭 회로, 교배표 칸) |
| D4 | 그래프 축 라벨은 **기호 [단위]** — $t$ [s], $v$ [m/s], $T$ [°C], 높이 [km]. 단위가 없으면 이름만(pH, 상대 빈도). 축 화살표·선과 겹치지 않게 |
| D5 | SVG `defs`(gradient·pattern·marker·clipPath) id는 **덱 전체에서 고유**: 덱 접두어 + 슬라이드 번호(`sc001-p10-ss`) |
| D6 | 원자 모형의 전자는 전자 껍질(원) 위에. 원자가 전자는 바깥 껍질 |
| D7 | **색 하나 = 뜻 하나**(2.4절). 한 슬라이드에서 같은 색이 두 뜻을 가지면 안 됨. 색만으로 전하지 않고 라벨·선 모양도 |
| D8 | 라벨이 잘리거나 겹치지 않게. 가장자리 라벨은 안쪽으로 |
| D9 | **화살표·막대 길이는 크기에 비례**(힘, 속도, 전류, 에너지 막대, 개체 수 막대). 비교하지 않는 그림이면 "크기 비례 아님" |
| D10 | 길이·간격·높이 표시는 **치수선**(양 끝 화살표 + 가운데 라벨), 윤곽 바깥으로 |
| D11 | 지면에 수직인 방향 기호는 SVG로 그림(⊗ ⊙ 문자 금지) — 🟢 `data-bgrid` |

**그래프는 계산값으로 그립니다(D4·D9 보강)**: 식이 있는 그래프(등가속도 운동, 반감기, 용해도, 기체 법칙, 개체군 생장, 기온 감률 등)는 **식으로 점을 계산한 path**(생성 스크립트나 `labs.js`)를 씁니다. 손으로 어림한 곡선, 교과서 그래프를 보고 따라 그린 선은 쓰지 않습니다. 측정 자료 그래프는 자료 표의 값을 그대로 찍고, 표를 plan.md에 둡니다. 본보기 덱 11번 장(반감기 곡선 $100\times(1/2)^t$)과 4번 장 실험실($v=at$)이 예입니다.

- 산화·환원은 극의 (+)/(−) 색으로 칠하지 않습니다(화학 팩).
- 생명·지구의 **실제 색**(엽록체 초록, 혈액, 암석·광물, 하늘·바다)은 그림 칠에만 쓰고, 화살표·라벨 색 뜻과 섞지 않습니다. 실제 색 표는 각 팩에 있습니다.
- 흑백 인쇄·색각 이상을 생각해 실선/점선, 무늬(지층), 라벨을 함께 씁니다.

### 5.1 SVG로 직접 그리는 것 ✏️ (영역 팩에 그리는 약속)
자유 물체도의 물체·점, 운동 그래프·다중 섬광 사진 그림, 파동·광선도·렌즈, 루이스 전자점식·분자 구조, 입자 상자, 실험 기구, 세포·기관 모식도, 가계도·교배표 그림, 생태 그래프·먹이 그물, 지층·지질 단면, 판 경계 단면, 천구·궤도, 일기도·등치선, 지도. **우선 손으로 그린 SVG + 좌표 생성 스크립트**(Python, 덱 작업 폴더)로 만들고, 같은 그림이 여러 덱에 되풀이되면 생성 스크립트를 공용 도우미로 남깁니다(화학 묶음의 공-막대·루이스 도우미처럼). 엔진은 고치지 않습니다.

### 5.2 단계 공개 `.step`
같은 `data-g` 값은 함께 공개. 공개 순서는 그룹이 문서에서 처음 나온 위치. 순서를 고정하려면 원하는 자리에 빈 `<span class="step" data-g="…"></span>`.

### 5.3 그림 원칙 (전 영역)
- **교과서 그림·사진은 복사하지 않고** 같은 개념을 설명하는 새 도식으로 그립니다(저작권). 사진이 꼭 필요하면 선생님이 준 사용 가능한 사진만.
- 모식도는 **단순화를 밝힙니다**("크기 비례 아님", "실제 모양을 단순하게 나타냄"). 중요한 비율(행성 크기·거리, 세포 크기)은 비례가 아니면 반드시 적습니다.
- 이름표는 지시선(`muted` 1.5px)으로 구조에 닿게, 이름표끼리 같은 줄에 맞춥니다.
- 축척·방위·범례가 필요한 그림(지도, 단면, 일기도)은 셋 다 둡니다.

### 5.4 실험실 (Lab)
슬라이더·버튼 입력 → 계산 → 수치·그림 갱신. 원칙:
- 슬라이더 옆에 **현재 값과 단위**(`output`, 일반 글자). 결과는 크게, 해석은 문장(`output.kind`).
- 계산은 교과서 식 그대로, 상수는 plan.md 0절 값(M11). 극단값에서도 그림이 칸 밖으로 나가지 않게 상한·로그 척도.
- **측정**: "측정하기" 버튼 → 기록 표(`table.tight`)에 행이 쌓이고, 측정값에는 고정 시드의 작은 오차. "그래프로 나타내기" → 표의 점이 그래프에 찍힘. "설계하기" → 조작·종속·통제 변인 고르기. 초기화 버튼(`data-act="reset"`).
- 입자·천체 운동 같은 시뮬레이션은 `API.loop`(보일 때만 돎), 입자 60–150개 이하.
- 시험: `tools/_labtest.mjs`에 `PRE`(JS 식)를 주어 조작마다 결과가 바뀌는지, 표가 쌓이는지 확인(본보기 덱 4번 장).
