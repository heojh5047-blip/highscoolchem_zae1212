# 과학 수업 슬라이드 제작 묶음 (물리·화학·생명과학·지구과학 공통, 2022 개정)

AI(Claude Code)와 함께 **과학 수업용 슬라이드**를 만드는 출발 묶음입니다. 고등학교 화학 4과목 슬라이드 90개를 만들며 실제 수업으로 다듬은 엔진·규칙·점검 도구를, 물리·화학·생명과학·지구과학이 섞인 과목에 맞게 정리했습니다.

## 어떤 과목에 쓰나요

| 과목 | 비고 |
|---|---|
| **고등학교 통합과학1·통합과학2** | 네 영역 + 융합 단원 — 약속 틀 `통합과학_약속_틀.md` |
| **중학교 과학1·과학2·과학3** | 학년별 교과서 차례대로, 중학생 수준에 맞춘 약속 — `중학과학_약속_틀.md` |
| (필요하면) 고등 물리학·화학·생명과학·지구과학 선택 과목 | 같은 규칙에서 그 영역 팩만 씁니다 |

결과물은 **덱(슬라이드 묶음) 하나 = HTML 파일 하나**입니다. 화면은 16:9 고정이라 어느 프로젝터에서나 줄바꿈이 같고, 단계별로 하나씩 나타내기, 질문 먼저 보여 주기, 판서 펜, 목차, 화면 가리기, 조작하는 실험실(슬라이더로 값을 바꾸고 측정해 표·그래프 만들기)을 쓸 수 있습니다.

## 준비물

| 준비물 | 왜 필요한가 | 확인 |
|---|---|---|
| **Claude Code** | 슬라이드를 쓰고, 만들고, 점검하는 AI | 데스크톱 앱 또는 터미널 |
| **Python 3** | 빌드(`build.py`), 캡처 모음, PDF 쪽 텍스트 | `python --version` |
| **Node.js 20 이상** | 점검·캡처 도구 | `node --version` |
| **Chrome 또는 Edge** | 점검 도구가 화면을 찍어 봄 | 보통 이미 있음 |
| **교과서 PDF**(필수)·**지도서 PDF**(있으면) | 덱 내용의 기준 | 선생님이 준비 |
| **교육과정 문서**(성취기준) | 성취기준 코드·문장·탐구 활동 | 선생님이 준비 |
| Firebase 계정(구글 계정) | 웹사이트 방식을 쓸 때 | 선택 |

프로그램이 없으면 AI가 알려 줍니다(Python 패키지 `pillow`, `pymupdf`는 AI가 설치를 물어봅니다).

## 처음 시작하는 법 (새 프로젝트에서)

1. **새 폴더(새 저장소)에 이 zip을 풉니다.** 예: `문서\과학_슬라이드`. 이 묶음에는 다른 학교·과목의 덱, 교과서, Firebase 값이 들어 있지 않습니다.
2. **자료를 넣습니다.**
   - 교과서·지도서 PDF → `차시자료/_소스/_자료/` (이름은 AI가 정해 복사하므로 아무 이름이어도 됩니다)
   - 교육과정 문서(성취기준) → 같은 `_자료/` 폴더
3. **Claude Code에서 그 폴더를 열고** 이렇게 말합니다.
   > **AI에게_먼저_읽히기.md를 읽고 1절 준비를 해 줘. 과목은 통합과학1이고 교과서는 ○○출판사야.**

   AI가 과목 키(예: `통합과학1_○○`)를 정하고, 교과서 차례를 읽어 **덱목록**(어느 단원을 몇 개의 덱으로 만들지)을 표로 보여 줍니다. 확인해 주세요.
4. **덱을 하나씩 만듭니다.**
   > **AI에게_먼저_읽히기.md 2절대로 통합과학1_○○/1-1-1 덱을 만들어 줘.**

   AI가 구성안을 쓰고 **확인이 필요한 점**을 묻습니다. 답하면 슬라이드를 만들고 스스로 점검·검토한 뒤 결과를 알려 줍니다.
5. **웹사이트로 쓰려면 Firebase 프로젝트를 새로 만듭니다**(아래 「① Firebase 사이트」). 만든 값을 AI에게 주면 `config.js`와 `.firebaserc`(`your-project-id` 자리)에 적고 배포합니다.

복사해서 바로 쓰는 요청문은 **`프롬프트_모음.md`**에 있습니다.

## 결과물 두 가지

### ① Firebase 사이트 (기본)
- `차시자료/` 폴더가 그대로 웹사이트가 됩니다: **덱 목록**(과목 탭) · **수업 화면** · **관리자 수정 화면**.
- 관리자(선생님)는 구글로 로그인해 슬라이드의 **글자·제목·표 칸·정답·그림 속 글자(수식 포함)**를 눌러 고치고 「저장」하면 학생 화면에 바로 반영됩니다. 그림 모양·실험실·장 추가는 AI에게 부탁합니다.
- 필요한 것: Firebase 프로젝트 하나(무료 요금제로 충분). 선생님이 콘솔에서 ① 프로젝트 만들기 ② 웹 앱 추가 ③ Google 로그인 켜기 ④ Realtime Database 만들기를 하면, 나머지(설정 파일·배포)는 AI가 합니다.
- 바꾸는 파일: `차시자료/js/config.js`(Firebase 값, 관리자 이메일), `database.rules.json`(관리자 이메일), `.firebaserc`(프로젝트 이름).
- 배포 전 시험: `차시자료`에서 `python -m http.server 8000` → 브라우저에서 `http://localhost:8000/index.html?local`.

### ② 오프라인 HTML 파일 (선택)
- 덱 하나를 **인터넷 없이 열리는 파일 하나**로 만듭니다(수식 글꼴까지 파일 안에, 보통 1–1.5 MB). USB·메일로 옮겨 두 번 눌러 엽니다.
- AI에게 「이 덱을 오프라인 파일로도 만들어 줘」라고 하면 `차시자료/완성본/<과목>/<덱>.html`이 생깁니다.

## 폴더 설명

```
과학공통_슬라이드_제작_프롬프트/
├─ README.md                     이 파일(사람용)
├─ AI에게_먼저_읽히기.md          AI가 맨 먼저 읽는 작업 순서
├─ 프롬프트_모음.md               복사해서 쓰는 요청문
├─ firebase.json · database.rules.json · .firebaserc · .gitignore   웹사이트 설정
├─ docs/
│  └─ 슬라이드_제작_가이드라인_과학공통.md   핵심 규칙(조판·수식·색·수업 흐름·점검 + 물리·화학·생명·지구 영역 팩)
│     (교육과정_<과목>_성취기준.md는 AI가 교육과정 문서로 만들어 여기에 둡니다)
└─ 차시자료/                     ← 웹사이트가 되는 폴더
   ├─ index.html · view.html · edit.html · js/ · css/   사이트 화면(덱 목록·수업·수정)
   ├─ 과학공통_본보기/            본보기 덱(13장) 빌드 결과 — 네 영역 그림·실험실 미리 보기
   ├─ <과목 키>/<덱>.html         만든 덱 — 만들면 생김
   ├─ 완성본/                     (선택) 오프라인 파일 — 만들면 생김
   └─ _소스/                      원본(웹사이트에 올라가지 않음)
      ├─ AUTHORING.md             엔진 쓰는 법(AI용)
      ├─ 묶음설정.json             덱 표지 꼬리말(「제작: …」)
      ├─ 작업지시/                 공통.md, 과학공통_약속.md, 약속 틀 2개, 에이전트_안내_틀.md, 덱목록.json, 진행상황.md, 검토/
      ├─ content/                 덱 원본(plan.md, slides.html …) — AI가 여기서 고침
      ├─ engine/ · tools/ · vendor/katex/   엔진·빌드·점검 도구·수식 글꼴(고치지 않음)
      ├─ tools/관리/               진행 기록·완료 덱 배포 도구
      ├─ _자료/                   ★ 교과서·지도서·교육과정 PDF를 넣는 곳(저장소에 올리지 않음)
      └─ _추출/                   PDF 쪽별 텍스트(AI가 만듦)
```

## 수업에서 쓰는 법

**→ / 스페이스 / 클릭** 다음, **←** 이전, **F** 전체 화면, **O** 목차, **P** 판서 펜(**X** 지우기), **B** 화면 가리기, **H** 도움말, **Ctrl+P** 인쇄(모든 단계를 펼쳐 한 쪽에 한 장 — 학습지). 답이 나오기 직전 한 번 누르면 질문이 노랗게 강조되고, 한 번 더 누르면 답이 나옵니다.

## 자주 묻는 것

**Q. 슬라이드 글자 하나만 고치고 싶어요.**
A. 웹사이트라면 관리자 수정 화면에서 바로 고치세요. 그 밖에는 AI에게 「통합과학1 1-1-1 덱 5번 장 제목을 ○○로 바꿔 줘」처럼 말하면 원본을 고쳐 다시 만듭니다. 빌드된 HTML을 직접 고치면 다음 빌드 때 사라집니다.

**Q. 웹에서 고친 덱을 AI가 다시 만들면 어떻게 되나요?**
A. 웹 수정본이 새 원본을 가립니다. AI가 먼저 「수정본 내려받기」 파일을 달라고 할 거예요. 그 변경을 원본에 합친 뒤 다시 배포하고, 웹에서 「원본으로 되돌리기」를 누르면 됩니다.

**Q. 지도서가 없어도 되나요?**
A. 됩니다. AI가 정답을 직접 풀어 검산하고, 예시 답안·탐구 결과 예시는 직접 만들어 「확인이 필요한 점」에 적어 둡니다. 나중에 지도서가 생기면 「지도서 대조」 요청(프롬프트 모음)으로 틀린 것만 고칩니다.

**Q. 교과서에 틀린 값이 있으면요?**
A. 덱에는 바른 값을 쓰고, 그 장 아래에 「교과서 ○쪽에는 …로 되어 있음」을 작게 적어 둡니다. 보고에도 올라오니 확인해 주세요.

**Q. 화면에 출판사 이름이 나오나요?**
A. 나오지 않습니다. 표지에는 「고등학교 통합과학1 12–17쪽」처럼 과목과 쪽만 씁니다.

**Q. 중학생에게는 어렵지 않을까요?**
A. 중학교 약속(`중학과학_약속_틀.md` 3절)에 한 장 글 양, 쉬운 어휘, 말로 쓰는 식, 질문 난이도, 실험실 조작 수를 정해 두었습니다. 더 쉽게 하려면 프롬프트 모음의 「중학교용 수준 조정」 요청을 쓰세요.

**Q. 표지 아래 「제작: …」 문구를 바꾸려면?**
A. `차시자료/_소스/묶음설정.json`의 `credit`(덱 표지)과 `차시자료/js/config.js`의 `CREDIT`(덱 목록 화면 아래)을 고치거나 AI에게 부탁하세요.

**Q. AI가 중간에 멈췄어요(사용량 한도).**
A. 한도가 풀린 뒤 「이어서 해 줘」라고 하면 진행상황.md와 덱 폴더의 파일을 읽고 멈춘 곳부터 잇습니다.

**Q. 맥(Mac)에서도 되나요?**
A. 됩니다. 명령이 `python3`일 수 있고, Chrome이 `/Applications`에 있으면 점검 도구가 찾아 씁니다.

## 들어 있지 않은 것 (각자 준비)

- 교과서·지도서 PDF, 교육과정 문서, 쪽별 텍스트 — 저작권 때문에 넣지 않았습니다. `.gitignore`가 저장소에 올라가지 않게 막습니다.
- 과목별 완성 덱 — 첫 덱을 만들어 검토를 마치면 그 덱이 그 과목의 본보기가 됩니다. 그 전에는 본보기 덱(`과학공통_본보기`, 13장)을 봅니다.
- Firebase 프로젝트 값 — 새로 만들어 넣습니다(`your-project-id` 자리).
