## 화학용으로 바뀐 것

- **화학식**: 빌드가 KaTeX mhchem(`contrib/mhchem.min.js`)을 함께 불러와 본문·그림 라벨 어디서나 `$\ce{N2(g) + 3H2(g) <=> 2NH3(g)}$`가 됩니다. 본문 글자로 쓴 `H2O`, `Na+`는 자동 점검 **C1**이 찾아냅니다.
- **원자 모형 부품** `<g data-atom="x,y,r,원소[,라벨|-][,d]">`: 원소별 고정 색 공 + 원소 기호 라벨(실험실 `API.atom`). 색 표는 `window.HARNESS_ATOM`으로 바꿀 수 있습니다.
- **색 이름** `ox`(산화)·`rd`(환원) 추가. 화학 전지와 전기 분해에서 극의 (+)/(−)와 산화·환원이 엇갈리므로 산화·환원은 극 색과 따로 둡니다.
- **필수 탐구(S12)**: 성취기준 <탐구 활동>(화학 9 · 물질과 에너지 8 · 화학 반응의 세계 10)은 담당 덱에서 **실험실 + 탐구 슬라이드로 반드시 이행**하고, 구성안·검토·보고에서 확인합니다.
- 점검 도구(`motion_check`·`ask_check`·`force_check`·`audit_all`)는 과목 폴더를 자동으로 찾습니다(과목 이름 고정 없음).

## 웹사이트 (관리자가 웹에서 수정)

`차시자료/`가 그대로 Firebase Hosting 사이트가 됩니다(`firebase.json`).
- `index.html` 덱 목록(과목 탭) · `view.html` 수업 화면 · `edit.html` 관리자 수정 화면(구글 로그인)
- 관리자는 슬라이드의 **문장·제목·표 칸·정답·그림 속 글자(수식·화학식 포함)**를 눌러 고치고 「저장」 → 학생 화면에 바로 반영. 그림 모양·실험실·슬라이드 추가는 Claude Code로.
- 저장은 Realtime Database(`decks/`, `meta/`, `backups/`), 쓰기는 `database.rules.json`의 관리자 이메일만.
- 배포할 때 바꾸는 파일은 `차시자료/js/config.js`와 `database.rules.json` 둘뿐. 절차는 `AI에게_먼저_읽히기.md` 4절.
- Firebase 없이 시험: `차시자료`에서 `python -m http.server 8000` → `http://localhost:8000/index.html?local`.

## AI에게 주는 법

- **규칙만 따르게 할 때:** `docs/슬라이드_제작도구_가이드라인_화학.md`, `차시자료/_소스/작업지시/공통.md`, `화학3과목_공통_약속.md`, 해당 `<과목>_약속.md`를 먼저 읽게 하고, 만들 차시의 교과서·지도서 쪽을 함께 준다.
- **똑같은 방식으로 빌드·점검까지 할 때:** 이 폴더 전체를 작업 폴더로 열고 교과서·지도서 PDF를 `차시자료/_소스/_자료/`에 덱목록.json의 파일 이름(예: `화학_미래엔_교과서_2.pdf`, `화학_비상_교과서.pdf`)으로 넣은 뒤, "공통.md의 [구성안] 절차대로 `화학_미래엔/2-2-2`의 plan.md를 만들어" → "[제작] 절차대로 만들어" 처럼 지시한다.

## 빌드·점검 (명령은 `차시자료/_소스/tools`에서)

```
python extract_pages.py ../_자료/화학_미래엔_교과서_2.pdf ../_추출/화학_미래엔_교과서_2.txt --offset=49   # PDF → 쪽별 텍스트
python build.py 화학_미래엔/2-2-2                               # content → 차시자료/화학_미래엔/<파일>.html
node render.mjs ../../화학_미래엔/<파일>.html ../_render/화학_미래엔/<덱>   # 장마다 캡처 + 자동 점검(0건이 목표)
python sheet.py ../_render/화학_미래엔/<덱>                       # 캡처 4장을 한 장에
node motion_check.mjs 화학_미래엔/2-2-2                          # 움직임 켜고 모든 단계 넘김(콘솔 오류 0)
node ask_check.mjs 화학_미래엔/2-2-2                             # 질문 먼저 강조 점검
node test_input.mjs ../../화학_미래엔/<파일>.html                 # 마우스·터치·펜 입력 시험
```

필요한 것: Python 3(+ Pillow, 선택 PyMuPDF 또는 poppler의 pdftotext), Node.js 20 이상, Chrome(캡처·점검 도구가 헤드리스 Chrome을 씀 — Windows 기본 경로가 아니면 환경 변수 `CHROME`).

## 들어 있지 않은 것 (각자 준비)

- 교과서·지도서 PDF(`_자료/`)와 쪽별 텍스트(`_추출/`) — 저작권 때문에 뺐습니다. `extract_pages.py`로 만드세요.
- 완성된 화학 본보기 덱 — 아직 없습니다. 첫 화학 덱을 만들어 검토를 마치면 그 덱을 같은 과목의 본보기로 쓰세요(AUTHORING.md 머리말).
- 평가 문항 제작 도구, 사이트(편집기·로그인) 파일, 교실용 오프라인 변환에 쓰는 `app/offline.js` — `build.py --offline`은 이 묶음만으로는 동작하지 않습니다. 오프라인 변환을 쓸 때는 `app/offline.js`가 **`contrib/mhchem.min.js`도 파일 안에 넣도록**(katex.min.js 다음, auto-render 앞) 고쳐야 화학식이 보입니다.
- 덱목록.json의 쪽·문항 배분·필수 탐구 쪽 일부는 PDF 추출 텍스트로 추정한 값입니다. [구성안] 단계에서 PDF로 확인하게 되어 있습니다.
