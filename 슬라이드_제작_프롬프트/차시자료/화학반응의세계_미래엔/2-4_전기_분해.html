지난 배움과 연결 03에서 화학 전지는 산화·환원 반응으로 화학 에너지를 전기 에너지로 바꾼다는 것을 배웠다. 오늘은 거꾸로 전기 에너지를 가해 산화·환원 반응을 일으키는 과정을 알아본다.

생각 열기왜 소독약 냄새가 나지?

소금물에 두 전극을 담그고 전류를 흘렸더니 두 전극에서 기포가 생기고 소독약 냄새가 났다.

Q 어떤 반응이 일어나 소독약 냄새가 나는 것일까?

예상 전류가 소금물 속 이온에 산화·환원 반응을 일으켜, 수영장 소독에 쓰는 염소와 같은 물질이 생긴 것이 아닐까?

→ 「염화 나트륨 수용액의 전기 분해」(8번 장)와 「소금물과 표백제」(24번 장)에서 확인해 보자.

연결화학 전지를 거꾸로 돌리면?

화학 전지 (03에서 배움)

저절로 일어나는 산화·환원 반응 → 화학 에너지 → 전기 에너지

전기 분해

전원 장치로 반응을 일으킴 → 전기 에너지 → 화학 에너지

물질에 전기 에너지를 가하면 산화·환원 반응이 일어나 물질이 분해되는데, 이를 전기 분해라고 한다.

극 약속 전원의 (+)단자에 이은 전극이 (+)극: (+)극 = 산화 전극, (−)극 = 환원 전극 (화학 전지와 반대)

1염화 나트륨 용융액의 전기 분해

염화 나트륨($\ce{NaCl}$)을 녹여 액체로 만든 용융액에는 나트륨 이온($\ce{Na+}$)과 염화 이온($\ce{Cl-}$)이 들어 있다.

Q 전류를 흘려 주면 각 이온은 어느 극으로 이동할까?

→ $\ce{Na+}$은 (−)극으로, $\ce{Cl-}$은 (+)극으로 끌려간다.

관찰 (+)극에서는 황록색 염소 기체가 발생하고, (−)극에서는 은백색 나트륨이 생긴다.

1전극에서 일어나는 산화·환원 반응

Q 두 전극에서 일어나는 반응을 반쪽 반응식으로 나타내면?

$\begin{aligned}(+)\text{극: }&\ce{2Cl-(l) -> Cl2(g) + 2e-} &&\color{#C2410C}\text{(산화)}\\(-)\text{극: }&\ce{2Na+(l) + 2e- -> 2Na(l)} &&\color{#0E7490}\text{(환원)}\\\hline\text{전체 반응: }&\ce{2Na+(l) + 2Cl-(l) -> 2Na(l) + Cl2(g)}\end{aligned}$

(+)극에서 내놓은 전자 2개가 도선과 전원 장치를 지나 (−)극의 나트륨 이온 2개에게 간다. 전자의 수를 맞추면 두 식을 더할 수 있다.

전해질의 용융액에 전류를 흘려 주면 (+)극에서는 음이온이 산화되고, (−)극에서는 양이온이 환원되어 용융액이 분해된다.

예측염화 나트륨 수용액을 전기 분해 하면?

염화 나트륨 수용액에는 $\ce{Na+}$, $\ce{Cl-}$과 함께 많은 양의 물이 있다. 용융액처럼 염소 기체와 나트륨이 생길까?

㉮

(+)극: 염소 기체 · (−)극: 나트륨

㉯

(+)극: 염소 기체 · (−)극: 수소 기체

㉰

(+)극: 산소 기체 · (−)극: 나트륨

Q 나트륨은 물과 만나면 어떻게 될까?

→ 나트륨은 물과 격렬하게 반응한다. 이온화 경향이 매우 커서 $\ce{Na+}$은 전자를 얻기 어렵다 — 물이 먼저 전자를 얻는다.

㉯ — (−)극에서는 나트륨 이온 대신 물이 환원된다.

1염화 나트륨 수용액의 전기 분해

(+)극에서는 염화 이온이 산화되어 염소 기체가, (−)극에서는 나트륨 이온 대신 물이 환원되어 수소 기체가 발생한다.

$\begin{aligned}(+)\text{극: }&\ce{2Cl-(aq) -> Cl2(g) + 2e-} \ \ \color{#C2410C}\text{(산화)}\\(-)\text{극: }&\ce{2H2O(l) + 2e- -> H2(g) + 2OH-(aq)} \ \ \color{#0E7490}\text{(환원)}\end{aligned}$

Q 전체 반응식은?

$\ce{2Cl-(aq) + 2H2O(l) -> Cl2(g) + H2(g) + 2OH-(aq)}$

→ 생각 열기의 소독약 냄새는 (+)극에서 생긴 염소 기체의 냄새이다. (−)극 주변은 $\ce{OH-}$이 생겨 염기성이 된다.

1수용액에서는 이온과 물이 경쟁한다

(−)극 · 환원 전극

전해질의 양이온과 물 중 환원되기 쉬운 물질이 환원된다.

$\ce{Li+}$, $\ce{K+}$, $\ce{Na+}$ 등이 녹아 있으면 물이 대신 환원되어 수소 기체가 발생한다.

$\ce{2H2O(l) + 2e- -> H2(g) + 2OH-(aq)}$

(+)극 · 산화 전극

전해질의 음이온과 물 중 산화되기 쉬운 물질이 산화된다.

$\ce{SO4^2-}$, $\ce{CO3^2-}$, $\ce{OH-}$ 등이 녹아 있으면 물이 대신 산화되어 산소 기체가 발생한다.

$\ce{2H2O(l) -> O2(g) + 4H+(aq) + 4e-}$

Q 황산 구리(II) 수용액이면 (−)극에서 무엇이 환원될까? (03의 표준 환원 전위: $\ce{Cu^2+}$ $+0.34\ \text{V}$, $\ce{H2O}/\ce{H2}$ $-0.83\ \text{V}$)

→ 표준 환원 전위가 더 큰 $\ce{Cu^2+}$이 환원되기 쉽다 → 구리가 석출된다.

물의 전기 분해 순수한 물은 전류가 거의 흐르지 않으므로, 수소와 산소를 얻으려면 황산 나트륨($\ce{Na2SO4}$)이나 수산화 나트륨($\ce{NaOH}$) 같은 전해질을 녹인다.

1전극에서 생기는 물질 판단하기

예: 염화 칼륨($\ce{KCl}$) 수용액을 전기 분해 할 때 각 전극의 생성물은? 세 단계로 따져 보자.

① 무엇이 있나?

양이온 $\ce{K+}$, 음이온 $\ce{Cl-}$, 그리고 물 $\ce{H2O}$

양이온은 (−)극으로, 음이온은 (+)극으로 이동한다.

② (−)극: 무엇이 환원?

$\ce{K+}$과 물 중 환원되기 쉬운 쪽은?

$\ce{K+}$은 환원되기 어렵다 → 물이 환원 → 수소 기체

$\ce{2H2O + 2e- -> H2 + 2OH-}$

③ (+)극: 무엇이 산화?

$\ce{Cl-}$과 물 중 산화되기 쉬운 쪽은?

$\ce{Cl-}$이 산화 → 염소 기체

$\ce{2Cl- -> Cl2 + 2e-}$

→ 염화 칼륨 수용액은 염화 나트륨 수용액과 같은 꼴로 분해된다: (+)극 염소, (−)극 수소.

덱이 더한 예이다(교과서 59쪽 규칙 적용).

확인하기전기 분해의 원리

1 액체나 수용액에 전기 에너지를 가하여 산화·환원 반응을 일으켜 물질을 분해하는 것을 전기 분해(이)라고 한다.

2 황산 구리(II) 수용액과 황산 나트륨 수용액을 전기 분해 할 때 각 전극에서 생성되는 물질을 비교해 보자. 무엇이 같고 무엇이 다를까?

수용액(+)극 (산화)(−)극 (환원)
$\ce{CuSO4(aq)}$산소 기체 — $\ce{2H2O -> O2 + 4H+ + 4e-}$구리 — $\ce{Cu^2+ + 2e- -> Cu}$
$\ce{Na2SO4(aq)}$산소 기체 — 물이 산화수소 기체 — $\ce{2H2O + 2e- -> H2 + 2OH-}$

→ (+)극은 둘 다 $\ce{SO4^2-}$ 대신 물이 산화되어 산소가 생긴다. (−)극은 $\ce{Cu^2+}$이 물보다 환원되기 쉬워 구리가, $\ce{Na+}$은 물보다 환원되기 어려워 수소가 생긴다.

2전기 분해의 이용

일상생활에서 쓰는 물질 가운데 전기 분해로 얻는 것이 많다. 어떤 것이 있을까?

금속 얻기

알루미늄, 구리 등 금속을 광석이나 혼합물에서 얻는다.

수소

물을 전기 분해 하여 얻은 수소를 연료 전지에 쓴다.

염소

소금물을 전기 분해 하여 얻은 염소를 살균제로 쓴다.

도금

장신구나 금속 공예 작품을 만들 때 쓴다.

도금 금속이 녹스는 것을 막거나 금속 표면을 아름답게 꾸미려고 금속 표면에 다른 금속을 입히는 기술이다.

Q 구리 펜던트에 은을 입히려면 펜던트를 전원 장치의 어느 극에 연결해야 할까? → 탐구로 확인해 보자.

탐구[필수 탐구] 은도금하기

[탐구]염 수용액과 전원 장치를 이용하여 금속 제품 표면에 도금하기

목표 탐구 수행 / 결론 도출

금속 염 수용액과 건전지를 이용하여 구리 표면에 은을 도금하고, 도금의 원리를 설명할 수 있다.

준비물

구리 펜던트, 은판, 다이사이아노은산 칼륨($\ce{K[Ag(CN)2]}$) 용액, 6홈판, 건전지(1.5 V AA 3개), 스위치형 집게 달린 건전지 받침, 핀셋, 증류수, 실험복, 보안경, 실험용 고무장갑

안전

· 반드시 실험복, 보안경, 실험용 고무장갑을 착용한다.

· 다이사이아노은산 칼륨 용액이 손에 닿지 않게 하고, 묻으면 흐르는 물로 즉시 씻는다. 반드시 환기가 잘되는 곳에서 실험한다.

· 남은 도금액(은·사이안화 이온이 든 폐액)은 하수구에 버리지 않고 폐수 처리 기준과 방법에 따라 처리한다.

도움 자료: 실험실 안전 수칙, 주요 시약별 주의 사항

탐구과정 1–3 — 구리 펜던트에 은 입히기

1 용액 넣기

다이사이아노은산 칼륨 용액을 6홈판의 한 홈에 넣는다.

2 연결하고 전원 켜기

전지의 (+)극에 은판, (−)극에 구리 펜던트를 연결하고 용액에 넣은 뒤 전원을 켠다.

3 꺼내어 씻기

표면이 모두 은색으로 바뀌면 전원을 끄고, 펜던트와 은판을 꺼내 증류수로 씻어 말린다.

도움말 은판과 구리 펜던트가 닿지 않게 하고, 펜던트 표면이 은색으로 바뀌면 방향을 돌려 가며 도금되지 않은 부분이 없게 한다.

Q 구리 펜던트와 은판에서 일어나는 변화를 각각 화학 반응식으로 나타내면?

은판이 조금씩 닳는다.

Q 은판의 변화와 용액 속 은 이온 수의 변화는 어떤 관계일까?

→ 은판에서 녹아 나온 은 이온 수 = 펜던트에 석출된 은 원자 수. 그래서 용액 속 은 이온 수는 변하지 않는다(은판 질량 감소 = 펜던트 질량 증가).

Q 석출 질량은 무엇에 비례할까?

→ 흐른 전자의 양(전류 × 시간)에 비례한다. 은은 전자 1 mol당 1 mol(108 g), 구리는 전자 2 mol당 1 mol(63.5 g) 석출된다.

탐구결론 도출 — 도금의 원리

Q 금속 제품 표면을 원하는 금속으로 도금하려면 어떻게 해야 할까?

연결

도금할 물체를 전원 장치의 (−)극에, 입힐 금속판을 (+)극에 연결한다.

도금액

입힐 금속의 이온이 들어 있는 염 수용액을 쓴다.

두께 조절

전류와 시간을 늘리면 흐른 전자의 양이 늘어 도금층이 두꺼워진다.

→ (−)극에서는 금속 이온이 전자를 얻어 금속으로 석출되고(환원), (+)극에서는 금속판이 전자를 잃고 이온이 되어(산화) 도금액의 이온을 채운다.

스스로 평가하기

2일상생활 속 도금

이온화 경향이 작은 금, 은, 크로뮴 등으로 금속 표면을 도금하면 내부 금속을 보호하거나 표면을 아름답게 꾸밀 수 있다.

금 도금

장식품을 만든다.

주석 도금

녹스는 것을 막는다(통조림 캔).

크로뮴 도금

녹을 막고 광택을 낸다(수도꼭지).

Q 겉을 덮는 금속은 왜 이온화 경향이 작은 것을 쓸까?

→ 이온화 경향이 작은 금속은 공기와 물에 의해 잘 산화되지 않아 오래 광택을 유지하고, 안쪽 금속이 공기·물과 닿지 않게 막아 준다.

자료실철 표면을 아연으로 도금해도 철을 보호할 수 있을까?

공기 중에서 철이 물과 닿으면 산화되어 붉은 녹이 생긴다. 철 표면을 아연으로 도금한 함석은 흠집이 나서 철이 드러나도 녹이 잘 슬지 않는다. 왜 그럴까?

→ 이온화 경향이 큰 아연이 철보다 먼저 산화되므로 철의 부식을 막는다.

$\begin{aligned}\color{#C2410C}\text{산화: }&\ce{Zn(s) -> Zn^2+(aq) + 2e-}\\\color{#0E7490}\text{환원: }&\ce{O2(g) + 2H2O(l) + 4e- -> 4OH-(aq)}\end{aligned}$

아연이 내놓은 전자가 드러난 철 표면에서 산소에게 전달된다. 철은 전자를 잃지 않는다.

2구리의 정제 — 순수한 금속 얻기

불순물을 포함한 구리판을 (+)극에, 순수한 구리판을 (−)극에 연결하고 황산 구리(II) 수용액에 담가 전류를 흘린다.

Q 불순물 속 금속들은 각각 어떻게 될까?

구리보다 산화가 잘되는 것 — 아연, 철, 니켈: 구리와 함께 산화되어 이온으로 녹아 나온다.

구리보다 산화되기 어려운 것 — 은, 백금, 금: 금속 그대로 (+)극 밑에 가라앉아 제거된다.

→ (−)극에서는 구리 이온만 환원되어 순수한 구리가 석출된다.

2구리의 정제 — 전극 반응

$\begin{aligned}(+)\text{극: }&\ce{M(s) -> M^2+(aq) + 2e-} \quad (\ce{M}: \ce{Zn}, \ce{Fe}, \ce{Ni}, \ce{Cu}\ \text{등}) &&\color{#C2410C}\text{(산화)}\\(-)\text{극: }&\ce{Cu^2+(aq) + 2e- -> Cu(s)} &&\color{#0E7490}\text{(환원)}\end{aligned}$

Q 용액에 $\ce{Zn^2+}$, $\ce{Fe^2+}$도 녹아 있는데, 왜 (−)극에는 구리만 석출될까?

반쪽 반응 (03의 표)$\ce{Cu^2+ + 2e- -> Cu}$$\ce{Fe^2+ + 2e- -> Fe}$$\ce{Zn^2+ + 2e- -> Zn}$
$E^\circ$$+0.34\ \text{V}$$-0.45\ \text{V}$$-0.76\ \text{V}$

→ 표준 환원 전위가 가장 큰 $\ce{Cu^2+}$이 가장 환원되기 쉽다. 이온화 경향이 큰 아연·철의 이온은 용액에 남는다.

Q 전기 분해가 진행되면 (+)극과 (−)극의 질량은? → (+)극은 감소, (−)극은 증가한다. 용액 속 $\ce{Cu^2+}$은 조금 줄어든다((+)극에서 아연·철도 함께 산화되기 때문).

2제조업 · 환경 · 신재생 에너지

생활 — 소금물과 표백제

소금물을 전기 분해 하면 수산화 나트륨과 염소 기체가 생긴다. 두 물질이 반응하면 산화력이 매우 큰 하이포염소산 나트륨($\ce{NaClO}$)이 되어 표백제·살균 소독제로 쓰인다.

$\ce{Cl2 + 2NaOH -> NaCl + NaClO + H2O}$

→ 생각 열기의 소독약 냄새: 염소와 하이포염소산 나트륨

표백제 생산

소금으로 표백제·살균 소독제를 만든다.

폐수 처리

폐수 속 유기물을 산화·환원 반응으로 분해하고, 금속 이온을 환원시켜 자원을 재활용한다.

수소 제조

물을 전기 분해 하여 얻은 수소 기체를 에너지원으로 쓴다.

해 보기조사 예시 — 알루미늄 제련

산화 알루미늄($\ce{Al2O3}$)은 녹는점이 매우 높아, 빙정석을 녹인 액체에 녹여 녹는점을 낮춘 뒤 전기 분해 한다.

Q 각 전극의 반응은?

$\begin{aligned}(-)\text{극: }&\ce{Al^3+(l) + 3e- -> Al(l)} \ \ \color{#0E7490}\text{(환원)}\\(+)\text{극: }&\ce{2O^2-(l) -> O2(g) + 4e-} \ \ \color{#C2410C}\text{(산화)}\end{aligned}$

→ (+)극에서 생긴 산소는 뜨거운 탄소 전극과 반응해 이산화 탄소가 되므로 탄소 전극이 닳는다. 많은 전기 에너지가 들어 재활용 알루미늄을 쓰면 에너지를 크게 아낄 수 있다.

2 구리의 정제 과정에서 불순물이 포함된 구리가 연결된 전극에서 일어나는 반응을 써 보자. 어떤 반응일까?

Q 이온화 경향이 큰 금속은 왜 전기 분해로만 얻을까?

→ 이온화 경향이 클수록 금속 이온이 전자를 얻기(환원되기) 어려워, 탄소 같은 환원제로는 환원되지 않는다. 큰 전기 에너지로 강제로 환원시켜야 한다. 이온화 경향이 작은 금속은 쉽게 환원되거나 홑원소 상태로 산출된다(구리는 얻은 뒤 전기 분해로 정제).

구분은 대표적인 예이다(덱 예시). 조사할 때 자료의 출처를 함께 적는다.

대단원 마무리 09수용액의 전기 분해 생성물

$\ce{CuCl2}(aq)$과 $\ce{NaCl}(aq)$을 전기 분해 할 때 ㉠, ㉡에서 생성되는 물질을 써 보자. (단, 표준 환원 전위는 $\ce{Cu^2+}(aq)>\ce{H2O}(l)>\ce{Na+}(aq)$이다.)

물질(+)극(−)극
$\ce{CuCl2}(aq)$$\ce{Cl2}(g)$㉠
$\ce{NaCl}(aq)$$\ce{Cl2}(g)$㉡

(−)극에서는 양이온과 물 중 표준 환원 전위가 큰 것(환원되기 쉬운 것)이 환원된다.

㉠ $\ce{Cu^2+}$ > $\ce{H2O}$ → $\ce{Cu^2+ + 2e- -> Cu}$

㉡ $\ce{H2O}$ > $\ce{Na+}$ → $\ce{2H2O + 2e- -> H2 + 2OH-}$

㉠ 구리 $\ce{Cu}(s)$    ㉡ 수소 $\ce{H2}(g)$

대단원 마무리 10불순물이 포함된 구리의 정제

그림은 $25\ {}^\circ\text{C}$에서 불순물 $\mathrm{X}$, $\mathrm{Y}$가 포함된 구리에서 순수한 구리를 얻는 장치이다. (단, $\mathrm{X}$와 $\mathrm{Y}$는 임의의 원소 기호이다.)

⑴ $\mathrm{X}$, $\mathrm{Y}$, $\ce{Cu}$의 이온이 금속으로 되는 반응의 표준 환원 전위를 등호나 부등호로 비교해 보자.

$\mathrm{X}$는 이온으로 녹아 나오지만 석출되지 않음 → 구리보다 산화되기 쉽다. $\mathrm{Y}$는 산화되지 않고 가라앉음 → 구리보다 산화되기 어렵다.

$E^\circ_{\mathrm{X}} < E^\circ_{\ce{Cu}} < E^\circ_{\mathrm{Y}}$

⑵ 환원 전극((−)극)의 질량은 어떻게 변하는지 써 보자.

증가한다 — $\ce{Cu^2+ + 2e- -> Cu}$로 구리가 석출된다.

채점 요소: ⑴ 부등호 방향과 근거(녹아 나옴·가라앉음) ⑵ 증가 + 구리 석출
