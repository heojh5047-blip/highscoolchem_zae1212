Q 반응이 끝난 뒤 효모(속의 효소)는 없어졌을까? 효모는 반응을 어떻게 빠르게 했을까?

→ 효소는 소모되지 않고 남는다. 활성화 에너지가 낮은 새로운 반응 경로로 반응을 이끈다 — 오늘 그 경로(메커니즘)를 알아보자.

다시 보기반응 속도식은 실험으로, 봉우리 사이의 골짜기는 중간체

Ⅳ-3 반응 속도식 반응 속도 $=k[\ce{A}]^m[\ce{B}]^n$ — 차수 $m$, $n$은 반응식의 계수가 아니라 실험으로 정한다.

Ⅳ-4 활성화 에너지 봉우리 = 활성화 착물(‡), $E_\mathrm{a}$가 작을수록 빠르다. 봉우리가 두 개면 그 사이 골짜기에 중간체가 있다.

Q 오른쪽 도표의 반응은 몇 단계일까?

→ 봉우리가 2개이므로 두 단계 반응이다. 오늘은 단계 하나하나를 반응식으로 나타낸다.

Q 반응식의 계수에서 반응 차수를 바로 읽을 수 없는 까닭은?

→ 대부분의 화학 반응은 한 단계가 아니라 여러 단계를 거쳐 일어나기 때문이다. 반응식은 그 단계들을 모두 더한 결과이다.

오개념 주의: 「반응 차수 = 반응식의 계수」는 단일 단계 반응에서만 맞다(다음 장).

2단일 단계 반응과 분자도

1분자 반응 기체 $\ce{N2O5}$의 분해: $\ce{2N2O5(g) -> 4NO2(g) + O2(g)}$
반응 속도 $=-\dfrac{d[\ce{N2O5}]}{dt}=k[\ce{N2O5}]$ (1차)

위 식은 전체 반응식이다. 속도를 정하는 1분자 단계는 그림처럼 $\ce{N2O5}$ 한 분자가 쪼개지는 $\ce{N2O5 -> NO2 + NO3}$이다.

2분자 반응(가장 흔함) $\ce{NO(g) + O3(g) -> NO2(g) + O2(g)}$
반응 속도 $=-\dfrac{d[\ce{NO}]}{dt}=-\dfrac{d[\ce{O3}]}{dt}=k[\ce{NO}][\ce{O3}]$ (2차)

단일 단계 반응에 참여하는 반응물 분자(또는 이온)의 수 = 분자도

3단일 단계 반응에서는 분자도 = 반응 차수

표 Ⅳ-12 단일 단계 반응의 속도식
단일 단계 반응식분자도속도식
$\mathrm{A}\longrightarrow$ 생성물1분자$k[\mathrm{A}]$
$2\mathrm{A}\longrightarrow$ 생성물2분자$k[\mathrm{A}]^2$
$\mathrm{A}+\mathrm{B}\longrightarrow$ 생성물2분자$k[\mathrm{A}][\mathrm{B}]$
$2\mathrm{A}+\mathrm{B}\longrightarrow$ 생성물3분자$k[\mathrm{A}]^2[\mathrm{B}]$

단일 단계 반응의 속도식은 화학량론(계수)으로부터 추론할 수 있다. 전체 반응의 속도식은 오직 실험으로만 정한다.

Q 메커니즘에 3분자 반응이 거의 나오지 않는 까닭은?

→ 세 분자가 동시에 충분한 에너지와 알맞은 방향으로 만날 확률이 매우 낮기 때문이다. 그래서 메커니즘은 주로 1분자·2분자 반응으로 제시한다.

Q 계수만 보고 한 단계 반응이라 여기면 속도식은? 실험 자료로 구한 속도식은?

5다단계 반응과 반응 속도 결정 단계

다단계 반응의 메커니즘은 일련의 단일 단계 반응과 각 단계의 반응 속도로 나타내며, 각 단계의 반응식을 모두 더하면 전체 반응식이 된다.

여러 단계 중 한 단계가 다른 단계보다 매우 느리면 그 단계가 전체 반응 속도를 좌우한다 → 반응 속도 결정 단계(속도 제한 단계)

전체 반응은 가장 느린 단계와 거의 같은 속도로 진행된다.

6$\ce{NO2 + CO}$ 반응의 메커니즘과 속도 결정 단계

1단계$\ce{NO2(g) + NO2(g) -> NO3(g) + NO(g)}$$k_1$, 느림
2단계$\ce{NO3(g) + CO(g) -> NO2(g) + CO2(g)}$$k_2$, 빠름
합$\ce{NO2(g) + CO(g) -> NO(g) + CO2(g)}$N 1, O 3, C 1

양쪽에 같이 나오는 $\ce{NO3}$ 1개와 $\ce{NO2}$ 1개를 지우면 전체 반응식이 된다.

Q 어느 단계가 속도 결정 단계일까?

→ 1단계의 속도 $k_1[\ce{NO2}]^2$이 실험 속도식 $k[\ce{NO2}]^2$과 일치($k_1=k$) → 1단계

$\ce{CO}$는 빠른 2단계에만 참여하므로 속도식에 나타나지 않는다. $\ce{NO3}$는 느리게 생기지만, 생기기만 하면 곧바로 $\ce{CO}$와 반응한다.

7반응 중간체와 활성화 착물은 다르다

$\ce{NO3}$처럼 반응 중간에 생겼다가 완전히 소비되어 전체 반응식에는 나타나지 않는 화학종을 반응 중간체라고 한다.

존재짧지만 존재순간적인 상태

Q 속도 결정 단계는 도표에서 어떻게 보일까?

→ 반응물에서 잰 가장 높은 봉우리를 넘는 단계(여기서는 1단계, $E_\mathrm{a1}$이 가장 큼)

8제안된 메커니즘이 옳은지 판단하는 두 조건

조건 ① 단계의 합 = 전체 반응식

중간체를 지우고 원자 수와 전하가 전체 반응식과 같아야 한다.

조건 ② 속도 결정 단계의 속도식 = 실험 속도식

가장 느린 단계(와 그 앞 단계)의 반응물이 속도식에 나타나야 한다.

$\ce{NO2 + CO}$ 반응(실험: 반응 속도 $=k[\ce{NO2}]^2$)에 제안된 두 메커니즘을 판단해 보자.

제안메커니즘조건 ①조건 ②판단
(가)한 단계: $\ce{NO2 + CO -> NO + CO2}$○× ($k[\ce{NO2}][\ce{CO}]$)옳지 않음
(나)1단계(느림) $\ce{2NO2 -> NO3 + NO}$ / 2단계(빠름) $\ce{NO3 + CO -> NO2 + CO2}$○○ ($k_1[\ce{NO2}]^2$)옳을 수 있음

두 조건을 만족해도 「가능한」 메커니즘일 뿐이다 — 중간체 검출, 동위원소 표지법 같은 보완 실험으로 확인한다.

9속도 결정 단계가 뒤에 올 때 — $\ce{2NO + O2}$ 반응

1단계$\ce{NO(g) + O2(g) <=> NO3(g)}$빠른 평형
2단계$\ce{NO3(g) + NO(g) -> 2NO2(g)}$느림, 속도 결정
합$\ce{2NO(g) + O2(g) -> 2NO2(g)}$N 2, O 4

속도 결정 단계의 속도식: 반응 속도 $=k_2[\ce{NO3}][\ce{NO}]$ — 그런데 중간체 $\ce{NO3}$의 농도는 잴 수 없다.

Q 실험 속도식 $k[\ce{NO}]^2[\ce{O2}]$은 메커니즘과 맞을까?

→ 속도 결정 단계까지 들어간 반응물을 세면 $\ce{NO}$ 2개, $\ce{O2}$ 1개($\ce{NO3}$ 속에 $\ce{NO}$ 1, $\ce{O2}$ 1) → $[\ce{NO}]^2[\ce{O2}]$와 맞는다.

교과서 풀이 1단계는 정반응과 역반응의 속도가 같으므로 $k_1[\ce{NO}][\ce{O2}]=k_{-1}[\ce{NO3}]$, $[\ce{NO3}]=\dfrac{k_1}{k_{-1}}[\ce{NO}][\ce{O2}]$
→ 반응 속도 $=\dfrac{k_2k_1}{k_{-1}}[\ce{NO}]^2[\ce{O2}]=k[\ce{NO}]^2[\ce{O2}]$

확인 문제 02메커니즘과 실험 속도식 맞추어 보기

$\ce{2NO(g) + 2H2(g) -> N2(g) + 2H2O(g)}$의 실험 반응 속도식은 반응 속도 $=k[\ce{NO}]^2[\ce{H2}]$이다. 제안된 메커니즘은 1단계 $\ce{2NO + H2 -> N2 + H2O2}$(느림), 2단계 $\ce{H2O2 + H2 -> 2H2O}$(빠름)이다.

① 전체 반응식과 속도식이 맞는지 확인하여라. ② 각 단계의 분자도와 중간체를 써라. ③ 활성화 에너지가 더 큰 단계는?

① 두 단계를 더하고 $\ce{H2O2}$를 지우면 $\ce{2NO + 2H2 -> N2 + 2H2O}$ — 일치(N 2, O 2, H 4).
느린 1단계의 속도 $k_1[\ce{NO}]^2[\ce{H2}]$ — 실험 속도식과 일치

② 1단계 3분자, 2단계 2분자, 중간체 $\ce{H2O2}$

③ 느린 1단계(속도 결정 단계)

10반응 중간체를 어떻게 확인할까?

계산 모형: 1단계 속도 상수 1, 2단계 속도 상수 3(상대값)

중간체는 매우 짧은 시간만 존재하므로 반응물이나 생성물처럼 분리하기 어렵다.

직접 방법분광기기로 반응 중에 중간체의 흡수 스펙트럼을 잡는다.
간접 방법중간체와 빠르게 반응하는 물질을 넣어 생긴 물질로 확인한다.
동위원소 표지법원자에 표시를 해 어떤 결합이 끊어지고 생기는지 추적한다.
$\begin{aligned}&\ce{CH3CO-OH + H-^{18}O-CH3}\\&\ce{-> CH3CO-^{18}O-CH3 + H2O}\end{aligned}$

Q 반응 메커니즘을 밝히는 가장 기본적인 실험은?

→ 반응 속도 측정(속도식 구하기). 그것만으로 어려우면 위의 보완 실험을 함께 쓴다.

탐구 활동[필수 탐구] 반응 중간체의 존재 확인 사례 조사

반응 중간체는 불안정하여 아주 짧은 시간만 존재하지만, 반응 메커니즘을 정하려면 그 존재를 확인하는 것이 매우 중요하다. 실험 기법과 분광기기가 발달하여 직접 확인하는 것이 가능해지고 있고, 불가능할 때는 간접 방법을 쓴다.

11촉매 — 소모되지 않으면서 반응을 빠르게 하는 물질

촉매: 화학 반응에서 자신은 소모되지 않으면서 반응 속도를 빠르게 하는 물질. 효소는 생명체가 만드는, 선택성이 매우 큰 생물학적 촉매이다.

촉매는 새로운 반응 메커니즘으로 반응을 촉진하지만 전체 반응식에는 나타나지 않는다.

13촉매 유무에 따른 반응 에너지 도표

Q 촉매는 정반응과 역반응의 활성화 에너지를 어떻게 바꿀까?

→ 정반응: $76\to57\ \text{kJ/mol}$로 낮아진다(19 kJ/mol).

→ 역반응도 같은 크기만큼 낮아진다 → 정반응·역반응의 $k$가 모두 커진다.

→ 반응물·생성물의 에너지는 그대로 → $\Delta H$, 평형 상수, 수득률은 변하지 않는다. 평형에 빨리 도달할 뿐이다.

역반응 활성화 에너지도 $171\to152\ \text{kJ/mol}$. 단일 단계 가역 반응에서 $K=\dfrac{k_\text{정}}{k_\text{역}}$ — 두 속도 상수가 같은 비율로 커지면 $K$는 그대로(Ⅳ-1 화학 평형과 연결). $\ce{I-}$ 경로의 $57\ \text{kJ/mol}$은 덱의 모형 값이다.

Q 오늘날에는 왜 $\ce{NO}$ 대신 $\ce{Pt}$나 $\ce{V2O5}$를 쓸까?

→ 기체 촉매 $\ce{NO}$는 기체 생성물 $\ce{SO3}$와 분리하기 어렵기 때문이다. 고체 촉매는 분리가 쉽다.

예제 Ⅳ-6활성화 에너지가 6 kJ/mol 낮아지면

$25\ {}^\circ\text{C}$에서 활성화 에너지가 $87\ \text{kJ/mol}$인 반응에 촉매를 쓰자 활성화 에너지가 $81\ \text{kJ/mol}$로 $6\ \text{kJ/mol}$ 낮아졌다. 촉매가 없을 때에 비해 반응 속도는 몇 배 빨라졌는가?

촉매가 없을 때 $k=Ae^{-E_\mathrm{a}/RT}$, 있을 때 $k'=Ae^{-(E_\mathrm{a}-\Delta E_\mathrm{a})/RT}$ ($A$는 같다고 본다)

$\dfrac{k'}{k}=e^{\Delta E_\mathrm{a}/RT}=\exp\left(\dfrac{6000\ \text{J/mol}}{8.314\ \text{J/(mol}\cdot\text{K)}\times298\ \text{K}}\right)=e^{2.42}$

약 $11.26$배 빨라진다

kJ을 J로 바꾸지 않으면 1000배 틀린다 — $\Delta E_\mathrm{a}=6000\ \text{J/mol}$.

$25\ {}^\circ\text{C}$에서 $\ce{H2O2}$ 분해에 $\ce{I-}$를 넣으면 활성화 에너지가 $76\ \text{kJ/mol}$에서 $57\ \text{kJ/mol}$로 낮아진다고 하자. 옳은 것만을 <보기>에서 있는 대로 골라라.

ㄱ. $\ce{I-}$는 1단계에서 소모되고 2단계에서 다시 생기므로 전체 반응식에 나타나지 않는다.

ㄴ. $\ce{I-}$를 넣으면 반응열 $\Delta H$의 크기가 작아진다.

ㄷ. $A$가 같다면 반응 속도 상수는 약 $2\times10^3$배가 된다.

ㄱ, ㄷ

ㄴ: 촉매는 반응물·생성물의 에너지를 바꾸지 않는다. ㄷ: $e^{19000/(8.314\times298)}=e^{7.67}\approx2.1\times10^3$

16촉매의 종류 — 균일 촉매와 불균일 촉매

균일 촉매: 반응물과 같은 상태 — $\ce{SO2}$ 산화의 $\ce{NO(g)}$, $\ce{H2O2}$ 분해의 $\ce{I-(aq)}$

불균일 촉매: 반응물과 다른 상태 — 기체 반응의 고체 $\ce{Pt}$. 산업 공정에서 많이 쓴다.

살아 있는 세포 속의 효소는 균일 촉매처럼도, 불균일 촉매처럼도 작용하여 천연 촉매 또는 생체촉매라고 한다.

Q 효소는 어떤 점에서 두 촉매를 닮았을까?

→ 기질이 임시로 고정되는 표면을 주고(불균일), 활성 자리가 기질과 직접 반응한다(균일).

17불균일 촉매 수소화 — 에틸렌 + 수소 → 에테인

촉매가 없으면 $E_\mathrm{a}$가 너무 커서 상온에서 거의 반응하지 않는다. 잘게 부순 $\ce{Pt}$·$\ce{Ni}$이 있으면 높은 압력에서 네 단계의 새 경로로 빨라진다.

Q 어느 단계가 속도 결정 단계일까?

→ 2단계: 화학적 흡착으로 H–H 결합이 끊어지는 단계. 식물성 기름을 고체 기름으로 바꿀 때도 쓴다.

Q 금속 촉매를 벌집 모양 표면에 얇게 입히는 까닭은?

→ 불균일 촉매 반응은 표면에서 일어나므로, 표면적을 넓혀 기체가 닿는 자리를 많게 한다.

19효소 — 활성 자리를 가진 선택성 촉매

$\mathrm{E}+\mathrm{S}\longrightarrow\mathrm{ES}\longrightarrow\mathrm{E}+\mathrm{P}$
E 효소 · S 기질 · ES 효소-기질 복합체 · P 생성물

효소는 분자량이 매우 큰 단백질로 활성 자리가 있어, 특정한 물질을 특정한 경로로만 반응시킨다(선택성). ES가 생기면 기질 속 결합이 약해지고 새 결합이 생겨 P가 된다.

Q 효소 반응에서 속도 결정 단계는?

→ 활성 자리가 기질과 ES 복합체를 만드는 단계(교과서). 효소로 활성화 에너지가 낮아져 속도가 커진다.

$\ce{CF2Cl2}$는 2단계에서 소모되고 4단계에서 다시 생기므로 중간체가 아니라 촉매처럼 작용한다.

연습 문제 3자발적인데 왜 느릴까?

에틸렌에 수소를 첨가하는 반응 $\ce{C2H4(g) + H2(g) -> C2H6(g)}$은 $\Delta G^\circ=-101.01\ \text{kJ/mol}$로 큰 (−)값을 가지는 자발적 반응이지만, 촉매가 없으면 매우 느리게 진행된다. 그 까닭을 설명하여라.

$\Delta G$는 상태 함수로 반응물과 생성물의 차이일 뿐, 반응 경로·활성화 에너지와는 관계가 없다. 촉매가 없으면 활성화 에너지가 매우 커서 느리다. $\ce{Pt}$ 촉매 표면에 물리적 흡착 → 화학적 흡착하는 새 경로로 활성화 에너지가 낮아져 빨라진다.
