생각 열기어떤 전지가 좋은 전지일까?

실용 전지는 주로 휴대용 전원으로 쓴다. 가장 바람직한 실용 전지는 일정한 전위차를 유지하고, 안전하며, 휴대할 수 있는 환경친화적 전지이다. 그 원리는 다니엘 전지와 다르지 않다.

Q 리모컨 건전지는 다 쓰면 버리고, 스마트폰 배터리는 충전해 다시 쓴다. 두 전지는 무엇이 다를까?

→ 건전지는 역반응을 일으킬 수 없어 한 번 쓰면 수명이 다하고, 스마트폰 배터리는 전기 에너지를 가해 역반응(충전)을 일으킬 수 있다.

1여러 가지 실용 전지 — 1차·2차·연료 전지

실용 전지는 각종 전기 장치에 전력을 공급하는 장치로, 1차 전지·2차 전지·연료 전지 등이 있다.

21차 전지 — 알칼리 전지의 구조

알칼리 전지는 많은 소형 가전제품에 쓰는 대표적인 1차 전지로, 전지 전위 $1.55\ \text{V}$를 낸다. (−)극(산화 전극)은 아연, (+)극(환원 전극)은 비활성 탄소 막대(흑연 봉)이고, 전해질은 $\ce{KOH}$ 반죽이다.

Q 전자는 어느 극에서 나와 어디로 갈까?

→ 아연((−)극, 산화 전극)에서 나와 바깥 도선을 거쳐 흑연 봉((+)극, 환원 전극)으로 간다.

Q 흡착제/격리판은 어떤 일을 할까?

→ 두 전극 물질이 직접 닿지 않게 떼어 놓으면서 이온은 지나가게 한다 — 다니엘 전지의 염다리 역할(01 탐구 활동).

3알칼리 전지의 전극 반응

산화 전극 (−)$\ce{Zn(s) + 2OH-(aq) -> Zn(OH)2(s) + 2e-}$
환원 전극 (+)$\ce{2MnO2(s) + H2O(l) + 2e- -> Mn2O3(s) + 2OH-(aq)}$
전체 반응$\ce{Zn(s) + 2MnO2(s) + H2O(l) -> Zn(OH)2(s) + Mn2O3(s)}$   $E_\text{전지}=1.55\ \text{V}$

Q 전체 반응식에 $\ce{OH-}$이 없는 까닭은?

→ 환원 전극이 만든 $\ce{OH-}$ 2개가 격리판을 지나 산화 전극에서 다시 쓰이므로, 전해질의 $\ce{OH-}$은 줄지 않는다.

Q 산화되는 원소와 환원되는 원소는?

→ $\ce{Zn}$: $0\rightarrow+2$ 산화, $\ce{Mn}$: $+4\rightarrow+3$ 환원 — 전자 2개를 주고받는다.

교과서 175쪽 환원 전극식은 $\ce{H2O}$ 계수가 2로 적혀 있으나, 원자 수가 맞고 전체 반응과 이어지도록 1로 고쳐 썼다.

41차 전지 — 은 단추 전지

소형 시계를 움직이는 데 많이 쓰는 또 다른 1차 전지이다.

산화 전극 (−)$\ce{Zn(s) + 2OH-(aq) -> ZnO(s) + H2O(l) + 2e-}$
$\ce{ZnO}/\ce{Zn}$의 표준 환원 전위 $E^\circ=-1.260\ \text{V}$
환원 전극 (+)$\ce{Ag2O(s) + H2O(l) + 2e- -> 2Ag(s) + 2OH-(aq)}$
$E^\circ=+0.342\ \text{V}$
전체 반응$\ce{Zn(s) + Ag2O(s) -> ZnO(s) + 2Ag(s)}$

Q 은 단추 전지의 전지 전위는 몇 V일까?

$E^\circ_\text{전지}=E^\circ_\text{환원 전극}-E^\circ_\text{산화 전극}=0.342-(-1.260)=$ $+1.602\ \text{V}$

교과서 날개는 산화 전극 반응 옆에 산화 방향 전위 $+1.260\ \text{V}$를 적고 두 값을 더했다 — 같은 결과이다.

52차 전지 — 방전과 충전

2차 전지는 정반응이 평형에 도달하면 전기 에너지를 가하여 역반응을 일으켜 충전할 수 있는 전지이다. 역반응이 일어나면 반응물이 다시 만들어지므로 반복해서 충전할 수 있다.

방전

자발적 정반응($\Delta G<0$) — 화학 에너지 → 전기 에너지(갈바니 전지)

충전

바깥 전원이 전기 에너지를 공급해 비자발적 역반응($\Delta G>0$)을 일으킨다(전해 전지처럼)

Q 1차 전지는 왜 충전해서 다시 쓸 수 없을까?

→ 반응이 평형에 이른 뒤 역반응을 일으킬 수 없도록 만들어진 전지이기 때문이다. 2차 전지는 방전 생성물이 전극에 그대로 붙어 있어 역반응으로 되돌릴 수 있다.

62차 전지 — 납-산 전지

자동차 배터리로 쓰는 2차 전지(02의 표 Ⅲ-9 「납축전지」)이다. 납 산화 전극과 이산화 납 환원 전극을 황산 용액에 담근 $2.1\ \text{V}$ 전지를 직렬로 이어 쓴다.

산화 전극 (−)$\ce{Pb(s) + HSO4-(aq) -> PbSO4(s) + H+(aq) + 2e-}$
환원 전극 (+)$\ce{PbO2(s) + 3H+(aq) + HSO4-(aq) + 2e- -> PbSO4(s) + 2H2O(l)}$
전체 반응$\ce{Pb(s) + PbO2(s) + 2H+(aq) + 2HSO4-(aq) -> 2PbSO4(s) + 2H2O(l)}$   $E_\text{전지}=2.1\ \text{V}$

Q 전지 6개를 직렬로 이으면 전압은 약 몇 V일까?

→ $6\times2.1=12.6\ \text{V}$, 곧 약 $12\ \text{V}$이다($24\ \text{V}$는 12개).

Q 방전하면 황산 용액과 두 전극은 어떻게 될까?

→ $\ce{H+}$과 $\ce{HSO4-}$이 쓰이고 물이 생겨 황산이 묽어지고, 두 전극 모두 $\ce{PbSO4}$로 덮인다.

확인 문제 01납-산 전지의 충전

방전한 납-산 전지를 충전기에 이었다. 충전기의 (−)단자는 납 전극에, (+)단자는 이산화 납 전극에 잇는다.

(1) 충전할 때의 전체 반응식은?

$\ce{2PbSO4(s) + 2H2O(l) -> Pb(s) + PbO2(s) + 2H+(aq) + 2HSO4-(aq)}$
방전 반응의 역반응

(2) 충전할 때 납 전극과 이산화 납 전극은 각각 어떤 전극일까?

→ 납 전극: $\ce{PbSO4 + H+ + 2e- -> Pb + HSO4-}$, 전자를 얻는 환원 전극

→ 이산화 납 전극: $\ce{PbSO4 + 2H2O -> PbO2 + 3H+ + HSO4- + 2e-}$, 산화 전극

충전할 때는 (+)극 쪽이 산화 전극이다. 전극 이름은 극의 부호가 아니라 그 전극에서 일어나는 반응으로 정한다(Ⅲ-5 전해 전지와 같음).

72차 전지 — 리튬-이온 전지

산화 전극 (−)$\mathrm{Li}_x\mathrm{C}_6\longrightarrow x\ce{Li+} + x\ce{e-} + \ce{C6(s)}$
환원 전극 (+)$\mathrm{Li}_{1-x}\mathrm{Mn_2O_4}(s) + x\ce{Li+} + x\ce{e-}\longrightarrow\ce{LiMn2O4(s)}$
전체 반응$\mathrm{Li}_x\mathrm{C}_6+\mathrm{Li}_{1-x}\mathrm{Mn_2O_4}(s)\longrightarrow\ce{LiMn2O4(s) + C6(s)}$   $E_\text{전지}=3.7\ \text{V}$

휴대용 컴퓨터·스마트폰·전기 자동차에 쓴다. 중량당 에너지 효율이 높고 자가 방전율이 낮아 메모리 효과 없이 오래 쓸 수 있다.

Q 방전할 때 전자와 $\ce{Li+}$은 각각 어떤 길로 이동할까?

→ 전자는 바깥 도선으로, $\ce{Li+}$은 전해질과 분리막을 지나 — 둘 다 흑연 쪽에서 망가니즈 산화물 쪽으로 이동한다.

확인 문제 02리튬-이온 전지의 산화수 변화

$\ce{Li}$의 산화수는 $+1$, $\ce{O}$의 산화수는 $-2$로 둔다.

(1) $\ce{LiMn2O4}$에서 $\ce{Mn}$의 (평균) 산화수는?

→ $(+1)+2m+4\times(-2)=0$ → $m=$ $+3.5$

(2) $\mathrm{Li}_{1-x}\mathrm{Mn_2O_4}$에서 $\ce{Mn}$의 산화수는?

→ $(1-x)+2m-8=0$ → $m=$ $3.5+\dfrac{x}{2}$

(3) 방전할 때 환원되는 원소와 산화되는 원소는?

→ $\ce{Mn}$은 산화수가 낮아져 환원되고, 흑연 층 사이의 리튬(0)은 $\ce{Li+}$(+1)이 되어 산화된다.

탐구 활동[필수 탐구] 전기 자동차와 드론용 2차 전지 기술 종류와 특성 조사

2차 전지는 반복해서 방전·충전하므로 일회용 1차 전지보다 친환경적이다. 전기 용량이 큰 음극·양극 소재와 효율적인 전해질·분리막 덕분에 무거운 자동차를 먼 거리까지 빠르게 움직인다. 한편 리튬·니켈 같은 핵심 광물의 채굴이 늘며 환경 문제와 자원의 무기화 문제도 생겼다.

과정

  1. 모둠별로 전기 자동차·드론 산업에 쓰이는 진보된 2차 전지 기술의 종류와 특성을 조사한다.
  2. 각 기술의 장단점과 산업적·환경적 한계를 토론한다.
  3. 결과를 1000자 이내로 요약한다.

9연료 전지의 원리 — 수소 연료 전지

수소 연료 전지는 연료인 수소와 산화제인 산소를 바깥에서 산화 전극과 환원 전극으로 공급하는 한 계속 전기를 만든다. 이 점에서 볼타 전지와 다르다.

산화 전극의 수소는 백금 나노 촉매와 반응해 전자와 양성자($\ce{H+}$)를 내놓는다. 환원 전극의 산소는 전자, 그리고 양성자 교환 고분자 전해질 막을 지나온 양성자와 반응해 물이 된다.

Q 전자와 양성자는 각각 어떤 길로 환원 전극에 갈까?

→ 전자는 바깥 도선(전구)으로, 양성자는 고분자 전해질 막을 지나 간다.

10수소 연료 전지의 전극 반응

산화 전극 (−)$\ce{2H2(g) -> 4H+(aq) + 4e-}$
환원 전극 (+)$\ce{O2(g) + 4H+(aq) + 4e- -> 2H2O(l)}$
전체 반응$\ce{2H2(g) + O2(g) -> 2H2O(l)}$   $E_\text{전지}=1.2\ \text{V}$

Q 전체 반응은 어떤 반응과 같을까?

→ 수소의 연소와 같다. 다만 불꽃과 열 대신 전자를 도선으로 흐르게 해 전기 에너지로 꺼낸다.

Q 생성물인 물은 어디에 쓰일 수 있을까?

→ 인공위성·우주선에서는 연료 전지로 전력과 함께 물을 얻는다.

확인 문제 03수소 연료 전지의 표준 전지 전위와 효율

$25\ {}^\circ\text{C}$에서 $\ce{H2O}(l)$의 $\Delta G^\circ_\text{f}=-237.1\ \text{kJ/mol}$, $\Delta H^\circ_\text{f}=-285.8\ \text{kJ/mol}$이다.

(1) $\ce{2H2(g) + O2(g) -> 2H2O(l)}$의 $E^\circ_\text{전지}$는?

$\Delta G^\circ=2\times(-237.1)=-474.2\ \text{kJ}$, $n=4$
$E^\circ_\text{전지}=-\dfrac{\Delta G^\circ}{nF}=\dfrac{474200}{4\times96485}=$ $1.229\ \text{V}$
교과서 그림의 $1.2\ \text{V}$와 같다

(2) 반응 엔탈피 가운데 전기적 일로 바꿀 수 있는 최대 비율(이론 효율)은?

$\dfrac{\Delta G^\circ}{\Delta H^\circ}=\dfrac{-474.2}{2\times(-285.8)}=\dfrac{-474.2}{-571.6}=$ $0.83$ ($83\ \%$)

열기관은 열을 거쳐 일을 하므로 효율이 이보다 훨씬 낮다 — 연료 전지가 「고에너지 효율」 전원인 까닭이다.

Q 빈칸에 들어갈 연료 전지의 특징은?

활용 오랫동안 인공위성·우주선의 전력과 물을 만들었고, 1990년대부터 전력 공급이 어려운 고립 지역, 상업용 건물·시설에 쓰였다. 수소 연료 전지 자동차처럼 쓰임이 넓어지고 있다.

탐구 활동[필수 탐구] 수소 연료 전지의 상용화 기술 동향 조사

수소 연료 전지는 오래전부터 우주 개발에 써 온 전지이며, 2차 전지 기술과 함께 대표적인 청정에너지로 꼽히는 만큼 장점이 많다.

과정

  1. 모둠별로 수소 연료 전지의 상용화에 걸림돌이 되는 것과 이를 극복하는 기술 동향을 조사한다.
  2. 새 기술과 소재 개발에 적용되는 화학의 원리와 활용 범위를 토론한다.
  3. 모둠별로 발표한 뒤 400자 이내로 적는다.

조사할 때 「생산 → 저장·운송 → 활용」 가운데 어느 단계의 문제인지 나누어 정리한다.

진로연료 전지와 수소 경제

이산화 탄소 증가와 지구 온난화로 세계 주요국은 탄소 배출을 줄이는 정책을 함께 펴고 있다. 친환경 에너지는 생산량이 일정하지 않아 전기를 저장할 수단이 필요한데, 수소 기술이 그 열쇠로 기대된다.

연료 전지는 소형 기기부터 선박·건물·발전소까지 쓸 수 있고, 대형 발전 설비 없이 건물·가정에서 분산 발전을 하여 수요에 따라 전력을 공급한다. 한국·일본·미국 중심으로 시장이 커지고(연평균 30 % 성장 전망) 전문 인력 수요도 늘고 있다.

연습 문제 1다니엘 전지에서 염다리의 작용

다니엘 전지에서 염다리의 작용을 $\ce{Zn(s)}\,|\,\ce{Zn^2+(aq)}\,\|\,\ce{Cu^2+(aq)}\,|\,\ce{Cu(s)}$ 전지를 예로 들어 설명하여라.

산화 전극에서 $\ce{Zn -> Zn^2+ + 2e-}$로 양이온이 늘고, 환원 전극에서 $\ce{Cu^2+ + 2e- -> Cu}$로 양이온이 줄어 두 용액에 전하가 쌓이려 한다. 염다리의 음이온($\ce{NO3-}$)은 아연 쪽으로, 양이온($\ce{K+}$)은 구리 쪽으로 이동해 두 용액을 전기적으로 중성으로 유지하고 회로를 완성한다.

채점 요소(덱): ① 전하가 쌓이는 까닭 ② 염다리 이온의 이동 방향 ③ 전기적 중성 유지·회로 완성 — 전자는 염다리로 이동하지 않고, 두 용액은 섞이지 않는다.

연습 문제 2농도가 표준이 아닐 때의 전지 전위 [심화]

$25\ {}^\circ\text{C}$에서 $\ce{O2(g) + 4H+(aq) + 4Br-(aq) -> 2H2O(l) + 2Br2(l)}$의 전지 전위 $E_\text{전지}$를 계산하여라. (단, $\ce{O2}$의 분압은 $1\ \text{atm}$, $[\ce{H+}]=[\ce{Br-}]=0.20\ \text{M}$이고, $\ce{O2 + 4H+ + 4e- -> 2H2O}$ $E^\circ=+1.229\ \text{V}$, $\ce{Br2 + 2e- -> 2Br-}$ $E^\circ=+1.077\ \text{V}$)

풀이 1 환원 $\ce{O2 + 4H+ + 4e- -> 2H2O}$, 산화 $\ce{4Br- -> 2Br2 + 4e-}$ → $n=4$, $E^\circ_\text{전지}=1.229-1.077=0.152\ \text{V}$

풀이 2 순수한 액체는 넣지 않는다: $Q=\dfrac{1}{P_{\ce{O2}}[\ce{H+}]^4[\ce{Br-}]^4}=\dfrac{1}{(1)(0.20)^4(0.20)^4}=3.9\times10^5$

$E_\text{전지}=E^\circ_\text{전지}-\dfrac{0.0592}{n}\log Q=0.152-\dfrac{0.0592}{4}\log(3.9\times10^5)=$ $0.069\ \text{V}$

연습 문제 3은–카드뮴 전지의 표준 전지 전위

$25\ {}^\circ\text{C}$에서 $\ce{2Ag+(aq) + Cd(s) -> 2Ag(s) + Cd^2+(aq)}$의 $E^\circ_\text{전지}$를 계산하여라. (단, $\ce{Ag+ + e- -> Ag}$ $E^\circ=+0.799\ \text{V}$, $\ce{Cd^2+}/\ce{Cd}$ $E^\circ=-0.402\ \text{V}$)

풀이 1 환원 전극 $\ce{2Ag+ + 2e- -> 2Ag}$ ($+0.799\ \text{V}$), 산화 전극 $\ce{Cd -> Cd^2+ + 2e-}$ (표준 환원 전위 $-0.402\ \text{V}$)

$E^\circ_\text{전지}=E^\circ_\text{환원 전극}-E^\circ_\text{산화 전극}=0.799-(-0.402)=$ $+1.201\ \text{V}$

$\ce{Ag+}$ 반쪽 반응에 2를 곱해도 $E^\circ$는 그대로이다(세기 성질). 교과서 문제의 「$\ce{Cd(s) -> Cd^2+(aq) + 2e-}$ ($E^\circ=-0.402$ V)」의 값은 환원 전위이고, 반응식의 $\ce{Cd^2+(s)}$는 $(aq)$로 읽는다.

연습 문제 4균형 반응식 완성과 자발성

다음 반응의 균형 반응식을 완성하고, $E^\circ$ 값을 계산하여 반응의 자발성을 설명하여라. (표 Ⅲ-10 값)

(1) $\ce{Co(s) + H+(aq) -> Co^2+(aq) + H2(g)}$

산화 $\ce{Co -> Co^2+ + 2e-}$ ($-0.28\ \text{V}$), 환원 $\ce{2H+ + 2e- -> H2}$ ($0.00\ \text{V}$)

$\ce{Co(s) + 2H+(aq) -> Co^2+(aq) + H2(g)}$
$E^\circ=0.00-(-0.28)=$ $+0.28\ \text{V}$, 자발적

(2) $\ce{Hg2^2+(aq) -> Hg^2+(aq) + Hg(l)}$

산화 $\ce{Hg2^2+ -> 2Hg^2+ + 2e-}$ ($0.90\ \text{V}$), 환원 $\ce{Hg2^2+ + 2e- -> 2Hg}$ ($0.79\ \text{V}$)

$\ce{2Hg2^2+(aq) -> 2Hg^2+(aq) + 2Hg(l)}$
$E^\circ=0.79-0.90=$ $-0.11\ \text{V}$, 비자발적

(2)는 계수를 2로 나눈 문제의 식($\ce{Hg2^2+ -> Hg^2+ + Hg}$)도 원자 수와 전하가 맞는다. $E^\circ_\text{전지}>0$이면 $\Delta G^\circ<0$이므로 자발적이다.

연습 문제 5평형 상수로 $\Delta G^\circ$와 $E^\circ_\text{전지}$ 구하기

$25\ {}^\circ\text{C}$에서 $n=2$이고 $K=1\times10^5$일 때, 산화 환원 반응의 자유 에너지 변화 $\Delta G^\circ$와 전지 전위 $E^\circ_\text{전지}$는 얼마인가?

$\Delta G^\circ=-RT\ln K=-(8.314\ \text{J/(mol}\cdot\text{K)})(298\ \text{K})\ln(10^5)=$ $-2.85\times10^4\ \text{J/mol}$
$E^\circ_\text{전지}=-\dfrac{\Delta G^\circ}{nF}=\dfrac{2.85\times10^4}{2\times96485}=$ $0.148\ \text{V}$

검산: $E^\circ=\dfrac{0.0592}{n}\log K=\dfrac{0.0592}{2}\times5=0.148\ \text{V}$ — $K>1$이면 $\Delta G^\circ<0$, $E^\circ>0$
