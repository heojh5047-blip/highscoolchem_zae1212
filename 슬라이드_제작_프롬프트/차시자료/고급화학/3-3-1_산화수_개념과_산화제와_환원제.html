생각 열기산소가 없어도 산화일까?

마그네슘이 산소와 결합하는 반응은 산화이다. 그렇다면 산소가 전혀 없는 $\ce{2Na(s) + Cl2(g) -> 2NaCl(s)}$에서는 어느 것이 산화되었을까?

Q 「산소와 결합하는 반응만 산화이다」는 맞는 말일까?

→ 아니다. $\ce{Na}$은 산소 없이도 전자를 잃어 $\ce{Na+}$이 되므로 산화된다. 산화의 정의는 산소 → 전자 → 산화수로 넓어졌다.

Q 그러면 전자가 완전히 옮겨 가지 않는 공유 결합 물질(예: $\ce{H2 + Cl2 -> 2HCl}$)의 산화·환원은 어떻게 판단할까?

→ 공유 전자를 전기음성도가 큰 원자가 가진다고 보고 매긴 가상의 전하, 산화수로 판단한다.

1산화 환원 반응과 전자의 이동

원소에서 이온 결합 화합물이 만들어질 때는 먼저 중성 원자가 전자를 잃거나 얻어 이온이 되고, 그 뒤 이온 사이의 전기적 인력으로 이온 결합이 생긴다.

$\ce{Na -> Na+ + e-}$  (전자 잃음)    $\ce{Cl2 + 2e- -> 2Cl-}$  (전자 얻음)

Q $\ce{2Na + Cl2 -> 2NaCl}$에서 $\ce{Na}$이 잃은 전자 수와 $\ce{Cl2}$가 얻은 전자 수는?

→ 둘 다 $2$개로 같다. 전자는 생기거나 없어지지 않고 옮겨 갈 뿐이다.

산화 환원 반응은 잃은 전자 수와 얻은 전자 수가 같은 반응이다 — 원자 보존에 따른 질량 균형과 함께 전하 균형이 이루어진다.

2산화수의 개념

산화수는 분자나 이온 안의 결합에서 전기음성도가 큰 원자가 공유 전자를 완전히 차지한다고 가정할 때 각 원자가 가지는 가상의 전하이다.

이렇게 가정하면 원자가 가진 전자 수가 중성 원자일 때와 달라지므로, 각 원자는 $0$ 또는 양(+)·음(−)의 정수 산화수를 가진다.

Q 물 분자에서 $\ce{O}$와 $\ce{H}$의 산화수는?

→ 전기음성도가 큰 $\ce{O}$가 공유 전자쌍 두 개를 모두 가지면 전자가 $8$개($6$개보다 $2$개 많음) → $\ce{O}$ $-2$, 전자를 모두 내준 $\ce{H}$는 $+1$

산화수는 원래 전이 금속의 산화 상태를 나타내던 말이며, 산화수와 산화 상태는 구분하지 않고 쓴다. 산화수는 실제 전하가 아니라 전자의 이동을 따라가기 위한 「장부」이다.

Q 일산화 탄소 $\ce{CO}$에서 $\ce{C}$의 형식 전하와 산화수는?

→ 형식 전하: $4-2-\tfrac12\times6=-1$   산화수: 결합 전자 6개를 $\ce{O}$가 가지므로 $4-2=+2$

같은 원자라도 두 값은 다를 수 있다. 산화수는 형식 전하와는 무관하다.

확인 문제 01암모늄 이온의 질소

암모늄 이온 $\ce{NH4+}$에서 질소 원자의 형식 전하와 산화수를 각각 구하여라. (전기음성도 $\ce{N}>\ce{H}$)

형식 전하: 원자가 전자 $5$ − 비결합 전자 $0$ − $\tfrac12\times8$ $=+1$

산화수: 공유 전자 $8$개를 모두 $\ce{N}$이 가짐 → $5-8=-3$  (확인: $-3+4(+1)=+1$ = 이온의 전하)

형식 전하 $+1$, 산화수 $-3$

이온의 $+$ 전하를 형식 전하로는 질소가 지지만, 산화수로는 네 수소가 $+1$씩 나눠 가진다.

4산화수의 변화와 산화 환원 반응

어떤 원자의 산화수 변화는 그 원자가 가진 전자 수의 변화와 같다. 그래서 산화·환원을 두 가지로 정의할 수 있다.

Q $\ce{CuO(s) + H2(g) -> Cu(s) + H2O(l)}$에서 산화된 원자와 환원된 원자는?

→ $\ce{H}$: $0\rightarrow+1$ 산화, $\ce{Cu}$: $+2\rightarrow0$ 환원 ($\ce{O}$는 $-2$ 그대로)

Q $\ce{NaH}$에서 「$\ce{H}$는 $+1$」과 「$\ce{Na}$는 $+1$」이 부딪친다. 어느 규칙을 먼저 따를까?

→ 표의 수소 예외가 바로 이 경우이다. 알칼리 금속 $\ce{Na}$ $+1$, 총합 $0$ → $\ce{H}$ $-1$ (전기음성도가 큰 $\ce{H}$가 전자를 가진다)

7규칙으로 산화수 정하기

① 다이크로뮴산 이온 $\ce{Cr2O7^2-}$

$\ce{O}$는 $-2$, 총합은 이온의 전하 $-2$

$2x+7(-2)=-2$

$x=+6$

② 과망가니즈산 이온 $\ce{MnO4-}$

$\ce{O}$는 $-2$, 총합은 $-1$

$x+4(-2)=-1$

$x=+7$
순서 ① 값이 정해진 원소($\ce{F}$, 알칼리·알칼리 토금속, $\ce{H}$, $\ce{O}$)부터 적는다 → ② 총합 = 0 또는 이온의 전하로 식을 세운다 → ③ 남은 원자의 산화수를 구한다 → ④ 반응식 위에 적어 둔다.

같은 원소라도 화합물에 따라 산화수가 달라진다: $\ce{Mn}$은 $\ce{MnO4-}$ $+7$, $\ce{MnO2}$ $+4$, $\ce{Mn^2+}$ $+2$.

확인 문제 02밑줄 친 원자의 산화수

다음 화학종에서 표시한 원자의 산화수를 구하여라.

(1) $\ce{H2SO4}$의 $\ce{S}$  → $2(+1)+x+4(-2)=0$, $+6$

(2) $\ce{H2O2}$의 $\ce{O}$  → 과산화물, $2(+1)+2x=0$, $-1$

(3) $\ce{OF2}$의 $\ce{O}$  → $\ce{F}$가 $-1$, $x+2(-1)=0$, $+2$

(4) $\ce{Fe3O4}$의 $\ce{Fe}$  → $3x+4(-2)=0$, $+\tfrac83$

(4)는 평균 산화수이다. 실제로는 $\ce{Fe^2+}$ 1개와 $\ce{Fe^3+}$ 2개가 들어 있다($2+3+3=8$). 원자 하나의 산화수는 정수이다.

연결산화 환원 반응 계수 맞추기 — 두 가지 균형

반응식의 계수는 「원자 수가 같게」 맞추었다. 산화 환원 반응에서는 전자가 생기거나 없어지지 않고 주고받으며 보존되므로 하나를 더 살펴야 한다.

Q 오른쪽 위 반응식은 원자 수가 맞는다. 그런데도 맞지 않는 것은?

→ 전하: 왼쪽 $+1$, 오른쪽 $+2$. $\ce{Cu}$는 전자 2개를 잃는데 $\ce{Ag+}$ 하나는 전자 1개만 받는다.

$\ce{Ag+}$와 $\ce{Ag}$의 계수를 $2$로 → 화학량론적 균형(원자 수)과 전하의 균형을 함께 맞춘다.

8반쪽 반응법

반쪽 반응법: 전체 반응을 산화 반쪽 반응과 환원 반쪽 반응으로 나눈 뒤, 각 반쪽 반응에서 원자 수와 전하를 맞추고 더한다.

$\square\ce{Zn(s)} + \square\ce{H3O+(aq) -> }\square\ce{Zn^2+(aq)} + \square\ce{H2(g)} + \square\ce{H2O(l)}$

Q 환원 반쪽 반응에 왜 $2$를 곱할까?

→ $\ce{Zn}$이 잃는 전자는 $2$개, $\ce{H3O+}$ 하나가 얻는 전자는 $1$개 → 전자 수를 같게 하려고 $\times2$

$\ce{Zn(s) + 2H3O+(aq) -> Zn^2+(aq) + H2(g) + 2H2O(l)}$
균형 전체 반응 — 원자 수 $\ce{Zn}$ 1, $\ce{H}$ 6, $\ce{O}$ 2 · 전하 $+2=+2$

핵심: ① 산화 환원 반응은 두 반쪽 반응으로 나누어 쓸 수 있다 ② 반쪽 반응마다 원자와 전하가 보존된다 ③ 한쪽에서 잃은 전자를 다른 쪽이 동시에 얻는다. 화학 전지(Ⅲ-4)를 이해하는 바탕이다.

9산화수 변화로 계수 맞추기

산성 용액: $\ce{MnO4-(aq) + Fe^2+(aq) -> Mn^2+(aq) + Fe^3+(aq)}$ — 산화수의 증가량과 감소량이 같도록 계수를 정한다.

① 산화수 적기

$\ce{Mn}$ $+7\rightarrow+2$
$\ce{Fe}$ $+2\rightarrow+3$

② 증가 = 감소

$-5$와 $+1$ → $\ce{Fe^2+}$, $\ce{Fe^3+}$ 계수 $5$

③ O·H 맞추기

$\ce{O}$는 $\ce{H2O}$로, $\ce{H}$는 $\ce{H+}$로

④ 확인

원자 수, 전하 $+17=+17$

$\ce{MnO4-(aq) + 5Fe^2+(aq) + 8H+(aq) -> Mn^2+(aq) + 5Fe^3+(aq) + 4H2O(l)}$

1002 산화제와 환원제

산화와 환원은 쌍을 이루어 같은 수의 전자를 주고받으며 동시에 일어난다. 그래서 반응에는 전자를 잃는 화학종과 얻는 화학종이 반드시 함께 있다.

Q 「산화제는 산화되는 물질이다」는 옳을까?

→ 아니다. 산화제는 상대를 산화시키고 자신은 전자를 얻어 환원된다.

Q 산화제는 「$\ce{H}$」일까, 「$\ce{H3O+}$」일까?

→ 산화제·환원제는 화학종으로 말한다. 환원된 $\ce{H}$가 들어 있는 화학종 $\ce{H3O+}$가 산화제, $\ce{Zn}$이 환원제이다.

12강한 산화제와 환원제의 특성

  • 강한 산화제는 전자를 얻는 성질이 강하고, 강한 환원제는 전자를 내주는 성질이 강하다.
  • 같은 원자를 포함하는 화학종에서는 큰 산화수의 원자를 포함한 화학종이 강한 산화제, 작은 산화수의 원자를 포함한 화학종이 강한 환원제이다.

Q $\ce{MnO4-}$는 산화제와 환원제 가운데 무엇으로 쓰일까?

→ $\ce{Mn}$이 가장 큰 산화수 $+7$이라 더 늘 수 없고 줄기만 한다 → 강한 산화제

Q 산소의 산화수가 $-1$인 $\ce{H2O2}$는?

→ $0$($\ce{O2}$)으로 늘 수도, $-2$($\ce{H2O}$)로 줄 수도 있다 → 상대에 따라 산화제도 환원제도 된다. 다음 예제에서는 환원제!

예제 Ⅲ-9산성 용액에서 반응식 완성하기 (1)

산성 용액에서 다음 반응의 균형 반응식을 완성하고, 산화제와 환원제를 구분하여라.   $\ce{MnO4-(aq) + H2O2(aq) -> Mn^2+(aq) + O2(g)}$

풀이 1 산성 용액에서는 $\ce{H2O}$와 $\ce{H+}$를 써서 맞춘다. 두 반쪽으로 나눈다.
  환원 반쪽: $\ce{MnO4-(aq) -> Mn^2+(aq)}$    산화 반쪽: $\ce{H2O2(aq) -> O2(g)}$

풀이 2 $\ce{O}$는 $\ce{H2O}$로, $\ce{H}$는 $\ce{H+}$로, 전하는 $\ce{e-}$로 맞춘다.

$\ce{MnO4-(aq) + 8H+(aq) + 5e- -> Mn^2+(aq) + 4H2O(l)}$
전하: $-1+8-5=+2$ ✓
$\ce{H2O2(aq) -> O2(g) + 2H+(aq) + 2e-}$
전하: $0=+2-2$ ✓

예제 Ⅲ-9산성 용액에서 반응식 완성하기 (2)

환원 반쪽은 전자 $5$개를 얻고, 산화 반쪽은 $2$개를 잃는다.

전하 균형: 환원 반쪽 $\times2$, 산화 반쪽 $\times5$ → 전자 $10$개씩

더하면 $\ce{2MnO4- + 16H+ + 5H2O2 -> 2Mn^2+ + 8H2O + 5O2 + 10H+}$ → 양쪽의 $\ce{H+}$를 정리

$\ce{2MnO4-(aq) + 6H+(aq) + 5H2O2(aq) -> 2Mn^2+(aq) + 8H2O(l) + 5O2(g)}$
$\ce{Mn}$ 2, $\ce{O}$ 18, $\ce{H}$ 16 · 전하 $+4=+4$
산화제 $\ce{MnO4-}$ ($\ce{Mn}$ $+7\rightarrow+2$), 환원제 $\ce{H2O2}$ ($\ce{O}$ $-1\rightarrow0$)

13염기성 용액에서 맞추기 [보충]

염기성 용액에는 $\ce{H+}$가 거의 없다. 산성처럼 맞춘 뒤 남은 $\ce{H+}$ 수만큼 $\ce{OH-}$를 양쪽에 더해 $\ce{H2O}$로 바꾼다.   예: $\ce{MnO4- + I- -> MnO2 + IO3-}$

환원 반쪽($\times2$): $\ce{MnO4- + 4H+ + 3e- -> MnO2 + 2H2O}$

산화 반쪽: $\ce{I- + 3H2O -> IO3- + 6H+ + 6e-}$

더해 정리(산성 꼴): $\ce{2MnO4- + I- + 2H+ -> 2MnO2 + IO3- + H2O}$

양쪽에 $\ce{2OH-}$를 더하면 왼쪽 $\ce{2H+ + 2OH- -> 2H2O}$

교과서 본문은 산성 용액의 반쪽 반응법까지 다룬다. 이 장은 성취기준 해설(산성과 염기성 용액)을 따라 덧붙인 [보충]이다.
$\ce{2MnO4-(aq) + I-(aq) + H2O(l) -> 2MnO2(s) + IO3-(aq) + 2OH-(aq)}$
$\ce{Mn}$ 2, $\ce{I}$ 1, $\ce{O}$ 9, $\ce{H}$ 2 · 전하 $-3=-3$

확인 문제 03과망가니즈산 칼륨과 염산

$\ce{2KMnO4 + 16HCl -> 2KCl + 2MnCl2 + 5Cl2 + 8H2O}$에서 산화수가 변하는 원소와 그 변화를 쓰고, 산화제와 환원제를 고르시오. 또 $\ce{HCl}$ 16개 가운데 환원제로 작용한 것은 몇 개인가?

$\ce{Mn}$: $+7\rightarrow+2$ (환원)   $\ce{Cl}$: $-1\rightarrow0$ (산화)   $\ce{K}$, $\ce{H}$, $\ce{O}$는 변하지 않음

산화제 $\ce{KMnO4}$, 환원제 $\ce{HCl}$

$\ce{Mn}$ $2$개가 $5$개씩 → 전자 $10$개를 얻음 = $\ce{Cl}$ $10$개가 $1$개씩 잃음($\ce{5Cl2}$)

$16$개 중 $10$개 — 나머지 $6$개는 $\ce{KCl}$·$\ce{MnCl2}$의 $\ce{Cl-}$로 남는다(산으로 작용)

탐구 활동[필수 탐구] 산화 환원 반응의 응용 기술이 적용된 분야 조사

철이 녹스는 과정, 식물의 광합성, 산소로 하는 세포 호흡처럼 매우 많은 산화 환원 반응이 우리 삶을 떠받친다. 그 반응을 응용한 기술 가운데 하나가 화학 전지이다.

과정

  1. 모둠별로 응용 기술을 적용 분야별로 조사한다.
  2. 각 기술에 쓰이는 산화 환원 반응식을 찾고, 산화수 변화로 산화제와 환원제를 표시한다.
  3. 그 반응이 왜 그 기술에 알맞은지 토론한 뒤 발표한다.

조사 자료는 출처를 적는다. 반응식은 원자 수와 전하가 맞는지 확인한 뒤 발표 자료에 넣는다.

탐구 활동조사 결과 예시

분야기술산화 환원 반응환원제 → 산화제
에너지알칼리 전지$\ce{Zn + MnO2 + H2O -> ZnO + Mn(OH)2}$$\ce{Zn}$ → $\ce{MnO2}$
에너지수소 연료 전지$\ce{2H2 + O2 -> 2H2O}$$\ce{H2}$ → $\ce{O2}$
금속 제련용광로 제철$\ce{Fe2O3 + 3CO -> 2Fe + 3CO2}$$\ce{CO}$ → $\ce{Fe2O3}$
부식과 방지철의 부식, 아연 도금$\ce{2Fe + O2 + 2H2O -> 2Fe(OH)2}$ (아연이 먼저 산화되어 철을 보호)$\ce{Fe}$ → $\ce{O2}$
생명 현상세포 호흡$\ce{C6H12O6 + 6O2 -> 6CO2 + 6H2O}$ (광합성은 역방향)$\ce{C6H12O6}$ → $\ce{O2}$
분석·측정음주 측정기$\ce{2Cr2O7^2- + 3C2H5OH + 16H+ -> 4Cr^3+ + 3CH3COOH + 11H2O}$$\ce{C2H5OH}$ → $\ce{Cr2O7^2-}$

토론 정리 예 전지는 환원제((−)극 물질)와 산화제((+)극 물질)를 떼어 놓고 전자를 도선으로 흐르게 한 장치이다. 산화수 변화를 따라가면 어느 물질이 전자를 내주는지 바로 알 수 있다.

연습 문제 1산화와 환원의 정의

전자의 이동과 산화수 변화로 산화와 환원을 정의하여라.

산화: 전자를 잃는 반응 = 산화수가 증가하는 반응
환원: 전자를 얻는 반응 = 산화수가 감소하는 반응

산화와 환원은 같은 수의 전자를 주고받으며 동시에 일어난다(표 Ⅲ-5).

채점 요소(덱): ① 전자의 이동 ② 산화수의 변화 — 산화·환원 각각 두 관점을 모두 쓰면 완전한 답이다.

연습 문제 2산성 용액에서 반응식 완성 (1)

산성 용액에서 균형 반응식을 완성하고, 산화제와 환원제를 구분하여라.   1) $\ce{O2(g) + NO(g) -> NO3-(aq)}$

산화수: $\ce{O}$ $0\rightarrow-2$ (환원), $\ce{N}$ $+2\rightarrow+5$ (산화)

환원($\times3$): $\ce{O2 + 4H+ + 4e- -> 2H2O}$

산화($\times4$): $\ce{NO + 2H2O -> NO3- + 4H+ + 3e-}$

전자 $12$개씩 → 더하고 $\ce{H2O}$·$\ce{H+}$ 정리

$\ce{3O2(g) + 4NO(g) + 2H2O(l) -> 4NO3-(aq) + 4H+(aq)}$
$\ce{O}$ 12, $\ce{N}$ 4, $\ce{H}$ 4 · 전하 $0=0$
산화제 $\ce{O2}$, 환원제 $\ce{NO}$

연습 문제 2산성 용액에서 반응식 완성 (2)

산성 용액에서 균형 반응식을 완성하고, 산화제와 환원제를 구분하여라.   2) $\ce{CrO4^2-(aq) + N2O(g) -> Cr^3+(aq) + NO(g)}$

산화수: $\ce{Cr}$ $+6\rightarrow+3$ (환원), $\ce{N}$ $+1\rightarrow+2$ (산화)

환원($\times2$): $\ce{CrO4^2- + 8H+ + 3e- -> Cr^3+ + 4H2O}$

산화($\times3$): $\ce{N2O + H2O -> 2NO + 2H+ + 2e-}$

전자 $6$개씩 → 더하고 정리

$\ce{2CrO4^2-(aq) + 3N2O(g) + 10H+(aq) -> 2Cr^3+(aq) + 6NO(g) + 5H2O(l)}$
$\ce{Cr}$ 2, $\ce{O}$ 11, $\ce{N}$ 6, $\ce{H}$ 10 · 전하 $+6=+6$
산화제 $\ce{CrO4^2-}$, 환원제 $\ce{N2O}$

연습 문제 3알칼리 전지의 반쪽 반응 (1)

알칼리 전지 반응: $\ce{Zn(s) + MnO2(s) + H2O(l) -> ZnO(s) + Mn(OH)2(s)}$
1) 산화 반쪽 반응과 환원 반쪽 반응에서 반응물 $1\ \text{mol}$당 전자의 몰수비는 얼마인가?

산화수: $\ce{Zn}$ $0\rightarrow+2$, $\ce{Mn}$ $+4\rightarrow+2$

산화 반쪽: $\ce{Zn(s) + H2O(l) -> ZnO(s) + 2H+(aq) + 2e-}$

환원 반쪽: $\ce{2H+(aq) + MnO2(s) + 2e- -> Mn(OH)2(s)}$

반응물 $1\ \text{mol}$당 전자 $2\ \text{mol}$ — 몰수비 $2$

$\ce{Zn}$ $1\ \text{mol}$이 잃는 전자 $2\ \text{mol}$을 $\ce{MnO2}$ $1\ \text{mol}$이 얻는다 → 두 반쪽 반응의 전자 수가 같다($1:1$).

연습 문제 3알칼리 전지의 양적 관계 (2)

2) 아연 $9.00\ \text{g}$이 반응하였을 때 이산화 망가니즈와 물의 소모량은 각각 몇 g인가? (단, $\ce{Zn}$과 $\ce{MnO2}$의 화학식량은 각각 $65.41$, $86.94$이다.)

계수비 $\ce{Zn} : \ce{MnO2} : \ce{H2O}=1:1:1$

$n_{\ce{Zn}}=\dfrac{9.00\ \text{g}}{65.41\ \text{g/mol}}=0.1376\ \text{mol}$

$\ce{MnO2}$: $0.1376\ \text{mol}\times86.94\ \text{g/mol}=12.0\ \text{g}$

$\ce{H2O}$: $0.1376\ \text{mol}\times18.02\ \text{g/mol}=2.48\ \text{g}$

이산화 망가니즈 $12.0\ \text{g}$, 물 $2.48\ \text{g}$

교과서 풀이는 몰수를 $0.138\ \text{mol}$로 반올림한 뒤 곱해 $12.00\ \text{g}$, $2.49\ \text{g}$이다. 중간값을 반올림하지 않으면 위 값이 된다($\ce{H2O}$ 화학식량 $18.02$).
