## 1. 공통 (두 출판사)

### 1.1 범위 제한 (교육과정 성취기준 해설 — 반드시 지킴)
- Ⅰ 몰: **수치 계산에 치우치지 않고** 물질 양 표현의 편리성. 계수비 = 몰수비를 강조, 질량 관계는 몰수로 바꿔 풂.
- Ⅱ 쌍극자 모멘트는 **정성적**(크기 계산·단위 D 없음). 중심 원자는 **2·3주기 전형 원소 중 Be, B와 옥텟 규칙을 따르는 경우**로 한정 — $\ce{PCl5}$, $\ce{SF6}$, 확장 옥텟, 혼성 오비탈, 형식 전하, 공명 구조는 넣지 않는다(교과서가 읽기 자료로 쓴 것만 그 수준으로).
- Ⅲ 몰 농도는 평형 상수 이해에 필요한 정도만, **압력 평형 상수 $K_\mathrm{p}$는 다루지 않음**. 거시적 평형 특징과 동적 평형을 구분해서 다룸.
- Ⅳ 중화 반응의 양적 관계는 **강산–강염기로 한정**, **중화 적정 곡선은 다루지 않음**(pH–부피 곡선을 그리지 않는다. 「화학 반응의 세계」에서 다룸).
- 지도서 「지도상의 유의점」이 더 좁으면 그것을 따르고 plan.md 범위 점검 절에 적는다.

### 1.2 식 꼴·기호 (교과서 그대로)
- 몰: 물질의 양(mol) $=\dfrac{\text{입자 수}}{6.02\times10^{23}}=\dfrac{\text{질량(g)}}{\text{몰질량(g/mol)}}=\dfrac{\text{기체의 부피(L)}}{22.4\ \text{L/mol}}$(0 °C, 1 기압). 교과서가 $n$, $N$, $w$, $M$ 기호를 쓰면 그 기호로.
- 평형 상수 $K=\dfrac{[\ce{C}]^c[\ce{D}]^d}{[\ce{A}]^a[\ce{B}]^b}$, 반응 지수 $Q$(같은 꼴, 평형이 아닐 때), $Q<K$ 정반응 쪽, $Q=K$ 평형, $Q>K$ 역반응 쪽.
- 물의 이온화 상수 $K_\mathrm{w}=[\ce{H3O+}][\ce{OH-}]=1.0\times10^{-14}$(25 °C), $\text{pH}+\text{pOH}=14.00$(25 °C).
- **pH 정의식은 출판사마다 다르다**: 미래엔 $\text{pH}=-\log[\ce{H+}]$(물의 자동 이온화는 $\ce{H3O+}$로 쓰고 pH에서 $[\ce{H+}]$로 줄여 씀 — 교과서가 둘을 같다고 적은 문장을 그대로 둠), 비상 $\text{pH}=-\log[\ce{H3O+}]$. 덱 안에서 교과서 꼴 하나로.
- 몰농도 $M=\dfrac{\text{용질의 양(mol)}}{\text{용액의 부피(L)}}$, 단위 M(= mol/L). 중화 양적 관계 $nMV=n'M'V'$.
- **겹치는 글자**: $n$은 몰수와 **가수**($nMV=n'M'V'$의 $n$은 산·염기의 가수) — 중화 슬라이드에서 처음 나올 때 "가수 $n$"으로 적는다. $M$은 몰질량과 몰농도(그리고 단위 M) — 몰농도 기호로 쓸 때 "몰농도 $M$"을 함께. $V$는 기체 부피·용액 부피. $K$·$Q$는 평형, $K_\mathrm{w}$는 물.

### 1.4 오개념·예측 질문 (가이드 10.1 + 지도서 「오개념」 표지)
지도서의 "오개념" 상자는 해당 개념 슬라이드에 S6(예측 → 관찰 → 설명) 장으로 넣는다. 예: 계수를 질량비로 봄, 아래 첨자를 바꿔 계수 맞춤, 극성 결합 = 극성 분자, 평형에서 반응이 멈춤, 촉매가 평형을 이동시킴, 희석하면 pH가 7을 넘음.

## 2. 미래엔 「화학」 (과목 키 `화학_미래엔`)

### 2.1 교재 구조
- 대단원(Ⅰ–Ⅳ) → 중단원(1, 2) → 소단원(01–03). 대단원 도입(핵심 아이디어, 포트폴리오 안내) 2쪽 → 중단원 도입 1쪽(소단원 목록·도입 장면) → 소단원(도입 만화 질문 + ● 학습 목표 → 본문 → 소단원 마무리) → 중단원 끝 읽기(과학 마당·포트폴리오 이야기·포트폴리오 화학과 나의 미래) → 중단원 마무리(함께 풀어 보기 + 문항 + 스스로 점검하기) → 대단원 마무리(개념 정리·문항·서술형) → 과학 역량 키우기(과학 글쓰기) → 프로젝트.
- PDF는 대단원마다 따로: 교과서 쪽 = PDF 쪽 + `pdfOffset`(Ⅰ 9, Ⅱ 49, Ⅲ 93, Ⅳ 135). 지도서 쪽 = PDF 쪽 + `guideOffset`(Ⅰ 65, Ⅱ 119, Ⅲ 177, Ⅳ 231). 지도서는 차시별로 "교과서 N 쪽~M 쪽"을 머리에 단다.
- 대단원 도입·중단원 도입은 그 대단원·중단원의 **첫 소단원 덱 앞머리**에 넣는다(덱목록 `withUnitIntro`).

### 2.2 h2 표식 (교과서 이름)
- 활동: `탐구`(탐구 능력 표시와 함께, 실험 영상·모의실험 QR 포함), `해 보기`, `자료 읽기`, `연습 해 보기`(tag ex — "풀이 따라가기" 1·2·3 단계를 단계 공개), `확인하기`(tag q, 본문 중간 빈칸·O× 문항)
- 소단원 끝: `소단원 마무리` — `창의력 키우기`, `디지털 소양 키우기` 두 활동(tag)

### 2.3 문항 배분
중단원 마무리 문항은 쪽 옆 소단원 머리표에 따라 소단원 덱에 나눠 넣는다(덱목록 `review`). 머리표가 추출 텍스트에서 섞이므로 **PDF 쪽 이미지로 확인**한다. 추정 배분: Ⅰ-1 01–03 → 1-1-1, 04–10 → 1-1-2 / Ⅰ-2 01–05 → 1-2-1, 06–09 → 1-2-2 / Ⅱ-1 01–02 → 2-1-1, 03–09 → 2-1-2 / Ⅱ-2 01–03 → 2-2-1, 04–06 → 2-2-2, 07–10 → 2-2-3 / Ⅲ-1 01–02 → 3-1-1, 03–05 → 3-1-2, 06–08 → 3-1-3 / Ⅲ-2 머리표대로 3-2-1·3-2-2·3-2-3 / Ⅳ-1 01–05 → 4-1-1, 06–11 → 4-1-2 / Ⅳ-2 01–05 → 4-2-1, 06–09 → 4-2-2. 대단원 마무리 문항은 단원 마무리 덱에. 지도서 뒤쪽의 "중단원 형성 평가 문제", "대단원 고난도 문제"는 넣지 않는다(교사가 요청할 때만).

### 2.4 지도서 쓰는 법
지도서 표지어: `차시 도입을 위한 지도 방안`(도입 발문), `지도 방안`, `지도상의 유의점`(범위·주의), `오개념`, `예시 답안`(정답·결과 표 값), `평가 기준 예시`(탐구 결론 슬라이드의 점검 기준), `참고 자료`·`보충`(교사 메모 수준 — 화면에는 꼭 필요한 것만), `[활동 도움·유의 사항]`. 2단 편집이라 추출 텍스트에서 문장이 섞이므로 근거 문장은 PDF 쪽 이미지로 확인한다. 예시 답안 수치는 직접 검산해 쓴다.

### 2.5 스스로 정리 빈칸
중단원 마무리 첫 쪽의 「함께 풀어 보기」 빈칸 가운데 이 소단원 몫을 개념 지도로 옮겨 채운다(1-1-1 → 함께 풀어 보기 1번 묶음 …). 대단원 마무리 첫 쪽의 개념 정리는 단원 마무리 덱에서 전체를 다시 채운다.

## 3. 비상교육 「화학」 (과목 키 `화학_비상`)

### 3.1 교재 구조
- 대단원(Ⅰ–Ⅳ) → 소단원(01–04), 중단원 없음. 대단원 도입 2쪽 → 「단원을 여는 질문」 1쪽 → 소단원(학습 목표 → 본문 → 탐구·해 보기 → 과학 이야기 → 소단원 끝 「스스로 정리하기」(학습 전에는 / 학습 후에는)) → 「역량을 키우는 활동」 → 「대단원 마무리」(1단계 개념 이해·개념 정리 빈칸 / 2단계 개념 적용 문항 / 3단계 창의 탐구: 과학 글쓰기·포트폴리오 만들기) → 「직업 탐색하기」 → 「함께 소통하기」(쟁점 토론).

- 대단원 도입과 「단원을 여는 질문」은 그 대단원 첫 소단원 덱 앞머리에.

### 3.2 h2 표식 (교과서 이름)
- 활동: `탐구`(실험 가·나가 있으면 `탐구 가`, `탐구 나`), `해 보기`, `예제`(tag ex), `과학 이야기`, `디지털 활용`(QR 활동 — 실험실로 대신하거나 결과 예시)

- 소단원 끝: `스스로 정리하기`(학습 전/후 생각 비교 — 덱 마지막 장과 합침)

소단원 끝 문항이 따로 없다(추출 텍스트 기준 — 「학습 점검」 같은 소단원 끝 문항이 PDF에 있으면 그 덱에 넣는다). 대단원 마무리 2단계 「개념 적용」 문항은 문항 위 머리표(`| 화학과 우리 생활 |`처럼 소단원 개념 이름)로 소단원을 알 수 있으므로, **그 소단원 덱 끝에 '확인 01'처럼 넣고**(tag q), 단원 마무리 덱에서는 번호·정답 대응표로 한 장에 모은다. 3단계 창의 탐구는 단원 마무리 덱에만. 정답은 교과서 부록 정답과 해설(189쪽~)과 지도서를 대조하고 직접 검산.
