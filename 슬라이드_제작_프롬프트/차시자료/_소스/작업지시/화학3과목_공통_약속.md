# 화학 3과목 덱 공통 약속 (화학 · 물질과 에너지 · 화학 반응의 세계, 미래엔 · 비상)

공통.md와 함께 읽는다. 과목별 약속(`화학_약속.md`, `물질과에너지_약속.md`, `화학반응의세계_약속.md`)은 이 문서를 따르고 과목·출판사마다 다른 것만 적는다. 각 덱 plan.md 0절의 "덱 공통 약속"은 이 두 문서를 따르고, 덱에서 새로 정하는 것만 덧붙인다.

## 1. 파일·폴더·id

- 과목 키(`<과목>_<출판사>`)가 폴더 이름이다: 내용 `SRC/content/<과목 키>/<folder>/`, 빌드 `python build.py <과목 키>/<folder>`, 결과 `ROOT/차시자료/<과목 키>/<folder>.html`, 캡처 `SRC/_render/<과목 키>/<folder>/`.
- `meta.json`: `{"title": "<title>", "file": "<folder>", "header": "<header>"}` — 값은 덱목록.json 그대로.
- id 접두어는 덱목록의 `idPrefix`(예: 화학_미래엔 2-2-2 → `cm222-`, 화학_비상 2-3 → `cv23-`, 마무리 덱은 `…9-`). 덱 전용 CSS 클래스 `.cm222-…`, 실험실 이름 `cm222vsepr`처럼 접두어 + 낱말, SVG `<defs>` id는 `grad-cm222-07`처럼 접두어 + 슬라이드 번호(D5).
- 덱 하나 = 소단원 하나(덱목록 `decks[]`). `split`이 붙은 덱은 40장을 넘으면 `…a`/`…b` 두 덱으로 나누고(폴더 이름 끝에 `a`, `b`), 둘째 덱 첫머리에 앞 덱 요약 1장을 둔다.

## 3. h2 표식

표식 글은 **교과서 이름 그대로**(과목 약속 3절의 출판사별 목록). 클래스는 성격으로 고른다: 활동·탐구·읽기 `tag` · 연결·다시 보기 `tag alt` · 확인·문항·평가 `tag q` · 예제·연습 `tag ex` · 정리 `tag ink`. 성취기준 필수 탐구(S12)는 표식 뒤에 작은 글자 `[필수 탐구]`를 붙인다(예: `<span class="tag">탐구</span><span class="small c-muted">[필수 탐구]</span>`).

## 6. 표기 (가이드 C1–C12, M1–M13의 공통 적용)

- 화학식·이온·반응식은 `\ce{}`. 본문 글자 `H2O` 금지(자동 점검 C1). 물질 이름은 교과서 표기, 처음 나올 때 "이름($\ce{화학식}$)".
- 온도 `25\ {}^\circ\text{C}`, `298\ \text{K}`, 압력은 교과서 표기(미래엔·비상 모두 본문은 "기압", 계산식 단위는 `\text{atm}`이 섞임 — 덱 안에서 한 문맥에 하나로), 부피 `\text{L}`, `\text{mL}`, 농도 `\text{M}`, 몰랄 농도 `\text{m}`.
- 붙여쓰기: 두 출판사 모두 **전기음성도, 몰농도, 몰질량, 몰분율, 몰랄 농도**(몰랄 농도만 띄움). 교육과정 원문 인용(`.std`)만 "전기 음성도", "몰 농도".
- 가상 원소·물질: $\mathrm{X}$, $\mathrm{A}(g)$는 `\ce{A(g)}` 또는 `\mathrm{A}(g)` — 덱 안에서 하나로. 용기·자료 이름 (가), (나)는 글자 그대로.
- 계산 풀이(S8): 주어진 것 → 구할 것 → 관계식 → 계산(등호 맞춤 `aligned`) → 단위·유효 숫자. 몰 환산은 "질량 → 몰 → (계수비) → 몰 → 질량/부피/입자 수" 사다리.

## 7. 공통 상수 (M11 — 덱 plan.md 0절에 다시 적고, 문항이 다른 값을 주면 문항 값)

$N_\mathrm{A}=6.02\times10^{23}$ · 0 °C, 1 기압에서 기체 1 몰 = 22.4 L · $K_\mathrm{w}=1.0\times10^{-14}$(25 °C) · $R=0.082\ \text{atm}\cdot\text{L/(mol}\cdot\text{K)}$(교과서가 쓴 단위 꼴로) · $T(\text{K})=t({}^\circ\text{C})+273$ · 1 atm = 760 mmHg · 원자량은 문항 단서 또는 교과서 부록 주기율표 값(H 1, C 12, N 14, O 16, Na 23, Cl 35.5 등 교과서 값 그대로).

## 8. 탐구 슬라이드와 필수 탐구 (S7·S9·S11·S12)

- 탐구 하나 = 슬라이드 3–6장: ① 목표·필수 탐구 문장(`.std`) ② 준비물·안전(보호 장구, 주의 사항, 폐수 처리) ③ 과정(그림 단계 카드) ④ 결과 표(빈칸, 예시 값은 지도서 예시 답안·직접 계산) ⑤ 정리·결론(단계 공개) + 필요하면 ⑥ 실험실.
- 교과서 탐구 단계 이름(미래엔: 목표·과정·결과 및 정리·결론 도출·도움말·도움 자료 / 비상: 문제 인식·탐구 설계·탐구 수행·결과 정리·결론 도출)은 h3·작은 표식.
- **필수 탐구(덱목록 `requiredInquiry`)는 실험실을 반드시 만든다**(가이드 5.11 필수 실험실). 실험실은 탐구 활동 문장의 동사를 모두 구현하고, 결과 표가 실험실 조작으로 채워지게 한다. 교과서 탐구가 실제 실험이면 실험실은 "예측 → 수업 실험 → 데이터 입력·비교" 도구로 쓴다.
- 실험 영상(QR)·모의실험·스프레드시트 활동은 실험실로 대신하고, 원래 활동 이름을 표식에 남긴다.

## 9. 덱 끝 마무리 (모든 소단원 덱 공통)

- 끝에서 셋째부터: 이 소단원 몫 문항(과목 약속의 문항 배분) — 한 장에 한 문항(S2), 그림 + `.board` + 가운데 정답, 서술형은 예시 답안과 채점 요소.
- 끝에서 둘째 장 「스스로 정리」: 교과서의 정리 쪽(미래엔 「화학」 중단원 마무리 "함께 풀어 보기", 미래엔 진로 과목·비상 "대단원 마무리" 첫 쪽의 개념 정리)을 본뜬 **개념 지도·빈칸**에서 이 소단원 몫만 채운다(단계 공개). 다른 덱 몫은 흐린 점선 노드. 교과서 빈칸이 없으면 덱이 핵심 화학식·정의로 빈칸을 만든다. h2 표식 `스스로 정리`(교과서 이름이 있으면 그 이름).
- 마지막 장 「스스로 점검하기」(비상은 「스스로 정리하기」를 함께): 지식·이해 / 과정·기능 / 가치·태도 체크 칸 + 항목마다 점검 질문과 단계 공개 답 + 다음 시간 도입 질문. `.chips.sm .chk`(18px)는 쓰지 않는다.
- 단원 마무리 덱(`…-M`): 대단원 마무리 개념 정리 전체 → 모든 문항(이미 소단원 덱에 넣은 문항은 번호·제목·소단원 덱·정답 대응표로 한 장에 모으고, 아직 안 쓴 문항만 한 장씩) → 과학 글쓰기·역량 활동·함께 소통하기·직업 탐색·프로젝트(활동 지시 + 예시 결과).
