연결원자 수만 맞추면 될까?

$\ce{Cu + Ag+ -> Cu^2+ + Ag}$

양쪽의 $\mathrm{Cu}$ 원자 수와 $\mathrm{Ag}$ 원자 수는 같다.

Q 이 반응식은 완성된 것일까?

전하 합

왼쪽 +1, 오른쪽 +2 — 다르다.

전자 수

구리가 잃은 전자 2개, 은 이온이 얻은 전자 1개 — 다르다.

물질이 잃은 총 전자 수 = 얻은 총 전자 수가 되도록 맞춘다: $\ce{Cu + 2Ag+ -> Cu^2+ + 2Ag}$

5반쪽 반응식으로 반응식 완성하기

산화 반응과 환원 반응을 분리하여 나타낸 반응식을 반쪽 반응식이라고 한다. 예: $\ce{Fe^3+ + Cu -> Fe^2+ + Cu^2+}$

① 나누고 원자 수 맞추기

산화 $\ce{Cu -> Cu^2+}$
환원 $\ce{Fe^3+ -> Fe^2+}$

② 전자로 전하 맞추기

$\ce{Cu -> Cu^2+ + 2e-}$
$\ce{Fe^3+ + e- -> Fe^2+}$

③ 전자 수 같게

$\ce{Cu -> Cu^2+ + 2e-}$
$\ce{2Fe^3+ + 2e- -> 2Fe^2+}$

④ 두 식 더하기

$\ce{2Fe^3+ + Cu -> 2Fe^2+ + Cu^2+}$

$\ce{Cu}$ 1 mol은 전자 2 mol을 잃고, $\ce{Fe^3+}$ 1 mol은 전자 1 mol을 얻는다 → $\ce{Cu}$ 1 mol당 $\ce{Fe^3+}$ 2 mol이 반응한다. (연계 「화학」 화학의 언어 — 양적 관계)

연습 해 보기$\ce{Fe^2+ + MnO4- + H+ -> Fe^3+ + Mn^2+ + H2O}$ ①

1 산화 반응과 환원 반응으로 나누고, 원자 수가 같도록 계수를 맞춘다.

산화 $\ce{Fe^2+ -> Fe^3+}$

환원 $\ce{MnO4-}$ + ( 8 ) $\ce{H+ -> Mn^2+}$ + ( 4 ) $\ce{H2O}$

2 화살표 양쪽의 전하량이 같도록 전자를 더한다.

산화 $\ce{Fe^2+ -> Fe^3+ + e-}$

환원 왼쪽 $(-1)+8(+1)=+7$, 오른쪽 $+2$ → ( 5 ) $\ce{e-}$를 왼쪽에

$\ce{MnO4- + 8H+ + 5e- -> Mn^2+ + 4H2O}$

연습 해 보기$\ce{Fe^2+ + MnO4- + H+ -> Fe^3+ + Mn^2+ + H2O}$ ②

3 이동한 전자 수가 같도록 계수를 맞춘다.

산화 ( 5 ) $\ce{Fe^2+ ->}$ ( 5 ) $\ce{Fe^3+}$ + ( 5 ) $\ce{e-}$

4 두 반쪽 반응을 더하여 하나의 반응식으로 만든다.

$\ce{5Fe^2+ + MnO4- + 8H+ -> 5Fe^3+ + Mn^2+ + 4H2O}$
확인왼쪽오른쪽
1. 원자의 종류와 수Fe 5 · Mn 1 · O 4 · H 8Fe 5 · Mn 1 · O 4 · H 8
2. 총전하량$5(+2)+(-1)+8(+1)=+17$$5(+3)+(+2)=+17$

$\mathrm{Mn}$ +7 → +2 (5 감소)

$\mathrm{Fe}$ +2 → +3 (1 증가) × 5

증가량 = 감소량

환원 $\ce{BrO3- + 6H+ + 6e- -> Br- + 3H2O}$  ($\mathrm{Br}$ +5 → −1)

$\ce{BrO3- + 6I- + 6H+ -> Br- + 3I2 + 3H2O}$

확인하기반쪽 반응식과 반응식 완성

2 다음 산화·환원 반응식을 완성해 보자.   $\ce{Cl- + Cr2O7^2- + H+ -> Cl2 + Cr^3+ + H2O}$

환원 $\ce{Cr2O7^2- + 14H+ + 6e- -> 2Cr^3+ + 7H2O}$

$\ce{6Cl- + Cr2O7^2- + 14H+ -> 3Cl2 + 2Cr^3+ + 7H2O}$

소단원 마무리비유로 설명하고, 생활에서 찾기

창의력 키우기

"산화와 환원은 항상 동시에 일어나며, 같은 물질이 반응에 따라 산화제도 될 수 있고 환원제도 될 수 있다." 이 특징을 설명하는 비유를 들어 보자.

예: 시소 — 한쪽이 내려가면 다른 쪽은 반드시 올라간다(동시성). 중간 키 학생은 큰 친구와 서면 작은 쪽, 작은 친구와 서면 큰 쪽이 된다(상대적 세기).

디지털 소양 키우기

주변에서 일어나는 다양한 산화·환원 반응에서 산화제와 환원제를 찾고, 공유 플랫폼을 활용하여 공유해 보자.

예: 손난로(철 — 환원제, 산소 — 산화제), 표백제, 사과의 갈변. 사진에 사람이 나오지 않게 하고, 자료의 출처를 밝힌다.
