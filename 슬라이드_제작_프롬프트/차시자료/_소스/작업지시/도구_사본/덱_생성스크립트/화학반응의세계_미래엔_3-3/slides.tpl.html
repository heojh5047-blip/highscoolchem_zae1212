01 탄소 원자 사이의 이중 결합

에틸렌(에텐) $\ce{CH2=CH2}$ — 탄소 원자 사이에 결합이 두 개 있다.

01·02 서로 반응하는 작용기

$\ce{-OH}$ 하이드록시기 $\ce{-COOH}$ 카복실기

작용기는 탄소 화합물의 성질을 정하고, 화학 반응에서 다른 작용기로 바뀌기도 한다(02).

Q 작은 분자 두 개가 이어지려면 무엇이 필요할까?

새 결합을 만들 자리 — 이중 결합 하나가 끊어지거나, 두 작용기가 반응해 작은 분자가 빠지면서 이어진다.

이 두 길이 오늘 배울 첨가 중합과 축합 중합이다.

1단위체와 고분자

우리 몸을 이루는 단백질이나 우리가 흔히 쓰는 플라스틱은 작은 분자들이 반복적으로 결합하여 거대한 분자를 이룬 것이다.

작은 분자들이 반복적으로 결합하여 형성된 거대한 분자를 고분자라 하고, 고분자를 이루는 작은 분자를 단위체라고 한다.

1에틸렌 → 폴리에틸렌: 현상 · 입자 · 기호

① 현상

비닐봉지 — 에틸렌은 기체, 폴리에틸렌은 질긴 고체

② 입자

에틸렌 분자 3개 → 공유 결합으로 이어진 사슬 (검정 C, 흰색 H)

③ 기호

$n\,\ce{CH2=CH2} \longrightarrow \left[\ce{-CH2-CH2\bond{-}}\right]_n$

$n$: 반복되는 수(수천 이상)

Q 고분자는 단위체 분자가 많이 섞여 있는 혼합물일까?

아니다. 단위체가 공유 결합으로 이어진 하나의 거대한 분자이다. 그래서 단위체와 성질이 다르다.

→ 단위체의 이중 결합(맞잡은 두 손) 중 하나가 끊어지고, 다른 단위체와 단일 결합을 이루며 고분자가 된다. 떨어져 나가는 것이 없다.

2 (나)처럼 단위체가 결합하여 고분자가 될 때 일어나는 변화를 설명해 보자.

→ 단위체의 작용기(양 끝 주황·보라)가 서로 반응하여 간단한 분자가 떨어져 나가고, 다른 단위체와 결합을 이루며 고분자가 된다.

3단백질 — 아미노산의 축합 중합

단백질은 피부와 근육을 구성하는 성분으로 생명 현상에서 중요한 역할을 한다.

단백질의 단위체는 아미노산으로, 20여 가지가 있다.

$\ce{R}$−(알킬기)는 아미노산의 종류에 따라 달라진다. 탄화수소에서 수소 하나가 없는 것으로, 다른 탄소 사슬에 연결된다.

연계 통합과학1 ‘물질과 규칙성’

원자 수 확인 ($\ce{R}$ = $\ce{H}$인 글리신) $\ce{2C2H5NO2 -> C4H8N2O3 + H2O}$ — C 4 = 4, H 10 = 8 + 2, N 2 = 2, O 4 = 3 + 1

3아미노산의 배열 순서가 단백질을 결정한다

아미노산 사이의 결합을 펩타이드 결합이라 하고, 아미노산 여러 개가 길게 연결된 것을 폴리펩타이드라고 한다. 아미노산이 무수히 많이 연결되어 단백질을 이룬다.

아미노산이 어떤 순서로 배열하여 결합하는지에 따라 수많은 종류의 단백질이 만들어진다.

Q 아미노산 3가지로 아미노산 3개가 이어진 사슬을 만들면 몇 가지가 나올까? (같은 것을 여러 번 써도 된다)

→ $3\times3\times3=27$가지 — 20여 가지 아미노산이 수백 개 이어지면 종류는 셀 수 없이 많다.

Q 단백질이 만들어지는 중합 반응은 첨가와 축합 중 어느 것일까?

→ 축합 중합 — 아미노산 사이에서 물이 떨어져 나간다.

3핵산 — 뉴클레오타이드의 축합 중합

핵산은 생물의 유전 정보가 들어 있는 물질로 DNA와 RNA가 있다. 핵산의 단위체는 뉴클레오타이드이며, 뉴클레오타이드는 인산, 당, 염기로 구성된다.

한 뉴클레오타이드의 인산 부분과 다른 뉴클레오타이드의 당 부분이 축합 중합 반응으로 결합하여 핵산의 골격을 이룬다.

당 부분이 디옥시라이보스이면 DNA, 라이보스이면 RNA이다.

Q 골격이 만들어질 때 떨어져 나가는 분자는?

→ 물 — 그래서 축합 중합이다.

2 단백질과 핵산은 단위체의 ( 첨가 / 축합 ) 중합 반응으로 고분자가 된다. → 축합

3플라스틱 ① 폴리에틸렌(PE)

플라스틱은 대표적인 합성 고분자로, 가볍고 튼튼하며 다양한 물건을 대량으로 만들 수 있어 널리 쓰인다. 단위체의 종류에 따라 생성되는 플라스틱의 종류가 매우 다양하다.

비닐봉지, 완충 포장재에 쓰이는 폴리에틸렌(PE)은 에틸렌(에텐)의 첨가 중합 반응으로 생성된다.

고분자의 구조식 반복되는 부분을 괄호로 묶고 $n$을 붙여 간략하게 나타내기도 한다.

음료수병과 일회용 컵에 쓰이는 PET는 테레프탈산과 에틸렌 글리콜의 축합 중합 반응으로 생성된다.

3고무 — 천연고무와 합성 고무

천연고무는 고무나무의 수액을 추출하여 얻는 고분자로, 탄성과 방수성이 좋아 매트리스 등에 쓰인다. 단위체는 아이소프렌이며, 첨가 중합 반응으로 생성된다.

수액을 얻는 데 시간이 오래 걸리고 생산량이 한정적이어서, 과학자들은 아이소프렌과 비슷한 구조의 단위체로 합성 고무를 만들었다. 잠수복의 네오프렌은 클로로프렌의 첨가 중합 반응으로 생성된 합성 고무이다.

Q 두 구조식에서 다른 부분은 어디일까?

→ 천연고무의 $\ce{-CH3}$ 자리에 네오프렌은 $\ce{-Cl}$이 있다. 원자 수(덱 보충): 반복 단위 $\ce{C5H8}$ = 아이소프렌 $\ce{C5H8}$, $\ce{C4H5Cl}$ = 클로로프렌 $\ce{C4H5Cl}$

확인하기플라스틱과 고무

1 폴리에틸렌의 단위체는 ( 에틸렌(에텐) )이다.

2 음료수병에 쓰이는 폴리(에틸렌 테레프탈레이트)는 ( 첨가 / 축합 ) 중합으로 만들어진다. → 축합

소단원 마무리‘폴리’의 뜻 · 몸으로 표현하는 중합 반응

창의력 키우기

‘폴리(poly)’의 어원을 찾아보고, 고분자의 이름에 대부분 ‘폴리’라는 말이 들어 있는 까닭을 설명해 보자.

예시 폴리는 그리스어에서 온 말로 ‘많은’이라는 뜻이다. 고분자는 단위체가 많이 반복 결합한 분자이므로 ‘폴리 + 단위체 이름’으로 부른다.

에틸렌 → 폴리에틸렌, 스타이렌 → 폴리스타이렌, 펩타이드 → 폴리펩타이드

디지털 소양 키우기

단위체가 중합 반응을 해 고분자를 생성하는 반응을 친구들과 함께 몸짓으로 표현해 보고, 사진이나 영상을 찍어 공유 플랫폼으로 공유해 보자.

예시 대본 첨가 중합: 두 손을 맞잡은 짝(이중 결합)이 한 손을 놓고 옆 친구와 손을 잡아 줄이 길어진다. 축합 중합: 양손에 공(작용기)을 든 친구들이 손을 잡을 때마다 공 두 개를 바구니(물 분자)에 내려놓는다.
