Q 흡열 반응도 저절로 일어날 수 있을까?

그렇다 — 반응의 방향을 정하는 요인은 엔탈피 하나가 아니다. 또 하나의 요인 = 엔트로피

1자발적 변화

열은 온도가 높은 곳에서 낮은 곳으로 이동하고, 물은 위에서 아래로 흐른다. 이처럼 외부의 지속적인 도움 없이 스스로 일어나는 변화를 자발적 변화라고 한다.

비자발적 변화

물이 수소와 산소로 분해되는 현상은 자발적이지 않다.

$\ce{2H2O(l) -> 2H2(g) + O2(g)}$

전류를 흘려 주면 분해되지만, 전류가 공급되지 않으면 분해되지 않는다.

Q 열이 차가운 물체에서 뜨거운 물체로 저절로 이동할 수 있을까?

없다 — 자발적 변화의 반대 방향은 저절로 일어나지 않는다.

→ 좁은 곳에 모여 있던 입자들이 넓은 공간으로 퍼져 나가 점점 더 무질서한 상태가 된다.

2 (가)와 (나)에서와는 반대로 냄새나 잉크가 한쪽으로 다시 모이는 현상이 일어날 수 있는지 토의해 보자.

→ 저절로는 일어나지 않는다. 퍼진 입자들이 한곳에 다시 모일 확률은 매우 작다.

1무질서해지는 변화는 자발적이다

냄새 분자가 공기 중으로, 잉크 분자가 물속으로 퍼져 나갈 때 점점 더 무질서한 상태가 된다.

이처럼 무질서해지는 변화는 자발적으로 일어나지만, 그 반대의 현상은 자발적으로 일어나지 않는다.

오개념 바로잡기 자발적 변화가 냄새나 잉크가 확산하는 것처럼 항상 빠르게 일어나는 것은 아니다. 철이 부식되는 것처럼 천천히 진행되는 자발적 변화도 있다.

Q 자발적 변화라면 빠르게 일어날까?

아니다 — 자발성은 변화의 방향, 빠르기는 반응 속도(Ⅳ 단원)의 문제이다.

2엔트로피 — 무질서도의 척도

오랜 기간 수많은 관찰을 통해 과학자들은 자발적 변화에서 공통적으로 엔트로피라고 부르는 성질이 증가하는 경향이 있음을 알게 되었다.

엔트로피(entropy)란 무질서도를 나타내는 척도로, 기호 $S$로 표시한다.

엔트로피가 증가한다 = 질서 있는 상태에서 무질서한 상태가 된다.

Q 자연계의 변화는 왜 무질서해지는 방향으로 진행할까?

확률과 관계가 있다 — 어떤 상태가 무질서해진다는 것은 그 상태로 존재할 확률이 크다는 뜻이다.

2무질서도와 확률 — 동전 4개 던지기

동전 4개를 동시에 던지면 나올 수 있는 경우는 $2^4=16$가지이다.

모두 같은 면이 나올 확률은?

$\dfrac{1+1}{16}=\dfrac{2}{16}=\dfrac{1}{8}$

앞면과 뒷면이 섞여 나올 확률은?

$\dfrac{4+6+4}{16}=\dfrac{14}{16}=\dfrac{7}{8}$

Q 동전의 개수가 늘어나면 모두 같은 면이 나올 확률은 어떻게 될까?

점점 작아진다 — 동전 10개이면 $2\div2^{10}\approx0.2\ \%$뿐이다. 섞인(무질서한) 상태가 압도적으로 많이 나온다.

3엔트로피 변화 $\Delta S$

어떤 변화가 일어날 때 엔트로피 변화($\Delta S$)는 최종 상태의 엔트로피에서 초기 상태의 엔트로피를 뺀 값이다.

$\Delta S=S_\text{최종}-S_\text{초기}$
$S_\text{최종}$: 최종 상태의 엔트로피 · $S_\text{초기}$: 초기 상태의 엔트로피

엔트로피가 증가하면 $\Delta S>0$

엔트로피가 감소하면 $\Delta S<0$

엔트로피가 증가하는 변화 — 다음 세 가지를 차례로 알아보자.

㉠ 분자의 움직임이 활발해질 때

㉡ 순수한 두 물질이 섞일 때

㉢ 입자 수가 증가할 때

Q 이 세 경우에 엔트로피는 어떻게 변할까? → 모두 증가한다($\Delta S>0$)

3㉠ 분자의 움직임이 활발해질 때

물질이 열을 흡수하여 온도가 높아지거나 상태 변화가 일어나면 분자 운동이 활발해져 무질서도가 증가 → 엔트로피 증가.

Q 고체, 액체, 기체의 엔트로피 크기 순서는? → $S_\text{고체}<S_\text{액체}<S_\text{기체}$

Q 융해·기화와 액화·응고에서 $\Delta S$의 부호는? → 융해·기화 $\Delta S>0$, 액화·응고 $\Delta S<0$

드라이아이스의 승화
$\ce{CO2(s) -> CO2(g)}$
고체가 바로 기체가 되므로 엔트로피가 크게 증가한다.

3㉡ 순수한 두 물질이 섞일 때

오개념 바로잡기 용해 과정에서 엔트로피가 항상 증가하는 것은 아니다. 기체가 용해하는 과정에서는 엔트로피가 감소한다.

순수한 두 물질이 섞이면 무질서도가 커지므로 엔트로피가 증가한다.

설탕이 물에 녹을 때는 설탕 분자가 더 넓은 공간으로 퍼지므로 무질서해진다. → 고체나 액체의 용해 과정에서 엔트로피 증가

입자들이 농도나 밀도 차에 의해 액체나 기체 속으로 확산할 때도 엔트로피가 증가한다.

Q 탄산음료를 만들 때 이산화 탄소가 물에 녹는 과정 $\ce{CO2(g) -> CO2(aq)}$의 $\Delta S$ 부호는?

$\Delta S<0$ — 자유롭게 움직이던 기체 분자가 용액 속에 갇힌다

3㉢ 입자 수가 증가할 때

$\ce{CaCO3(s) -> CaO(s) + CO2(g)}$

화학 반응에서 입자 수가 증가하면 엔트로피가 증가한다.

특히 기체의 엔트로피는 액체나 고체보다 훨씬 크므로, 기체 분자 수의 증가는 엔트로피 증가에 매우 큰 영향을 미친다.

엔트로피와 물질의 양 엔트로피는 물질의 양에 의존한다 — 분자의 수 또는 물질의 양이 늘어나면 증가한다.

Q 탄산 칼슘의 열분해에서 엔트로피가 크게 증가하는 까닭은? → 입자 수가 늘고 기체($\ce{CO2}$)가 생성되기 때문

해 보기엔트로피 변화의 부호 예측하기

다음 변화가 일어날 때 엔트로피가 어떻게 변하는지 쓰고, 그렇게 답한 까닭을 써 보자.

① 공기 중의 수증기가 얼어 눈 결정이 된다.

$\ce{H2O(g) -> H2O(s)}$

→ 감소($\Delta S<0$) 자유롭게 움직이던 기체 분자가 규칙적인 고체가 된다.

② 아연과 염산이 반응하여 수소 기체가 발생한다.

$\ce{Zn(s) + 2HCl(aq) -> ZnCl2(aq) + H2(g)}$

→ 증가($\Delta S>0$) 물질의 양은 약간 줄지만, 기체가 생성되는 영향이 더 크다.

③ 질소와 수소를 반응시켜 암모니아를 합성한다.

$\ce{N2(g) + 3H2(g) -> 2NH3(g)}$

→ 감소($\Delta S<0$) 기체 분자 수가 4에서 2로 줄어든다.

확인하기엔트로피 변화 확인하기

1 에탄올이 증발하는 것은 엔트로피가 ( 증가하는, 감소하는 ) 변화이다.

증가하는 — 액체가 기체가 된다

2 $\ce{2A(g) -> 2B(g) + C(g)}$의 반응에서 엔트로피 변화($\Delta S$)의 부호를 예측해 보자.

기체 분자 수: 반응물 2 → 생성물 3, 기체 분자 수가 증가한다.

$\Delta S>0$

연결자발성을 정하는 두 가지 경향

물질은 엔탈피가 낮을수록 안정해.

화학 반응이 일어나면 물질이 가진 엔탈피와 엔트로피가 달라진다. 자연계에서 일어나는 변화는 두 경향을 가진다.

엔탈피를 낮추려는 방향

$\Delta H<0$

안정해지려는 경향

엔트로피를 높이려는 방향

$\Delta S>0$

무질서해지려는 경향

→ 이 두 요인이 함께 작용하여 특정한 반응의 자발성을 결정한다.

계와 주위

반응이 직접 일어나는 영역 또는 물질을 계, 계를 제외한 외부의 모든 영역을 주위라고 한다. 여기에서는 계의 엔탈피와 엔트로피만 다룬다.

Q 두 경향이 서로 반대 방향이면 자발성은 어떻게 정해질까?

영향이 더 큰 쪽이 자발성을 결정한다.

4엔탈피와 엔트로피 변화가 모두 자발성에 유리한 반응

이산화 질소의 분해   $\ce{2NO2(g) -> N2(g) + 2O2(g)}\quad\Delta H=-66.4\ \text{kJ}$

엔탈피 감소($\Delta H<0$) → 자발성에 유리

기체 분자 수가 증가하여 엔트로피 증가($\Delta S>0$) → 유리

화살표 길이는 영향의 크고 작음만 나타낸다(크기 비례 아님).

Q 이 반응은 자발적일까?

두 요인 모두 유리 → 항상 자발적이다.

4엔탈피와 엔트로피 변화가 모두 자발성에 불리한 반응

과산화 수소의 생성   $\ce{2H2O(l) + O2(g) -> 2H2O2(l)}\quad\Delta H=+196.4\ \text{kJ}$

물과 산소가 반응하여 과산화 수소가 되는 반응에서 두 요인을 판단해 보자.

엔탈피 증가($\Delta H>0$) → 자발성에 불리

반응이 진행될수록 기체의 양이 줄어들어 엔트로피가 크게 감소($\Delta S<0$) → 불리

반대로 과산화 수소는 물과 산소로 저절로 분해되는 경향이 있다. → 소단원 마무리

화살표 길이는 영향의 크고 작음만 나타낸다(크기 비례 아님).

Q 이 반응은 자발적일까?

두 요인 모두 불리 → 항상 비자발적이다.

Q 역반응 $\ce{2H2O2(l) -> 2H2O(l) + O2(g)}$은? → $\Delta H<0$, $\Delta S>0$ → 항상 자발적

4엔탈피 변화가 자발성에 유리한 반응

산과 염기의 중화 반응   $\ce{H+(aq) + OH-(aq) -> H2O(l)}\quad\Delta H=-55.8\ \text{kJ}$

전체 입자 수가 감소하여 엔트로피 감소($\Delta S<0$) → 불리

엔탈피가 더 크게 낮아짐($\Delta H<0$) → 유리, 영향이 더 큼

엔탈피 감소 영향이 더 큰 경우

(비교) 엔탈피 감소 영향이 더 작은 경우 → 비자발적

엔탈피를 낮추려는 경향이 엔트로피가 감소하는 경향보다 크면 반응이 자발적으로 일어난다.

4엔트로피 변화가 자발성에 유리한 반응

휴대용 냉각 팩   $\ce{NH4NO3(s) -> NH4+(aq) + NO3-(aq)}\quad\Delta H=+25\ \text{kJ}$

엔탈피 증가($\Delta H>0$) → 불리

입자 수가 늘고 이온들이 물 분자에 섞여 들어가 입자 운동이 자유로워짐 → 엔트로피 크게 증가($\Delta S>0$) → 유리, 영향이 더 큼

엔트로피 증가 영향이 더 큰 경우

(비교) 엔트로피 증가 영향이 더 작은 경우 → 비자발적

엔트로피를 높이려는 경향이 엔탈피가 증가하는 경향보다 크면 자발적 → 흡열 반응도 저절로 일어날 수 있다

Q 발열 반응이면 모두 자발적일까?

아니다 — 엔트로피 변화가 함께 작용한다. 발열 반응이 모두 자발적인 것은 아니고, 흡열 반응도 자발적일 수 있다.

창의력 키우기

시약용이나 소독용 과산화 수소에는 과산화 수소의 분해를 늦추는 물질인 인산을 첨가하기도 한다. 이처럼 과산화 수소에 인산을 첨가하는 까닭을 화학 반응의 자발성을 이용하여 설명해 보자.

→ $\ce{2H2O2(l) -> 2H2O(l) + O2(g)}$은 엔탈피가 감소하고($\Delta H<0$) 기체가 생겨 엔트로피가 증가하므로($\Delta S>0$) 항상 자발적이다. 보관하는 동안에도 저절로 분해되므로, 인산을 넣어 분해를 늦춰 농도를 오래 유지한다.

디지털 소양 키우기

일상생활 속에서 엔트로피가 증가하는 변화를 찾아 사진을 찍고, 공유 플랫폼을 활용하여 공유해 보자.

→ 예: 장작이 탄다, 도미노가 무너진다, 컵 속 얼음이 녹는다, 커피에 각설탕이 녹는다

사진마다 "무엇이 더 무질서해졌는지" 한 줄 설명을 함께 올린다.

대단원 마무리 08엔트로피에 대한 설명

엔트로피에 대한 설명으로 옳지 않은 것은?

① 무질서도를 나타내는 척도이다. ② 엔트로피의 크기는 물질의 양과 관계가 없다. ③ 순수한 두 물질이 섞일 때 엔트로피가 증가한다. ④ 온도가 높아져 분자 운동이 활발해지면 엔트로피가 증가한다. ⑤ 기체가 더 넓은 공간으로 퍼져 나갈 때 엔트로피가 증가한다.

엔트로피는 물질의 양에 의존하는 성질 — 분자의 수 또는 물질의 양이 늘어나면 엔트로피는 증가한다.

대단원 마무리 11서술형흡열 반응이 자발적으로 일어나는 까닭

휴대용 냉각 팩 속에서 질산 암모늄이 물에 용해되는 반응은 흡열 반응이며, 자발적으로 일어난다. 이 반응에서 나타나는 엔트로피 변화를 입자 관점에서 설명하고, 이를 근거로 흡열 반응이 어떻게 자발적으로 일어날 수 있는지 설명해 보자.

예시 답안 고체 질산 암모늄이 물에 녹아 $\ce{NH4+}$과 $\ce{NO3-}$으로 나뉘면 입자 수가 늘고, 이온들이 물 분자 사이로 섞여 들어가 자유롭게 움직이므로 무질서도가 커져 엔트로피가 크게 증가한다($\Delta S>0$). 엔탈피는 증가하지만($\Delta H>0$), 엔트로피를 높이려는 경향이 엔탈피가 증가하는 경향보다 크므로 반응이 자발적으로 일어난다.
채점 요소 ① 입자 수 증가, 이온이 물에 섞여 입자 운동이 자유로워짐 ② 엔트로피 증가($\Delta S>0$) ③ 엔트로피 증가의 영향이 엔탈피 증가의 영향보다 큼
