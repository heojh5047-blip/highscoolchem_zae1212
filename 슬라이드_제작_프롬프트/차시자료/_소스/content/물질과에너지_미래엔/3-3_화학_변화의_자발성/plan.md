Q 이 반응에서 엔트로피가 크게 증가하는 가장 큰 까닭은? ★ 기체($\ce{CO2}$)가 생성되기 때문.

- **S21 ④ 엔탈피 변화가 자발성에 유리한 반응**(84–85, 그림 Ⅲ-10) `.formula` $\ce{H+(aq) + OH-(aq) -> H2O(l)}\quad\Delta H=-55.8\ \text{kJ}$. 입자: $\ce{H+}$, $\ce{OH-}$ 두 입자 → $\ce{H2O}$ 하나(입자 수 감소) [a] move. ★ 전체 입자 수가 감소하여 엔트로피 감소($\Delta S&lt;0$) — 불리 ★ 엔탈피가 더 크게 낮아짐($\Delta H&lt;0$) — 유리, 영향이 더 큼 ★ 결론: 엔탈피를 낮추려는 경향이 엔트로피가 감소하는 경향보다 크면 반응이 자발적으로 일어난다. 줄다리기 두 줄: (위) 엔탈피 감소 긴 화살표 오른쪽 + 엔트로피 감소 짧은 화살표 왼쪽 → 자발적 / (아래) 엔탈피 감소 영향이 더 작으면 → 비자발적.

- **S26 대단원 마무리 08**(90) 엔트로피에 대한 설명으로 옳지 않은 것은? ① 무질서도를 나타내는 척도이다. ② 엔트로피의 크기는 물질의 양과 관계가 없다. ③ 순수한 두 물질이 섞일 때 엔트로피가 증가한다. ④ 온도가 높아져 분자 운동이 활발해지면 엔트로피가 증가한다. ⑤ 기체가 더 넓은 공간으로 퍼져 나갈 때 엔트로피가 증가한다. 판서 ★ 해설: 엔트로피는 물질의 양에 의존 — 분자 수 또는 물질의 양이 늘어나면 증가한다(83). ★ 정답 ②.

- **S31 스스로 점검하기**(91) 체크: [지식·이해] 엔탈피와 엔트로피의 의미를 알고, 엔탈피와 엔트로피 변화로 화학 변화의 자발성을 설명했다.(교과서 91) [과정·기능] 상태 변화·혼합·입자 수 변화로 엔트로피 변화의 부호를 예측하고, 동전 실험실로 무질서도와 확률의 관계를 확인했다. [가치·태도] 주변에서 일어나는 변화를 엔탈피와 엔트로피 변화로 설명할 수 있음을 이해하여 화학의 중요성을 인식했다.(교과서 91) Q 3개 ★: 드라이아이스가 승화할 때 $\Delta S$의 부호는? → $\Delta S&gt;0$ / $\Delta H&lt;0$이고 $\Delta S&lt;0$인 반응이 자발적이려면? → 엔탈피 감소 영향이 엔트로피 감소 영향보다 커야 한다 / 자발적 변화는 항상 빠르게 일어날까? → 아니다(철의 부식). 다음 시간: 대단원 Ⅲ 마무리 — 엔탈피, 헤스 법칙, 엔트로피를 하나의 개념 지도로 잇는다.

## 2. 실험실 명세 — em33coin (S10)

- 목적: "무질서한 상태는 그 상태로 존재할 확률이 크다"(81)를 동전 던지기로 확인한다(교과서 그림 Ⅲ-5 확장, 정성적 엔트로피 — 값 계산 없음).
- **조작**: 동전 수 $N$ 슬라이더 2–12(1, 기본 4) · 버튼 「1번 던지기」, 「100번 던지기」 · 「초기화」.
- **고정 시드 난수**: mulberry32(시드 33), 초기화하면 처음 수열로 돌아간다(재현 가능).
- **그림(왼쪽 위)**: 마지막으로 던진 $N$개 동전(원, 앞 `#E8C547` 글자 '앞' / 뒤 `#B9C2CC` 글자 '뒤'), 던지기 때 동전이 0.5초 돌아가는 움직임(API.loop, 정지 모드에서는 바로 결과).
- **그래프(오른쪽)**: 가로축 "앞면의 수"(0…N), 세로축 "비율"(0–0.5 또는 자동 상한). 막대 = 지금 동전 수로 던진 결과의 비율(파랑 `#3F7FD6`), 점·선 = 이론 확률 $\binom{N}{k}/2^N$(ink). 양 끝 막대(0, N = 모두 같은 면)는 테두리 `equi` 강조 + 라벨 "모두 같은 면".
- **출력**: 던진 횟수, "모두 같은 면" 횟수와 비율, 이론 확률 $2/2^N$(분수와 %), 해석 문장(`output.kind`): N이 커질수록 "모두 같은 면"은 거의 나오지 않고 앞면·뒷면이 섞인 결과가 대부분 → 섞인(무질서한) 상태가 될 확률이 크다.
- **결과 표**(동전 수마다 한 행, 같은 N은 행 갱신, 최근 4행): 동전 수 · 던진 횟수 · 모두 같은 면(회) · 실험 비율 · 이론 확률.
- 시험(PRE): N=4 100번 → 이론 12.5 %, 실험 비율이 10–16 % 안쪽 · N=10 100번 → 이론 0.2 %, 실험 0–2 회 · 표 2행 · 1번 던지기 → 던진 횟수 +1 · 초기화 → 표 0행.
