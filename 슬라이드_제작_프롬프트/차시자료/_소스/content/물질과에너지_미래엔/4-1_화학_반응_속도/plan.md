**S15 ③ 반응 속도식** 정의(형광펜): "반응 속도와 반응물의 농도 사이의 관계를 나타낸 식을 반응 속도식이라고 한다." formula $a\ce{A} + b\ce{B} -> \text{생성물}$ → $v=k[\ce{A}]^m[\ce{B}]^n$ · unit "$k$: 반응 속도 상수 · $m$, $n$: $\ce{A}$, $\ce{B}$에 대한 반응 차수 · $m+n$: 전체 반응 차수". 카드 ★: "반응 차수 $m$, $n$은 **실험으로 정한다.** 화학 반응식의 계수 $a$, $b$와 같을 수도, 다를 수도 있다." ★ 예: $\ce{2H2O2 -> 2H2O + O2}$ $v=k[\ce{H2O2}]$ (계수 2, 차수 1).

**S16 ③ 반응 차수와 반응 속도 상수** 그래프 3(작은 그림, $v$–$[\ce{A}]$): 0차(가로선) · 1차(원점 지나는 직선) · 2차(포물선) [a] draw, 아래 "농도 2배 → 속도 1배 / 2배 / 4배". 표(★ 단위): 전체 반응 차수 0 / 1 / 2 / 3 — $k$의 단위 M/s / $\text{s}^{-1}$ / $\text{M}^{-1}\cdot\text{s}^{-1}$ / $\text{M}^{-2}\cdot\text{s}^{-1}$. 카드 "반응 속도 상수 $k$: 반응마다 다르고, 같은 반응에서는 **온도가 같으면 일정**(농도와 무관). 온도가 바뀌면 $k$도 바뀐다(04에서)."

**S17 ③ 초기 속도법** 단계 카드 4: ① 다른 반응물 농도는 같게 두고 **한 반응물의 처음 농도만** 바꾼 실험 두 개를 고른다 ② 농도가 몇 배일 때 초기 반응 속도가 몇 배인지 비교: $2^m=\dfrac{v_2}{v_1}$ ③ 모든 반응물의 차수를 구해 반응 속도식을 쓴다 ④ 실험 한 개의 값을 넣어 $k$를 구한다(단위 포함). note "농도 $x$배 → 속도 $x^m$배".
