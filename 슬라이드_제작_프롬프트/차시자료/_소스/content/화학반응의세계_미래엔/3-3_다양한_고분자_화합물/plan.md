## 2. 실험실 명세 — `rm33poly` (S12)

- 단위체 고르기(버튼 3): ① 에틸렌 → 폴리에틸렌(첨가) ② 아미노산(글리신) → 폴리펩타이드(축합) ③ 테레프탈산 + 에틸렌 글리콜 → PET(축합, 두 단위체를 번갈아).
- 버튼: 「단위체 하나 잇기」(n = 1 → 8), 「기록」(표·그래프에 점), 「초기화」.
- 계산: 단위체 분자량 합 $\sum M$; 떨어져 나간 물 분자 수 $w$ = 0(첨가) 또는 $n-1$(축합); 고분자 분자량 $=\sum M-18w$. 원소별 원자 수: 단위체 합 = 고분자 + 물(표로, 화학식은 `.ov`에 `API.tex`).
  - PE $n$: $\ce{C_{2n}H_{4n}}$, $28n$. 글리신 $n$: $\ce{C_{2n}H_{3n+2}N_{n}O_{n+1}}$, $75n-18(n-1)$. PET(산·글리콜 번갈아, 산부터): 원자 수는 코드에서 합산, 분자량 $166a+62g-18(n-1)$.
- 그림(650×520): 위 — 구슬 사슬(단위체 색, 새 연결 field), 축합이면 연결마다 물 분자(O 12·H 8 공-막대)가 위로 떠올라 오른쪽 위 「떨어져 나간 물」 칸에 쌓임(API.loop). 가운데 — 원자 수 비교 줄(.ov). 아래 — 분자량–$n$ 그래프(가로 $n$ 1–8, 세로 분자량 0–800), 기록한 점(계열 모양) 누적.
- 표시: 이은 단위체 수, 떨어져 나간 물 분자 수, 고분자 분자량, 해석 문장(첨가: "단위체를 이을 때마다 분자량이 단위체 하나만큼(28) 는다. 떨어져 나가는 것이 없다." / 축합: "이을 때마다 물 분자 하나가 떨어져 나가 분자량이 75 − 18 = 57씩 는다.").
- 기록 표(최근 5행): 고분자, $n$, 물 분자 수, 분자량.
- 시험(PRE): 각 단위체에서 n = 1, 4, 8 기록 → 분자량 PE 28·112·224, 글리신 75·246·474, PET 166·402·786, 표 행 수, 그래프 점 수.
