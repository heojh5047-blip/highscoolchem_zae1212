**S9 과학 글쓰기 11 (1)** Q "(가)에서 이산화 탄소가 지나치게 많이 배출될 때 혈액의 pH는 어떻게 변할까? (다)의 반응식과 관련지어 설명해 볼까?" 단계 흐름 ★ 과다 호흡 → 혈액의 $[\ce{CO2}]$ 감소 → ★ ① 역반응 우세 → $[\ce{H2CO3}]$ 감소 → ★ ② 역반응 우세 → $[\ce{H3O+}]$ 감소 → ★ pH 증가(7.45 초과 — 알칼리증). 그림: ①·② 평형 화살표(역반응 `bfield` 굵게 [a]) + pH 띠 화살표 오른쪽. 판서.

**S10 과학 글쓰기 11 (2)** Q "(나)의 방법을 실행했을 때 혈액의 pH는 어떻게 조절될까?" 단계 ★ 천천히 호흡(배출 ↓) / 운동($\ce{CO2}$ 생성 ↑) → 혈액의 $[\ce{CO2}]$ 증가 → ★ ① 정반응 우세 → $[\ce{H2CO3}]$ 증가 → ★ ② 정반응 우세 → $[\ce{H3O+}]$ 증가 → ★ 높아졌던 pH가 낮아져 정상 범위(7.35–7.45)로. 그림: 정반응 `field` 굵게 + pH 띠 화살표 왼쪽.

**S11 과학 글쓰기 11 예시 글** 예시 글 ★ (answer 왼쪽): "(1) 과도하게 호흡하면 혈액 속 이산화 탄소가 지나치게 많이 빠져나가 $[\ce{CO2}]$가 감소한다. 그러면 ①의 평형이 역반응 쪽으로 이동해 $[\ce{H2CO3}]$가 감소하고, 이어서 ②의 평형도 역반응 쪽으로 이동해 $[\ce{H3O+}]$가 감소한다. 따라서 혈액의 pH는 높아진다. (2) 숨을 천천히 쉬어 이산화 탄소 배출을 줄이거나 운동으로 이산화 탄소를 많이 만들면 혈액의 $[\ce{CO2}]$가 증가한다. 그러면 ①과 ②의 평형이 정반응 쪽으로 이동해 $[\ce{H3O+}]$가 증가하므로, 높아졌던 혈액의 pH가 낮아져 적정 범위로 돌아온다." 채점 요소 note ★: ① $[\ce{CO2}]$ 변화 ② ①의 평형 이동 방향 ③ ②의 평형 이동과 $[\ce{H3O+}]$ 변화 ④ pH 변화 방향.

**S12 실험실 rm19breath — 호흡과 혈액의 pH** (덱 추가, 2절) 조작: 활동 버튼 [휴식] [달리기], 호흡 빠르기 슬라이더 6–30회/분(1). 읽기: 혈액 속 $\ce{CO2}$(정상 = 100 %), pH(소수 둘째 자리), 평형 이동 방향. 그림: 왼쪽 폐(호흡 속도에 맞춰 부풀고 줄어듦, API.loop) + 날숨 $\ce{CO2}$ 공 / 가운데 ①·② 평형 화살표(정반응 `field`·역반응 `bfield` 굵기 바뀜) / 오른쪽 pH 눈금 7.0–7.8(정상 띠 7.35–7.45) + 바늘. 「기록」 → 표 최대 5행(활동 · 호흡 · $\ce{CO2}$ · pH · 판정), 「초기화」. 과제 note: "휴식 12회 → 과다 호흡 28회 → 천천히 8회 → 달리기 28회를 차례로 기록해 비교해 보자."

**S13 포트폴리오 이야기 — 혈액의 pH와 고산병** (28) 표식 `포트폴리오 이야기` + small "생활 속 과학". 글: 해발 2000–3000 m 이상의 높은 지대에서 호흡 곤란, 두통, 구토 등이 나타나는 것을 고산병이라고 한다. 원인 중 하나는 혈액의 pH가 올라가는 것이다. 흐름 그림(카드 다섯 개, [a] pop 차례): 높은 지대: 공기의 밀도↓ → 산소 부족 → 호흡수 증가 → 혈액의 $\ce{CO2}$를 많이 잃음 → 완충 능력↓, $[\ce{H3O+}]$↓ → pH↑ = 고산병. **S14 포트폴리오 이야기 — 활동하기(조사)** (28) "고산병을 예방하는 약인 아세타졸아마이드의 역할을 조사해 보자." ★ 예시 결과 카드: ① 아세타졸아마이드는 $\ce{CO2 + H2O <=> H2CO3}$ 반응을 빠르게 하는 효소(탄산 탈수 효소)의 작용을 억제한다. ② 콩팥에서 $\ce{HCO3-}$이 오줌으로 더 많이 빠져나가게 해 혈액을 약간 산성 쪽으로 만든다. ③ 그 결과 높아지려는 혈액의 pH를 낮추고, 호흡을 자극해 산소를 더 많이 받아들이게 한다. 조사 길잡이 small: 약의 작용은 의약품 설명서·공공 의료 정보 누리집 등 믿을 만한 출처로 확인하고, 복용은 반드시 의사와 상의한다. 그림: $\ce{HCO3-}$ 콩팥 → 배출 화살표 단순 도식.

**S15 화학과 나의 미래 — 피부의 건강을 연구하는 화장품 연구원** (29) 하는 일: 화장품 원료로 알맞은 물질을 찾고, 화장품이 피부·인체에 미치는 영향과 부작용을 연구 — 피부 분석에서 가장 기본은 피부의 pH, 적정 pH 5.5 정도로 유지하는 데 도움이 되는 소재를 연구·개발. 필요한 능력: 보습·적정 pH 유지·노화 방지에 효과적인 식물 소재 연구, 피부 유전자 분석 → 화학과 생명과학을 아우르는 지식 · 소비자 심리·데이터 분석 능력 · 과학 내용을 쉽게 풀어내는 의사소통 능력. 관련 학과: 화학과, 재료 공학과, 생명과학과 등. 누리집 small: 커리어넷에서 화장품 연구원 정보 찾기. Q "pH 5.5인 피부는 산성일까, 염기성일까? 알칼리성 비누로 씻은 뒤 피부 pH는?" ★ → 약산성 · 비누(pH 약 9–10)로 씻으면 잠시 높아졌다가 피부의 완충 작용으로 돌아온다. 활동하기(체험) 카드 ★ 예시: 천연 화장품의 종류(토너·수분 젤·립밤·비누) · 만드는 법 예: 알로에 겔 + 정제수 + 글리세린 → 수분 젤, pH 시험지로 약산성(5–6) 확인 · 안전: 선생님 지도, 팔 안쪽에 먼저 발라 보기(패치 테스트), 냉장 보관·빨리 쓰기. 그림: 피부 단면 + pH 눈금 5.5 표시.

**S16 프로젝트 — 생명과 지구의 pH를 지켜라! ① 생체 내 pH 유지** (34) 도입: 산 염기 반응이나 완충 작용은 생명체의 항상성 유지나 지구 생태의 지속가능성 등에 매우 큰 영향을 미친다. 글: 위에서는 위산이 분비되어 pH가 2 정도로 유지된다 — 단백질 분해 효소인 펩신이 작용하려면 $\ce{H+}$이 필요. 위벽은 펩신 때문에 손상되는 것을 막으려고 $\ce{HCO3-}$이 포함된 점액을 분비하고, $\ce{HCO3-}$은 위산의 $\ce{H+}$을 중화해 위벽의 pH를 7 정도로 유지한다. formula $\ce{HCO3-(aq) + H3O+(aq) <=> H2CO3(aq) + H2O(l)}$. 그림: 위벽 주름 단면 + 점액층(옅은 초록) + 위 속 $\ce{H+}$ 공이 점액으로 다가와 $\ce{HCO3-}$과 만남 [a] move · pH 2 / pH 7 라벨. Q "이 반응에서 브뢴스테드·라우리 염기는?" ★ → $\ce{HCO3-}$($\ce{H3O+}$에게서 $\ce{H+}$을 받음).

**S17 프로젝트 ② 해양 생태계와 이산화 탄소** (34) 글: $\ce{CO2}$는 바닷물에 녹아 $\ce{HCO3-}$, $\ce{CO3^2-}$ 등을 만든다. formula (가) $\ce{CO2(g) + H2O(l) + CO3^2-(aq) <=> 2HCO3-(aq)}$ (나) $\ce{Ca^2+(aq) + CO3^2-(aq) <=> CaCO3(s)}$ — $\ce{CO3^2-}$이 $\ce{Ca^2+}$과 반응해 해양 생물의 탄산 칼슘 골격을 만든다. Q "바닷속 $\ce{CO2}$ 농도가 증가하면?" 단계 ★ (가) 정반응 우세 → $[\ce{CO3^2-}]$ 감소 ★ (나) 역반응 우세 → $\ce{CaCO3}$ 골격이 녹음 ★ 조개·산호·바다 달팽이 등 탄산 칼슘 골격을 가진 생물이 살기 어려워진다. 그림: 바다 단면 + 대기 $\ce{CO2}$ 화살표 [a] + 조개 껍데기.

## 2. 실험실 명세 — rm19breath (S12, 덱 추가)
- 입력: 버튼 `rest`/`run`(활동), range `r` 6–30(회/분).
- 모형(덱이 만든 단순 모형 — 화면에 식을 보이지 않음): $\ce{CO2}$ 생성 $g$ = 휴식 1, 달리기 2. 혈액 $\ce{CO2}$ 상대값 $c=100\times\dfrac{g\cdot12}{r}$ % (정상 휴식 12회 = 100 %), 15–250 %로 제한. 혈액 $[\ce{HCO3-}]$은 짧은 시간 동안 일정하다고 보고 pH $=7.40-\log_{10}(c/100)$ (탄산–탄산수소 완충 평형의 비율 관계를 단순화). 
  - 확인 값: 휴식 12 → 100 %, 7.40 정상 · 휴식 28 → 43 %, 7.77 알칼리증 · 휴식 8 → 150 %, 7.22 산증 · 달리기 28 → 86 %, 7.47(약간 높음) · 달리기 24 → 100 %, 7.40.
- 판정: pH < 7.35 "산증 쪽", 7.35–7.45 "정상 범위", > 7.45 "알칼리증 쪽". 평형 이동 문장: $c<95$ → "①·② 역반응 쪽 이동 → [H₃O⁺] 감소" 글자 대신 output 일반 글자 "①·② 역반응 쪽 → 하이드로늄 이온 감소", $c>105$ → "정반응 쪽 → 하이드로늄 이온 증가", 그 밖 "평형 유지".
- 표시: 폐 두 개가 호흡 속도로 커졌다 작아짐(API.loop), 날숨 $\ce{CO2}$ 점 수 = 호흡 빠르기에 비례 · 평형 화살표 ①·② 위(정반응, `field`)·아래(역반응, `bfield`) 굵기 = 이동 방향 · pH 계기(가로 눈금 7.0–7.8, 정상 띠) + 바늘.
- 기록: 「기록」 → 행 추가(최대 5행), 「초기화」 → 표 비움, 휴식·12회.
- 시험: PRE로 (1) 휴식 12 → pH 7.40 정상 (2) r=28 → 7.77 알칼리증 (3) 달리기 + 24 → 7.40 (4) 기록 3번 → 3행.
