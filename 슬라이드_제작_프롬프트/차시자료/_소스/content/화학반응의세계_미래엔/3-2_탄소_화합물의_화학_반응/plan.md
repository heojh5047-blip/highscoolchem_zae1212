## 1. 슬라이드 (화면 문장 — 근거 쪽)

**S1 표지** — kicker `Ⅲ. 탄소 화합물과 반응 › 02`, h1 「탄소 화합물의<br>화학 반응」, sub 「작용기가 바뀌면 물질의 성질은 어떻게 달라질까?」, meta 「고등학교 화학 반응의 세계 88–91쪽」. 그림: 아세트알데하이드 공-막대 모형(원자 move out) + 포밀기 점선 원 + 캡션 「아세트알데하이드 $\ce{CH3CHO}$ — 에탄올이 산화된 물질」.

**S2 학습 목표 (88)** — std [12반응03-02]. 목표 1 간단한 탄소 화합물의 화학 반응 예를 찾을 수 있다. 2 탄소 화합물의 화학 반응을 작용기의 변화로 설명할 수 있다. 흐름: 발효 → 에탄올의 산화 → 작용기와 성질 → 은거울 반응 → 음주 측정기. 지난 시간과 연결: 작용기 $\ce{-OH}$, $\ce{-CHO}$, $\ce{-COOH}$가 성질을 결정했다. 오늘은 작용기가 다른 작용기로 바뀌는 반응을 본다.

**S3 생각 열기 (88)** — h2 「이게 무슨 냄새지?」. 그림: 매실청 유리병(매실, 기포 move loop). 문장: 오랫동안 보관해 둔 매실청에서 기포가 올라오고 술 냄새가 나거나, 맛이 시큼해질 때가 있다. Q 매실청 안에서 어떤 화학 반응이 일어나 맛이 변한 것일까? → (step) ① 설탕이 발효되어 에탄올과 이산화 탄소가 생긴다 → 기포, 술 냄새 ② 에탄올이 산화되어 아세트산이 된다 → 시큼한 맛. (step) 오늘의 열쇠: **작용기의 변화**.

**S4 연결 (3-1 다시 보기)** — tag alt 연결, h2 「작용기가 성질을 정한다」. 표: 작용기 / 탄소 화합물 / 대표 물질 / 성질 — $\ce{-OH}$ 하이드록시기 · 알코올 · 에탄올 $\ce{C2H5OH}$ · 수용액 중성, 소독 · $\ce{-CHO}$ 포밀기 · 알데하이드 · 아세트알데하이드 $\ce{CH3CHO}$ · 환원성(쉽게 산화됨) · $\ce{-COOH}$ 카복실기 · 카복실산 · 아세트산 $\ce{CH3COOH}$ · 산성. Q 탄소 수는 그대로 두고 작용기만 $\ce{-OH}$에서 $\ce{-COOH}$로 바꾸면 성질은 어떻게 될까? → (step) 중성 → 산성. 작용기가 바뀌면 성질도 바뀐다.

**S5 ① 발효 (88)** — h2 「곡물과 설탕의 발효 — 에탄올이 생긴다」. 쌀·옥수수 같은 곡물이나 설탕을 발효시키면 포도당으로부터 에탄올과 이산화 탄소가 만들어진다. 단계 카드 3장(S10 거시→미시→기호): (a) 현상: 막걸리 — 쌀·누룩 → 기포가 생기고 술 냄새 (b) 입자: 포도당 1분자 → 에탄올 2분자 + 이산화 탄소 2분자(공-막대 소형, pop) (c) 식 $\ce{C6H12O6 -> 2C2H5OH + 2CO2}$. step: 원자 수 확인 C 6 = 4 + 2, H 12 = 12, O 6 = 2 + 4. note: 막걸리를 더 발효시키면 식초가 된다 — 이때는 무엇이 변할까?

**S6 ② 에탄올의 산화 (88 그림 Ⅲ-12)** — h2 「에탄올 → 아세트알데하이드 → 아세트산」. 구조식 3개(가로 흐름, 산화 화살표 ox, 라벨 '산화'), 작용기 상자 step 공개. 문장(step): 에탄올이 산화되면 작용기 $\ce{-OH}$가 $\ce{-CHO}$로 변해 아세트알데하이드가 된다. (step) 아세트알데하이드가 산화되면 $\ce{-CHO}$가 $\ce{-COOH}$로 변해 아세트산이 된다. 형광펜 정의: <mark>화학 반응이 일어나 탄소 화합물의 작용기가 변하면 물질의 성질이 변한다.</mark>

**S7 ② 산화일까? (연결 Ⅱ, 덱 보충)** — h2 「왜 '산화'라고 할까?」. 분자식 비교 표: 에탄올 $\ce{C2H6O}$ → 아세트알데하이드 $\ce{C2H4O}$ → 아세트산 $\ce{C2H4O2}$. 변화: 수소 원자 2개를 잃음 / 산소 원자 1개를 얻음. 작용기 탄소의 산화수 $-1 \to +1 \to +3$ (증가 = 산화). 그림: 에탄올 공-막대에서 H 2개가 떨어져 나감(move), 아세트알데하이드에 O 1개가 붙음(move). Q 이때 무엇이 환원될까? → (step) 함께 반응한 산화제(몸속 효소가 쓰는 물질, 다이크로뮴산 이온, 은 이온 등)가 환원된다. 산화와 환원은 동시에 일어난다(Ⅱ단원). Q 알데하이드가 다른 물질을 환원시키는 까닭은? → (step) 자신이 쉽게 산화되기($\ce{-CHO}\to\ce{-COOH}$) 때문이다 — 환원성.

**S8 ③ 작용기와 성질의 변화** — h2 「작용기가 변하면 성질이 변한다」. 3열 카드(에탄올 / 아세트알데하이드 / 아세트산): 작용기, 성질·쓰임 — 에탄올: 물과 잘 섞임, 중성, 소독·술 / 아세트알데하이드: 자극성 냄새, 환원성, 몸속에서 두통·구토의 원인 / 아세트산: 시큼한 맛, 산성, 식초의 주성분. Q 막걸리가 오래되면 맛이 시큼해지는 까닭을 작용기로 설명하면? → (step) 에탄올의 $\ce{-OH}$가 $\ce{-CHO}$를 거쳐 $\ce{-COOH}$로 변해 산성 물질인 아세트산이 생기기 때문.

**S9 자료 읽기 (88 그림 Ⅲ-13)** — h2 「메탄올 → 폼알데하이드 → 폼산」. 구조식 3개 + 산화 화살표. 지시: 그림에서 변화된 작용기를 표시하고, 작용기 변화에 따른 물질의 성질 변화를 설명해 보자. (step) 작용기 상자: $\ce{-OH}$ → $\ce{-CHO}$ → $\ce{-COOH}$. (step) 메탄올: 중성, 물에 잘 섞이는 액체 → 폼알데하이드: 자극성 냄새가 나는 기체, 환원성 → 폼산: 산성. (step, small) 덱 보충: 메탄올을 마시면 몸속에서 폼알데하이드·폼산으로 산화되어 시신경을 해칠 수 있다.

**S10 해 보기 (89)** — h2 「탄소 화합물의 화학 반응 예 찾기」(준비물 스마트 기기, 탐구 능력·문제 해결 능력). 광고 요지 카드(다듬은 문장): 현미로 고두밥을 짓고 전통 누룩을 넣어 치댄 뒤 옹기에 담아 30 °C 정도에서 보관하면 현미막걸리가 된다. 이 막걸리를 일정한 온도와 습도에서 2년 동안 숙성시키면 천연 발효 식초가 된다. 정리 1 Q 식초가 만들어지는 과정에서 일어나는 탄소 화합물의 화학 반응식을 써 보자. → (step) $\ce{C6H12O6 -> 2C2H5OH + 2CO2}$ (막걸리: 알코올 발효) (step) $\ce{C2H5OH ->[\text{산화}] CH3CHO ->[\text{산화}] CH3COOH}$ (식초) (step, small) 한 번에 쓰면 $\ce{C2H5OH + O2 -> CH3COOH + H2O}$ (덱 보충).

- 순서 버튼: 「① 암모니아수 한 방울」(누를 때마다 방울 수 +1: 1–2 방울 → 갈색 앙금, 3–4 → 앙금 줄어듦, 5 이상 → 앙금이 모두 녹아 투명) → 「② 시료·KOH 넣고 뚜껑」(앙금이 다 녹은 뒤에만; 앙금이 남았으면 안내 문장) → 「③ 중탕하며 흔들기」 → API.loop로 모의 시간(실제 1 s = 모의 30 s) 진행, 은 석출 정도 $p(t)=1-e^{-t/\tau}$.
- $\tau$(s): 포밀기 있는 시료만. 기준(60 °C, KOH 넣음) 포도당 60, 아세트알데하이드 40; 온도 보정 $\tau\times2^{(60-T)/10}$; KOH 안 넣음 ×3. 에탄올·아세트산·증류수 → 변화 없음($p=0$). 300 s에서 멈춤.
- 그림: 왼쪽 물 중탕 비커 + 유리병(벽 은빛 층의 불투명도 = $p$, 갈색 앙금), 위 온도계 글자, 오른쪽 그래프 「은 석출 정도 [%]」–「시간 [s]」(0–300) — 진행 중 곡선 ink, 기록한 곡선은 시료 계열 색·모양 + 이름 라벨.
- 출력: 경과 시간, 은 석출 정도 %, 결과(은거울 생김 / 변화 없음), 해석 문장(작용기 $\ce{-CHO}$ 유무, 산화·환원). 「기록」 → 표(시료 · 작용기 · 온도 · KOH · 은거울이 생긴 시간(석출 50 % 도달, 모의 오차 ±3 %) 또는 '안 생김')에 행이 쌓임(최근 5행). 「초기화」.
- PRE 시험: 포도당 60 °C 기록 → 포도당 80 °C → 아세트알데하이드 → 에탄올 → 아세트산 → KOH 없이 포도당; 암모니아 방울 전 ② 막힘 확인.

### rm32bre — 음주 측정기 실험실 (S20)
- 시료 버튼 4: 에탄올 · 아세트알데하이드 · 아세트산 · 물. 슬라이더: 솜에 적신 양 1–8 방울. 버튼 「관 밀폐하고 관찰」 → API.loop로 3분(모의) 동안 초록 앞면이 솜 쪽에서 안쪽으로 나아감 $L(t)=L_\infty(1-e^{-t/40})$.
