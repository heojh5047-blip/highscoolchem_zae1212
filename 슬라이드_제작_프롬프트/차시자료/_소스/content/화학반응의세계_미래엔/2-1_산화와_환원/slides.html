생각 열기고려청자의 비취색과 철

우리 선조들은 고려청자의 신비로운 비취색을 만들어 냈다. 그 비법은 흙 속의 철 성분이었다고 한다.

Q 가마 속에서 흙 속의 철은 어떤 화학 반응을 했을까?

가마 안에 산소가 부족하게 구우면, 흙 속 산화 철(III)이 산소를 잃어(환원되어) 푸른빛을 띠는 철 화합물이 된다고 알려져 있다.

산소를 얻고 잃는 것, 전자를 주고받는 것 — 철에게 일어난 일을 오늘 여러 잣대로 설명해 보자.

1산소를 얻고 잃는 반응 — 철의 제련

용광로에서 코크스가 연소하여 생긴 일산화 탄소가 산화 철(III)을 환원시킨다. (연계 통합과학2)

물질이 산소를 얻는 반응을 산화, 산소를 잃는 반응을 환원이라고 한다.

1전자를 잃고 얻는 반응 — 마그네슘의 연소

$\ce{2Mg(s) + O2(g) -> 2MgO(s)}$

$\ce{Mg}$은 전자를 잃어 $\ce{Mg^2+}$이 되고, $\ce{O2}$는 전자를 얻어 산화 이온 $\ce{O^2-}$이 되어 이온 결합 물질 $\ce{MgO}$를 만든다.

물질이 전자를 잃는 반응을 산화, 전자를 얻는 반응을 환원이라고 한다.

전자의 이동으로 보면 산소가 없는 반응까지 산화·환원으로 설명할 수 있다.

1산화와 환원은 언제나 동시에

산화  $\ce{2Mg -> 2Mg^2+ + 4e-}$
환원  $\ce{O2 + 4e- -> 2O^2-}$
전체  $\ce{2Mg + O2 -> 2Mg^2+ + 2O^2-}$

Q 마그네슘이 잃은 전자는 어디로 갔을까? 그 수는?

마그네슘 2개가 잃은 전자 4개를 산소 분자 1개가 모두 얻었다 — 잃은 전자 수 = 얻은 전자 수

한 반응에서 전자를 잃는 물질이 있으면 반드시 전자를 얻는 물질도 있다. 산화·환원 반응은 언제나 동시에 일어난다.
'산화·환원 반응'이라는 용어도 두 반응이 항상 함께 일어남을 강조한다.

연결공유 결합 물질 사이의 반응에서는?

철의 제련이나 마그네슘의 연소는 산소 또는 전자의 이동이 비교적 명확하다.

그러나 수소와 산소가 물이 되는 반응은 공유 결합 물질 사이의 반응이라 이온이 생기지 않는다.

1. 분자 모형에서 공유 전자쌍의 치우침이 나타나는 원자에 부분 전하($\delta^+$, $\delta^-$)를 표시해 보자.

2. 전자의 치우침을 전자를 잃고 얻는 것으로 가정할 때, 전자를 잃는 것과 얻는 것은 어떤 물질일까?

2 다음 반응에서 산화되는 물질과 환원되는 물질을 각각 써 보자.

$\ce{Fe + Cl2 -> FeCl2}$

산화되는 물질 $\ce{Fe}$   환원되는 물질 $\ce{Cl2}$

$\ce{Fe}$는 전자 2개를 잃어 $\ce{Fe^2+}$이 되고, $\ce{Cl2}$는 전자 2개를 얻어 $\ce{Cl-}$ 2개가 된다.

2산화수

전자의 이동이 뚜렷하지 않은 반응도 설명하기 위해 산화수를 쓴다. 산화수는 어떤 물질에서 각 원자가 어느 정도 산화되었는지를 나타내는 가상의 전하이다.

이온 결합 물질 이온의 전하와 같다. $\ce{NaCl}$: $\mathrm{Na}$ +1, $\mathrm{Cl}$ −1

공유 결합 물질 전기음성도가 큰 원자가 공유 전자쌍을 모두 차지한다고 가정한다.

물: $\mathrm{O}$는 전자 2개를 얻음 → −2, $\mathrm{H}$는 전자 1개씩 잃음 → +1

표기 약속 산화수는 부호를 숫자 앞에(+1, −2), 이온의 전하는 숫자 뒤에($\ce{O^2-}$) 쓴다.

2산화수를 정하는 규칙

1원소를 구성하는 원자의 산화수는 0이다.$\ce{H2}$, $\ce{O2}$, $\ce{Na}$, $\ce{C}$
2단원자 이온에서 원자의 산화수는 그 이온의 전하와 같다.$\ce{Na+}$의 $\mathrm{Na}$ +1
3다원자 이온을 구성하는 원자의 산화수 합은 그 이온의 전하와 같다.$\ce{NO3-}$: $(+5)\times1+(-2)\times3=-1$
4화합물에서 전기음성도가 큰 원자가 (−)산화수, 작은 원자가 (+)산화수를 갖는다. 화합물의 산화수 합은 0이다.$\ce{NH3}$: $(-3)+(+1)\times3=0$
$\ce{NO2}$: $(+4)+(-2)\times2=0$

화합물에서 원자의 산화수

ⅰ) $\mathrm{F}$는 −1

ⅱ) 1족 원소는 +1, 2족 원소는 +2

ⅲ) $\mathrm{H}$는 대부분 +1, 금속의 수소 화합물에서는 −1 ($\ce{HCl}$ +1, $\ce{NaH}$ −1)

ⅳ) $\mathrm{O}$는 대부분 −2, 과산화물·플루오린 화합물에서는 다름 ($\ce{H2O2}$ −1, $\ce{OF2}$ +2)

해 보기화합물과 이온에서 원자의 산화수 구하기

1. 표시된 원자의 산화수 ㉠–㉣을 구해 보자.

물질$\ce{CaCO3}$의 $\mathrm{C}$ ㉠$\ce{SO2}$의 $\mathrm{S}$ ㉡$\ce{CH2F2}$의 $\mathrm{C}$ ㉢$\ce{MnO4-}$의 $\mathrm{Mn}$ ㉣
산화수+4+40+7

2. 산화수를 구한 과정을 친구들에게 설명해 보자.

㉠ $(+2)+x+(-2)\times3=0 \Rightarrow x=+4$   ㉡ $x+(-2)\times2=0 \Rightarrow x=+4$
㉢ $x+(+1)\times2+(-1)\times2=0 \Rightarrow x=0$   ㉣ $x+(-2)\times4=-1 \Rightarrow x=+7$

2같은 원자라도 산화수가 다르다

결합하는 원자에 따라 산화수가 달라진다.

$\overset{+4}{\ce{C}}\overset{-2}{\ce{O}}{}_2$     $\overset{-4}{\ce{C}}\overset{+1}{\ce{H}}{}_4$

$\mathrm{C}$보다 $\mathrm{O}$의 전기음성도가 커서 $\ce{CO2}$의 $\mathrm{C}$는 +4, $\mathrm{C}$가 $\mathrm{H}$보다 커서 $\ce{CH4}$의 $\mathrm{C}$는 −4이다.

크로뮴도 $\ce{Cr^3+}$(+3), $\ce{Cr^2+}$(+2), $\ce{CrO4^2-}$·$\ce{Cr2O7^2-}$(+6)처럼 다양한 산화수를 가지며, 수용액의 색도 다르다.

3산화수 변화와 산화·환원 반응

반응 전후 산화수가 증가하는 원자를 포함하는 물질은 산화된 것이고, 산화수가 감소하는 원자를 포함하는 물질은 환원된 것이다.

메테인 $\ce{CH4}$은 산화되고, 산소 $\ce{O2}$는 환원된다.

연습 해 보기황화 수소와 염소의 반응

황화 수소 $\ce{H2S}$와 염소 $\ce{Cl2}$가 반응하면 염화 수소 $\ce{HCl}$가 생성된다. 산화되는 물질과 환원되는 물질을 찾아보자.

1 단계 화학 반응식을 쓰고, 각 원자의 산화수를 구한다.

$\ce{H2S(g) + Cl2(g) -> S(s) + 2HCl(g)}$

$\ce{H2S}$의 S ❶ −2   $\ce{Cl2}$의 Cl ❷ 0   $\ce{S}$ ❸ 0   $\ce{HCl}$의 Cl ❹ −1

2 단계 산화수가 증가한 원자가 포함된 물질은 산화, 감소한 원자가 포함된 물질은 환원.

• S의 산화수는 ❺ 증가하므로 $\ce{H2S}$는 ❻ 산화된다.

• Cl의 산화수는 ❼ 감소하므로 $\ce{Cl2}$는 ❽ 환원된다.

직접 해 보기암모니아의 생성

질소 $\ce{N2}$ 기체와 수소 $\ce{H2}$ 기체가 반응하여 암모니아 $\ce{NH3}$ 기체가 생성되는 반응의 화학 반응식을 쓰고, 산화수 변화를 이용해 산화되는 물질과 환원되는 물질을 찾아보자.

$\ce{N2(g) + 3H2(g) -> 2NH3(g)}$

$\mathrm{N}$: 0 → −3 감소 · $\mathrm{H}$: 0 → +1 증가

산화되는 물질 $\ce{H2}$, 환원되는 물질 $\ce{N2}$

3산화·환원의 정의

구분산소전자산화수
산화산소를 얻음전자를 잃음산화수 증가함
환원산소를 잃음전자를 얻음산화수 감소함

산화수 변화는 산화와 환원을 가장 넓은 범위에서 정의하는 방법이다.

Q 중화 반응 $\ce{HCl(aq) + NaOH(aq) -> H2O(l) + NaCl(aq)}$는 산화·환원 반응일까?

아니다. $\mathrm{H}$ +1, $\mathrm{Cl}$ −1, $\mathrm{Na}$ +1, $\mathrm{O}$ −2로 산화수가 변하는 원자가 없다.

4산화제와 환원제

자신은 산화되고 다른 물질을 환원시키는 물질을 환원제, 자신은 환원되고 다른 물질을 산화시키는 물질을 산화제라고 한다.

$\ce{Mg(s) + S(s) -> MgS(s)}$

산화수 $\mathrm{Mg}$: 0 → +2 (산화) · $\mathrm{S}$: 0 → −2 (환원)

산화·환원 반응은 동시에 일어나므로 산화제와 환원제는 항상 함께 존재한다.

주로 산화제 $\ce{F2}$, $\ce{Cl2}$, $\ce{K2Cr2O7}$, $\ce{KMnO4}$, $\ce{H2O2}$, $\ce{O2}$ — 산소를 잘 내놓거나 전자를 얻기 쉬움

주로 환원제 $\ce{Li}$, $\ce{Na}$, $\ce{K}$, $\ce{SnCl2}$ — 산소와 잘 반응하거나 전자를 잃기 쉬움

Q 어떤 반응에서 산화제로 작용한 물질은 다른 반응에서도 항상 산화제일까?

해 보기산화제와 환원제 구분하기

(가) $\ce{SO2(g) + Cl2(g) + 2H2O(l) -> H2SO4(aq) + 2HCl(aq)}$

$\mathrm{S}$: +4 → +6 증가 → $\ce{SO2}$ 산화 · $\mathrm{Cl}$: 0 → −1 → $\ce{Cl2}$ 환원  ⇒ $\ce{SO2}$는 환원제

(나) $\ce{SO2(g) + 2H2S(g) -> 2H2O(l) + 3S(s)}$

$\ce{SO2}$의 $\mathrm{S}$: +4 → 0 감소 → $\ce{SO2}$ 환원 · $\ce{H2S}$의 $\mathrm{S}$: −2 → 0 → $\ce{H2S}$ 산화  ⇒ $\ce{SO2}$는 산화제

Q 두 반응에서 이산화 황의 역할이 다른 까닭은?

전자를 잃거나 얻으려는 경향은 상대적이므로, 같은 물질이라도 반응하는 물질에 따라 산화제로도, 환원제로도 작용한다.

비유: 여우는 토끼를 쫓기도 하지만 호랑이에게 쫓기기도 한다. 산화제와 환원제의 세기도 상대적이다.

Q 이 반응식은 완성된 것일까?

전하 합

왼쪽 +1, 오른쪽 +2 — 다르다.

전자 수

구리가 잃은 전자 2개, 은 이온이 얻은 전자 1개 — 다르다.

물질이 잃은 총 전자 수 = 얻은 총 전자 수가 되도록 맞춘다: $\ce{Cu + 2Ag+ -> Cu^2+ + 2Ag}$

01 산화와 환원

어떤 물질에서 각 원자가 어느 정도 산화되었는지를 나타내는 가상의 전하: ⓪ 산화수

산화: 산소를 ❶ 얻음 · 전자를 ❷ 잃음 · 산화수 ❸ 증가

환원: 산소를 잃음 · 전자를 ❹ 얻음 · 산화수 ❺ 감소

산화와 환원은 ❻ 동시에 일어나고, 잃은 전자 수 = ❼ 얻은 전자 수

산화제는 자신이 ❽ 환원되는 물질, 환원제는 자신이 ❾ 산화되는 물질 — ❿ 상대적 세기로 정해진다.
