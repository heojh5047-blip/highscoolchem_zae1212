Q 구리선 표면의 은빛 물질은 무엇이고, 용액은 왜 푸르게 변했을까?

은 이온이 은 $\ce{Ag}$으로 석출되고, 구리 $\ce{Cu}$가 구리 이온 $\ce{Cu^2+}$이 되어 녹아 나왔다. $\ce{Cu^2+}$은 수용액에서 파란색을 띤다.

이 반응에는 산소가 없다. 그래도 산화·환원 반응이라고 할 수 있을까?

다시 보기산소를 얻고 잃는 반응

통합과학에서 배운 정의: 산화는 물질이 산소를 얻는 반응, 환원은 물질이 산소를 잃는 반응이다.

산화 구리(II)와 탄소 가루를 섞어 가열하면 붉은 구리가 생기고 이산화 탄소가 나온다.

원자 수: Cu 2 = 2, O 2 = 2, C 1 = 1

Q 산소를 잃은 물질과 얻은 물질은?

$\ce{CuO}$는 환원되고, $\ce{C}$는 산화된다.

1철의 제련 — 산화와 환원은 함께

용광로에서 코크스가 타서 생긴 일산화 탄소가 철광석(산화 철(III))에서 산소를 떼어 낸다.

한 물질이 산소를 잃으면 다른 물질이 그 산소를 얻는다 — 산화와 환원은 항상 동시에 일어난다.

연결산소가 없는 반응도 산화·환원일까?

$\ce{2Na(s) + Cl2(g) -> 2NaCl(s)}$

Q 이 반응은 산소를 주고받지 않는다. 그래도 산화·환원 반응이라고 할 수 있을까?

나트륨은 전자를 잃어 $\ce{Na+}$이 되고, 염소는 전자를 얻어 $\ce{Cl-}$이 된다. 산소 대신 전자가 옮겨 갔다.

→ 산화·환원을 전자의 이동으로 넓혀 정의한다.

2전자의 이동과 산화·환원

산화는 원자나 이온이 전자를 잃는 반응, 환원은 전자를 얻는 반응이다.

산화 $\ce{2Na -> 2Na+ + 2e-}$
환원 $\ce{Cl2 + 2e- -> 2Cl-}$

반쪽 반응식

산화나 환원 한쪽만 전자 $\ce{e-}$를 써서 나타낸 식. 두 반쪽 반응식을 더하면 전체 반응식이 된다.

Q 어느 금속이 가장 전자를 잃기 쉬운가? ○가 많은 줄을 보자.

2잃은 전자 수 = 얻은 전자 수

$\ce{Cu(s) + 2Ag+(aq) -> Cu^2+(aq) + 2Ag(s)}$

Q 왜 $\ce{Ag+}$은 2개가 필요할까?

구리 원자 1개가 내놓은 전자 2개를, $\ce{Ag+}$ 1개는 1개씩만 받기 때문이다.

산화 $\ce{Cu -> Cu^2+ + 2e-}$
환원 $\ce{2Ag+ + 2e- -> 2Ag}$

산화·환원 반응에서 잃은 전자 수와 얻은 전자 수는 같다.

확인하기맞으면 ○, 틀리면 ×

  1. 산화는 원자나 이온이 전자를 잃는 반응이다. → ○
  2. $\ce{Zn + Cu^2+ -> Zn^2+ + Cu}$에서 $\ce{Cu^2+}$은 산화된다. → × 전자를 얻으므로 환원된다.
  3. 산화 반응만 따로 일어날 수 있다. → × 잃은 전자를 받는 물질이 있어야 하므로 산화와 환원은 동시에 일어난다.
  4. $\ce{Cu + 2Ag+ -> Cu^2+ + 2Ag}$에서 구리 1 mol이 반응하면 전자 2 mol이 이동한다. → ○

연결전자를 완전히 주고받지 않는 반응은?

$\ce{2H2(g) + O2(g) -> 2H2O(l)}$

Q 물은 공유 결합 물질이라 이온이 생기지 않는다. 이 반응에서 전자의 이동을 어떻게 판단할까?

공유 전자쌍은 전기음성도가 큰 $\mathrm{O}$ 쪽으로 치우친다. 이것을 '$\mathrm{O}$가 전자를 얻었다'고 보기로 약속하자.

→ 원자가 얻거나 잃었다고 보는 전자 수: 산화수

3산화수

산화수는 공유 전자쌍이 전기음성도가 큰 원자 쪽으로 완전히 이동한다고 가정할 때 각 원자가 갖는 전하이다. 이온 결합 물질에서는 이온의 전하와 같다.

$\mathrm{O}$: 전자 8개 — 원자가 전자 6개보다 2개 많다 → −2

$\mathrm{H}$: 전자 0개 — 원자가 전자 1개보다 1개 적다 → +1

표기 약속 산화수는 부호를 숫자 앞에(+1, −2), 이온의 전하는 숫자 뒤에($\ce{O^2-}$) 쓴다.

3산화수 규칙

번호규칙예
1원소(홑원소 물질)를 이루는 원자의 산화수는 0이다.$\ce{H2}$, $\ce{O2}$, $\ce{Na}$, $\ce{Cu}$
2단원자 이온의 산화수는 그 이온의 전하와 같다.$\ce{Na+}$ +1, $\ce{Cu^2+}$ +2
3화합물을 이루는 원자의 산화수 합은 0, 다원자 이온은 이온의 전하와 같다.$\ce{SO4^2-}$: $(+6)+4(-2)=-2$
4화합물에서 1족 금속은 +1, 2족 금속은 +2이다.$\ce{NaCl}$, $\ce{MgO}$
5화합물에서 $\mathrm{F}$는 −1이다.$\ce{HF}$
6화합물에서 $\mathrm{H}$는 +1이다. (금속의 수소 화합물에서는 −1)$\ce{HCl}$ / $\ce{NaH}$
7화합물에서 $\mathrm{O}$는 −2이다. (과산화물 −1, $\ce{OF2}$ +2)$\ce{H2O}$ / $\ce{H2O2}$

규칙이 서로 맞지 않으면 앞 번호를 먼저 따른다. 예: $\ce{OF2}$에서는 5번($\mathrm{F}$ −1)이 7번보다 앞서므로 $\mathrm{O}$는 +2이다.

4산화수 변화와 산화·환원

산화는 산화수가 증가하는 반응, 환원은 산화수가 감소하는 반응이다.

이온이 생기지 않는 반응도 산화수로 산화·환원을 판단할 수 있다.

Q 중화 반응 $\ce{HCl + NaOH -> NaCl + H2O}$는 산화·환원 반응일까?

아니다. $\mathrm{H}$ +1, $\mathrm{Cl}$ −1, $\mathrm{Na}$ +1, $\mathrm{O}$ −2로 산화수가 변하는 원자가 없다.

확인하기철의 제련을 산화수로 보기

$\ce{Fe2O3 + 3CO -> 2Fe + 3CO2}$에서 각 원자의 산화수 변화를 쓰고, 산화된 물질과 환원된 물질을 고르시오.

원자변화판단
$\mathrm{Fe}$+3 → 0감소 · 환원
$\mathrm{C}$+2 → +4증가 · 산화
$\mathrm{O}$−2 → −2변화 없음
산화된 물질 $\ce{CO}$, 환원된 물질 $\ce{Fe2O3}$ — 산소의 이동으로 본 결과와 같다.

5산화제와 환원제

산화제는 자신은 환원되면서 다른 물질을 산화시키는 물질, 환원제는 자신은 산화되면서 다른 물질을 환원시키는 물질이다.

$\ce{Zn + Cu^2+ -> Zn^2+ + Cu}$

Q 산화제는 산화되는 물질일까?

주의 아니다. 산화제는 상대를 산화'시키고' 자신은 환원된다. 환원제는 상대를 환원시키고 자신은 산화된다.

5이산화 황은 산화제일까, 환원제일까?

(가) 황화 수소와 반응

$\ce{SO2 + 2H2S -> 3S + 2H2O}$

$\ce{SO2}$의 $\mathrm{S}$: +4 → 0 감소(환원됨)
→ $\ce{SO2}$는 산화제

(나) 염소와 반응

$\ce{SO2 + Cl2 + 2H2O -> H2SO4 + 2HCl}$

$\ce{SO2}$의 $\mathrm{S}$: +4 → +6 증가(산화됨)
→ $\ce{SO2}$는 환원제

산화제와 환원제는 정해져 있지 않고, 반응하는 상대 물질과 비교한 상대적 세기에 따라 결정된다.

금속도 같다: $\ce{Cu}$는 $\ce{Ag+}$과 반응할 때 환원제이고, $\ce{Cu^2+}$은 $\ce{Zn}$과 반응할 때 산화제이다(해 보기 결과).

연결원자 수만 맞추면 될까?

$\ce{Cu + Ag+ -> Cu^2+ + Ag}$

양쪽의 $\mathrm{Cu}$ 원자 수와 $\mathrm{Ag}$ 원자 수는 같다.

Q 이 반응식은 완성된 것일까?

전하 합

왼쪽 +1, 오른쪽 +2 — 다르다.

전자 수

구리가 잃은 전자 2개, 은 이온이 얻은 전자 1개 — 다르다.

→ 반쪽 반응식으로 전자 수를 같게 맞춘다: $\ce{Cu + 2Ag+ -> Cu^2+ + 2Ag}$

① 나누기

산화수가 변하는 원자를 찾아 산화 반쪽 반응과 환원 반쪽 반응으로 나눈다.

② 원자 수

$\mathrm{O}$, $\mathrm{H}$ 이외의 원자 수를 맞추고, $\mathrm{O}$는 $\ce{H2O}$로, $\mathrm{H}$는 $\ce{H+}$로 맞춘다(산성 용액).

③ 전하

전자 $\ce{e-}$를 더해 양쪽의 전하 합을 같게 한다.

④ 전자 수

두 반쪽 반응식의 전자 수가 같아지도록 정수배 한다.

⑤ 더하기

두 식을 더하고 양쪽에 같은 것($\ce{e-}$ 등)을 지운다.

마지막에 원자 수와 전하 합이 양쪽에서 같은지 다시 확인한다.

연습 해 보기과망가니즈산 이온과 철(II) 이온 ①

산성 용액에서 일어나는 $\ce{MnO4- + Fe^2+ -> Mn^2+ + Fe^3+}$의 반응식을 완성하자.

① 나누기 산화 $\ce{Fe^2+ -> Fe^3+}$   환원 $\ce{MnO4- -> Mn^2+}$

② 원자 수 $\mathrm{O}$ 4개는 $\ce{H2O}$ 4개로, 그 $\mathrm{H}$ 8개는 $\ce{H+}$ 8개로

$\ce{MnO4- + 8H+ -> Mn^2+ + 4H2O}$

③ 전하 왼쪽 $(-1)+8(+1)=+7$, 오른쪽 $+2$ → 왼쪽에 $\ce{e-}$ 5개

$\ce{MnO4- + 8H+ + 5e- -> Mn^2+ + 4H2O}$
$\ce{Fe^2+ -> Fe^3+ + e-}$

연습 해 보기과망가니즈산 이온과 철(II) 이온 ②

④ 전자 수 환원 반쪽은 $\ce{e-}$ 5개, 산화 반쪽은 1개 → 산화 반쪽을 5배: $\ce{5Fe^2+ -> 5Fe^3+ + 5e-}$

⑤ 더하기 두 식을 더하고 $\ce{5e-}$를 지운다.

$\ce{MnO4- + 5Fe^2+ + 8H+ -> Mn^2+ + 5Fe^3+ + 4H2O}$
검산왼쪽오른쪽
$\mathrm{Mn}$ · $\mathrm{Fe}$1 · 51 · 5
$\mathrm{O}$ · $\mathrm{H}$4 · 84 · 8
전하 합$(-1)+5(+2)+8(+1)=+17$$(+2)+5(+3)=+17$

산화수로 확인

$\mathrm{Mn}$: +7 → +2 (5 감소)

$\mathrm{Fe}$: +2 → +3 (1 증가) × 5 = 5 증가

산화수 증가량 = 감소량 = 이동한 전자 수

연습 해 보기다이크로뮴산 이온과 철(II) 이온

산성 용액에서 일어나는 $\ce{Cr2O7^2- + Fe^2+ -> Cr^3+ + Fe^3+}$의 반응식을 반쪽 반응식으로 완성하시오.

환원 $\ce{Cr2O7^2- + 14H+ + 6e- -> 2Cr^3+ + 7H2O}$

산화 $\ce{Fe^2+ -> Fe^3+ + e-}$  (× 6)

검산: 전하 $(-2)+6(+2)+14(+1)=+24$, $2(+3)+6(+3)=+24$ · $\mathrm{Cr}$ +6 → +3 (2개, 6 감소)

$\ce{Cr2O7^2- + 6Fe^2+ + 14H+ -> 2Cr^3+ + 6Fe^3+ + 7H2O}$

창의력 키우기

반쪽 반응식 카드(산화 카드·환원 카드)를 만들어, 전자 수가 맞도록 짝을 지어 전체 반응식을 만드는 놀이를 설계해 보자.

예: $\ce{Zn -> Zn^2+ + 2e-}$ 카드 1장 + $\ce{Ag+ + e- -> Ag}$ 카드 2장 → $\ce{Zn + 2Ag+ -> Zn^2+ + 2Ag}$

디지털 소양 키우기

생활 속 산화·환원 현상(녹, 표백, 사과의 갈변, 전지)의 사진을 찍어 모둠 공유 문서에 올리고, 산화되는 물질과 환원되는 물질을 표시해 보자.

사진에 사람이 나오지 않게 하고, 다른 사람의 자료는 출처를 밝힌다.

확인 문제 04서술형 — 과산화 수소의 두 얼굴

(가) $\ce{2KI + H2O2 + H2SO4 -> I2 + K2SO4 + 2H2O}$
(나) $\ce{2KMnO4 + 5H2O2 + 3H2SO4 -> K2SO4 + 2MnSO4 + 5O2 + 8H2O}$

두 반응에서 과산화 수소 $\ce{H2O2}$의 역할을 산화수 변화를 근거로 서술하시오.

예시 답안 (가)에서 $\ce{H2O2}$의 $\mathrm{O}$는 −1 → −2로 산화수가 감소하므로 환원되고, $\ce{KI}$를 산화시키는 산화제이다. (나)에서는 $\mathrm{O}$가 −1 → 0으로 증가하므로 산화되고, $\ce{KMnO4}$를 환원시키는 환원제이다. 같은 물질도 상대 물질에 따라 산화제도, 환원제도 된다.
채점 요소: ① (가) 산화수 감소 → 산화제 ② (나) 산화수 증가 → 환원제 ③ 상대적 세기로 결정됨

스스로 정리산화·환원 반응 — 개념 지도

01 산화와 환원

산화: 산소를 ❶ 얻음 · 전자를 ❷ 잃음 · 산화수 ❸ 증가

환원: 산소를 잃음 · 전자를 ❹ 얻음 · 산화수 ❺ 감소

산화와 환원은 ❻ 동시에 일어나고, 잃은 전자 수 = ❼ 얻은 전자 수

산화제는 자신이 ❽ 환원되는 물질, 환원제는 자신이 ❾ 산화되는 물질 — ❿ 상대적 세기로 정해진다.
