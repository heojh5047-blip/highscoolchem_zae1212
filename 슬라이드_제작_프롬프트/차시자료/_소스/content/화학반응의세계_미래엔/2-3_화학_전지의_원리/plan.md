## 2. 실험실 명세 — rm23cell (필수 탐구 반02-탐1)

- 조작: 왼쪽 금속판·오른쪽 금속판(마그네슘·아연·철·구리·은 — 탐구 준비물 3종 + 표 Ⅱ-1의 철·은), 전해질(각 금속 이온 1 M 수용액 / 둘 다 묽은 황산 / 증류수), 염다리(있음/없음), 전극 사이 거리 슬라이더 1–5 cm, 「측정·기록」, 「초기화」.
- 계산(덱 모형): 표준 환원 전위가 작은 쪽 = (−)극. 이온 수용액: $E=|E^\circ_L-E^\circ_R|$(= 이론값 $E^\circ_\text{전지}$) · 묽은 황산: $E=0.00-E^\circ_{(-)}$(최소 0.02), 5분 뒤 ×0.4(분극) · 증류수: $E\times0.5$, 전류 거의 0 · 염다리 없음: 0 V · 같은 금속: 0 V. 전압계 = $E-0.02$ + 설정마다 고정된 오차(±0.02). 전류 = 전압 / (100 Ω + 내부 저항), 내부 저항 = 5d(이온)·4d(산)·4000 Ω(증류수).
- 출력: 전압계(그림 속 + 표), 5분 뒤 전압, 이론값(이온 수용액만), 전류 mA, 해석 문장(극·전자 방향·분극·전해질·염다리), 그림의 극 라벨 「(−)극 · 산화 전극」/「(+)극 · 환원 전극」이 금속 짝에 따라 바뀌고, 전자 점이 (−)극 → 도선 → (+)극으로 흐름(API.loop). 오른쪽 비커는 거리만큼 이동.
- 기록 표(최근 6행): # · (−)극 · (+)극 · 전해질 · 거리 · 전압 · 5분 뒤 · 전압 막대(그래프). 서로 다른 설정 3가지 이상이면 "전압이 가장 큰 것 … 효율적인 전지 = 표준 환원 전위 차이가 큰 금속 짝 + 전압을 유지하는 반쪽 전지·염다리 + 가까운 전극".
- 실험실 시험(PRE, scratchpad `화학반응의세계_미래엔_2-3/pre.js`): 아연–구리 1.09 V(이론 1.10) → 마그네슘–구리 2.69 V(2.71) → 왼쪽 구리·오른쪽 아연이면 극 라벨이 뒤바뀜 → 묽은 황산 0.74 V, 5분 뒤 0.30 V → 증류수 전류 0.1 mA → 염다리 없음 0.00 V → 거리 5 cm 전류 9.9 → 8.6 mA → 기록 0→1→2→3행, 3가지부터 효율 조건 문장 → 초기화 0행. 모두 확인.
