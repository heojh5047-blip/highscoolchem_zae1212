**S8 탄소 원자의 결합 특성 (2) 다양한 결합 방식** 그림 위 줄 "탄소 사이 결합의 종류" — 에테인(단일 결합 C–C), 에텐(2중 결합 C=C), 에타인(3중 결합 C≡C) 구조식. 아래 줄 "탄소 골격의 모양"(수소 생략) — 사슬 모양(탄소 4개 일렬), 가지 달린 사슬 모양(탄소 3개 + 가지 1개), 고리 모양(탄소 6개 육각형). ★(위 줄) ★(아래 줄) ★ 결론 answer: "탄소는 결합 4개를 **단일·2중·3중 결합**으로 나누어 쓰고, **사슬·가지·고리** 모양으로 이어질 수 있다 → 탄소 화합물의 종류가 매우 많다." [a] 골격 결합선 draw(2).

**S9 화학식으로 나타내기** 에탄올 4칸 카드: 분자식 $\ce{C2H6O}$ — 원자의 종류와 수 / 구조식 — 원자 사이의 공유 결합을 모두 선으로(결합선 1개 = 공유 전자쌍 1개) / 간단한 구조식 $\ce{CH3CH2OH}$ — 탄소마다 붙은 수소를 묶고 작용기는 따로 / 공-막대 모형 — 입체 모양. ★ note: "분자식만으로는 원자가 어떤 순서로 연결되었는지 알 수 없다. 탄소 화합물은 구조식이나 간단한 구조식으로 나타내야 성질을 비교할 수 있다." 점검: 구조식에서 C 원자마다 결합선이 4개인지 센다.

**S10 연습 해 보기** 프로페인 $\ce{C3H8}$의 구조식과 간단한 구조식을 쓰자. 왼쪽 Q + board. 오른쪽 풀이 따라가기 ★1 탄소 원자 3개를 사슬로 잇는다(C–C–C) ★2 탄소마다 결합선이 4개가 되도록 수소를 붙인다 → 수소 3 + 2 + 3 = 8개 ★3 간단한 구조식으로 묶는다(구조식 그림 함께). 정답: 구조식(그림) · $\ce{CH3CH2CH3}$.

**S11 ③ 탄화수소** 정의(형광펜): "탄소와 수소로만 이루어진 탄소 화합물을 탄화수소라고 한다." 분류 표(2×2): 열 = 사슬 모양 / 고리 모양, 행 = 포화 탄화수소(탄소 사이가 모두 단일 결합) / 불포화 탄화수소(2중 결합이나 3중 결합이 있음). 칸: (사슬·포화) 에테인 — 알케인 / (고리·포화) 사이클로헥세인 / (사슬·불포화) 에텐(알켄), 에타인(알카인) / (고리·불포화) 벤젠 — 방향족 탄화수소. 칸마다 작은 골격 그림. ★ 행 단위 공개 2단계.

**S12 사슬 모양 포화 탄화수소 — 알케인** 정의: "사슬 모양의 포화 탄화수소를 알케인이라고 하며, 분자식은 $\mathrm{C}_n\mathrm{H}_{2n+2}$이다." 표(탄소 수 1–6): 메테인 $\ce{CH4}$ −162 °C 기체 / 에테인 $\ce{C2H6}$ −89 기체 / 프로페인 $\ce{C3H8}$ −42 기체 / 뷰테인 $\ce{C4H10}$ −0.5 기체 / 펜테인 $\ce{C5H12}$ 36 액체 / 헥세인 $\ce{C6H14}$ 69 액체. 오른쪽 막대그래프(끓는점–탄소 수, D4 축 "탄소 수", "끓는점 [°C]") [a] 막대 scale. Q "탄소 수가 많아지면 끓는점은 어떻게 될까?" ★ "높아진다 — 분자가 클수록 분자 사이의 인력이 커진다." note 쓰임: 메테인 = 도시가스(LNG)의 주성분, 프로페인·뷰테인 = 액화 석유 가스(LPG)·휴대용 가스.

**S13 사슬 모양 불포화 탄화수소** 두 카드: 에텐(에틸렌) $\ce{C2H4}$ — 2중 결합 1개, 모든 원자가 한 평면, 결합각 약 120°, 쓰임: 폴리에틸렌의 원료(03에서), 과일을 익히는 식물 호르몬 / 에타인(아세틸렌) $\ce{C2H2}$ — 3중 결합 1개, 일직선(180°), 쓰임: 산소–아세틸렌 불꽃으로 금속 용접·절단. 각 카드 구조식 + 공-막대 모형. ★ small: 2중 결합이 1개인 사슬 모양 탄화수소를 알켄($\mathrm{C}_n\mathrm{H}_{2n}$), 3중 결합이 1개인 것을 알카인($\mathrm{C}_n\mathrm{H}_{2n-2}$)이라고 한다. note(연결): 다중 결합은 전자쌍 하나처럼 취급 → 에텐 평면 삼각형(120°), 에타인 선형(180°). [a] 원자 move(2).

**S14 고리 모양 탄화수소** 두 카드: 사이클로헥세인 $\ce{C6H12}$ — 탄소 6개가 고리, 모두 단일 결합(포화), 구조식(꼭짓점 $\ce{CH2}$) / 벤젠 $\ce{C6H6}$ — 탄소 6개가 정육각형 고리, 모든 원자가 한 평면, 단일 결합과 2중 결합을 번갈아 그리지만 실제 탄소 사이 결합 6개는 모두 같다(중간 성질) → 육각형 안에 원을 그려 나타내기도 한다. ★ 벤젠 간단한 표현 2가지(교대 결합 육각형 ⇄ 원). small: 벤젠 고리가 있는 탄화수소를 방향족 탄화수소라고 한다. 벤젠은 독성이 있어 직접 다루지 않는다. [a] 원 draw.

**S15 자료 읽기: 원유의 분별 증류** 증류탑 그림(아래 가열 원유 → 위로 갈수록 온도 낮음): 석유 가스 30 °C 이하, C1–C4 / 휘발유 30–180 °C, C5–C12 / 등유 170–250 °C, C10–C16 / 경유 250–350 °C, C14–C20 / 중유 350 °C 이상, C20 이상 / 아스팔트(찌꺼기). **S17 연결** "에테인에 원자 무리 하나를 붙이면?" 에테인 vs 에탄올 구조식(수소 원자 1개 자리 → ─OH, equi 상자) + 비교 표: 끓는점 −89 °C / 78 °C, 25 °C 상태 기체 / 액체, 물에 대한 용해성 거의 녹지 않음 / 물과 섞임. Q "수소 원자 하나가 ─OH로 바뀌었을 뿐인데 왜 성질이 크게 달라질까?" ★ answer "→ 화합물의 성질을 결정하는 원자 무리가 있다: **작용기**". [a] ─OH 묶음 move(H 자리로 들어옴).

**S18 ④ 작용기** 정의(형광펜): "탄소 화합물에서 특정한 성질을 나타내는 원자나 원자단을 작용기라고 한다." "같은 작용기를 가진 화합물은 성질이 비슷하므로, 탄소 화합물은 작용기에 따라 분류한다." 표: 작용기 이름 | 구조(그림, R = 탄화수소 부분) | 화합물 계열 | 예 — 하이드록시기 $\ce{-OH}$ | 알코올 | 에탄올 $\ce{C2H5OH}$ / 폼일기 $\ce{-CHO}$ | 알데하이드 | 아세트알데하이드 $\ce{CH3CHO}$ / 카복실기 $\ce{-COOH}$ | 카복실산 | 아세트산 $\ce{CH3COOH}$. ★ 행 단위 공개. small: 이 단원에서는 세 작용기만 다룬다.

**S19 ⑤ 알코올** 정의: "탄화수소의 수소 원자 대신 하이드록시기($\ce{-OH}$)가 결합한 화합물을 알코올이라고 한다." 두 카드: 메탄올 $\ce{CH3OH}$ — 연료·화학 공업 원료, 독성이 강해 마시면 시력을 잃을 수 있다 / 에탄올 $\ce{C2H5OH}$ — 술의 성분, 소독용 알코올, 바이오 연료. 각 구조식(─OH 상자) + 공-막대 모형. ★ `.formula` 에탄올 연소 $\ce{C2H5OH(l) + 3O2(g) -> 2CO2(g) + 3H2O(l)}$ (바이오에탄올을 연료로 쓰는 까닭). [a] ─OH 상자 draw.

**S20 알코올의 성질** 그림: 에탄올 분자 1개와 물 분자 3개, ─OH와 물 사이 수소 결합 점선(field) [a] dash. 성질 3가지(단계 공개): ★1 **끓는점이 높다** — 분자 사이에 수소 결합을 하여, 탄소 수가 같은 알케인보다 끓는점이 훨씬 높다(에테인 −89 °C, 에탄올 78 °C). ★2 **물에 잘 녹는다** — ─OH가 물 분자와 수소 결합한다. 탄소 수가 많아지면 탄화수소 부분이 커져 잘 녹지 않는다(1-헥산올 0.6 g/100 g 물). ★3 **수용액은 중성이다** — ─OH는 물속에서 $\ce{OH-}$으로 떨어져 나오지 않는다. note q(오개념): 알코올의 ─OH는 수산화 나트륨 $\ce{NaOH}$의 $\ce{OH-}$과 다르다 — 알코올은 염기가 아니다.

**S21 ⑥ 알데하이드** 정의: "폼일기($\ce{-CHO}$)를 가진 화합물을 알데하이드라고 한다." 두 카드: 폼알데하이드 $\ce{HCHO}$ — 25 °C 기체, 물에 잘 녹으며 수용액(폼알린)은 생물 표본 보존에 쓰인다, 접착제·수지 원료, 새집 증후군의 원인 물질(독성) / 아세트알데하이드 $\ce{CH3CHO}$ — 몸속에서 에탄올이 분해될 때 생기며 숙취의 원인이 된다. 구조식(─CHO 상자) + 공-막대 모형. ★ 성질: 분자 사이에 수소 결합을 하지 못해 탄소 수가 같은 알코올보다 끓는점이 낮다(아세트알데하이드 20 °C, 에탄올 78 °C). 탄소 수가 적은 것은 물에 잘 녹고, 수용액은 중성이다. ★ note(다음 시간): 알데하이드는 다른 물질을 환원시키는 성질이 있어 은거울 반응을 한다 → 02.

**S22 ⑦ 카복실산** 정의: "카복실기($\ce{-COOH}$)를 가진 화합물을 카복실산이라고 한다." 두 카드: 폼산 $\ce{HCOOH}$ — 개미·벌의 침 속 물질 / 아세트산 $\ce{CH3COOH}$ — 식초의 신맛을 내는 물질. 구조식 + 공-막대. ★ 성질: 물에 녹아 일부가 이온화하여 **산성**을 나타낸다(약산) `.formula` $\ce{CH3COOH(aq) + H2O(l) <=> CH3COO^-(aq) + H3O+(aq)}$ — 그림: ─COOH의 H가 $\ce{H+}$로 물 분자에 옮겨 감(plus 화살표) [a] move. ★ 탄산수소 나트륨과 반응하여 이산화 탄소 기체를 낸다 $\ce{CH3COOH(aq) + NaHCO3(s) -> CH3COONa(aq) + H2O(l) + CO2(g)}$. small(연결): Ⅰ단원의 약산 — 아세트산의 $K_\mathrm{a}$는 작다.

## 6. 범위 점검

- 작용기: 알코올·알데하이드·카복실산만(성취기준 해설) ✓. 케톤·에스터·에테르·아민·할로젠화 알킬은 다루지 않음 ✓ (에스터는 3-2·3-4 몫)
- "작용기가 바뀌면 화합물의 성질도 바뀐다" 수준 — 성질은 끓는점·용해성·액성의 정성 비교 + 자료 값 ✓. $K_\mathrm{a}$ 계산·pH 계산 없음 ✓
- 명명법 규칙(IUPAC 접미사·위치 번호) 설명 없음 — 교과서 이름(관용 이름 병기)만 ✓. 실험실의 1-프로판올 등은 이름 표시만
- 이성질체(구조 이성질체·기하 이성질체), 혼성 오비탈, 벤젠의 공명 구조 용어는 다루지 않음 — 벤젠은 "탄소 사이 결합이 모두 같다(중간 성질)"까지 ✓
- 알켄·알카인 일반식은 small 한 줄(교과서 확인 필요) ✓
- 실험 안전·폐수 처리(성취기준 적용 시 고려 사항) S26에 명시 ✓
