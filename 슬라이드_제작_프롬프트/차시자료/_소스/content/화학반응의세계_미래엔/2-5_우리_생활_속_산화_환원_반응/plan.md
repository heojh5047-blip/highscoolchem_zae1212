## 2. 실험실 명세 — rm25design (필수 탐구 반02-탐3)

- 고르기(버튼): 용도(스마트폰 / 전기 자동차 / 전력 저장 장치), (−)극 물질(아연·마그네슘·철·수소), (+)극 물질(산소(공기)·구리 이온·은 이온), 전해질(수용액·유기 액체·고체), 재활용 설계(없음/있음), 「평가표에 기록」, 「초기화」.
- 계산: $E^\circ_\text{전지}=E^\circ_{(+)}-E^\circ_{(-)}$(표 Ⅱ-1). 시제품 전압 = $E^\circ_\text{전지}\times(0.90\text{–}0.96)$(설계마다 고정, 내부 저항). 평가 점수 1–5: 전압(≥3 V 5, ≥2 4, ≥1.5 3, ≥1 2, 그 밖 1), 나머지 5기준 = 두 전극 점수 평균 + 전해질 보정(수용액 [−1,+1,+1,+1,0], 유기 액체 [0,−2,0,−1,0], 고체 [+1,+2,−1,0,+1] — 에너지 밀도·안전성·자원·환경·수명 순) + 재활용 설계 환경 +1, 마그네슘 + 수용액 안전 −1, 반올림 후 1–5로 자름. 전극 점수: 아연 [3,4,4,4,2], 마그네슘 [4,3,4,4,1], 철 [2,5,5,5,4], 수소 [4,2,3,5,4], 산소 [5,4,5,5,3], 구리 이온 [2,4,3,3,3], 은 이온 [2,4,1,3,3]. 용도 가중치(전압·밀도·안전·자원·환경·수명): 스마트폰 [2,2,3,1,1,2], 전기 자동차 [2,3,3,1,1,2], 전력 저장 [1,1,3,3,2,2] → 총점 100점. 지속 가능성 지수 = (안전성 + 자원 + 환경·재활용) ÷ 3.
- 출력: 표준 전지 전위·시제품 전압·지속 가능성·총점, 6기준 점수 표(평가표), 전지 그림(고른 물질 칠, 고체 전해질 빗금, 도선 위 전자 점·전해질 속 양이온/음이온 점 API.loop), 방사형 그래프(우리 설계 vs 리튬 이온 전지 자료 [5,4,2,2,2,4]), 가장 약한 기준과 개선 힌트, 기록 표(최근 3행), 기록 3개 이상에서 같은 용도끼리 총점 최고·전압 최고 비교 문장.
- PRE 시험(scratchpad `화학반응의세계_미래엔_2-5/pre.js`): ① 스마트폰 아연–공기 수용액 1.99 V·1.79 V·[3,3,5,5,5,3]·78점 → ② 자동차 마그네슘–공기 고체·재활용 3.60 V·3.37 V·92점 → ③ 저장 철–공기 수용액·재활용 1.68 V·1.52 V·90점 → ④ 저장 마그네슘–공기 수용액 3.60 V·3.32 V·83점(마그네슘 경고) "전력 저장 장치용 기록 2개 중 총점 최고 #3, 전압 최고 #4 … 전압이 가장 높은 설계가 가장 좋은 전지는 아니다" → ⑤ 스마트폰 아연–은 이온 유기 액체 1.56 V·55점 → 수소–공기 고체 자동차 1.23 V·87점 → 초기화 0행. 기록 0→1→2→3→4→3행(최근 3행), 모든 값 gen.py의 파이썬 계산과 같음.
