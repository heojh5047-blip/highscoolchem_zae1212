**S6 연결** h2 "아레니우스 정의 다시 보기" 두 카드: 산 — "물에 녹아 $\ce{H+}$을 내놓는 물질" `.formula` $\ce{HCl(aq) -> H+(aq) + Cl-(aq)}$ / 염기 — "물에 녹아 $\ce{OH-}$을 내놓는 물질" $\ce{NaOH(aq) -> Na+(aq) + OH-(aq)}$. ★ card tip: "수용액에서 $\ce{H+}$은 혼자 있지 않고 물 분자와 결합해 하이드로늄 이온 $\ce{H3O+}$로 있다." `.formula` $\ce{H+(aq) + H2O(l) -> H3O+(aq)}$. 그림: $\ce{H+}$(작은 H 공 + "양성자" 라벨)이 물 분자 위 받는 자리로 다가가 $\ce{H3O+}$ [a] move.

**S7 ① 아레니우스 정의의 한계** 두 카드 + 각 Q. 카드 1 "암모니아는 $\ce{OH-}$이 없는데 염기?" — "암모니아 분자 $\ce{NH3}$에는 $\ce{OH}$가 없지만 수용액은 염기성이다." ★ $\ce{NH3(aq) + H2O(l) <=> NH4+(aq) + OH-(aq)}$ ★ "$\ce{OH-}$은 암모니아가 아니라 **물**에서 나온다." 카드 2 "물이 없는 반응은?" — $\ce{HCl(g) + NH3(g) -> NH4Cl(s)}$ "수용액이 아니므로 아레니우스 정의로는 산 염기 반응이라고 할 수 없다." ★ answer: "→ $\ce{OH-}$이 없거나 물이 없을 때도 쓸 수 있는 정의가 필요하다: **$\ce{H+}$의 이동**에 주목한다."

**S8 ① 브뢴스테드·라우리 정의** 정의(mark): "산은 양성자($\ce{H+}$)를 내놓는 물질(양성자 주개)이고, 염기는 양성자를 받는 물질(양성자 받개)이다." 그림 (왼): 수소 원자(양성자 1개 + 전자 1개, 전자 껍질 원) → 전자를 잃음 → $\ce{H+}$ = 양성자. [a] 전자가 떨어져 나감(move). 그림(오): 산 —($\ce{H+}$, plus 화살표)→ 염기 도식. note small: "1923년 덴마크의 브뢴스테드와 영국의 라우리가 각각 제안하였다." ★ "산 염기 반응 = 양성자가 산에서 염기로 옮겨 가는 반응"

## 2. 실험실 명세 — rm11proton (S20, 연습용)

- 반응 버튼 7개: r1 $\ce{HCl + H2O -> Cl- + H3O+}$ · r2 $\ce{NH3 + H2O <=> NH4+ + OH-}$ · r3 $\ce{HCl + NH3 -> NH4Cl}$(생성물은 $\ce{Cl-}$·$\ce{NH4+}$ 이온 결합 고체) · r4 $\ce{CH3COOH + H2O <=> CH3COO- + H3O+}$ · r5 $\ce{HF + NH3 <=> F- + NH4+}$ · r6 $\ce{H2O + H2O <=> H3O+ + OH-}$ · r7 $\ce{HCO3- + OH- <=> CO3^2- + H2O}$.
- 1단계 「산 고르기」: 두 반응물 버튼 중 $\ce{H+}$을 내놓는 쪽을 누른다. 맞으면 2단계, 틀리면 해석 문장 "그 물질은 생성물에서 H가 늘어났다 → 받는 쪽(염기). 다시 골라 보자."(시도 수 증가). r6은 어느 쪽을 골라도 맞음(같은 물질).
- 2단계: 그림에 $\ce{H+}$ 공(plus)이 산 → 염기로 포물선을 따라 계속 옮겨 가는 애니메이션(API.loop, 보일 때만), 반응물 아래 역할(산 plus / 염기 minus), 생성물 아래 짝염기/짝산, 쌍 1 field·쌍 2 bfield 괄호선, 물의 역할 문장.
- 결과(readout): 산 · 염기 · 짝산–짝염기 쌍 · 물의 역할(염기/산/없음/산과 염기/생성물). 점수 output "맞힘 n / 시도 m".
- 「기록」 → 표에 행이 쌓임(최근 4행: 반응 번호, 산, 염기, 쌍). 「초기화」(data-act="reset")는 표·점수·단계를 비운다.
