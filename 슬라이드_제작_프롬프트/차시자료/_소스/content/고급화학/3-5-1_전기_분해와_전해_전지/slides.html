학습 목표

직류 전기를 이용한 전기 분해의 역사는 화학 전지의 발명보다 훨씬 앞선다. 18세기 후반부터 광물에서 원소를 분리하는 데 쓰였고, 물의 전기 분해로 얻은 순수한 수소 덕분에 하버법 암모니아 합성과 비료 생산이 가능해졌다. 전해 전지에서는 다니엘 전지의 전지 전위보다 큰 외부 전위를 걸어 다니엘 전지의 역반응을 일으킨다.

이 장에서는 전기 분해의 원리와 자유 에너지, 전해 전지에 가한 전하량과 생성물의 양적 관계를 알아본다.

1전해 전지와 전기 분해

산업에서 가장 많이 쓰는 전해 전지의 활용은 전기 분해이다. 전기 분해는 외부에서 전기 에너지를 공급하여 화합물을 구성 원소로 분해한다.

  • 다니엘 전지와 달리 두 전극이 같은 전해질 속에 있다.
  • 물을 전기 분해해 순수한 수소와 산소를 얻고, 염 혼합물에서 금속이나 비금속을 추출한다.

Q 물의 전기 분해에서 각 전극에서 생기는 기체는 무엇일까?

→ 산화 전극((+)극)에서 산소, 환원 전극((−)극)에서 수소가 발생한다.

Q 두 관에 모인 기체의 부피를 비교하면?

→ 수소 : 산소 $=2:1$ — 다음 장의 전극 반응식으로 확인한다.

그림 Ⅲ-31 물의 전기 분해(모식도)

2물의 전기 분해 — 전극 반응

Q 각 전극에서 물은 어떻게 반응할까?

환원 전극 (−)극$\ce{4H2O(l) + 4e- -> 2H2(g) + 4OH-(aq)}$
산화 전극 (+)극$\ce{2H2O(l) -> O2(g) + 4H+(aq) + 4e-}$
전체 반응$\ce{2H2O(l) -> 2H2(g) + O2(g)}$

Q 두 반쪽 반응을 더하면 왜 전체 반응이 될까?

→ 전자 $4$개가 지워지고, 생긴 $\ce{4H+}$와 $\ce{4OH-}$이 섞이면 $\ce{4H2O}$가 되어 $6\ce{H2O}-4\ce{H2O}=2\ce{H2O}$만 남는다.

Q 순수한 물 대신 황산 나트륨 같은 전해질을 조금 녹이는 까닭은?

→ 순수한 물에는 이온이 거의 없어 전류가 잘 흐르지 않는다. $\ce{Na+}$·$\ce{SO4^2-}$은 반응하지 않고 전하만 나른다.

3전기 분해의 원리와 깁스 자유 에너지

모든 화학 전지에서는 자발적 산화 환원 반응이 일어난다: $\Delta G^\circ<0$, $E^\circ_\text{전지}>0$.

그 역반응은 크기가 같고 부호가 반대인 값을 가진다: $\Delta G^\circ>0$, $E^\circ_\text{전지}<0$ — 비자발적이다.

Q 역반응의 $\Delta G^\circ$와 $E^\circ_\text{전지}$의 부호는?

외부 전원으로 $E^\circ_\text{전지}$보다 큰 전위를 공급하면 이 역반응이 일어난다.

Q 역반응을 일으키려면 외부에서 최소 얼마의 전기 에너지를 공급해야 할까?

→ 양의 $\Delta G^\circ$를 $0$으로 바꾸는 크기 — 자발 반응의 $\Delta G^\circ$와 부호가 반대인 $-\Delta G^\circ$이다. 다니엘 전지라면 $1\ \text{mol}$당 $212.3\ \text{kJ}$.

4다니엘 전지와 그 역반응

산화 전극$\ce{Zn(s) -> Zn^2+(aq) + 2e-}$$E^\circ(\ce{Zn^2+}/\ce{Zn})=-0.76\ \text{V}$
환원 전극$\ce{Cu^2+(aq) + 2e- -> Cu(s)}$$E^\circ(\ce{Cu^2+}/\ce{Cu})=0.34\ \text{V}$
전체 반응$\ce{Zn(s) + Cu^2+(aq) -> Zn^2+(aq) + Cu(s)}$$E^\circ_\text{전지}=1.1\ \text{V}$, $\Delta G^\circ=-212.3\ \text{kJ/mol}$
역반응$\ce{Zn^2+(aq) + Cu(s) -> Zn(s) + Cu^2+(aq)}$$E^\circ_\text{전지}=-1.1\ \text{V}$, $\Delta G^\circ=212.3\ \text{kJ/mol}$

검산: $\Delta G^\circ=-nFE^\circ_\text{전지}=-(2)(96485)(1.10)\ \text{J}=-212.3\ \text{kJ}$

Q 역반응(전해 전지)에서 아연 전극과 구리 전극의 이름은?

→ 아연 전극: $\ce{Zn^2+ + 2e- -> Zn}$이 일어나는 환원 전극, 구리 전극: $\ce{Cu -> Cu^2+ + 2e-}$이 일어나는 산화 전극

$-0.76\ \text{V}$, $0.34\ \text{V}$는 표준 환원 전위이다(교과서는 $-0.76\ \text{V}$를 산화 반응 옆에 적음).

Q 전해 전지의 빈칸에 들어갈 부호는?

두 전지 모두 산화는 산화 전극에서, 환원은 환원 전극에서 일어나지만, 전극의 부호는 반대이다.

Q 「전기 분해에서는 (+)극에서 환원이 일어난다」는 말은 맞을까?

→ 틀리다. 전원의 (+)극이 연결된 전극에서 전자를 끌어가므로 그 전극의 물질이 전자를 잃는다 — 전해 전지의 (+)극은 산화 전극이다. 전극 이름은 반응으로 정한다.

표 Ⅲ-12 다니엘 전지와 전해 전지의 비교

확인 문제 01물을 전기 분해하는 데 필요한 최소 전압

$25\ {}^\circ\text{C}$에서 수소 연료 전지 반응 $\ce{2H2(g) + O2(g) -> 2H2O(l)}$의 $\Delta G^\circ=-474.2\ \text{kJ}$이다. ($F=96485\ \text{C/mol}$)

(1) 물의 전기 분해 $\ce{2H2O(l) -> 2H2(g) + O2(g)}$의 $\Delta G^\circ$는? → 역반응이므로 $+474.2\ \text{kJ}$

(2) 이 반응의 $E^\circ_\text{전지}$는? → 전자 $n=4$: $E^\circ_\text{전지}=-\dfrac{\Delta G^\circ}{nF}=-\dfrac{474200}{4\times96485}=$ $-1.229\ \text{V}$

(3) 물을 전기 분해하려면 전원의 전압이 어때야 할까? → $1.23\ \text{V}$보다 큰 전압을 걸어야 한다. 실제로는 전극 반응을 일으키는 데 이론값보다 더 드는 전압(과전압) 때문에 더 큰 전압이 필요하다.

교과서 날개 물의 전기 분해로 수소를 만드는 데 막대한 에너지가 들어, 전기 분해 효율을 높이는 신소재 전극용 나노 촉매 개발이 경쟁적으로 이루어지고 있다.

6녹은 염의 전기 분해 — 염화 나트륨

염화 나트륨을 녹이면 $\ce{Na+}$과 $\ce{Cl-}$이 자유롭게 움직여 전류가 흐른다.

환원 전극 (−)극$\ce{Na+(l) + e- -> Na(l)}$
산화 전극 (+)극$\ce{2Cl-(l) -> Cl2(g) + 2e-}$
전체 반응$\ce{2NaCl(l) -> 2Na(l) + Cl2(g)}$

Q 각 전극에서 어떤 이온이 반응할까?

Q 고체 염화 나트륨은 왜 전기 분해되지 않을까?

→ 이온 결정 속의 이온은 제자리에 고정되어 움직이지 못하므로 전류가 흐르지 않는다(Ⅱ-3 이온 결정).

Q 나트륨을 수용액이 아니라 녹은 염에서 얻는 까닭은?

→ 수용액에서는 $\ce{Na+}$보다 물이 먼저 환원되어 수소가 생기기 때문이다(다음 장).

7수용액의 전기 분해 — 생성물 예측하기

환원 전극에서는 가장 환원되기 쉬운 화학종(표준 환원 전위가 큰 것)이, 산화 전극에서는 가장 산화되기 쉬운 화학종이 반응한다. 수용액에서는 용질의 이온과 물 분자가 경쟁한다.

물의 환원 $\ce{2H2O + 2e- -> H2 + 2OH-}$ $(-0.83\ \text{V})$, 물의 산화 $\ce{2H2O -> O2 + 4H+ + 4e-}$ $(\ce{O2}/\ce{H2O}\ +1.23\ \text{V})$

Q 염화 나트륨 수용액의 환원 전극에서는 무엇이 생길까?

→ 물($-0.83\ \text{V}$)이 $\ce{Na+}$($-2.70\ \text{V}$)보다 훨씬 환원되기 쉬우므로 수소가 발생한다.

Q 진한 염화 나트륨 수용액의 산화 전극에서는?

→ 값으로는 물이 $\ce{Cl-}$보다 조금 더 산화되기 쉽지만, 산소가 발생하려면 이론값보다 큰 전압(과전압)이 필요해 실제로는 염소가 발생한다.

Q 각 수용액에서 두 전극의 반응과 용액의 변화는?

전체 반응 — 진한 $\ce{NaCl}$: $\ce{2H2O + 2Cl- -> H2 + Cl2 + 2OH-}$  ·  $\ce{CuSO4}$($\ce{Pt}$): $\ce{2Cu^2+ + 2H2O -> 2Cu + O2 + 4H+}$

구리 전극을 쓰면 산화 전극의 구리가 물보다 먼저 산화된다(전극 자체가 반응). $\ce{SO4^2-}$은 어느 경우에도 반응하지 않는다.

9전기 도금과 구리의 정련

전기 도금: 도금할 물체를 환원 전극(전원의 (−)극)에, 도금할 금속을 산화 전극((+)극)에 연결하고, 그 금속 이온이 든 수용액에 담근다.

은 도금 — (−)극 $\ce{Ag+(aq) + e- -> Ag(s)}$, (+)극 $\ce{Ag(s) -> Ag+(aq) + e-}$

Q 은 도금을 하는 동안 수용액의 $\ce{Ag+}$ 농도는 어떻게 될까?

→ 산화 전극에서 녹아 나온 만큼 환원 전극에서 석출되므로 거의 그대로이다.

구리의 정련: 불순한 구리를 (+)극, 순수한 구리를 (−)극으로 하여 $\ce{CuSO4}$ 수용액을 전기 분해한다.

(+)극에서는 구리와 구리보다 산화되기 쉬운 $\ce{Zn}$·$\ce{Fe}$ 등이 녹아 나오고, $\ce{Ag}$·$\ce{Au}$는 녹지 않고 전극 밑에 가라앉는다. (−)극에는 환원되기 쉬운 $\ce{Cu}$만 석출된다.

탐구 활동[필수 탐구] 전해 전지 반응을 이용한 금속 도금의 종류와 특성 조사

일상생활에서 많이 접하는 도금은 전해 전지를 응용한 기술이다. 도금은 재료 표면의 산 부식을 막고 마찰 저항성을 높여 제품의 수명과 특성, 미적 가치를 높인다.

과정

  1. 모둠별로 일상생활과 산업에서 쓰는 물체에 적용된 도금의 종류를 조사한다.
  2. 도금이 원래 물체의 성질에 어떤 유익한 변화를 가져오는지 도금 금속의 종류별로 논의한다.
  3. 결과를 500자 이내로 요약한다.

아연함석 지붕, 볼트·가드레일(철)흠집이 나도 철보다 산화되기 쉬운 아연이 먼저 산화되어 철을 보호한다

Q 함석(아연 도금)과 주석 도금 철판에 흠집이 나면 어느 쪽 철이 더 빨리 녹슬까?

→ 주석 도금 철판: 철이 주석보다 산화되기 쉬워 드러난 철이 먼저 산화된다. 함석은 아연이 대신 산화된다.

10전해 전지에서 전하량과 생성물의 양적 관계

생성물의 양은 공급한 전하량을 전자의 양으로 바꾸어 구한다. 전극에서의 생산량은 공급된 전자의 몰수, 곧 전하량에 정비례한다(패러데이 법칙).

  • 전류 $1\ \text{A}$는 $1$초당 $1\ \text{C}$의 전하 흐름: $I=\dfrac{Q}{t}$ → 전하량 $Q=It$
  • 전하량 = 전자 $1\ \text{mol}$의 전하량 $F$ × 전자의 몰수: $Q=n_{e^-}F$ → $n_{e^-}=\dfrac{Q}{F}=\dfrac{It}{F}$
  • 전자의 몰수와 반쪽 반응의 계수비로 생성물의 몰수를 구한다.

교과서는 전하량을 $C$로 써서 $C=It$, $C=nF$로 나타낸다. 덱에서는 단위 쿨롱(C)과 헷갈리지 않게 $Q$로 쓴다. $F=96485\ \text{C/mol}$

Q 같은 전류를 2배 오래 흘리면 석출되는 구리의 질량은?

→ 전하량이 2배 → 전자의 몰수 2배 → 구리도 2배

Q 전자 $1\ \text{mol}$이 흐를 때 석출되는 $\ce{Ag}$, $\ce{Cu}$, $\ce{Al}$의 몰수는?

→ $\ce{Ag}$ $1\ \text{mol}$, $\ce{Cu}$ $\tfrac12\ \text{mol}$, $\ce{Al}$ $\tfrac13\ \text{mol}$ — 이온 하나가 받는 전자 수가 1, 2, 3이다.

예제 Ⅲ-13금 도금에 필요한 전자의 몰수

전해 전지 반응 $\ce{Au^3+(aq) + 3e- -> Au(s)}$은 전해 전지의 환원 전극에서 일어나는 금의 전기 도금 반응이다. $3.0\ \text{g}$의 금을 도금하는 데 필요한 전자의 몰수는 얼마인가? (단, $\ce{Au}$의 원자량은 $197.0$이다.)

풀이 1 금 $3.0\ \text{g}$의 몰수: $\dfrac{3.0\ \text{g}}{197.0\ \text{g/mol}}=0.01523\ \text{mol}$

풀이 2 금 $1\ \text{mol}$을 얻는 데 전자 $3\ \text{mol}$이 필요하다.

$n_{e^-}=0.01523\times3=0.04569\ \text{mol}$

더 해 보기 이때 필요한 전하량은? → $Q=n_{e^-}F=0.04569\times96485=4.41\times10^{3}\ \text{C}$

확인 문제 03전하량으로 생성물의 양 예측하기

백금 전극으로 $\ce{CuSO4}$ 수용액에 $2.00\ \text{A}$의 전류를 $30.0$분 동안 흘렸다. 환원 전극에서 석출되는 구리의 질량과, 산화 전극에서 발생하는 산소의 부피를 구하여라. (단, $\ce{Cu}$ $63.55\ \text{g/mol}$, $25\ {}^\circ\text{C}$·$1\ \text{atm}$에서 기체 $1\ \text{mol}$의 부피 $24.5\ \text{L}$)

풀이 1 $Q=It=2.00\ \text{A}\times1800\ \text{s}=3600\ \text{C}$ → $n_{e^-}=\dfrac{3600}{96485}=0.03731\ \text{mol}$

풀이 2 $\ce{Cu^2+ + 2e- -> Cu}$: $\ce{Cu}$ $\dfrac{0.03731}{2}=0.01866\ \text{mol}$ → $0.01866\times63.55=$ $1.19\ \text{g}$

풀이 3 $\ce{2H2O -> O2 + 4H+ + 4e-}$: $\ce{O2}$ $\dfrac{0.03731}{4}=0.009328\ \text{mol}$ → $\times24.5\ \text{L/mol}=$ $0.229\ \text{L}$

같은 전자 $4\ \text{mol}$으로 $\ce{Cu}$ $2\ \text{mol}$, $\ce{O2}$ $1\ \text{mol}$ — 두 전극의 생성물 몰수비는 계수비 $2:1$이다.

확인 문제 04생성물의 양으로 전기량 예측하기

숟가락에 은 $1.08\ \text{g}$을 도금하려고 한다. (단, $\ce{Ag}$ $107.9\ \text{g/mol}$, $F=96485\ \text{C/mol}$)

(1) 필요한 전하량은? → $\ce{Ag}$ $\dfrac{1.08}{107.9}=0.01001\ \text{mol}$, 전자도 $0.01001\ \text{mol}$ → $Q=0.01001\times96485=$ $966\ \text{C}$

(2) $0.500\ \text{A}$로 흘리면 몇 분이 걸릴까? → $t=\dfrac{Q}{I}=\dfrac{966}{0.500}=1.93\times10^{3}\ \text{s}\approx$ $32.2$분

(3) 같은 전하량으로 $\ce{Au^3+}$ 용액에서 금을 도금하면 몇 g일까? → $\ce{Au}$ $\dfrac{0.01001}{3}\times197.0=$ $0.657\ \text{g}$ — 이온의 전하가 클수록 같은 전하량에 석출되는 몰수가 작다.

연습 문제 1볼타 전지와 전해 전지의 전극 반응

$\ce{Cu(s) + Sn^2+(aq) -> Cu^2+(aq) + Sn(s)}$와 같은 전지 반응식에서 각 전극의 반응은 어떤 반응인지 볼타 전지와 전해 전지로 구분하여 제시하여라. 또한, 역반응에서 각 전극의 반응도 함께 제시하여라.

풀이 1 $E^\circ_\text{전지}=E^\circ(\ce{Sn^2+}/\ce{Sn})-E^\circ(\ce{Cu^2+}/\ce{Cu})=-0.14-0.34=-0.48\ \text{V}<0$ → 주어진 반응은 비자발적(전해 전지), 역반응은 자발적(볼타 전지)

전해 전지(주어진 반응): 산화 전극 $\ce{Cu(s) -> Cu^2+(aq) + 2e-}$, 환원 전극 $\ce{Sn^2+(aq) + 2e- -> Sn(s)}$
볼타 전지(역반응): 산화 전극 $\ce{Sn(s) -> Sn^2+(aq) + 2e-}$, 환원 전극 $\ce{Cu^2+(aq) + 2e- -> Cu(s)}$

$\ce{Sn^2+}/\ce{Sn}$ $-0.14\ \text{V}$는 덱이 보탠 값이다(교과서 표에 없음).

연습 문제 2전해 전지의 전극 부호와 $\Delta G$, $E_\text{전지}$

전해 전지에서 산화 전극과 환원 전극 각각의 전극 부호를 쓰고, $\Delta G$와 $E_\text{전지}$의 크기를 나타내어라.

산화 전극: (+)극, 환원 전극: (−)극
$\Delta G>0$, $E_\text{전지}<0$ — 비자발적 반응을 외부 전기 에너지로 일으킨다.

화학 전지(다니엘 전지)와 이름은 같고 부호는 반대이다(표 Ⅲ-12). 교과서 풀이는 두 전극에 각각 「$\Delta G>0$, $E_\text{전지}<0$」을 적었는데, 이는 전해 전지 전체 반응의 값이다.

연습 문제 3묽은 산 수용액의 전기 분해

묽은 산 수용액의 전기 분해에서 산화 전극, 환원 전극에서의 각 반응과 전체 전극 반응을 제시하여라.

산화 전극 $\ce{2H2O(l) -> O2(g) + 4H+(aq) + 4e-}$

환원 전극 $\ce{4H+(aq) + 4e- -> 2H2(g)}$

전체 $\ce{2H2O(l) -> 2H2(g) + O2(g)}$

Q 전기 분해가 끝난 뒤 산($\ce{H+}$)의 양은 어떻게 될까?

→ 산화 전극에서 생긴 $\ce{H+}$만큼 환원 전극에서 쓰이므로 그대로이다. 물만 줄어 산의 농도는 조금 진해진다.
