## 2. 실험실 `ac451cat` (S33, 교과서 257 탐구 활동 — 덱목록 labCandidate)
- 입력: 촉매 버튼(없음·$\ce{KI}$·$\ce{MnO2}$·카탈레이스(감자)) · 농도 버튼(1·2·3 %, 5 mL) · 온도 슬라이더(15–55 °C, 5 °C 간격) · 「측정 시작」(API.loop로 180 s를 약 5 s에 진행, 플라스크 거품·주사기 피스톤 움직임) · 「끝까지」 · 「초기화」. 측정 중 조건을 바꾸면 측정을 멈춘다.
- 모형: $\ce{H2O2}$ 1차, $V(t)=V_\text{max}(1-e^{-kt})$, $V_\text{max}=\dfrac{p\times10}{34.01}\ \text{M}\times0.005\ \text{L}\times\dfrac12\times24.5\ \text{L/mol}$(1·2·3 % → 18.0·36.0·54.0 mL), $k=k_{25}\exp\left[-\dfrac{E_\mathrm{a}}{R}\left(\dfrac1T-\dfrac1{298.15}\right)\right]$, $E_\mathrm{a}$ 없음 76(교과서)·$\ce{KI}$ 57·$\ce{MnO2}$ 50·카탈레이스 23 kJ/mol, $k_{25}$ $2.0\times10^{-7}$·0.010·0.025·0.050 s⁻¹, 카탈레이스는 변성 인자 $1/(1+e^{(t-45)/3})$(25 °C를 1로).
- 출력: $V$–$t$ 그래프(최근 4회 곡선 + 30 s마다 측정 점, 고정 시드 ±1.5 % 오차) · 촉매 없음(ink)/고른 촉매(field 점선, 골짜기 중간체) 반응 에너지 도표와 $E_\mathrm{a}$ 값 · 현재 값 줄 · 해석 문장(직전 기록과 한 조건만 다르면 촉매/온도/농도 비교, 둘 이상 다르면 「한 조건만 바꾸자」) · 기록 표(최근 4행: 회·촉매·온도·농도·30 s 부피·180 s 부피·반감기).
- PRE 시험(11/26, `pre.js`): 처음 「아직 측정하지 않았습니다」, 기록 0 → 없음 25 °C 「거의 생기지 않는다」 → $\ce{KI}$ 25 °C: 0.47 mL/s, 반감기 69 s, 180 s 44.6 mL, 「속도 상수 5.0×10⁴배, 최종 부피 54.0 mL 같다」 → 35 °C: 반감기 33 s, 「2.11배」 → 1 %: 「처음 속도 0.34배, 최종 부피 0.3배, 반감기는 같다」 → $\ce{MnO2}$ 3 % 25 °C: 「두 가지 이상 조건이 다르다」 → 카탈레이스 25 °C: 반감기 14 s, 「2.00배」 → 35 °C 「1.31배」 → 55 °C 반감기 172 s, 「0.06배, 효소가 변해 느려졌다」 → 기록 4행 표시 → 「측정 시작」 → 「측정 중 9회: t = 0 s」 → 촉매 바꾸면 「측정을 멈췄습니다」. 오른쪽 $E_\mathrm{a}'$ 값이 촉매마다 57·50·23으로 바뀜.

## 5. 범위 점검
- 04-10 성취기준 해설 「사전 평형, 정류 상태 근사와 같은 확장된 속도식보다 실험실 수준에서 관찰 가능한 속도식 중심」, 덱목록 note 「사전 평형·정류 상태 근사는 다루지 않음」 → S15($\ce{2NO + O2}$)는 교과서 본문이라 넣되, 덱 본문은 「속도 결정 단계까지 들어간 반응물 세기」로 실험 속도식과 맞추어 보는 데까지 하고, 교과서의 $k_1/k_{-1}$ 대입 풀이는 점선 상자 「교과서 풀이」로 작게만 보였다(문항 없음). 정류 상태 근사는 없다.
- 04-11 해설(자체 지도서 「균일 촉매, 불균일 촉매, 효소를 반응 경로 그림으로 비교」) → S23·S26·S28·S29·S31.

## 6. 확인이 필요한 점
1. 교과서 250쪽 1분자 반응 예 $\ce{2N2O5 -> 4NO2 + O2}$은 전체 반응식이다. 덱은 교과서 식과 속도식을 그대로 쓰고, 그 아래에 「속도를 정하는 1분자 단계는 $\ce{N2O5 -> NO2 + NO3}$」를 작은 글로 덧붙였다(그림도 이 단계).
2. 252쪽 $\ce{2NO + O2}$ 빠른 평형 풀이: 성취기준 해설·덱목록 note(사전 평형 제외)와 교과서 본문이 어긋난다. 덱은 교과서 풀이를 점선 상자로만 보였다 — 수업에서 뺄지 선생님 판단.
3. 교과서 256쪽 「그림 Ⅳ-32와 같은 네 단계」는 그림 Ⅳ-34의 착오로 보고, 덱은 「그림 Ⅳ-34」로 썼다.
4. 덱이 정한 값: S9 초기 속도 자료(가상), S13 활성화 착물 높이(132·116, 중간체 +96은 생성 엔탈피 계산), S23 $\ce{I-}$ 경로 $E_\mathrm{a}'=57$ kJ/mol·$\Delta H=-95$ kJ/mol, 실험실 촉매별 $E_\mathrm{a}$(57·50·23)·$k_{25}$·카탈레이스 변성 인자. 수업 실험값으로 바꾸어 쓰면 된다.
5. 탐구 활동 예시 결과(S19 사례·글, S34 조사 표·곡선)와 확인 문제 01·03, 연습 문제 3 채점 요소는 덱이 만들었다(출판사 지도서 없음). 확인 문제 02는 자체 지도서 형성평가 15의 ①–③(④ 촉매 부분은 확인 03에 반영).
6. 연습 문제 2에서 $\ce{CF2Cl2}$는 2단계에서 소모되고 4단계에서 다시 생기므로 촉매처럼 작용한다는 설명을 덱이 덧붙였다(교과서 풀이의 중간체 목록 $\ce{O}$, $\ce{ClO}$, $\ce{CF2Cl}$, $\ce{Cl}$과 같음).
