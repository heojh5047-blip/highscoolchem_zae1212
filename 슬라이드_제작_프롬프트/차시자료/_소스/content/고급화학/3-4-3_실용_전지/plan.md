## 6. 확인이 필요한 점
1. **교과서 175쪽 알칼리 전지 환원 전극식** $\ce{2MnO2(s) + 2H2O(l) + 2e- -> Mn2O3(s) + 2OH-(aq)}$은 H·O 수가 맞지 않는다(왼쪽 H 4·O 6, 오른쪽 H 2·O 5). 전체 반응($\ce{H2O}$ 계수 1)과 맞도록 덱은 $\ce{H2O}$ 계수를 1로 고쳐 쓰고 S7에 작은 글씨로 알렸다.
2. 은 단추 전지(176 날개): 교과서는 산화 전극 반응 옆에 $E^\circ=+1.260\ \text{V}$(산화 방향 전위)를 쓰고 두 값을 더해 1.602 V를 얻었다. 덱은 3-4-1b의 약속($E^\circ$는 항상 환원 전위)에 맞춰 $\ce{ZnO}/\ce{Zn}$ 환원 전위 $-1.260\ \text{V}$로 쓰고 $E^\circ_\text{전지}=0.342-(-1.260)$으로 계산했다(같은 값). 연습 문제 3의 「$\ce{Cd(s) -> Cd^2+(aq) + 2e-}$ ($E^\circ=-0.402$ V)」도 값은 환원 전위이므로 그렇게 풀이에 적었고, 문제의 $\ce{Cd^2+(s)}$는 $(aq)$로 바로잡았다.
3. 탐구 활동 고화-탐26·27의 예시 결과(기술 종류·장단점·걸림돌·요약문)는 지도서가 없어 덱이 일반 화학 지식으로 썼다(수소 생산 행만 자체 지도서 예시). 수치(작동 온도 등)는 교과서 179쪽에 있는 것만 썼다.
4. 그림 Ⅲ-28은 교과서 그림의 구성(가운데 흑연 봉 = 환원 전극, $\ce{MnO2}$ 반죽, 격리판, 아연 = 산화 전극)을 따랐다. 실제 시판 알칼리 전지는 아연 젤이 가운데, $\ce{MnO2}$가 바깥쪽인 구조가 많다 — 화면에는 넣지 않았다.
5. 확인 03의 $\Delta G^\circ_\text{f}$·$\Delta H^\circ_\text{f}$ 값은 문항에서 주었다(교과서 부록 표 값과 같은지 선생님 확인).
6. 연습 문제 1은 서술형이라 예시 답안·채점 요소를 덱이 만들었다(부록 풀이는 「본문 Ⅲ-4, 01 소단원 … 참조」뿐).
