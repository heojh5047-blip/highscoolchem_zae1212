- **알케인 골격 조립**: 분자식 버튼 $\ce{C4H10}$ · $\ce{C5H12}$ · $\ce{C6H14}$. 왼쪽 조립판(SVG 6열 × 3행 격자점, 간격 64): 점을 누르면 C를 놓고/뺀다. 가로·세로로 이웃한 C끼리 결합선이 자동으로 생긴다(H는 자동으로 채운다고 안내). 상태 줄: "탄소 k / n개 · 찾은 이성질체 m / N"(N = 2, 3, 5).
  - 「확인」: ① 탄소 수 ≠ n → "탄소를 n개 놓자(지금 k개)" ② 이어지지 않음 → "모든 탄소가 결합으로 이어져야 한다" ③ 고리(결합 수 ≠ 탄소 수 − 1) → "고리가 생겼다 — 고리 모양은 CnH2n이라 알케인이 아니다" ④ 알맞으면 탄소 골격의 정규형(AHU: 중심에서 뿌리 내린 괄호 문자열, 중심 2개면 작은 것)을 구해 자료와 맞춘다 → 오른쪽 3차원 공-막대 모형(끌어서 회전, 손 떼고 1.5 s 뒤 천천히 돎), 판독(이름 · 축약 구조식 · 끓는점), 처음 찾은 것이면 기록 표에 행 추가(분자식 | 이름 | 가지 수 | 끓는점), 이미 찾은 것이면 "이미 찾은 ○○이다 — 사슬을 꺾거나 뒤집어 그린 같은 분자" (행 추가 없음). N개를 다 찾으면 "$\ce{C5H12}$의 구조 이성질체 3개를 모두 찾았다".
  - 「골격 지우기」: 조립판 비우기.
- **2-뷰텐 모형**: 버튼 시스-2-뷰텐 · 트랜스-2-뷰텐 · 뷰테인(비교). 슬라이더 「가운데 결합을 축으로 돌리기」 0–180°(15° 간격, output "0°"). 체크 상자 「p 오비탈 보기」(2-뷰텐일 때 C2·C3의 혼성하지 않은 p 오비탈 엽 bfield/grav .30). 판독: 가운데 결합(2중 결합 σ + π / 단일 결합 σ) · π 결합 겹침(2-뷰텐: $100\,|\cos\theta|$ %, 90°에서 0 % "끊어짐" / 뷰테인: "π 결합 없음 — σ 겹침 그대로") · 끓는점.
  - 해석: θ = 0 "시스: 두 메틸기가 2중 결합의 같은 쪽 — 끓는점 3.7 °C" / 0 < θ < 90 "돌릴수록 두 p 오비탈이 나란하지 않아 π 결합의 겹침이 줄어든다(○ %)" / θ = 90 "p 오비탈이 서로 수직 → π 결합이 끊어진다. 약 264 kJ/mol(612 − 348)이 필요해 실온에서는 일어나지 않는다." / θ > 90 "π 결합을 끊고 다시 만들어야만 트랜스(시스) 모양이 된다 — 그래서 시스와 트랜스는 서로 다른 화합물이다." / 뷰테인 "단일 결합(σ)은 돌려도 겹침이 그대로 — 실온에서 자유롭게 돌아 모양만 바뀌는 같은 분자이다."
  - 「성질 기록」: 시스·트랜스면 기록 표에 행(분자식 $\ce{C4H8}$ | 이름 | 녹는점 −139/−106 °C를 가지 수 칸 대신 "극성/무극성" | 끓는점). 같은 것을 두 번 기록하지 않음.
- 「그래프」: 기록한 이성질체의 끓는점 막대(분자식별 묶음, 막대 아래 가지 수 또는 시스/트랜스, 세로축 "끓는점 (°C)" −20–80). 다시 누르면 모형. 기록이 없으면 "기록한 이성질체가 없다" 메시지.
- 「초기화」: 기록·조립판 비우기, $\ce{C4H10}$ / 시스, θ = 0, 시점 처음으로.
- 자료(gen.py가 labs.js에 넣음): 정규형 → {이름, 축약 구조식(tex), 가지 수, 끓는점, 3차원 좌표(C·H), 결합}. 끓는점은 0절 덱 보충 값. 2-뷰텐 좌표는 평면(C=C 1.34, C–C 1.50, C–H 1.09 Å, 120°), θ는 C3 쪽 원자를 C2=C3 축으로 돌려 계산.
- 동사 대응: 「분자 모형 만들기」 → 조립판에 탄소 골격 놓기 + 3차원 모형 · 「3차원 공간에서의 차이」 → 끌어서 회전, C=C/C–C 축 회전 슬라이더 · 「물리적 성질 차이 조사」 → 판독·기록 표·끓는점 그래프 · 「화학 반응성 차이」 → π 결합 겹침 판독·해석 문장(+ S33 Q2) · 「발표」 → S33 결론.

## 7. 확인이 필요한 점
1. 가지 달린 알케인·알켄의 이름(2-메틸프로페인, 2-메틸뷰테인, 2,2-다이메틸프로페인, C₆H₁₄ 이성질체 이름, 1-뷰텐, 프로펜, 2-메틸프로펜)과 염소화 생성물 이름은 교과서에 없어 대한화학회 IUPAC 이름으로 덱이 붙였다.
2. 끓는점(직선-사슬 알케인, C₄·C₅ 이성질체)·시스/트랜스-2-뷰텐 녹는점은 덱 보충 문헌값이고, C₆H₁₄ 끓는점은 자체 지도서 30쪽 값이다. 교과서 값은 시스 3.7 °C, 트랜스 0.9 °C뿐이다.
3. 61쪽 탐구 활동 예시 결과(S21)와 63쪽 탐구 결과 정리(S33)는 지도서가 없어 덱이 작성했다. $n$ = 11–14 이성질체 수는 덱이 계산한 값이다(문헌값 159, 355, 802, 1858과 같음).
4. 라디칼 연쇄 반응의 단계 식(S23)은 교과서가 단계 이름만 적어 덱이 보충했다. π 결합 세기 264 kJ/mol은 1-3-1의 결합 에너지로 어림한 값이다.
5. 교과서 63쪽 Br₂ 첨가의 양이온 중간체는 Br가 두 탄소에 걸친 고리 꼴로 그려져 있어 덱도 그 꼴로 그리고 이름은 교과서대로 「양이온 중간체」로만 썼다.
6. 메테인 연소 식은 교과서 꼴(+ 890 kJ/mol)을 그대로 보이고, 상태 기호를 붙인 열화학 반응식($\ce{H2O(l)}$, $\Delta H=-890\ \text{kJ}$)을 덱이 함께 적었다.
