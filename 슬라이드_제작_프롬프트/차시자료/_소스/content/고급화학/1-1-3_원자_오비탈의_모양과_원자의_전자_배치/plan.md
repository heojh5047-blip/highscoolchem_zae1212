**S3 다시 보기·생각 열기** `03 원자 오비탈의 모양 · 도입` h2 `<tag alt>다시 보기</tag>지난 시간에 배운 오비탈`. 카드 3: 파동 함수 $\psi$ → 확률 밀도 $\psi^2$ / s 오비탈: 구형 대칭, 마디 $n-1$개 / 1s, 2s, 3s: $n$이 클수록 크다. Q "수소 원자의 2s와 2p 오비탈은 에너지가 같을까? 나트륨 원자에서는?" ★ 답(.answer) "수소: 같다(에너지는 $n$에만 의존). 다전자 원자: 2s < 2p — 오늘 그 까닭을 찾는다." 그림 작게: 1s·2s·3s 경계면 원(1-1-1 그림과 같은 비율).

**S4 ① 원자 오비탈과 양자수** `03 · 원자 오비탈과 양자수` "슈뢰딩거 방정식은 전자가 2개 이상인 원자도 근사적 방법으로 풀 수 있다. 해인 파동 함수 $\psi$는 여러 개이고, 각 해는 **세 양자수**(주 양자수, 각운동량 양자수, 자기 양자수)의 특별한 조합으로 정해진다." 표: 양자수 | 기호 | 허용되는 값 | 관계 있는 것 — 주 양자수 $n$ $1,2,3,\cdots$ ★크기·에너지 / 각운동량 양자수 $l$ $0,1,\cdots,n-1$ ★모양 / 자기 양자수 $m_l$ $-l,\cdots,0,\cdots,+l$ ★공간 배향. ★ "양자수 조합 하나 = 파동 함수 하나 = 원자 오비탈 하나. 파동 함수로 각 오비탈의 상대적 에너지·모양·공간 배향을 설명한다."

**S5 ② 주 양자수와 껍질** 공식 $E_n\propto-\dfrac{1}{n^2}$ (수소: 에너지는 $n$에만 의존). "다른 원자에서도 전자의 에너지는 주로 $n$이 정한다." "$n$이 클수록 오비탈이 크고, 전자가 원자핵에서 멀리 떨어진 곳에 머무는 시간이 길다." ★ "$n$이 같은 오비탈들 = 같은 **껍질**. 확률 밀도가 가장 큰 곳을 경계로 하는 속이 빈 공 껍데기 모양이고, $n$이 클수록 커지는 데서 온 이름이다." 그림: 동심 원 4개 $n=1$ K, $n=2$ L, $n=3$ M, $n=4$ N(반지름 $n^2$에 비례하게 줄여서, 껍질 옅은 minus 띠) [a] 껍질 scale 차례. Q "$n=3$ 껍질의 이름은?" ★ M 껍질.

**S6 ③ 각운동량 양자수와 자기 양자수** 왼쪽 카드: 각운동량 양자수 $l=0,1,2,\cdots,n-1$ — 모양. 기호 표 $l$ 0 1 2 3 4 → s p d f g. "주 양자수가 $n$인 껍질은 $l$에 따라 $n$개의 **부껍질**로 나뉜다." 오른쪽 카드: 자기 양자수 $m_l=-l,\cdots,-1,0,1,\cdots,l$ — 공간 배향, 같은 부껍질의 오비탈 구분, $(2l+1)$개. 예: $l=1$ → $m_l=-1,0,1$ → p 오비탈 3개(배향이 다름). ★ Q "$n=3$ 껍질의 부껍질은?" ★ 3s, 3p, 3d (3개). ★ Q "$l=2$ 부껍질의 오비탈 수는?" ★ $2\times2+1=5$개(3d 5개).

**S7 표 Ⅰ-1 허용되는 양자수와 오비탈** 표($n$ | $l$ | 오비탈 이름 | $m_l$ | 오비탈 수): 1 0 1s 0 1 / 2 0 2s 0 1, 1 2p −1,0,1 3 / 3 0 3s 0 1, 1 3p 3, 2 3d −2…2 ★5 / 4 0 4s 1, 1 4p 3, 2 ★4d 5, 3 ★4f ★−3…3 ★7. 오른쪽: 껍질의 오비탈 총수 $n=1$: 1, $n=2$: 4, $n=3$: 9, $n=4$: ★16 → ★ "주 양자수가 $n$인 껍질의 오비탈 총수는 $n^2$개이다."

- Cr·Cu 예외와 전이 금속 양이온 4s 먼저: 교과서 부록 풀이(Cu $[\mathrm{Ar}]4s^1 3d^{10}$)와 자체 지도서 유의점·오개념 반영(S22·S24·S29). 그 밖의 예외(Mo, Ag 등)는 다루지 않는다.
- 스핀은 "회전한다고 생각할 수 있는" 비유로만(교과서 문장) — 실제 회전이라고 단정하지 않는다.
- 이온화 에너지 그래프·원자 반지름 값은 교과서 문장(경향)을 보이는 자료로만, 계산 문항 없음.

## 7. 확인이 필요한 점
1. 부록 풀이 연습 문제 1이 "l = 0이면 4s, l = 1이면 4p, l = 3이면 4f"로 4d($l=2$)를 빠뜨렸다 — 덱은 4d를 넣었다(인쇄 누락으로 판단).
2. 교과서 25–26쪽 "3-13족 원소들을 전이 원소"는 3–12족의 오기로 보고 3–12족으로 썼다(같은 쪽 "13-18족 전형 원소"와 겹침).
3. S26 원자 반지름, S27 첫째 이온화 에너지, S12 수은·스트론튬 선 파장은 교과서에 값이 없어 문헌값(수은 404.7·435.8·546.1·577.0·579.1 nm, 스트론튬 주요 선 약 407.8·421.6·460.7·483.2·496.2·640.8·650.4·687.8·707.0 nm)을 썼다.
4. 원자가 전자: 예제 Ⅰ-1은 바나듐을 "원자가 전자가 5개"(3d+4s), 부록 풀이는 Cu를 1개(4s만)로 센다 — 덱은 교과서 24쪽 정의(가장 바깥 주 양자수 준위의 전자)와 부록 풀이를 따르고, 예제 풀이에서는 "[Ar] 뒤에 5개"로 쓰고 S24에 전이 원소는 d 전자도 결합에 참여할 수 있다고 밝혔다.
5. S15 쌓는 순서 대각선 그림은 출판사 교과서에 없는 보충이다(예제 풀이에 필요).
6. 실험실은 덱 자체 활동(교과서 탐구 아님)이라 표식을 `실험실`로 했다.
