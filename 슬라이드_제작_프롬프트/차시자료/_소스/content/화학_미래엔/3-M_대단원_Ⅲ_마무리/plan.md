**S3 개념 정리 ① 화학 평형** (130) 가지 그림. 화학 평형 → 가역 반응과 화학 평형 → ❶ ★`가역 반응` — 정반응과 역반응이 모두 일어날 수 있는 반응 / 비가역 반응 — 한 방향으로만 일어나는 반응 / ❷ ★`화학 평형` — 가역 반응에서 반응물과 생성물의 농도가 일정하게 유지되는 동적 평형 상태 · 화학 평형과 평형 상수 → 평형 상수($K$) — ❸ ★`화학 평형 상태`에서 반응물의 농도 곱에 대한 생성물의 농도 곱의 비 · 화학 반응의 진행 방향 예측 → ❹ ★`반응 지수` ($Q$) — 관찰하는 시점에서 반응물의 농도 곱에 대한 생성물의 농도 곱의 비. 빈칸 앞 `data-q`.

**S4 개념 정리 ② 화학 평형 이동** (130) 화학 평형 이동 → 농도·압력 변화와 화학 평형 이동 → 농도: 반응물 농도 증가, 생성물 농도 감소 → ❺ ★`정반응` 우세 / 반응물 농도 감소, 생성물 농도 증가 → ❻ ★`역반응` 우세 / 압력 ❼ ★`증가` → 전체 기체 분자 수가 감소하는 반응 우세 / 압력 ❽ ★`감소` → 전체 기체 분자 수가 증가하는 반응 우세 · 온도 변화와 화학 평형 이동 → 온도 증가 → 에너지를 ❾ ★`흡수`하는 반응 우세 / 온도 감소 → 에너지를 ❿ ★`방출`하는 반응 우세 · 일상생활 속의 화학 평형 이동 → 생명 현상: 혈액이 체내에 산소를 공급하는 과정 / 산업 현장: 암모니아 합성 과정에서 수득률 높이기.

**S5 연결 — 평형 문제를 푸는 두 도구** 왼쪽 ❶ 양(농도) 변화 표 — 계수비 = 변한 양(mol)의 비: $a\mathrm{A}(g)+b\mathrm{B}(g)\ce{<=>}c\mathrm{C}(g)$ (1 L) 처음 $n_\mathrm{A}$, $n_\mathrm{B}$, 0 / 반응 $-ax$, $-bx$, $+cx$(field) / 평형 $n_\mathrm{A}-ax$, $n_\mathrm{B}-bx$, $cx$ ★ → 평형 농도를 $K=\frac{[\mathrm{C}]^c}{[\mathrm{A}]^a[\mathrm{B}]^b}$에 넣는다. 순수한 고체와 액체(물)는 식에 넣지 않는다. 오른쪽 ❷ 방향 판단: $Q<K$ 정반응 쪽 / $Q=K$ 평형 / $Q>K$ 역반응 쪽 · 표(변화 → 이동 방향 → $K$) ★ 반응물 농도 증가 → 그 물질을 소모하는 정반응, 그대로 ★ 압력 증가 → 기체 분자 수가 감소하는 쪽, 그대로 ★ 온도 증가 → 에너지를 흡수하는 쪽, 변함 ★ note: $K$는 온도에 따라서만 변한다. 흡열이면 온도가 높을수록 $K$ 증가, 발열이면 감소. 촉매는 평형을 이동시키지 않는다.

## 6. 범위 점검
- $K_\mathrm{p}$ 없음 — 모든 평형 상수는 농도(1 L 용기, mol/L)로. 09의 수득률 표·프로젝트 조건도 평형 상수 계산 없이 정성적 판단.
- 몰농도는 평형 상수 계산에 필요한 정도만(02 표 단위 M = mol/L).
- 거시적 평형(색·농도 일정)과 동적 평형(정반응·역반응 계속)을 구분 — 표지 그림에 두 화살표를 함께, S27 Q1 "정반응이 우세하게 진행해 같은 $K$에 다시 도달".
- 12 고압 산소 치료의 일산화 탄소 문장은 정성적 한 문장(반응식·평형 상수 없음). 프로젝트의 산업 조건(압력·온도·촉매)은 조사 예시 수준, 촉매는 평형을 이동시키지 않음을 명시.
