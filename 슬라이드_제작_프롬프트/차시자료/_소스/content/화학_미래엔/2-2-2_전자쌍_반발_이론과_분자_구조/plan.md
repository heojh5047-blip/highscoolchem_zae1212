**S2 학습 목표** `.std` [12화학02-03] 원문 + 목표 ① 전자쌍 반발 이론으로 중심 원자 주위의 전자쌍 배치를 설명할 수 있다. ② 중심 원자의 공유 전자쌍과 비공유 전자쌍 수로 분자 구조와 결합각을 추론할 수 있다. ③ 소프트웨어로 분자 구조를 모델링하여 3차원 모형으로 나타낼 수 있다. 오늘의 흐름: 루이스 전자점식 → 전자쌍 반발 이론 → 공유 전자쌍만 → 비공유 전자쌍 → 다중 결합 → 탐구: 분자 구조 모델링 → 확인 문제.

**S3 생각 열기** (도입, S6 예측) "물 분자 $\ce{H2O}$의 모양은 어떨까?" 선택지 카드 (가) 일직선 H–O–H (나) 굽은 모양. ★ 답: 굽은 모양(결합각 약 104.5°) — "왜 그럴까? 오늘 이 까닭을 찾는다." 알고 있는 낱말 체크 칩(공유 전자쌍, 비공유 전자쌍, 루이스 전자점식, 결합각).

**S4 연결** "루이스 전자점식으로 모양을 알 수 있을까?" 왼쪽: 물의 루이스 전자점식 두 가지(일직선으로 그린 것·꺾어 그린 것) — 같은 전자 배치. ★ "루이스 전자점식은 전자쌍의 수만 알려 주고, 원자들이 공간에 어떻게 놓이는지는 알려 주지 않는다." ★ "→ 전자쌍의 배치로 분자 모양을 설명하는 이론이 필요하다: 전자쌍 반발 이론".

**S5 ① 전자쌍 반발 이론** 정의(형광펜): "중심 원자 주위의 전자쌍들은 모두 (−)전하를 띠므로 서로 반발하여, **가능한 한 멀리 떨어져 있으려 한다.** 이 생각으로 분자 구조를 설명하는 것을 전자쌍 반발 이론이라고 한다." 그림: 중심 원자 둘레 전자쌍 구름 네 개가 한쪽에 몰린 모습(점선) → 고르게 퍼진 모습 [a]. 용어 카드: 중심 원자, 결합각(중심 원자와 두 원자를 이은 선 사이의 각).

**S6 해 보기: 풍선으로 전자쌍 배치 알아보기** 단계 카드 3: 풍선 2개 → 반대 방향 일직선(180°), 3개 → 한 평면에서 세 방향(120°), 4개 → 정사면체의 꼭짓점 방향(109.5°). 활동 지시: 같은 크기로 분 풍선을 매듭끼리 묶고 자연스럽게 놓이는 모습을 관찰하자. ★ 정리: "풍선이 서로 밀어내며 가장 멀리 떨어진 배치를 찾듯, 전자쌍도 반발이 가장 작은 배치를 이룬다."

**S7 전자쌍 수와 전자쌍 배치** 표: 전자쌍 수 2 / 3 / 4 · 전자쌍 배치 선형 / 평면 삼각형 / 정사면체형 · 전자쌍 사이 각 180° / 120° / 109.5° + 공-막대 그림(중심 회색 X 원 + 전자쌍 방향 막대). 
note: 중심 원자가 Be면 전자쌍 2개, B면 3개(옥텟 규칙의 예외 — 이 단원에서 다루는 범위).

**S8 확인하기(S6 예측)** "종이에 그린 메테인 $\ce{CH4}$의 결합각은 90°일까?" 평면 십자 그림(90°) vs ★ 입체 그림(109.5°). ★ "평면에서는 90°까지만 벌어지지만, 3차원 공간에서는 109.5°까지 벌어질 수 있다. 분자는 입체이다." 오개념 메모: 결합각을 평면 그림에서 재지 않는다.

**S9 ② $\ce{BeF2}$ — 선형** 루이스 전자점식(F 비공유 3쌍씩, Be 공유 2쌍) → 중심 원자 전자쌍 2(공유 2, 비공유 0) → ★ 공-막대 모형 선형, 결합각 180°. [a] F가 바깥으로.

**S10 $\ce{BF3}$ — 평면 삼각형** 루이스 전자점식 → 전자쌍 3(공유 3) → ★ 모형 평면 삼각형 120°. [a]

**S11 $\ce{CH4}$ — 정사면체형** 루이스 전자점식 → 전자쌍 4(공유 4) → ★ 공-막대 모형 + 쐐기 결합 구조식, 109.5°. 쐐기 표기 범례: 실선 = 종이 면, 채운 쐐기 = 종이 앞, 점선 쐐기 = 종이 뒤. [a]

**S12 확인하기** (data-tpl check) ○× 4개
1. $\ce{BeF2}$의 중심 원자에는 전자쌍이 2개 있다. ★ ○
2. $\ce{BF3}$의 분자 구조는 삼각뿔형이다. ★ × — 평면 삼각형(중심 원자에 비공유 전자쌍이 없음)
3. $\ce{CH4}$의 결합각은 90°이다. ★ × — 109.5°
4. 중심 원자에 공유 전자쌍만 있으면 분자 구조는 전자쌍 배치와 같다. ★ ○

**S13 연결** "중심 원자에 비공유 전자쌍이 있으면?" $\ce{NH3}$의 루이스 전자점식(공유 3, 비공유 1) — 전자쌍 4 → 정사면체형 배치. Q "결합각은 109.5°와 같을까, 클까, 작을까?" 선택 카드 3 ★ 답 "작다(107°) — 다음 장에서 까닭".

**S14 ③ 전자쌍 사이의 반발력** 비공유 전자쌍은 한 원자핵에만 끌려 중심 원자 가까이 더 넓게 퍼진다(로브 그림: 공유 전자쌍은 가늘고 길게, 비공유 전자쌍은 짧고 넓게). 반발력 크기 `.formula`: 비공유–비공유 > 비공유–공유 > 공유–공유. ★ "→ 비공유 전자쌍이 공유 전자쌍들을 밀어 결합각이 작아진다." [a] 공유 전자쌍 막대가 밀려 모임(rot).

**S15 $\ce{NH3}$ — 삼각뿔형** 루이스 전자점식 → 전자쌍 4(공유 3, 비공유 1) → 전자쌍 배치 정사면체형 → ★ 분자 구조(원자만 보면) 삼각뿔형, 결합각 107°. 그림: 공-막대 + 비공유 전자쌍 로브. note: 분자 구조의 이름은 원자의 배치만 보고 붙인다. [a]

**S16 $\ce{H2O}$ — 굽은 형** 전자쌍 4(공유 2, 비공유 2) → 정사면체형 배치 → ★ 굽은 형, 104.5°. [a]

**S17 비교: $\ce{CH4}$, $\ce{NH3}$, $\ce{H2O}$** 단계 카드 3 (공유/비공유, 배치, 구조, 결합각). ★ 결론: "전자쌍 수가 4로 같아도 비공유 전자쌍 수가 많을수록 결합각이 작아진다: 109.5° > 107° > 104.5°".

**S18 ④ 다중 결합이 있을 때: $\ce{CO2}$, $\ce{HCN}$** 규칙(형광펜): "2중 결합이나 3중 결합은 **하나의 전자쌍처럼** 취급한다(같은 방향을 향하는 전자쌍 묶음)." $\ce{CO2}$ 루이스 구조(O=C=O, O 비공유 2쌍씩) → 중심 C 주위 전자쌍 묶음 2 → ★ 선형 180°. $\ce{HCN}$ (H–C≡N) → 묶음 2 → ★ 선형 180°.

**S19 $\ce{HCHO}$ — 평면 삼각형** 루이스 구조(C에 H 2, =O) → 묶음 3 → ★ 평면 삼각형, 결합각 약 120°. note: 2중 결합은 전자가 많아 실제 각은 120°에서 조금 벗어난다(H–C–H 약 116°) — 교과서가 다루지 않으면 '약 120°'만. 

**S20 분자 구조를 정하는 순서** 단계 카드 4 ① 루이스 전자점식 그리기 ② 중심 원자 주위의 전자쌍 수 세기(다중 결합 = 1) ③ 전자쌍 배치 정하기 ④ 비공유 전자쌍은 빼고 원자 배치로 이름 붙이기. 아래 요약표: (공유, 비공유) → 구조: (2,0) 선형 · (3,0) 평면 삼각형 · (4,0) 정사면체형 · (3,1) 삼각뿔형 · (2,2) 굽은 형.

## 2. 실험실 명세 — cm222model (S25)

- 모드 버튼 두 개: **분자 고르기** / **전자쌍 고르기**.
  - 분자 고르기: 중심 원자 버튼 Be, B, C, N, O · 결합 원자 버튼 H, F, Cl · 다중 결합 분자 버튼 $\ce{CO2}$, $\ce{HCN}$, $\ce{HCHO}$. 결합 원자 수는 옥텟(Be 2, B 3, C 4, N 3, O 2)으로 정해지고, 비공유 전자쌍 수 = (원자가 전자 − 결합 수)/2. 다루지 않는 조합(Be–H, B–H, O–Cl)은 버튼을 흐리게 하고 이유 문장.
  - 전자쌍 고르기: 결합 원자 수(2–4)·비공유 전자쌍 수(0–2) 슬라이더. 허용 조합 (2,0)(3,0)(4,0)(3,1)(2,2); 그 밖(전자쌍 5개 이상, (2,1) 등)은 "이 단원(옥텟 규칙·단일 결합)에서 다루지 않는 조합" 문장.
- 그림(560×400): 3차원 공-막대 모형, 끌어서 회전(포인터), 손을 떼면 천천히 돈다(API.loop). 비공유 전자쌍은 equi 로브. 결합각 호(첫 두 결합 원자) muted + 값 라벨(.ov). 원자 기호는 `.ov` 라벨(앞 원자에 가려진 원자는 라벨 숨김). 「비공유 전자쌍 보이기」 체크.
- 결과: 화학식(.ov 큰 글씨), 공유·비공유 전자쌍 수, 전자쌍 배치, 분자 구조, 결합각(측정값 — 모형 좌표에서 계산, 0.5° 단위).
