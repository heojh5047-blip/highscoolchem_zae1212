Q "에어백을 알맞은 크기로 부풀리려면 아자이드화 나트륨을 얼마나 넣어야 할까? 그 양을 어떻게 알 수 있을까?" ★ formula $\ce{2NaN3(s) -> 2Na(s) + 3N2(g)}$ (덱 추가) ★ answer "→ 화학 반응식의 계수비로 필요한 반응물의 양을 미리 계산한다. 예) 0 °C, 1 기압에서 질소 67.2 L(3 몰)가 필요하면 $\ce{NaN3}$ 2 몰 = 130 g."

**S4 연결: 1-2-1에서 배운 것** (36 첫 문단, 34–35) "화학 반응을 이용해 특정한 양의 생성물을 얻으려면 반응물의 양을 미리 알아야 한다 — 이때 화학 반응식을 이용한다." 지난 시간 flow: 계수비 = 몰비 = 분자 수 비 = 기체의 부피비(온도·압력 일정) / × 몰질량 → 질량비. Q "$\ce{2H2O(l) -> 2H2(g) + O2(g)}$에서 물과 수소의 몰비는?" ★ "→ 계수가 2 : 2이므로 1 : 1 — 물 1 몰이 분해되면 수소 1 몰이 생긴다."

**S5 ① 수소 2 kg을 얻으려면 물은 몇 kg?** (36 표) 그림: 물 분자 2개 → 수소 분자 2개 + 산소 분자 1개 [a] move(H 4, O 2 보존). 표(단계 공개) 화학 반응식 $\ce{2H2O(l) -> 2H2(g) + O2(g)}$ / 몰비 ★ 1 몰 : 1 몰 / 질량비 ★ $(1\times18)\ \text{g}:(1\times2)\ \text{g}$ / 필요한 물질의 질량 ★ $\ce{H2O}:\ce{H2}=18:2=x:2000$, $\therefore x=18000$ ★ answer "수소 2 kg(2000 g)을 얻으려면 물 18 kg을 분해해야 한다." note "몰비에 각 물질의 몰질량을 곱하면 질량비".

**S6 ① 계수비로 몰·부피·질량 구하기** (36 그림 Ⅰ-12) 정의(형광) "화학 반응식의 계수비로부터 반응물과 생성물의 몰, 부피, 질량 관계를 알 수 있으므로, 이를 이용해 물질의 양(mol), 부피, 질량 중 필요한 값을 구할 수 있다." 그림: 노드 계수비 = 몰비 = 기체의 부피비 ; 몰비 ↕(× 몰질량 ↓ / ÷ 몰질량 ↑) 질량비 [a] draw. 아래 환산 사다리 4칸(★ 차례 공개): 주어진 질량·부피 → (÷ 몰질량, ÷ 22.4 L/mol) → 주어진 물질의 몰 → (× 계수비) → 구할 물질의 몰 → (× 몰질량, × 22.4 L/mol) → 질량·부피. note "실험에서는 질량이나 부피로 양을 재므로, 몰로 바꾸어 계수비를 쓴다."

**S7 예측 (S6, 가이드 10.1 권장)** Q "수소 2 g과 산소 2 g을 반응시키면 물은 4 g 생길까?" (가) 4 g 생긴다 (나) 4 g보다 적게 생긴다. ★ $\ce{2H2 + O2 -> 2H2O}$: $\ce{H2}$ $\frac{2}{2}=1$ 몰, $\ce{O2}$ $\frac{2}{32}=0.0625$ 몰 ★ $\ce{O2}$ 0.0625 몰과 반응하는 $\ce{H2}$는 0.125 몰 → $\ce{O2}$가 모두 소모되고 $\ce{H2}$ 0.875 몰(1.75 g) 남음 ★ 물 0.125 몰 × 18 g/mol = 2.25 g ★ answer "(나) — 물은 2.25 g. 남은 수소 1.75 g까지 더하면 4 g(질량 보존)."

**S8 ② 반응물 하나가 모두 소모되면** (37 첫 문단) 정의(형광) "화학 반응에서 반응물 중 하나가 모두 소모되면 반응이 더 이상 진행되지 않는다 → 화학 반응식으로 주어진 반응물로부터 최대로 생성되는 생성물의 양을 알 수 있다." 그림(전후 비교): 반응 전 $\ce{H2}$ 5개 + $\ce{O2}$ 2개 → 반응 후 $\ce{H2O}$ 4개 + 남은 $\ce{H2}$ 1개(`equi` 테 "남음") [a] move. ★ 원자 수 표 H 10 = 8 + 2, O 4 = 4. ★ "$\ce{O2}$ 2개가 모두 소모 → 물은 최대 4개. $\ce{H2}$ 1개는 반응하지 못하고 남는다." small "이렇게 먼저 모두 소모되어 생성물의 양을 정하는 반응물을 '한계 반응물'이라고도 한다." note "화학 반응식을 이용하면 필요한 물질의 양을 예측해 정확한 실험을 할 수 있다."

**S9 연습 해 보기** (37) 문제 "0 °C, 1 기압에서 $\ce{HCl}$ 0.2 몰이 녹아 있는 $\ce{HCl(aq)}$ 100 mL에 $\ce{Mg(s)}$ 1.2 g을 넣어 반응시켰다. 반응이 완결되었을 때 발생한 $\ce{H2(g)}$의 부피(L)를 구해 보자. (단, 온도와 압력은 일정, Mg의 몰질량 24 g/mol, 0 °C, 1 기압 기체 1 몰 22.4 L)". 풀이 따라가기: 1단계 $\ce{Mg(s) + 2HCl(aq) -> MgCl2(aq) + H2(g)}$, 계수비 Mg : HCl : $\ce{H2}$ = ❶[★1] : ❷[★2] : 1 / 2단계 Mg $\frac{1.2\ \text{g}}{24\ \text{g/mol}}=0.05\ \text{mol}$, HCl 0.2 mol, 1 : 2로 반응 → Mg은 모두 반응, HCl 0.1 몰 남음 / 3단계 Mg : $\ce{H2}$ = 1 : 1 = 0.05 mol : $x$ mol → $x=$❸[★0.05], 부피 $0.05\ \text{mol}\times22.4\ \text{L/mol}=$❹[★1.12] L ★ answer "답 1.12 L". board.
