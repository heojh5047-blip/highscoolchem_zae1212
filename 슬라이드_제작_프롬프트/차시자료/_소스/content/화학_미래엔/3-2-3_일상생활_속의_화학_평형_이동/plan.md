- 입력: 온도 슬라이더 200–600 °C(50 °C 간격, 처음 450) · 압력 슬라이더 10–400 기압(10 간격, 처음 200) · [촉매 있음/없음] 버튼 · [기록하기] · [처음부터].

- 반응 속도(상대값, 450 °C·촉매 = 100): $100\,e^{-\frac{E}{R}\left(\frac1T-\frac1{723}\right)}$, 촉매 $E=80$ kJ/mol, 없음은 같은 식에 $e^{-150000/(8.314\cdot T)}$배를 더 곱함(사실상 0). 한 번 지날 때 수득률 $=x\left(1-e^{-2r/100}\right)$.
- 표시: 큰 수 "평형 수득률 44 %", 작은 줄 "반응 속도 100 · 한 번 지날 때 38 %", 해석 문장(조건별 4가지). 그림 700×300: 왼쪽 그래프(가로 압력 0–400 기압, 세로 평형 수득률 0–100 %, 다섯 온도 곡선 회색 + 고른 온도 굵게 + 현재 점 `equi`, 기록 점) · 오른쪽 반응 용기 입자 모형($\ce{N2}$·$\ce{H2}$·$\ce{NH3}$ 수, N 12·H 36 보존, `API.loop` 떨림) + 촉매 칸(있음: 회색 격자) + "필요한 반응 용기" 글.
- 기록 표 최대 5행: 실험 / 온도 / 압력 / 촉매 / 평형 수득률 / 한 번 지날 때.
