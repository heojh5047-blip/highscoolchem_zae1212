## 2. 실험실 명세

### cm212graph — 해 보기 「전기음성도의 주기성 찾기」(스프레드시트 활동 대체, S11)
- 자료: 1–3주기 15원소(H, Li–F, Na–Cl) 교과서 값.
- 조작: 그래프 종류 3버튼 「원자 번호 순」(가로축 원자 번호 1–17, 18족 He·Ne 자리 비움) / 「주기별 (가로축: 족)」(2주기·3주기 두 꺾은선, H는 1주기 점 하나) / 「족별 (가로축: 주기)」(1·2·13·14·15·16·17족 꺾은선) · 모양 2버튼 「꺾은선」/「막대」 · 「그래프 공유」(data-act="rec") · 「초기화」(data-act="reset").
- 표시: 축 라벨(가로축 이름, 세로축 "전기음성도", 0–4 눈금), 점마다 원소 기호(.ov), 해석 문장(output.kind): 원자 번호 순 "원자 번호가 커지면 2주기·3주기에서 각각 커지다가 다음 주기에서 다시 작아진다 — 주기성", 주기별 "같은 주기에서 족 번호(원자 번호)가 커질수록 증가", 족별 "같은 족에서 주기(원자 번호)가 커질수록 감소". 막대 + 족별처럼 읽기 어려운 조합은 "막대가 많아 비교가 어렵다 — 꺾은선이 낫다".
- 공유 목록 표(최근 5행): 번호 · 그래프 · 모양 · 한눈에 보이는 경향. 정리 3의 "가장 효과적인 그래프 고르기"에 씀.

### cm212bond — 해 보기 「공유 전자쌍의 치우침 확인하기」(모의실험 대체, S11)
- 조작: 원자 A 버튼(H, Li, Na, C, N, O, F, S, Cl), 원자 B 버튼(같은 목록), 「기록」(data-act="rec"), 「초기화」(data-act="reset"). 기본 A = H, B = H.
- 계산: $\Delta=|\chi_A-\chi_B|$(교과서 값). 종류: 같은 원소 → 무극성 공유 결합 / 금속(Li, Na) + 비금속 → 이온 결합(전자가 완전히 이동) / 금속 + 금속 → "금속 원자끼리는 공유 결합을 만들지 않는다 — 다른 원자를 고르자" / 그 밖 → 극성 공유 결합. 단, C–S(값 같음, 다른 원소) → "표시 값이 같다. 정말 무극성일까? 소단원 마무리에서 생각해 보자."(치우침 그림 0, 종류 칸 "?").
- 그림(600×300): 두 원자(반지름 0절 값), 결합 막대, 공유 전자쌍 점 두 개 — 위치 = 가운데 + (큰 쪽으로) $\Delta\times 22$ px(최대 3.1 → 68 px), 전자 구름 회색 타원도 같은 방향으로 이동, $\delta^+$/$\delta^-$ 라벨(.ov), 쌍극자 화살표(길이 = $\Delta\times 60$ px, + 꼬리) — 무극성은 "쌍극자 모멘트 0". 이온 결합은 원자 대신 이온 $\ce{Na+}$/$\ce{Cl-}$ 크기, 막대 없음, 전자 이동 화살표(minus) + 전하 라벨. 아래 띠: 전기음성도 차이 0 → 3.1 눈금에 ▼ 표시. API.loop로 전자쌍 점이 제자리에서 살짝 떨림(정지 모드에서는 고정).
- 표시(readout): A 전기음성도, B 전기음성도, 차이, 결합의 종류. 기록 표(최근 5행): 결합 · 전기음성도 · 차이 · 치우치는 쪽 · 종류.
