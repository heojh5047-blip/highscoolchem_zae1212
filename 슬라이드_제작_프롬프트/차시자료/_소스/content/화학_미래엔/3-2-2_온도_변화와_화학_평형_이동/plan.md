- 왼쪽 조작부(372): 물질 버튼 [코발트 수용액] [$\ce{NO2}$ 기체] [처음부터](`data-act="reset"`, 표·그래프 비움) · 코발트일 때 [염화 칼슘 넣기](한 숟가락 = $\ce{Cl-}$ +0.95 M, 최대 5번) · 온도 버튼 [얼음물 0 °C] [실온 25 °C] [뜨거운 물 80 °C] · 슬라이더 「물중탕 온도」 0–90 °C(5씩) + [이 온도의 물에 담그기] · 결과(큰 글 `Q < K` 등) · 해석 문장(`output.kind`).
- 오른쪽 그림 700×300: 물중탕 비커(온도에 따라 바탕색, 얼음·김), 그 안에 시험관(코발트, 색 = 붉은색↔파란색 섞음, 파란 비율 $f=x/0.1$) 또는 밀봉 유리관($\ce{NO2}$·$\ce{N2O4}$ 분자 30개 기준, N·O 6, 기체 색 불투명도 $0.9(1-e^{-[\ce{NO2}]/0.06})$, 분자 진동 API.loop), 온도계 글. 위: 로그 수직선 $Q$ 대 $K$($10^{-3}K$–$10^{3}K$, cm321과 같은 꼴), $Q$ 점이 2초 동안 $K$로. 아래: 그래프 「$K$ (25 °C 값 = 1, 로그 눈금)」 – 「온도 (°C)」 0–90, 기록된 새 평형마다 점이 찍히고 온도 순으로 잇는 선(코발트 파랑, $\ce{NO2}$ 적갈색).
- 기록 표(최대 4행): 실험 · 물질 · 조작 · 직후 비교 · 우세한 반응 · 새 평형의 색.
- **코발트 계산**: $\mathrm{Co}_t=0.1$, $\mathrm{Cl}_t=0.2+0.95n$, $K_{25}=1/3.8^4$(4숟가락에서 25 °C 파란 비율 50 %), $K(T)=K_{25}\exp\!\left(-\frac{50000}{8.314}\left(\frac1T-\frac1{298}\right)\right)$. 평형 $x-K(\mathrm{Co}_t-x)(\mathrm{Cl}_t-4x)^4=0$ 이분법. 조작 직후 $Q=x/((\mathrm{Co}_t-x)(\mathrm{Cl}_t-4x)^4)$(옛 $x$, 새 $\mathrm{Cl}_t$ 또는 새 $K$). 예: 4숟가락 25 °C $f=0.50$ → 0 °C $f=0.15$(붉은색), 80 °C $f=0.95$(파란색).
- **$\ce{NO2}$ 계산**(3-2-1과 같은 식): $c=[\ce{NO2}]+2[\ce{N2O4}]=0.20$ M(부피 일정), $K(T)=212\,e^{6856(1/T-1/298)}$, $2Kx^2+x-c=0$. 25 °C $[\ce{NO2}]=0.0206$, 0 °C 0.0074, 80 °C 0.095.
- 문장 예: "25 → 80 °C: 온도를 높임 → K가 커짐 → Q < K → 에너지를 흡수하는 정반응(흡열)이 우세하게 진행한다. 파란색 이온이 늘어 파란색이 된다." / NO2: "온도를 높임 → K가 작아짐(212 → 5.9) → Q > K → 에너지를 흡수하는 역반응이 우세 → 이산화 질소가 늘어 적갈색이 진해진다."
- PRE 시험: 코발트 → 염화 칼슘 4번(파란 비율 0 → 50 %, 정반응) → 얼음물(역반응, 붉은색) → 뜨거운 물(정반응, 파란색) → 표 4행·그래프 점 / $\ce{NO2}$ → 80 °C(역반응, K 5.9) → 슬라이더 40 °C 담그기 → 0 °C(정반응) / 처음부터 → 0행.
