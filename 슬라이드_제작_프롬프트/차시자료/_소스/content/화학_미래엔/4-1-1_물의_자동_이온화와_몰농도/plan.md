## 2. 실험실 명세

### 2.1 cm411kw — $[\ce{H3O+}]$와 $[\ce{OH-}]$의 시소 (S16, 개념 실험실)
- 입력: 용액 버튼 0.10 M 염산 · 0.0010 M 염산 · 순수한 물 · 0.0010 M $\ce{NaOH}$ · 0.10 M $\ce{NaOH}$ (각각 $[\ce{H3O+}]=10^{-1},10^{-3},10^{-7},10^{-11},10^{-13}$) + 슬라이더 "$[\ce{H3O+}]$의 지수" $k$ = 1–13 ($[\ce{H3O+}]=1.0\times10^{-k}$ M).
- 계산: $[\ce{OH-}]=K_\mathrm{w}/[\ce{H3O+}]=1.0\times10^{-(14-k)}$, 곱 $=1.0\times10^{-14}$ 표시. 액성: $k<7$ 산성, $=7$ 중성, $>7$ 염기성.
- 그림(560×380): 세로 로그 눈금 $10^{0}$–$10^{-14}$(2칸마다 라벨) 두 기둥 — 왼쪽 $\ce{H3O+}$ 막대(plus)는 바닥($10^{-14}$)에서 $10^{-k}$까지, 오른쪽 $\ce{OH-}$ 막대(minus)는 $10^{-(14-k)}$까지 → 두 막대 길이의 합이 늘 14칸. $10^{-7}$ 가로 점선(중성). 막대 높이는 API.loop로 부드럽게 따라감. 비커 그림(이온 모식 원, 많고 적음).
- 출력: readout $[\ce{H3O+}]$, $[\ce{OH-}]$, 곱, 액성(큰 글씨), 해석 문장("$[\ce{H3O+}]$가 10배 커지면 $[\ce{OH-}]$는 10배 작아진다 — 곱은 늘 $1.0\times10^{-14}$").

### 2.2 cm411std — 표준 용액 만들기 (S28, **필수 탐구 화04-탐2**)
- 설정: 용질 버튼 $\ce{NaCl}$(58.5) · 포도당 $\ce{C6H12O6}$(180) · $\ce{CuSO4*5H2O}$(249.5, 파란 용액) / 목표 몰농도 슬라이더 0.05–0.50 M(0.05 간격, 처음 0.10) / 부피 플라스크 버튼 100 · 250 · 500 mL(처음 250).
- 과정 버튼 「다음 단계 ▶」: ① 질량 계산($n=MV$, 질량 = $n\times$몰질량 — 이때 계산 질량 공개) ② 저울로 달기(0.01 g까지 반올림한 값이 저울에 표시) ③ 비커에서 녹이기 ④ 부피 플라스크로 옮기기 ⑤ 씻은 물 옮기기 ⑥ 표선까지 물 채우기 ⑦ 마개 닫고 섞기 → 「농도 측정」 사용 가능.
- 잘못된 조작(체크, 과정 전에 고름): 씻은 물 생략(용질 4 % 남음) · 표선을 넘김(부피 +3 %) · 표선을 위에서 봄(부피 −1 %) · 흔들지 않음(측정할 때마다 ±8 % 흔들림).
- 계산: $n=\dfrac{\text{단 질량}}{\text{몰질량}}\times(1-\text{손실})$, $V'=V\times(1+\text{부피 오차})$, 실제 $M=n/V'$. 측정값 = 실제 $M\times(1+\varepsilon)$, $\varepsilon$는 고정 시드 ±0.4 %(흔들지 않으면 ±8 %). 오차(%) = (측정 − 목표)/목표 × 100.
- 그림(560×340): 왼쪽 전자저울(숫자 창 `.ov`)과 비커(유리 막대), 가운데 깔때기, 오른쪽 부피 플라스크(표선, 액면이 단계마다 차오름 — API.loop로 부드럽게, $\ce{CuSO4}$이면 몰농도에 비례한 파란색 진하기), 지금 단계 이름 표시. 아래 7단계 칩(현재 단계 강조).
- 출력: readout 필요한 용질의 양(mol)·계산 질량·단 질량, 「측정한 몰농도」 크게, 해석 문장(잘못된 조작에 따라 까닭: "씻은 물을 넣지 않아 비커에 용질이 남았다 → 몰농도가 목표보다 작다").
- 「측정 기록」 → 결과 표 누적(최근 5행: 용질, 목표, 단 질량, 조작, 측정 몰농도, 오차 %). 「초기화」(data-act="reset").

## 6. 범위 점검
- pH·pOH 계산은 4-1-2 몫 — 이 덱은 다음 시간 질문으로만, 실험실 cm411kw도 지수 $k$만 쓰고 'pH'라는 말을 쓰지 않는다 ✓
- 약산·약염기의 이온화 상수($K_\mathrm{a}$, $K_\mathrm{b}$)는 「화학 반응의 세계」 몫 — 넣지 않음. 염산·$\ce{NaOH}$는 "모두 이온화한다"로만 ✓
- 브뢴스테드·로리 정의는 용어로 들이지 않고 "$\ce{H+}$을 내놓는/받는"으로만 ✓ (교과서가 쓰면 그 수준으로 — 확인 필요)
- 중화 반응·적정은 Ⅳ-2 몫 — 이 덱에 없음 ✓
- $K_\mathrm{w}$ 온도 표는 정성적 해석(흡열 → 커짐)만, 계산 없음 ✓
- 몰랄 농도·퍼센트 농도 계산은 「물질과 에너지」 몫 — S19의 질량 백분율은 몰농도의 필요성을 보이는 데만 ✓
- 1.1 범위 제한(Ⅳ 중화 강산–강염기, 적정 곡선 없음) 해당 없음 ✓
