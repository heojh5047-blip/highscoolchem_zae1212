연결화학 반응이 일어나면 원자는 어떻게 될까?

물질 사이에 상호작용이 일어나 성질이 다른 새로운 물질이 생성되는 현상을 화학 반응이라고 한다.

현상 수소 기체와 산소 기체를 섞고 불꽃을 대면 물이 생긴다. (연계: 중학교 과학 '화학 반응의 규칙성')

원자 사이의 결합이 끊어지고 새로운 결합이 생긴다 → 반응 전후에 원자의 종류와 개수는 변하지 않는다.

1화학 반응식 — 1단계: 화학식과 →, +

화학 반응에 참여하는 반응물과 생성물의 화학식을 이용하여 화학 반응을 나타낸 것을 화학 반응식이라고 한다.

  • 반응물: 수소($\ce{H2}$), 산소($\ce{O2}$) → 화살표 왼쪽
  • 생성물: 물($\ce{H2O}$) → 화살표 오른쪽
  • 화살표(→)는 반응의 진행, 물질이 두 가지 이상이면 '+'로 잇는다.
$\ce{H2 + O2 -> H2O}$
아직 계수를 맞추지 않은 식

Q 이 식의 반응 전후 원자 수는 같을까?

→ 수소 원자 2개 = 2개 ✓, 산소 원자 2개 ≠ 1개 ✗ — 산소 원자 수가 맞지 않는다.

12단계: 원자 수가 같아지도록 계수 맞추기

반응 전후에 원자의 종류와 수가 항상 같아지도록 화학식 앞의 계수를 맞춘다.

① 원자 수 세기

$\ce{H2 + O2 -> H2O}$

H 2 = 2 ✓ · O 2 ≠ 1 ✗

② O 맞추기

$\ce{H2 + O2 -> 2H2O}$

$\ce{H2O}$ 앞에 2 → O 2 = 2 ✓ · 이제 H 2 ≠ 4 ✗

③ H 맞추기

$\ce{2H2 + O2 -> 2H2O}$

$\ce{H2}$ 앞에 2 → H 4 = 4 ✓ · O 2 = 2 ✓ 완성!

계수는 가장 간단한 정수로 나타내고, 계수가 1이면 생략한다.

예측아래 첨자를 바꾸어 맞춰도 될까?

Q 계수 대신 화학식의 아래 첨자를 바꾸어 $\ce{H2 + O2 -> H2O2}$로 쓰면 원자 수가 맞는다. 이렇게 써도 될까?

(가) 된다 — 원자 수가 맞으니까.(나) 안 된다.

$\ce{H2O2}$는 물이 아니라 과산화 수소(소독약)이다. 물이 생기는 반응을 나타낸 식이 아니다.

(나) — 아래 첨자를 바꾸면 다른 물질이 된다. 원자 수는 계수로만 맞춘다.

직접 해 보기일산화 탄소와 산소의 반응

일산화 탄소($\ce{CO}$) 기체와 산소($\ce{O2}$) 기체가 반응해 이산화 탄소($\ce{CO2}$) 기체를 생성하는 반응을 물질의 상태를 포함한 화학 반응식으로 나타내 보자.

① $\ce{CO + O2 -> CO2}$ → O 3 ≠ 2 ✗

② $\ce{CO + O2 -> 2CO2}$ → O 3 ≠ 4, C 1 ≠ 2 ✗

③ $\ce{2CO + O2 -> 2CO2}$ → C 2 = 2, O 4 = 4 ✓

$\ce{2CO(g) + O2(g) -> 2CO2(g)}$

"욕실에 놓아둔 철핀에 붉은색 녹이 생겼어."

단서 철($\ce{Fe}$)이 공기 속 산소($\ce{O2}$)와 반응해 녹의 주성분인 산화 철(III)($\ce{Fe2O3}$)이 된다.

Q 이 반응을 화학 반응식으로 나타내면?

① $\ce{Fe + O2 -> Fe2O3}$ — O 2 ≠ 3

② O는 2와 3의 최소공배수 6 → $\ce{Fe + 3O2 -> 2Fe2O3}$

③ Fe 4개 → $\ce{4Fe + 3O2 -> 2Fe2O3}$ (Fe 4 = 4, O 6 = 6)

$\ce{4Fe(s) + 3O2(g) -> 2Fe2O3(s)}$

실제 녹이 생길 때는 물도 함께 관여하지만, 여기서는 철과 산소만으로 나타낸다.

해 보기생활 속 화학 반응을 화학 반응식으로 ② 호흡

"호흡은 산소를 들이마시고, 이산화 탄소를 내보내는 반응이야!"

단서 세포 속에서 포도당($\ce{C6H12O6}$)과 산소가 반응해 이산화 탄소와 물이 생긴다.

① C 6개 → $\ce{6CO2}$

② H 12개 → $\ce{6H2O}$

③ 오른쪽 O $12+6=18$개 → 왼쪽 $6+2\times6$ → $\ce{6O2}$

$\ce{C6H12O6(s) + 6O2(g) -> 6CO2(g) + 6H2O(l)}$
원자가 많을 때는 한 물질에만 나오는 원소(C, H)부터, 홑원소 물질($\ce{O2}$)은 마지막에 맞추면 쉽다.

2질량비도 1 : 3 : 2일까?

Q 계수비가 1 : 3 : 2이면 질량비도 1 : 3 : 2일까? (몰질량 $\ce{N2}$ 28, $\ce{H2}$ 2, $\ce{NH3}$ 17 g/mol)

(가) 그렇다.(나) 아니다.

$\ce{N2}$: $1\ \text{mol}\times28\ \text{g/mol}=28\ \text{g}$

$\ce{H2}$: $3\ \text{mol}\times2\ \text{g/mol}=6\ \text{g}$

$\ce{NH3}$: $2\ \text{mol}\times17\ \text{g/mol}=34\ \text{g}$

자료 읽기 질량비 = 28 : 6 : 34 = 14 : 3 : 17

오개념 바로잡기 몰질량은 물질마다 달라 몰비와 질량비는 같지 않다. 몰비에 각각의 몰질량을 곱하면 질량비를 알 수 있다.
(나) — 반응 전 $28+6=34\ \text{g}$ = 반응 후 $34\ \text{g}$: 전체 질량은 보존되지만, 질량비는 계수비와 다르다.

③ 질량비 $64:96:88:72=8:12:11:9$ — 반응 전 160 g = 반응 후 160 g

④ 기체끼리의 부피비 $\ce{O2}:\ce{CO2}=3:2$ (액체인 메탄올·물에는 22.4 L를 쓰지 않는다)

소단원 마무리창의력 키우기 — 클레오파트라의 진주

고대 이집트의 왕 클레오파트라는 진주를 식초에 녹여 마셨다는 일화가 있다. 진주의 주성분인 탄산 칼슘($\ce{CaCO3}$)과 식초의 주성분인 아세트산($\ce{CH3COOH}$)의 화학 반응식을 찾아보고, 이 일화가 실제로 가능할지 토의해 보자.

토의 예 반응은 일어나 기포가 생기지만, 식초는 묽고 진주는 단단해서 통째로는 녹는 데 매우 오래 걸린다. 진주를 갈아 넣으면 가능성이 커진다.

$\ce{CaCO3(s) + 2CH3COOH(aq) -> (CH3COO)2Ca(aq) + H2O(l) + CO2(g)}$
Ca 1 = 1, C 5 = 5, H 8 = 8, O 7 = 7 · 생성물: 아세트산 칼슘, 물, 이산화 탄소

소단원 마무리디지털 소양 키우기 — 과학사 속 화학 반응식

과학사에서 찾을 수 있는 흥미로운 화학 반응식을 조사하고, 공유 플랫폼을 활용하여 공유해 보자.

산소의 발견 (1774)

$\ce{2HgO(s) -> 2Hg(l) + O2(g)}$

산화 수은(II)을 가열해 산소를 얻었다(프리스틀리, 라부아지에).

물의 합성

$\ce{2H2(g) + O2(g) -> 2H2O(l)}$

라부아지에가 물이 수소와 산소로 이루어진 화합물임을 밝혔다.

암모니아 합성 (1909)

$\ce{N2(g) + 3H2(g) -> 2NH3(g)}$

하버가 공기 속 질소로 비료 원료를 만들었다.

(2) 몰질량 $2\times12+6\times1=30\ \text{g/mol}$ → $\dfrac{3\ \text{g}}{30\ \text{g/mol}}=0.1\ \text{mol}$
