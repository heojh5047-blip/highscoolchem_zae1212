## 2. 실험실 명세 — `cm321conc` / `cm321press` 「평형 이동 실험실」 (같은 함수, 처음 모드만 다름)

- 왼쪽 조작부(390): 모드 버튼 [농도] [압력] [온도] · 모드별 조작 · 결과(큰 글 `Q < K` 등) · 해석 문장(`output.kind`). 오른쪽 그림 690×300 + 기록 표(최대 5행, 공통): 실험 · 변인 · 조작 · 직후 $Q$와 $K$ · 우세한 반응 · 새 평형에서 관찰. [처음부터] 버튼(`data-act="reset"`)은 표 비움.
- **농도 모드** ($\ce{Cr2O7^2- + H2O &lt;=&gt; 2CrO4^2- + 2H+}$, 4 mL, 모의 $K=3\times10^{-15}$): 처음 용액 [K₂Cr₂O₇(aq)](Cr 0.2 M) / [K₂CrO₄(aq)](Cr 0.1 M). 버튼 [NaOH(aq) 넣기], [HCl(aq) 넣기] — 한 번에 1 mol/L 0.1 mL(≈ 2 방울) → 알짜 염기 $b$를 ±0.025 M(부피 변화 무시). 평형 계산: 전하·Cr 보존으로 $C=[\ce{CrO4^2-}]=0.2-C_t+b+h-K_\mathrm{w}/h$, $D=(C_t-C)/2$, $C^2h^2=KD$ → $\log h$ 이분법. 넣은 직후: $C$, $D$ 그대로, $h'$는 중화만(이차식) → $Q'=C^2h'^2/D$. 그림: 시험관(색 = 주황·노랑 섞음, 노랑 비율 $C/C_t$), 로그 수직선 $Q/K$($10^{-3}$–$10^{3}$, 넘으면 끝에 "≪"/"≫"), $K$ 기준선, $Q$ 점이 1.5초 동안 $K$로 이동(API.loop), 막대 2개(Cr 중 $\ce{Cr2O7^2-}$·$\ce{CrO4^2-}$ 비율 %), 넣은 이온 화살표($\ce{OH-}$ minus / $\ce{H+}$ plus). 문장 예: "NaOH의 OH⁻가 H⁺와 중화 → [H⁺] 감소 → Q < K → 정반응이 우세하게 진행한다. CrO4²⁻이 늘어 노란색으로 변한다."
- **압력 모드** ($\ce{2NO2 &lt;=&gt; N2O4}$, 25 °C $K=212$, $\ce{NO2}$로 환산한 양 0.010 mol, 처음 50 mL → 평형 $[\ce{NO2}]=0.0206$, $[\ce{N2O4}]=0.0897$): 슬라이더 「바꿀 부피」 20–100 mL(5씩), 버튼 [부피 바꾸기], [He 넣기 · 피스톤 고정], [He 넣기 · 피스톤 자유](헬륨 양 = 그때 기체 양 → 부피 2배, 100 mL 상한이면 막음). 직후 농도 = 이전 × $V_\text{전}/V_\text{후}$, $Q=K\cdot V_\text{후}/V_\text{전}$ → 2초 동안 평형으로(N 보존 $c=[\ce{NO2}]+2[\ce{N2O4}]$, $2Kx^2+x-c=0$). 그림: 주사기(피스톤이 부피에 맞게 움직임), 기체 색 불투명도 $0.9(1-e^{-[\ce{NO2}]/0.06})$, 분자 모형(N 20개 기준: $\ce{NO2}$ $n=2\,\mathrm{round}(10x/c)$, $\ce{N2O4}$ $(20-n)/2$), 헬륨 점, 수직선·막대(mol/L). 문장: "부피 50 → 25 mL: 압력 증가 → Q(106) < K(212) → 전체 기체 분자 수가 감소하는 정반응이 우세 → 색이 (나)보다 옅어진다."
- **온도 모드**(관찰만): 같은 주사기, 버튼 [얼음물 0 °C] [실온 25 °C] [뜨거운 물 80 °C] → $K$가 바뀜($\Delta H=-57$ kJ로 계산: 1760 / 212 / 5.8), $Q$는 그대로 → 비교·이동. 문장 끝에 "까닭은 다음 시간(02)에서".
- PRE 시험: 농도 기본 → NaOH 4회 → 노랑 비율 증가·정반응, 표 4행 / HCl 1회 → 역반응 / 압력 50 → 25 mL → Q 106, 정반응, [NO2] 0.0296 / He 자유 → 역반응 / 온도 80 °C → 역반응 / 처음부터 → 0행.

1. 중단원 마무리 02(농도·압력·온도), 06(압력·온도)은 온도 개념이 필요해 3-2-2로 넘겼다. 02의 ㄴ·ㄷ·ㄹ, 06(2)(헬륨)은 이 덱 범위로도 풀 수 있다.
2. (해결 — 지도서 대조) 탐구 정리·같은 원리 다른 탐구·디지털 소양 예시 답안과 압력 탐구 (가)–(다) 색은 지도서 예시 답안에 맞췄다(13절).
3. (해결 — 지도서 대조) 함께 풀어 보기 빈칸 ③ 증가, ④ 감소가 지도서 정답과 같다.
4. 실험실 다이크로뮴산 평형 상수(모의값)와 1회 0.1 mL 첨가는 덱 가정이다(실제 수업에서는 몇 방울로 색이 바뀌는 정도가 시약 농도에 따라 다르다).
5. NO₂ 시연 시 폐기 방법(수산화 나트륨 수용액 흡수)은 덱 보충이다 — 학교 폐기물 처리 기준을 따른다.
