**S8 ① 가역 반응** 정의(형광펜) "정반응과 역반응이 모두 일어날 수 있는 반응을 **가역 반응**이라고 한다." 용어 카드: 정반응 = 반응물 → 생성물(오른쪽으로), 역반응 = 생성물 → 반응물(왼쪽으로), 가역 반응은 ⇌로 나타낸다. 그림: $\ce{2NO2 <=> N2O4}$ 위에 정반응 화살표(field, "정반응"), 아래 역반응 화살표(bfield, "역반응") + 분자 모형(NO2 두 개 ↔ N2O4 하나) [a] 두 NO2가 합쳐짐(move). ★ note "가역 반응식에서 왼쪽을 반응물, 오른쪽을 생성물이라고 부르지만 두 방향 반응이 모두 일어난다."

**S9 해 보기: 황산 구리(II) 오수화물** (거시 → 미시 → 기호, S10) 단계 카드 3: ① 푸른색 결정을 시험관에 넣고 가열 → 흰색 가루 + 시험관 입구 물방울 ② 식힌 흰색 가루에 물을 몇 방울 떨어뜨림 → 다시 푸른색, 시험관이 따뜻해짐 ③ 기호 ★ $\ce{CuSO4*5H2O(s) <=>[\text{가열}] CuSO4(s) + 5H2O(g)}$ — mhchem `<=>[가열]` 대신 식 아래 설명: 정반응(가열) 푸른색 → 흰색, 역반응(물 첨가) 흰색 → 푸른색. 안전 note: 보안경·장갑, 시험관 입구는 사람 없는 쪽으로 약간 아래로, 황산 구리(II)는 중금속 폐액통에. [a] 물방울 fade.

**S10 가역 반응의 예: 염화 코발트 종이** 염화 코발트(II) 종이는 마르면 푸른색, 물을 흡수하면 붉은색. ★ $\ce{CoCl2(s) + 6H2O(l) <=> CoCl2*6H2O(s)}$ (푸른색 ⇌ 붉은색). 그림: 종이 두 장(푸른/붉은) 사이 ⇌, 입김(물) → 붉게, 드라이어 바람(가열) → 푸르게. 활용: 습도 표시 카드·제습제 습도 표시. ★ "같은 종이를 여러 번 쓸 수 있다 → 정반응과 역반응이 모두 일어나는 가역 반응". [a] 종이 색 fade.

**S11 가역 반응의 예: 석회 동굴** 정반응: 이산화 탄소가 녹은 물이 석회암을 녹임 → 동굴. 역반응: 녹은 물이 동굴 천장에서 물과 이산화 탄소를 잃으며 다시 탄산 칼슘이 쌓임 → 종유석·석순. 식 ★ $\ce{CaCO3(s) + H2O(l) + CO2(g) <=> Ca(HCO3)2(aq)}$, 위 화살표 "정반응: 석회 동굴 생성", 아래 "역반응: 종유석·석순 생성". 그림: S6 동굴 단면 재사용(작게) + 두 화살표. [a] 물방울.
note: 물의 상태 변화($\ce{H2O(l) <=> H2O(g)}$)처럼 물리 변화에서도 두 방향 변화가 일어난다 → 뒤의 동적 평형에서 다룬다.

**S12 ① 비가역 반응** 정의(형광펜) "한쪽 방향으로만 일어나는 반응, 즉 역반응이 거의 일어나지 않는 반응을 **비가역 반응**이라고 한다." 단계 카드 3: ① 연소 — $\ce{CH4(g) + 2O2(g) -> CO2(g) + 2H2O(l)}$ "많은 열을 내고 생성물이 흩어진다" ② 앙금 생성 — $\ce{NaCl(aq) + AgNO3(aq) -> AgCl(s) + NaNO3(aq)}$ "흰색 앙금이 생긴다" ③ 기체 발생 — $\ce{Mg(s) + 2HCl(aq) -> MgCl2(aq) + H2(g)}$ "기체가 빠져나간다". ★ 공통점 "생성물이 반응계를 빠져나가거나(기체·앙금), 매우 안정하여 역반응이 거의 일어나지 않는다." 그림: 불꽃, 흰 앙금 시험관, 기포 시험관 [a] 기포 move.

**S13 확인하기** (check) 가역/비가역 ○×와 고르기 4개
1. 염화 코발트 종이에 입김을 불면 붉게 변하고, 말리면 다시 푸르게 된다. → ★ 가역 반응
2. 종이가 타서 재와 연기가 된다. → ★ 비가역 반응(연소)
3. 염화 나트륨 수용액에 질산 은 수용액을 넣으면 흰색 앙금이 생긴다. → ★ 비가역 반응(앙금 생성)
4. 물을 끓이면 수증기가 되고, 수증기를 식히면 다시 물이 된다. → ★ 두 방향 변화(상태 변화 — 가역 변화)

**S14 연결(S6 예측)** "밀폐 용기 속 물은 증발을 멈춘 것일까?" 그림 두 개: 뚜껑 연 비커(물이 점점 줄어듦) / 마개 닫은 플라스크(며칠이 지나도 수면 높이 일정). Q "닫힌 플라스크에서 물이 줄지 않는 것은 물 분자가 더 이상 증발하지 않기 때문일까?" 선택 카드 (가) 증발이 멈췄다 (나) 증발은 계속되지만, 같은 수만큼 응축된다. ★ 답 (나) "→ 다음 장에서 입자 수준으로 확인한다."

**S15 ② 동적 평형: 상평형** 단계 카드 3(D30·S3): ① 처음 — 증발 속도 > 응축 속도(수증기 분자 적음, 위로 화살표 굵음) ② 시간이 지나면 — 수증기 분자가 많아져 응축 속도가 커짐 ③ 평형 — 증발 속도 = 응축 속도, 수면 높이·수증기 양 일정. 입자: 수증기 분자 수 1 → 4 → 6(카드마다), 위/아래 화살표 길이 = 속도(D9). 정의(형광펜) ★ "정반응 속도와 역반응 속도가 같아서 겉으로는 변화가 없어 보이지만, 실제로는 두 반응이 계속 일어나는 상태를 **동적 평형**이라고 한다." ★ "물과 수증기 사이의 동적 평형을 **상평형**이라고 한다: $\ce{H2O(l) <=> H2O(g)}$." [a] 수증기 분자 move.

**S16 용해 평형** 설탕을 물에 계속 넣으면 어느 순간 더 녹지 않는 것처럼 보인다(포화 용액). 단계 카드 2: ① 녹는 중 — 용해 속도 > 석출 속도 ② 포화 용액 — 용해 속도 = 석출 속도, 바닥 설탕 양 일정. ★ 정의 "용질이 녹는 속도와 석출되는 속도가 같은 동적 평형을 **용해 평형**이라고 한다: $\ce{C12H22O11(s) <=> C12H22O11(aq)}$." ★ 증거 note "포화 용액 속에 모서리가 깨진 설탕 결정을 넣어 두면, 질량은 변하지 않지만 결정의 모양이 바뀐다 → 녹는 것과 석출되는 것이 계속 일어난다." [a] 용질 입자 왕복(move).

**S17 ③ 화학 평형: $\ce{2NO2 <=> N2O4}$** (거시 → 미시 → 기호, S3) 단계 카드 3: 밀폐 플라스크 ① 처음: 적갈색 진함, $\ce{NO2}$ 12개 ② 시간 경과: 색이 옅어짐, $\ce{NO2}$ 6개 + $\ce{N2O4}$ 3개 ③ 평형: 색 일정(옅은 적갈색), $\ce{NO2}$ 4개 + $\ce{N2O4}$ 4개 — N 원자 12 = 6+6 = 4+8 보존. 각 카드 아래 정반응·역반응 화살표 길이 비교(① 정 긴 / 역 없음 ② 정 > 역 ③ 정 = 역). ★ "색이 더 이상 변하지 않아도 $\ce{NO2}$ 두 개가 결합하고 $\ce{N2O4}$가 분해되는 반응은 계속 일어난다." 범례: N(파랑) O(빨강), $\ce{NO2}$·$\ce{N2O4}$ 모형. [a] 카드3 분자 흔들림.

**S18 농도와 반응 속도 그래프** (그래프 묶음, D25) 위: 농도–시간 — $[\ce{NO2}]$ 1 → 1/3로 감소(적갈색), $[\ce{N2O4}]$ 0 → 1/3로 증가(ink 긴 점선), $t_1$ 세로 점선, 평형 구간 음영 "평형". 아래: 반응 속도–시간 — 정반응 속도(field) 감소, 역반응 속도(bfield) 0에서 증가, $t_1$에서 같아짐. 오른쪽 Q 세 개 ★: "$t_1$ 이후 두 물질의 농도는? → 각각 일정하다(같지는 않다)" "$t_1$ 이후 정반응 속도와 역반응 속도는? → 같다" "$t_1$ 이후 반응은 멈추었나? → 아니다, 같은 속도로 계속된다". [a] 곡선 draw.

**S19 ③ 화학 평형 상태의 특징** 정의(형광펜) "가역 반응에서 정반응 속도와 역반응 속도가 같아 반응물과 생성물의 농도가 일정하게 유지되는 상태를 **화학 평형 상태**라고 한다." 표(성취기준 해설: 거시/미시 구분): 
| 보는 수준 | 평형 상태의 특징 |
| 거시적(눈으로 관찰) | 색·압력·농도 같은 성질이 일정하다 · 겉으로는 반응이 멈춘 것처럼 보인다 · 닫힌 계에서 정반응 쪽에서 출발하든 역반응 쪽에서 출발하든 평형에 도달한다 |
| 미시적(입자 수준) | 정반응과 역반응이 같은 속도로 계속 일어난다(동적 평형) · 반응물과 생성물이 함께 존재한다 |
★ 주의 note "평형 상태에서 반응물과 생성물의 농도는 **일정**하지만 **같은** 것은 아니다." 

**S20 확인하기(오개념, S6)** "친구들의 생각 중 옳은 것은?" 학생 말풍선 3개: A "평형에 도달하면 반응이 멈춰." B "평형에서는 반응물과 생성물의 농도가 같아져." C "평형에서도 정반응과 역반응이 같은 속도로 계속 일어나." ★ 답 C. ★ 해설 A(×): 반응은 계속된다 — 정반응 속도 = 역반응 속도라 농도 변화가 없을 뿐. B(×): 농도는 일정할 뿐 같지 않다(S18 그래프에서도 다를 수 있음).

## 2. 실험실 명세 — cm311eq 「평에 도달하기」(S21)

- 계: 밀폐 상자(가로 360 × 세로 280, 반사 벽) 속 $\ce{NO2}$·$\ce{N2O4}$ 분자. N 원자 수 보존: $n_{\ce{NO2}} + 2n_{\ce{N2O4}}$ 일정.
- 입력: 슬라이더 「처음 $\ce{NO2}$ 분자 수」 0–60(4씩), 「처음 $\ce{N2O4}$ 분자 수」 0–30(2씩), 버튼 「시작/일시 정지」, 「처음부터」(data-act="reset"), 「측정 기록」. 두 값이 모두 0이면 시작 안 함("분자를 넣어 주자").
- 반응 규칙(고정 시드 난수): 시간 간격 $dt$마다 정반응 일어날 확률 수 $= k_\mathrm{f}\,n(n-1)/2\cdot dt$ (가까운 $\ce{NO2}$ 두 개가 합쳐져 $\ce{N2O4}$), 역반응 $= k_\mathrm{r}\,m\,dt$ ($\ce{N2O4}$ 하나가 두 $\ce{NO2}$로 갈라져 반대로 튐). $k_\mathrm{r}/k_\mathrm{f}=10$ → NO2 60개로 시작하면 평형에서 약 NO2 20 · N2O4 20 근처(무작위 요동).
- 출력: ① 상자(미시) — 분자 모형(N 12, O 12, 라벨 없음, 범례) ② 상자 배경색(거시) — 적갈색 불투명도 ∝ $\ce{NO2}$ 수 ③ 분자 수–시간 그래프(NO2 적갈색, N2O4 ink 점선) ④ 반응 속도–시간 그래프(최근 2 s 이동 평균, 정반응 field, 역반응 bfield) ⑤ 누적 횟수 「정반응 N회 · 역반응 M회」(평형에서도 계속 늘어남) ⑥ 판정 문장: 처음 "정반응이 우세하다(색이 옅어진다)" / "역반응이 우세하다(색이 진해진다)" / 평형 판정(최근 4 s 동안 분자 수 변화 작고 두 속도 차가 작음) "평형 상태: 분자 수와 색은 일정하지만 정반응과 역반응은 같은 속도로 계속 일어난다."
- 측정 기록: 행 누적(최근 5행) — 처음 NO2, 처음 N2O4, 평형 NO2(최근 4 s 평균), 평형 N2O4, 판정.
- 움직임: API.loop로 분자 운동(속도 고정, 벽 반사), 반응 순간 짧게 노란 반짝임.

## 3. 실험실 명세 — cm311water 「물 옮기기 모형」(S24)

- 입력: 「A에 넣는 관 지름」 4–12 mm(1씩, 기본 10), 「B에 넣는 관 지름」 4–12 mm(기본 6), 「처음 물을 넣을 눈금실린더」 A / B 버튼, 버튼 「1회 옮기기」 「5회 옮기기」 「처음부터」.
- 계산: 눈금실린더 안지름 $D=25$ mm. 관에 담기는 물 = 그 실린더 부피 × $(d/D)^2$ (관을 바닥까지 넣으므로 관 속 물기둥 높이 = 수면 높이). 한 회: $a=f_\mathrm{A}V_\mathrm{A}$, $b=f_\mathrm{B}V_\mathrm{B}$ 동시에 → $V_\mathrm{A}\leftarrow V_\mathrm{A}-a+b$. 읽은 값에는 ±0.2 mL 눈금 읽기 오차(고정 시드).
- 출력: 두 눈금실린더 그림(수면 높이, 관 그림, 옮길 때 관 이동 애니메이션 loop), A·B 부피(mL), 이번 회 A → B 양·B → A 양, 부피–옮긴 횟수 그래프(A ink, B field 아님 → B는 `#1F6FD1` minus? → **A `#16233D` 실선, B `#0E7490` 긴 점선** — 정반응/역반응 색과 겹치지 않게), 표 누적(회차, A, B, A→B, B→A, 최근 6행), 해석 문장: 옮기는 양 차이 > 0.3 mL "A → B로 옮기는 양이 더 많다 → A가 줄어든다" / ≤ 0.3 "두 방향 옮기는 양이 거의 같다 → 부피 일정, 옮기기는 계속(동적 평형 모형)".
- 이론 평형 부피: $V_\mathrm{A}=50\times\dfrac{d_\mathrm{B}^2}{d_\mathrm{A}^2+d_\mathrm{B}^2}$ — 실험실 끝 표시는 하지 않고, 결론 슬라이드에서 말로만.
