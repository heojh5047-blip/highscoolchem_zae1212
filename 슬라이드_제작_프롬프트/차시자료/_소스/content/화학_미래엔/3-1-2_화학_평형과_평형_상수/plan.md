## 2. 실험실 명세 — `cm312ratio` 「농도비 규칙성 찾기」(S7, 스프레드시트 활동 대체)

- 왼쪽 조작부(폭 420): ① 새 실험 — 처음 $[\ce{NO2}]$ 0–0.200 mol/L(0.010씩, 기본 0.150), 처음 $[\ce{N2O4}]$ 0–0.600(0.020씩, 기본 0.100) 슬라이더 + [평형 농도 측정] 버튼 → 평형 계산 후 표에 실험 6, 7, 8 … 행 추가(최대 8행, 넘으면 가장 오래된 덱 실험 행을 바꿈). ② 수식 고르기 버튼 ㉠ ㉡ ㉢ ㉣($\frac{[\ce{N2O4}]}{[\ce{NO2}]^3}$, 덱 보충) + [계산(아래로 채우기)] — 고른 수식 열을 모든 행에 채움. ③ [처음부터].
- 평형 계산: N 보존 $c=[\ce{NO2}]_0+2[\ce{N2O4}]_0$, $2Kx^2+x-c=0$, $x=[\ce{NO2}]$, $[\ce{N2O4}]=(c-x)/2$, $K=212$. 측정 오차 각 값에 ±1 %(고정 시드 mulberry32) 후 소수 셋째 자리 반올림. 두 처음 농도가 0이면 측정 거부 문장.
- 오른쪽: 표(실험·평형 $[\ce{NO2}]$·평형 $[\ce{N2O4}]$·㉠·㉡·㉢·㉣) — 실험 1–5는 교과서 값. 아래 그래프: 가로 실험 번호, 세로 "평균에 대한 비"(0.6–1.4), 계산한 수식마다 점·선(색+모양). 
- 출력: `output` 일정성 판정 — 고른 식의 (최대−최소)/평균 % 와 문장("㉡: 값의 차이 0.9 % → 처음 농도와 관계없이 거의 일정하다" / "㉠: 차이 17 % → 일정하지 않다"). 모든 식을 계산하면 "가장 일정한 식: ㉡".
- PRE 시험: ① ㉠ 계산 → 표 ㉠ 열 5칸(9.94…11.2) ② ㉡ → 211–212, 판정 "일정" ③ 측정 2회 → 행 7 ④ ㉡ 새 행 값도 ≈212(±3 %) ⑤ 처음부터 → 5행.
