1물의 전기 분해

전기 에너지를 가해 화합물을 성분 물질로 분해하는 것을 전기 분해라고 한다.

관찰

(−)극에서 수소 기체, (+)극에서 산소 기체가 생긴다.

모인 기체의 부피는 (−)극 : (+)극 = 2 : 1이다.

순수한 물은 전류가 거의 흐르지 않아 황산 나트륨($\ce{Na2SO4}$) 같은 전해질을 조금 녹인다. 전해질은 전류가 잘 흐르게 할 뿐 분해되지 않는다.

전극의 (+)·(−)는 연결된 전원 장치의 극을 따른다(긴 판이 (+)극). 전자는 도선을 따라 (+)극 → 전원 장치 → (−)극으로 이동한다.

Q 부피비가 2 : 1보다 조금 큰 까닭은 무엇일까?

오차 산소가 수소보다 물에 조금 더 잘 녹고, 처음 생긴 기체 일부는 전극에 붙어 있기 때문이다.

탐구결론 도출

Q1 두 전극에서 생기는 기체는 무엇이고, 부피비는 얼마인가?

→ (−)극에서 수소, (+)극에서 산소가 약 2 : 1의 부피비로 생긴다.

Q2 물은 어떤 원소로 이루어져 있고, 원자 수 비는 얼마인가?

→ 수소와 산소, $\mathrm{H} : \mathrm{O} = 2 : 1$ ($\ce{H2O}$)

Q3 전류를 흘려 물이 분해된 것은 화학 결합에 대해 무엇을 알려 주는가?

→ 전기 에너지(전자의 이동)로 물 분자 속 결합이 끊어졌다. 수소와 산소 사이의 화학 결합에는 전자가 관여한다.

평가 기준 상: 부피비와 기체 확인 결과를 근거로 결합에 전자가 관여함을 설명 · 중: 기체의 종류와 부피비를 옳게 정리 · 하: 측정은 했으나 해석이 불완전

1물의 전기 분해: 현상 → 입자 → 화학식

① 현상

(−)극에서 기포가 더 많이 생기고, 기체가 2배로 모인다.

② 입자 모형

원자는 그대로, 짝만 바뀐다: $\mathrm{H}$ 4 = 4, $\mathrm{O}$ 2 = 2

③ 화학 반응식

$\ce{2H2O(l) -> 2H2(g) + O2(g)}$

계수비 $\ce{H2} : \ce{O2} = 2 : 1$

= 같은 온도·압력에서 기체의 부피비 2 : 1

1전극에서 일어나는 반응

Q 두 기체의 부피비는 왜 2 : 1일까?

(−)극물이 전자를 얻는다$\ce{2H2O(l) + 2e- -> H2(g) + 2OH-(aq)}$
(+)극물이 전자를 잃는다$\ce{2H2O(l) -> O2(g) + 4H+(aq) + 4e-}$

같은 수의 전자(4개)가 이동하는 동안 수소 분자는 산소 분자의 2배 생긴다 → 부피비 2 : 1

(−)극 반응을 2배 하여 (+)극 반응과 더하면 전체 반응식 $\ce{2H2O -> 2H2 + O2}$이 된다.

물이 분해될 때 전극에서 전자를 주고받는다 → 물 분자 속 결합에 전자가 관여한다.

확인하기물의 전기 분해

옳으면 ○, 옳지 않으면 ×를 하자.

  1. 물의 전기 분해에서 (+)극에서는 수소 기체가 생긴다. × — 산소 기체
  2. 두 전극에서 생기는 기체의 부피비는 수소 : 산소 = 2 : 1이다. ○
  3. 황산 나트륨은 전류가 잘 흐르게 하려고 넣는다. ○
  4. 물을 전기 분해할 수 있는 것은 물 분자 속 결합에 전자가 관여하기 때문이다. ○

2염화 나트륨의 전기 분해

Q 이온으로 이루어진 염화 나트륨도 전기 분해될까?

염화 나트륨을 가열하여 녹인 뒤 전류를 흘려 준다.

(−)극: 은백색의 금속 나트륨 · (+)극: 황록색의 염소 기체

$\ce{2NaCl(l) -> 2Na(l) + Cl2(g)}$
안전 염화 나트륨은 약 $801\ {}^\circ\text{C}$에서 녹고 염소는 독성이 있다. 학교에서는 실험하지 않고 영상·그림 자료로 본다.

3옥텟 규칙

18족 원소(비활성 기체)는 다른 원소와 거의 반응하지 않는다. 가장 바깥 전자 껍질에 전자가 8개($\ce{He}$은 2개) 채워진 안정한 전자 배치이기 때문이다.

원자들이 전자를 잃거나 얻거나 공유하여 18족 원소와 같은 전자 배치를 가지려는 경향을 옥텟 규칙이라고 한다.

수소($\ce{H}$)는 헬륨처럼 전자 2개를 가지려 한다.

3옥텟 규칙과 이온

$\ce{Na -> Na+ + e-}$
$\ce{Cl + e- -> Cl-}$

금속 원소는 원자가 전자를 잃고 양이온, 비금속 원소는 전자를 얻어 음이온이 되기 쉽다.

Q 마그네슘($\ce{Mg}$: 2, 8, 2)과 산소($\ce{O}$: 2, 6)는 어떤 이온이 될까?

$\ce{Mg^2+}$ (2, 8), $\ce{O^2-}$ (2, 8)

4이온 결합

양이온과 음이온 사이의 정전기적 인력으로 이루어지는 결합을 이온 결합이라고 한다.

① 전자 이동

$\ce{Na}$의 원자가 전자 1개가 $\ce{Cl}$로 옮겨 간다.

② 이온 생성

$\ce{Na+}$과 $\ce{Cl-}$이 생긴다 — 둘 다 18족과 같은 전자 배치

③ 정전기적 인력

수많은 이온이 서로 끌어당겨 규칙적으로 배열한 결정이 된다.

이온 결합 물질은 전기적으로 중성이다: (양이온의 전하 합) + (음이온의 전하 합) = 0

확인하기이온 결합 물질의 화학식

전하의 합이 0이 되도록 이온 수 비를 정하여 화학식을 써 보자.

양이온$\ce{Na+}$$\ce{Mg^2+}$$\ce{Mg^2+}$$\ce{Na+}$$\ce{Ca^2+}$
음이온$\ce{Cl-}$$\ce{O^2-}$$\ce{Cl-}$$\ce{O^2-}$$\ce{Cl-}$
이온 수 비1 : 11 : 11 : 22 : 11 : 2
화학식$\ce{NaCl}$$\ce{MgO}$$\ce{MgCl2}$$\ce{Na2O}$$\ce{CaCl2}$

이름: 염화 나트륨, 산화 마그네슘, 염화 마그네슘, 산화 나트륨, 염화 칼슘 — 음이온 이름을 먼저 읽는다.

5공유 결합

비금속 원자들이 전자쌍을 서로 공유하여 이루어지는 결합을 공유 결합이라고 한다. 두 원자가 함께 가진 전자쌍을 공유 전자쌍이라고 한다.

각 $\ce{H}$ 원자는 전자 2개를 가진 셈이 되어 $\ce{He}$과 같은 전자 배치가 된다.

공유 전자쌍의 전자(−)와 두 원자핵(+) 사이의 인력이 두 원자를 묶는다 — 공유 결합도 전기적 인력이다.

5공유 결합의 여러 예

$\ce{O}$은 전자 8개, 각 $\ce{H}$는 전자 2개를 가진 셈이다.

분자구조식공유 전자쌍결합
$\ce{H2}$$\ce{H-H}$1개단일 결합
$\ce{O2}$$\ce{O=O}$2개2중 결합
$\ce{N2}$$\ce{N#N}$3개3중 결합

구조식의 결합선 1개 = 공유 전자쌍 1개

전자를 점으로 나타내는 루이스 전자점식은 Ⅱ-2의 01에서 배운다.

확인 문제 03서술형

물과 액체 염화 나트륨을 전기 분해한 결과로부터 화학 결합에 대해 알 수 있는 점을 전자와 관련지어 서술하시오.

예시 답안 전류를 흘려 주면 물은 수소와 산소로, 액체 염화 나트륨은 나트륨과 염소로 분해된다. 이때 전극에서 전자를 얻거나 잃는 반응이 일어나며 결합이 끊어지므로, 공유 결합과 이온 결합 모두 전자가 관여하는 전기적 성질을 띤다.

창의력 키우기

물의 전기 분해로 얻은 수소를 연료로 쓰는 '수소 사회'를 상상해 보자. 수소를 만드는 데 필요한 전기를 어디에서 얻으면 좋을지 제안하고 까닭을 써 보자.

예: 태양광·풍력으로 만든 전기로 물을 분해하면 이산화 탄소를 내보내지 않고 수소를 얻을 수 있다.

디지털 소양 키우기

실험실(또는 실제 실험)에서 얻은 시간–기체 부피 자료를 스프레드시트에 입력해 그래프로 나타내고, 두 기체의 부피비가 일정한지 확인해 보자.

그래프의 두 직선 기울기를 비교하면 부피비를 한눈에 볼 수 있다.
