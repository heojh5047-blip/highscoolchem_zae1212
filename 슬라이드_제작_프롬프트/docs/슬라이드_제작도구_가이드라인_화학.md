# 수업용 화학 슬라이드 제작 도구 가이드라인 (2022 개정 고등학교 화학 3과목)

이 문서는 물리 수업용으로 만든 슬라이드 제작 규칙(`slide-harness_전기.html`에서 출발한 하우스 규칙)을 **2022 개정 교육과정 고등학교 화학 3과목** — 일반 선택 「화학」, 진로 선택 「물질과 에너지」, 진로 선택 「화학 반응의 세계」 — 에 맞게 고친 지침입니다. 이 규칙으로 **슬라이드 제작 도구**(단일 HTML 하네스 또는 웹앱)를 쓰거나, AI에게 슬라이드 생성을 맡길 때 시스템 지침으로 넣습니다.

- 도구를 직접 개발하는 사람
- AI에게 도구 제작이나 슬라이드 생성을 맡길 때 시스템 지침으로 넣으려는 사람

문서의 모든 규칙에는 번호(T1, M2, C3, D21 …)가 붙어 있습니다. 번호는 빌드된 덱 머리 주석의 **하우스 규칙**, 자동 점검 메시지와 같습니다.

> **번호 보존 원칙**: 물리 하네스에서 쓰던 번호(T1–T6, M1–M13, D1–D11, S1–S8)는 뜻과 번호를 그대로 둡니다. 화학에서 뜻을 넓힌 규칙은 같은 번호 아래 "화학 적용"을 적습니다. 물리 영역 전용 도식 규칙 D12–D20(자유 물체도, 운동 그래프, 광선도 등)은 **빈 번호**로 남겨 두고, 화학 도식 규칙은 **D21부터** 붙입니다. 화학식·반응식 표기 규칙은 새 계열 **C1–C12**, 화학 수업 흐름 규칙은 **S9–S12**입니다.
>
> **(신규)** 표시가 있는 규칙은 화학으로 넓히며 미리 정한 규칙입니다. 물리 전기 단원 규칙처럼 실제 수업 피드백으로 검증된 것은 아니므로, 수업에 써 보며 고치고 부록 A에 사례를 쌓아 갑니다.
>
> **(제안)** 표시가 있는 기능·컴포넌트는 **아직 구현되지 않은 것**입니다. 표시가 없는 것은 이 묶음의 엔진(`차시자료/_소스/engine`)에 이미 있는 것입니다. 화학용으로 이 묶음에서 새로 넣은 것은 **`\ce{}` 화학식(KaTeX mhchem)**, **원자 모형 부품 `data-atom`**, **산화·환원 색 `ox`·`rd`**, **자동 점검 C1(화학식을 본문 글자로 씀)** 네 가지입니다.

## 1. 목표와 범위

### 1.1 도구가 해결해야 할 문제

교사가 교과서·지도서 PDF나 학습지를 넣으면, 수업에서 바로 쓸 수 있는 **16:9 HTML 슬라이드**가 나와야 합니다. 이 슬라이드는 다음 조건을 갖춰야 해요.

1. 한국어 조판 품질이 높을 것 (어절 단위 줄바꿈, 수식·화학식과 조사가 붙어 있음)
2. **화학식·반응식·수식이 정확할 것** (`\ce{}` 화학식, 원자 수·전하가 보존된 반응식, 교과서와 같은 이름과 기호)
3. **입자 모형과 도식이 정확할 것** (원자 모형, 루이스 전자점식, 분자 구조와 결합각, 쌍극자 모멘트, 에너지 도표, 실험 장치, 화학 전지)
4. 교실 운영에 맞을 것 (단계 공개, 판서 공간, 판서 펜, 전체 화면, 인쇄)
5. 교사가 코드를 몰라도 고칠 수 있을 것

### 1.3 산출물 형태

| 형태 | 설명 | 권장 상황 |
|---|---|---|
| **A. 단일 HTML 하네스** | 엔진, 스타일, 내용이 파일 하나에 모두 들어 있음. 더블클릭으로 실행 | 개인 수업, USB 전달, 오프라인 교실 |
| **B. 편집기 웹앱** | 슬라이드를 목록, 캔버스, 속성 패널에서 편집하고 A 형태로 내보냄 | 여러 단원 제작, 동료 교사와 공유 |

B는 반드시 A를 **내보낼 수 있어야** 합니다. 내보낼 때는 **그 덱이 실제로 쓰는 컴포넌트만** 넣어 파일 크기를 줄입니다(9장).

**수식 라이브러리(KaTeX + mhchem)는 쓰임에 따라 다르게 넣습니다.**

| 경우 | KaTeX·mhchem | 이유 |
|---|---|---|
| 사이트에 올린 덱, 편집기 미리보기 | 외부 파일로 불러옴 (공용) | 덱마다 같은 파일을 품으면 덱당 약 0.7 MB씩 늘고, 브라우저 캐시를 쓰지 못함 |
| **교실용으로 내려받은 파일** | **파일 안에 포함** (mhchem.min.js 포함) | 수업 당일 인터넷이 없어도 수식·화학식이 보여야 함 |

자세한 방법은 4.2절에 있습니다.

## 2. 핵심 원칙 (하우스 규칙)

도구는 이 규칙을 **기본값으로 자동 적용**하고, 어기면 **자동 점검(8장)에서 경고**해야 해요.

### 2.1 조판 (Typography) — 전 영역 공통

| 번호 | 규칙 | 구현 방법 |
|---|---|---|
| T1 | 줄바꿈은 **어절 단위**. 본문, 표 칸, 목록, 제목 모두 해당 | `word-break: keep-all` + 엔진의 `keepWords()` (4.4절) |
| T2 | **수식·화학식은 중간에서 줄이 바뀌지 않음**. 인라인 화학식과 뒤에 붙는 조사("$\ce{H2O}$는")도 떨어지면 안 됨. 긴 반응식은 블록(`.formula`)으로 뺌 | `.katex{white-space:nowrap}` + WORD JOINER(U+2060) |
| T3 | 여러 식·반응식은 **세로로 쌓고**, 식 사이 간격을 충분히 둠. 반쪽 반응식 두 줄 + 전체 반응식처럼 관계가 있는 식은 화살표 위치를 맞춤 | 공식 블록 아래 여백 20px 이상. 식이 칸보다 넓으면 1단 배치 |
| T4 | 표 칸은 가능하면 **한 줄**. 넘치면 ① 문장 줄이기 ② 글자 크기 20px ③ 자간 −0.02em 순서로 조정 | `table.tight` 클래스 |
| T5 | 제목에 번호가 있으면 번호와 제목 사이 간격은 일정하게. 제목 글자 사이가 벌어지면 안 됨 | 제목을 flex로 만들지 말 것. 번호만 `inline-block` |
| T6 | 식을 여러 줄로 유도할 때는 **등호 위치를 맞춤**(평형 상수 계산, pH 계산, 헤스 법칙 합산) | `\begin{aligned} … \end{aligned}`, `&=` |

> T1 구현 시 주의: CSS `keep-all`만으로는 부족합니다. 인라인 요소 경계(`<mark>공유 전자쌍</mark>이다`, `$\ce{NH3}$는`)에서 브라우저가 줄을 바꿀 수 있어요. 물리 덱에서 교사가 "경/로를"처럼 끊긴 결과를 여러 번 지적했고, 결국 JS 보정(4.4절)이 필요했습니다.

### 2.2 수식 (Math) — 전 영역 공통

| 번호 | 규칙 | 예 |
|---|---|---|
| M1 | 모든 양의 기호·화학식은 LaTeX로 씀. **그림 속 라벨도 LaTeX** | 그림 속 `H₂O`, `K₁`(유니코드 첨자) ✗ → $\ce{H2O}$, $K_1$ ✓ |
| M2 | 단위의 곱은 `\cdot`. 가운뎃점(·)은 KaTeX에서 `\cdotp`로 바뀌어 보이므로 쓰지 않음 | `\text{J/g}\cdot{}^\circ\text{C}`, `\text{L}\cdot\text{atm/mol}\cdot\text{K}` |
| M3 | 단위는 **해당 양의 단위**만 붙임 | `n=\dfrac{w}{M}\ [\text{mol}]` ✗ → 식 아래 `.unit` 줄에 "$n$의 단위: mol" ✓ |
| M4 | 변수는 기울임, 숫자·단위·설명 첨자는 바로 선 글꼴 | $K_\mathrm{w}$, $K_\mathrm{a}$, $E^\circ_\text{전지}$, $\Delta H_\text{반응}$ |
| M5 | 본문 속 물질·용기 이름이 기호면 수식으로 씀 | "기체 $\mathrm{A}$와 $\mathrm{B}$", "용기 (가)" — 가상 원소 기호 X, Y도 `\mathrm{X}` |
| M6 | 수식 안 괄호는 크기를 맞춤 | `\left(\dfrac{1}{2}\right)^{n}` |
| M7 | 벡터는 쌍극자 모멘트처럼 꼭 필요할 때만 쓰고, 덱 안에서 표기를 하나로 통일 | 교과서가 화살표 그림(⟼)으로만 나타내면 기호를 새로 만들지 않음 |
| M8 | 곱셈 기호와 지수: 곱은 `\times`(알파벳 x 금지), 큰 수·작은 수는 **과학적 표기** | $6.02\times10^{23}$ ✓ / `6.02x10^23`, `6.02e23` ✗ |
| M9 | 수와 단위 사이에는 **한 칸**(`\ `), 단위는 반드시 `\text{}` 안에 | `0.1\ \text{M}`, `22.4\ \text{L}`, `25\ {}^\circ\text{C}` ✓ |
| M10 | 변화량은 `\Delta`, 처음 값 첨자 0. 덱 안에서 일관되게 | $\Delta H$, $\Delta S$, $\Delta[\ce{A}]$, $[\ce{A}]_0$ |
| M11 | **상수 값은 덱 메타(plan.md 0절)에 한 번 정의**하고 모든 문제·실험실이 그 값을 씀. 교과서 값(유효 숫자 포함)을 그대로 | $N_\mathrm{A}=6.02\times10^{23}\ \text{/mol}$, 0 °C·1 기압 기체 1 몰 22.4 L, $K_\mathrm{w}=1.0\times10^{-14}$(25 °C) |
| M12 | 핵종 표기는 왼쪽 위 질량수, 왼쪽 아래 원자 번호 | `\ce{^{14}_{6}C}`(반감기 단원) |
| M13 | 부호 규약(엔탈피의 부호, 산화수의 부호, 전극의 (+)/(−))은 **단원 첫 사용 시 슬라이드에 명시**하고 plan.md 0절에 기록 | "열을 방출하면 $\Delta H<0$이다." |

### 2.3 화학식·반응식 (Chemical notation) — 화학 3과목 공통 **(신규)**

| 번호 | 규칙 | 예 |
|---|---|---|
| C1 | **화학식·이온·반응식은 `\ce{}`(KaTeX mhchem)로 씀.** 본문, 표 칸, 정답, 그림 라벨 모두. 본문 글자 `H2O`, `Na+`, 유니코드 `H₂O`, `\mathrm{H_2O}` 손 조립은 쓰지 않음 | `$\ce{H2O}$`, `$\ce{CH3COOH}$`, `$\ce{Cr2O7^2-}$` ✓ · 자동 점검 **C1**이 `H2O`, `Na+`, `CO2(g)`처럼 본문 글자로 쓴 화학식을 찾음 |
| C2 | 상태 기호 (s), (l), (g), (aq)는 화학식 바로 뒤에 붙임. 교과서가 상태 기호를 쓴 식은 빠짐없이 | `\ce{NaCl(aq)}`, `\ce{2H2O(l) -> 2H2(g) + O2(g)}` |
| C3 | 반응 화살표: 한 방향 `->`, 가역 반응 `<=>`(⇌). 화살표 위 조건은 `->[\Delta]`, `->[\text{촉매}]`(한글은 `\text{}` 안에) | `\ce{N2(g) + 3H2(g) <=> 2NH3(g)}` |
| C4 | 이온의 전하는 **숫자 다음 부호**(2+, 3−), 1가는 숫자 생략. 부분 전하는 $\delta^+$, $\delta^-$ | `\ce{SO4^2-}`, `\ce{Al^3+}`, `$\delta^+$` |
| C5 | 화학 반응식은 **원자의 종류와 수, 전하의 총합이 양쪽에서 같아야** 함. 계수 1은 생략, 계수는 가장 간단한 정수비(교과서가 분수 계수를 쓴 식만 예외). plan.md에 덱의 모든 반응식 검산을 남김 | 반쪽 반응식은 전자 수까지 맞춤: `\ce{Zn -> Zn^2+ + 2e-}` |

### 2.6 수업 흐름 (Staging)

| 번호 | 규칙 |
|---|---|
| S1 | 예제 풀이, 정답, 결론은 `.step`으로 숨겼다가 한 번에 하나씩 공개. **그림과 그 설명은 같은 단계 요소 안에** 묶어 동시에 나타나게 함 |
| S2 | **연습 문제는 한 슬라이드에 하나**. 판서 공간(오른쪽 또는 아래 빈 영역)을 남기고, 정답 박스는 **가운데 정렬** |
| S3 | 과정이 있는 현상(평형에 도달하는 과정, 평형 이동, 적정 진행, 전지의 방전, 중합 반응 등)은 **단계별 그림 카드**로 보여 주고, 서로 다른 과정은 **슬라이드를 나눔** |
| S4 | 슬라이드를 추가하거나 나누면 번호가 바뀜. 도구는 바뀐 번호를 교사에게 알려야 함 (예: "28번 이후 +1") |
| S5 | 개념 도입 전에 **왜 필요한지**를 설명하는 연결 슬라이드를 둠 (예: 입자를 하나씩 셀 수 없다 → 묶음 단위 → 몰) |
| S6 | 오개념이 흔한 개념은 **예측 → 관찰 → 설명** 순서로: 예측 질문 슬라이드(선택지) → 실험실·영상 → 설명 공개 |
| S7 | 탐구 실험 슬라이드는 **목적 → 변인(조작·종속·통제) → 과정 → 결과(표·그래프) → 결론** 순서로 나누고, 결과 표는 학생이 채우도록 빈칸으로 둘 수 있음. 교과서 탐구 단계 이름(문제 인식, 탐구 설계 및 수행, 결과 및 정리, 결론 도출 등)은 h3·작은 표식으로 |
| S8 | 계산 문제 풀이는 **주어진 것 → 구할 것 → 적용할 관계(몰 환산, 계수비, 평형 상수식, $nMV=n'M'V'$ …) → 계산 → 단위·유효 숫자 확인** 순으로 `.step` 공개. 몰 환산은 "질량 → 몰 → 계수비 → 몰 → 질량"처럼 **환산 사다리**를 한 줄씩 |
| S9 **(신규)** | **실험 안전**: 시약을 다루는 탐구·시연 슬라이드에는 개인 보호 장구(보안경, 실험용 장갑, 실험복)와 그 실험의 주의 사항, **폐수·폐기물 처리**(성취기준 적용 시 고려 사항)를 한 줄 이상 넣음. 교과서의 안전 표시를 글로 옮김 |
| S10 **(신규)** | **거시 → 미시 → 기호**: 새 현상은 ① 눈에 보이는 현상(색 변화, 기체 발생, 전류) → ② 입자 모형 그림 → ③ 화학식·반응식·식 순서로 단계 공개. 세 표현이 한 슬라이드에 함께 있을 때는 같은 위치·같은 색으로 대응시킴 |
| S11 **(신규)** | **모의실험·디지털 탐구**: 교과서가 스마트 기기·모의실험·스프레드시트 활동을 주면 실험실(5.11절)로 대신하거나, 활동 순서·입력값·예시 결과를 단계 공개. 실험 영상(QR)이 있는 탐구는 "실험 영상" 표시와 함께 결과 예시를 교사용 지도서 값으로 |
| S12 **(신규, 필수)** | **성취기준 <탐구 활동>은 반드시 이행**: 교육과정 성취기준에 제시된 탐구 활동(화학 9개, 물질과 에너지 8개, 화학 반응의 세계 10개 — `덱목록.json`의 `requiredInquiry`, 원문은 `docs/교육과정_화학3과목_성취기준.md`)은 **선택이 아니라 필수**다. 담당 덱은 그 탐구를 ① **실험실(5.11절)** — 학생이 변인을 바꾸고 데이터를 얻는 모의실험 — 과 ② **탐구 슬라이드 묶음**(S7: 목적 → 변인 → 과정·안전(S9) → 결과 표·그래프 → 결론) 둘 다로 이행한다. 실제 실험이 가능한 탐구는 실험실이 대신하지 않고 **수업 실험의 예측·데이터 정리·해석 도구**가 된다. 교과서 활동이 성취기준 탐구 활동의 일부만 다루면(예: 농도만 다루고 온도·압력은 자료로만) **덱이 빠진 부분을 채운다**. 탐구 활동 문장의 동사(측정하기, 그래프로 표현하고 해석하기, 설계하고 수행하기, 시각화하기, 비교하기, 만들기)를 실험실의 조작·출력으로 구현하고, 슬라이드 제목 아래에 `.std`로 해당 탐구 활동 문장과 `[탐구]` 표시를 둔다 |

## 4. 렌더링 파이프라인

### 4.1 순서 (반드시 지킬 것)

```
1. Core        번호 매기기, 확대, 이동, 단계, 목차
2. Components  구현됨: data-atom, data-arw, data-chg, data-pm, data-circuit,
                       (물리용) data-field, data-vfield, data-bgrid, cappanel, 실험실(data-lab)
               제안:   data-lewis, data-mol, data-plot, data-energy, data-particles,
                       data-glass, data-cell, data-ptable
               (컴포넌트가 만든 <text class="tex">도 다음 단계에서 처리되도록 먼저 실행)
3. KaTeX       renderMathInElement: 본문 $...$ (mhchem이 먼저 로드되어 \ce{}가 됨)
4. texSVG      SVG 안의 <text class="tex"> → foreignObject + KaTeX
5. keepWords   어절 단위 보정 (KaTeX가 만든 요소 경계까지 보고 처리하므로 반드시 마지막)
6. Audit       (선택) 자동 점검
```

순서가 바뀌면 이런 문제가 생깁니다.

- keepWords를 KaTeX보다 먼저 돌리면 `$...$` 구분자가 span으로 쪼개져 수식이 렌더링되지 않습니다.
- texSVG를 컴포넌트보다 먼저 돌리면 컴포넌트가 만든 라벨(`data-atom`의 원소 기호, 그래프 축 $[\ce{A}]$ [M], 전극 반응식)이 LaTeX로 바뀌지 않습니다.

새 컴포넌트는 **같은 등록 방식**을 쓰게 합니다 **(제안)**. 지금 엔진은 부품마다 `deck.querySelectorAll('[data-…]')`로 따로 처리하므로, 새 컴포넌트를 넣을 때 아래 방식으로 정리하면 점검 함수까지 한곳에 모을 수 있습니다.

```js
Harness.component('data-plot', {
  render(svg, cfg, ctx) { /* SVG 요소 생성, 라벨은 <text class="tex"> */ },
  audit(svg, cfg)       { /* 규칙 위반 목록 반환 (8.2절) */ },
  onShow: true          // 슬라이드가 보일 때 다시 그릴지
});
```

### 4.2 KaTeX 설정

- 구분자: `$$...$$`(블록), `$...$`(인라인). `throwOnError:false`로 두고, 오류는 자동 점검에서 잡습니다.
- 공식 박스 안 KaTeX는 `font-size:1em`으로 두고, 박스 자체의 글자 크기로 조절합니다.
- 화학식은 **mhchem 확장**으로 씁니다. 빌드가 `katex.min.js` → `contrib/mhchem.min.js` → `contrib/auto-render.min.js` 순서로 불러오며, 이 순서가 바뀌면 `\ce{}`가 KaTeX 오류가 됩니다.
- 자주 쓰는 매크로를 덱 메타에 등록합니다 **(제안 — 지금 엔진은 매크로를 받지 않으므로 풀어 씀)**.

```js
macros: {
  "\\unit": "\\ \\text{#1}",          // 0.1\unit{M} → 0.1 M
  "\\Kw":   "K_\\mathrm{w}",           // 물의 이온화 상수
  "\\Ka":   "K_\\mathrm{a}",  "\\Kb": "K_\\mathrm{b}",
  "\\Ea":   "E_\\mathrm{a}"            // 활성화 에너지
}
```

### 4.2.1 KaTeX를 넣는 두 가지 방식

1.3절의 결정에 따라, 사이트 덱은 KaTeX를 **밖에서 불러오고**, 교실용 파일만 **안에 넣습니다**.

**사이트 덱 (기본)**

- KaTeX CSS·JS·글꼴을 덱 파일에 넣지 않고 공용 위치에서 불러옵니다. 여러 덱이 같은 파일 하나를 함께 쓰므로, 한 번 받으면 브라우저가 재사용합니다.
- 공용 위치는 외부 CDN보다 **같은 사이트의 공용 폴더**(예: `/katex/0.16.x/`)를 권장합니다. 학교 망에서 외부 CDN이 막히거나 느린 경우가 있는데, 같은 주소에서 받으면 그 문제가 없고 캐시 이점은 그대로입니다. 버전 번호를 경로에 넣어 오래 캐시해도 안전하게 합니다.
- 하네스 머리 주석에 "인터넷이 없는 교실에서는 교실용 파일을 내려받아 쓰라"는 안내를 둡니다.

**교실용 내려받기 (오프라인)**

편집기와 덱 보기 화면의 "내려받기"에 두 가지를 둡니다.

| 선택지 | 내용 | 크기 (대략) |
|---|---|---|
| 가벼운 파일 | 지금과 같음. KaTeX는 밖에서 불러옴 | 덱 크기 그대로 |
| **교실용 (오프라인)** | KaTeX CSS·JS·**mhchem**·자동 렌더링과 글꼴(woff2)을 파일 안에 넣음 | 덱 크기 + 약 0.4–0.7 MB |

교실용 파일을 만드는 순서는 다음과 같습니다.

```
1. 덱 HTML에서 KaTeX를 불러오는 <link>와 <script src> 태그를 찾는다.
2. katex.min.css를 읽어 @font-face 안의 글꼴 주소를 바꾼다.
   - woff2 항목만 남기고 woff, ttf 항목은 지운다 (최신 브라우저와 웨일은 woff2로 충분).
   - 남은 woff2 파일을 읽어 data:font/woff2;base64,… 로 바꿔 넣는다.
3. <link>를 <style>(바꾼 CSS)로, <script src>를 <script>(JS 본문)로 바꾼다.
   katex.min.js → mhchem.min.js → auto-render.min.js → 하네스 엔진 순서는 그대로 지킨다 (4.1절).
4. 파일 이름에 표시를 붙인다. 예: 2-2-2_전자쌍_반발_이론과_분자_구조_교실용.html
```

글꼴을 더 줄이고 싶으면, **그 덱이 실제로 쓰는 글꼴만** 넣습니다. 수식이 모두 그려진 뒤 브라우저가 내려받은 글꼴을 확인하면 됩니다.

```js
// 덱을 열고 모든 단계를 펼쳐 수식을 다 그린 뒤 실행
await document.fonts.ready;
const used = [...document.fonts]
  .filter(f => f.status === 'loaded' && f.family.includes('KaTeX'))
  .map(f => `${f.family} ${f.style} ${f.weight}`);
// used에 든 글꼴만 data URI로 넣고, 나머지 @font-face 블록은 지운다
```

이렇게 하면 보통 KaTeX_Main, KaTeX_Math 등 몇 개만 남아 글꼴 크기가 크게 줄어듭니다. 다만 실험실처럼 수식을 실시간으로 바꾸는 슬라이드가 있으면 새 글꼴이 필요할 수 있으니, 실험실이 있는 덱은 전체 글꼴을 넣는 편이 안전합니다.

**빌드 스크립트 쪽 (`build.py`)**

- `--offline` 옵션을 주면 위 순서대로 KaTeX를 넣은 `_교실용.html`을 함께 만듭니다.
- 편집기의 "교실용 내려받기"와 결과가 같아야 하므로, 두 곳이 같은 KaTeX 버전과 같은 변환 규칙을 씁니다.

**점검**

- 자동 점검의 "KaTeX를 불러오지 못함" 경고는 그대로 둡니다. 가벼운 파일을 인터넷 없이 열면 이 경고로 알 수 있습니다.
- 교실용 파일은 열 때 외부 요청이 **0건**이어야 합니다 (8.4절 체크리스트).

### 4.3 SVG 속 LaTeX 라벨 (M1)

SVG `<text>`에 KaTeX 글꼴 이름만 지정하는 방식은 **쓰지 않습니다.** 글꼴이 아직 안 불러와졌으면 일반 글꼴로 보이고, 첨자 위치도 어긋나요(물리 덱에서 교사가 두 번 지적한 문제). 화학식의 아래 첨자는 특히 눈에 띄므로 그림 속 화학식도 반드시 이 방식으로 씁니다.

대신 아래처럼 표시해 두고, 엔진이 `foreignObject` 안에 KaTeX HTML을 넣게 합니다.

```html
<text class="tex" x="100" y="40" data-tex="\ce{H2O}" data-size="24" data-anchor="middle"></text>
```

- `x, y`는 글자 **기준선** 위치입니다.
- `data-anchor`: `start`(기본) | `middle` | `end`.
- `data-mix="$\ce{Na+}$ 이온||둘째 줄"`: 한글과 수식·화학식이 섞인 라벨. `||`로 줄을 나눕니다.
- `data-halo`: 라벨 뒤에 흰 테두리를 둘러 선 위에서도 읽히게 합니다.
- 변환 후 모양이 본문 수식과 완전히 같아야 합니다.

### 4.4 어절 단위 보정 알고리즘 (T1, T2)

```
슬라이드 영역의 모든 텍스트 노드 n 에 대해
  (svg, .katex, button, output, canvas, 이미 처리된 .w 안은 건너뜀)
  n이 공백 아닌 글자로 시작하고 앞 형제가 요소(<br> 제외)면 → 맨 앞에 U+2060
  n이 공백 아닌 글자로 끝나고 뒤 형제가 요소(<br> 제외)면 → 맨 뒤에 U+2060
  공백으로 나눈 각 토큰을 <span class="w" style="white-space:nowrap">로 감쌈
```

`display:flex`인 요소에 텍스트를 직접 넣지 마세요. span으로 쪼개진 어절마다 flex item이 되어 글자 사이가 벌어집니다(T5 사례).

## 5. 컴포넌트 명세

컴포넌트는 `<svg viewBox="…" data-이름='{JSON}'>` 또는 `<g data-이름="…">` 형태이며, 만든 그림은 SVG의 **맨 아래층**(또는 그 `<g>` 안)에 들어갑니다. 그래서 강조 원, 추가 화살표 같은 요소를 SVG 안에 직접 써서 위에 겹칠 수 있고, 그 요소에 `.step`을 붙여 단계 공개할 수 있어요.

### 5.0 기본 부품 (구현됨)

| 부품 | 형식 | 그리는 것 |
|---|---|---|
| **원자 모형** | `<g data-atom="x,y,r,원소[,라벨\|-][,d]">` | 원소별 고정 색(2.5절)의 공 + 원소 기호 LaTeX 라벨. 라벨을 생략하면 원소 기호, `-`면 라벨 없음, 그 밖의 값은 LaTeX(예: `\mathrm{O}^{\delta-}`, `\mathrm{Na}^{+}`). `d`면 점선(빈자리·이전 위치). 실험실에서는 `API.atom(g,x,y,r,'O','',false)` |
| 화살표 | `<g data-arw="x1,y1,x2,y2,색[,굵기][,d]">` | 화살표. 색은 `HARNESS_COL` 이름(2.5절) 또는 hex, 굵기 기본 3, `d`면 점선. 전자 이동(`minus`), 산화·환원(`ox`·`rd`), 쌍극자 모멘트(꼬리 막대는 짧은 `line`을 덧그림) |
| 전하 | `<g data-chg="x,y,r,종류[,d]">` | 전하 원. 종류 `+`, `-`(광택과 부호), `P`, `M`, `N`(안에 라벨을 넣을 때). 단원자 이온·전자를 단순하게 보일 때 |
| ± 기호 | `<g data-pm="부호,크기,x:y x:y …[,색]">` | 여러 위치에 + 또는 − 기호. 전극 표면 전하, 대전체 |
| 회로도 | `<svg data-circuit='{"parts":[…]}'>` | 전지·전원 장치, 도선, 스위치, 전구, 전류계·전압계(5.2절). 물의 전기 분해, 화학 전지, 전기 분해·도금 장치의 회로 부분 |
| 판서 공간 | `.board` | 판서용 빈 영역 (S2 점검이 이 요소를 찾음) |
| 슬라이드 표식 | `<h2><span class="tag">탐구</span>…` | 제목 앞 표식. `tag`(활동), `tag alt`(연결·다시 보기), `tag q`(확인·평가), `tag ex`(예제·연습), `tag ink`(정리). 표식 글은 교과서 이름 그대로(과목 약속 3절) |
| 화학식 | 본문·라벨의 `$\ce{…}$` | KaTeX mhchem. 반응식, 이온, 상태 기호, 화살표 위 조건(C1–C4) |

물리 전용 부품 `data-field`(전기력선), `data-vfield`, `data-bgrid`, `.cappanel`도 엔진에 남아 있지만 화학 덱에서는 거의 쓰지 않습니다(물의 전기 분해에서 전기장을 보일 일이 있을 때만).

공통 옵션 (새 컴포넌트, **제안**)

| 키 | 뜻 |
|---|---|
| `scale` | 길이 축척. 같은 슬라이드의 그림끼리 맞추려면 같은 값 (D9) |
| `labels` | `false`면 라벨 생략 (학생이 채우는 빈 그림용) |
| `idPrefix` | marker 등 id 접두어. 생략하면 엔진이 자동으로 고유값 부여 (D5) |

### 5.1 단계 공개 `.step`

- 슬라이드 안의 `.step` 요소는 문서 순서대로 하나씩 나타납니다. **같은 `data-g` 값**(예: `data-g="o1"`)을 가진 `.step`은 한 단계로 묶여 함께 나타납니다. 그림 속 `<g>`와 본문 `<p>`를 같은 값으로 묶으면 S1을 지킬 수 있어요.
- 다음 키를 누르면 숨은 단계가 하나 나타나고, 더 없으면 다음 슬라이드로 넘어갑니다.
- 이전 키를 누르면 마지막으로 공개된 단계가 숨고, 공개된 단계가 없으면 이전 슬라이드로 가서 모든 단계를 펼친 상태로 보여 줍니다.
- `Harness.show(i, 'all')`은 i번 슬라이드를 모든 단계가 펼쳐진 상태로 엽니다(점검·스크린숏용).

### 5.2 회로도 `data-circuit` (전기 화학 장치)

```html
<svg viewBox="0 0 470 250" data-circuit='{"parts":[ ... ], "stroke":3}'></svg>
```

부품 형식은 `AUTHORING.md` 5.2절(도선 `wire`, 전지 `bat`, 접합점 `node`, 단자 `term`, 스위치 `sw`, 전구 `bulb`, 계기 `meter`, 저항 `R`, 라벨 `label`, 화살표 `arrow`)과 같습니다. 화학 장치에서는 회로 부분만 `data-circuit`로 그리고, **비커·전극·염다리·용액은 직접 그린 SVG**(D27·D28)로 겹칩니다.

- 전극 아래 끝은 용액 안까지, 도선은 전극 위 끝까지 정확히 잇습니다(끊긴 끝이 없게, 캡처로 확인).
- 전원 장치의 (+)단자에 이어진 전극이 (+)극입니다(D1). 화학 전지에서는 전지 자체가 전원이므로 전지 기호를 그리지 않고 전구·전압계·전류계를 잇습니다.

### 5.3 루이스 전자점식 `data-lewis` (제안, 물질의 구조와 성질)

> **5.3–5.9는 아직 없는 컴포넌트입니다.** 지금은 같은 그림을 `text.tex`(원소 기호), `circle`(전자점), `line`(결합선), `data-atom`, `data-arw`로 손수 그립니다. 컴포넌트를 만들 때는 내부에서 이 부품들을 그대로 써서 손 그림과 모양이 같게 합니다.
>
> **우선순위**: ① `data-lewis` — 루이스 전자점식은 점 배치 실수가 잦고(D22) 거의 모든 「화학」 Ⅱ단원 덱에 나옵니다. ② `data-mol` — 분자 구조·결합각(D23). ③ `data-energy` — 에너지 도표(D26). ④ `data-plot` — 농도–시간·pH·적정 곡선. ⑤ 나머지는 필요할 때.

```html
<svg viewBox="0 0 420 160" data-lewis='{
  "atoms":[{"el":"H","x":120,"y":80},{"el":"F","x":220,"y":80,"lone":["up","down","right"]}],
  "bonds":[{"a":0,"b":1,"order":1,"style":"dots"}],
  "size":40, "highlight":{"shared":"field","lone":"equi"}
}'></svg>
```

- 원자마다 원소 기호를 가운데 두고, 전자점은 위·아래·왼쪽·오른쪽 네 자리에(D22). `lone`은 비공유 전자쌍 자리, `bonds`의 공유 전자쌍은 두 원자 사이에 자동 배치.
- `style`: `dots`(점식), `lines`(루이스 구조: 결합선, 비공유 전자쌍은 점), `atom`(원자 하나의 전자점식 — 원자가 전자 수만큼 1개씩 → 쌍).
- `highlight`로 공유·비공유 전자쌍 강조 색. 강조 상자는 별도 `.step` 그룹으로 만들어 단계 공개.
- 점검: 원자마다 전자 수(공유 2 + 비공유)가 8(H 2, Be 4, B 6)인지, 원자가 전자 총합이 맞는지 계산해 경고.

### 5.4 분자 구조 `data-mol` (제안, 물질의 구조와 성질·탄소 화합물)

```html
<svg viewBox="0 0 420 360" data-mol='{
  "center":"N", "bonded":["H","H","H"], "lone":1, "shape":"auto",
  "model":"ball-stick", "angles":true, "dipole":false, "x":210, "y":180, "bond":110
}'></svg>
```

- `shape:"auto"`면 전자쌍 수(공유 + 비공유)로 배치를 정하고(VSEPR), 결합각은 교과서 값(180°, 120°, 109.5°, 107°, 104.5°)을 씀.
- `model`: `ball-stick`(공-막대, `data-atom` 사용), `wedge`(쐐기 결합 구조식, D23), `space`(공간 채움 — 정성적 그림에만).
- 비공유 전자쌍은 옅은 로브(풍선)로, 공유 전자쌍보다 넓게.
- `dipole:true`면 결합 쌍극자(D24)와 분자 쌍극자(합)를 별도 `.step` 그룹으로.
- 탄소 화합물 구조식 모드 `{"formula":"CH3CH2OH","mode":"structural"|"condensed"}` — 작용기(−OH, −CHO, −COOH)를 강조 상자로.

### 5.5 그래프 `data-plot` (제안, 전 영역)

```html
<svg viewBox="0 0 520 340" data-plot='{
  "x":{"tex":"t","unit":"s","min":0,"max":60,"tick":10},
  "y":{"tex":"[\\ce{NO2}]","unit":"M","min":0,"max":0.1,"tick":0.02},
  "series":[{"points":[[0,0.08],[10,0.05],[20,0.035],[40,0.03],[60,0.03]],"smooth":true,"color":"ink","label":"\\ce{NO2}"},
            {"points":[[0,0],[10,0.015],[20,0.022],[40,0.025],[60,0.025]],"smooth":true,"color":"field","label":"\\ce{N2O4}"}],
  "equilibrium":{"at":40,"label":"화학 평형"},
  "tangent":{"series":0,"at":10}
}'></svg>
```

- 축 라벨은 자동으로 "기호 [단위]"(D4). pH처럼 단위가 없으면 기호만.
- `equilibrium`은 평형 도달 시점 세로 점선 + 음영(D25), `tangent`는 접선과 기울기(순간 반응 속도), `halfLife`는 반감기 점선들.
- `mode`: `titration`(가로축 넣은 부피, 중화점 표시), `vapor`(증기압 곡선, 1 기압 기준선), `phase`(상평형 그림: 삼중점·임계점), `maxwell`(분자 운동 에너지 분포, 두 온도와 $E_\mathrm{a}$ 경계 음영), `gas`(보일·샤를 그래프).
- 측정값 산점도 + 추세선(`fit:"linear"`)을 지원해 탐구 슬라이드(S7, 스프레드시트 활동)에 씀.

### 5.6 에너지 도표 `data-energy` (제안, 화학 변화의 자발성·반응 속도)

```html
<svg viewBox="0 0 520 340" data-energy='{
  "levels":[{"tex":"\\ce{N2(g) + 3H2(g)}","H":0},{"tex":"\\ce{2NH3(g)}","H":-92}],
  "ea":{"H":250,"tex":"E_\\mathrm{a}"}, "catalyst":{"H":150},
  "dH":true, "unit":"kJ", "scale":"schematic"
}'></svg>
```

- 반응물·생성물 수평선, $\Delta H$ 화살표(반응물 → 생성물), $E_\mathrm{a}$ 치수선, 촉매 경로 점선(D26). 역반응의 활성화 에너지 옵션.
- `hess` 모드: 여러 경로를 같은 출발·도착 수평선 사이에 계단으로 — 경로별 $\Delta H$ 합이 같음을 점검.
- `scale:"schematic"`이면 그림 아래 "크기 비례 아님"(D9).

### 5.7 입자 상자 `data-particles` (제안, 화학의 언어·평형·용액)

```html
<svg viewBox="0 0 300 260" data-particles='{
  "box":{"w":260,"h":220,"lid":true},
  "species":[{"mol":["N","N"],"n":3},{"mol":["H","H"],"n":9},{"mol":["N","H","H","H"],"n":0}],
  "state":"gas", "seed":7
}'></svg>
```

- 분자를 `data-atom` 묶음으로 무작위(고정 `seed`) 배치. `state`: `gas`/`liquid`/`solid`/`aq`(물 분자는 `grav`로 옅게).
- 같은 덱의 여러 상자는 같은 원자 크기(D21). 반응 전후 상자의 원자 수 보존을 점검(C5).
- 평형 이동 단계 카드(D30)는 `species`의 `n`만 바꾼 상자 3개로.

### 5.8 실험 기구 `data-glass` (제안, 역동적인 화학 반응·산 염기 평형)

```html
<svg viewBox="0 0 200 420" data-glass='{"type":"buret","x":100,"y":20,"vol":50,"level":12.5,"liquid":"#E8F2FB","label":"\\ce{NaOH(aq)}"}'></svg>
```

- `type`: `beaker`, `flask`(삼각 플라스크), `volumetric`(부피 플라스크, 표선), `buret`(위가 0 눈금), `pipet`, `cylinder`(눈금실린더), `testtube`, `utube`(삼투), `bridge`(염다리) — D27 규칙을 자동으로 지킴.
- `level`은 눈금 값, 액면 메니스커스 아래를 그 눈금에 맞춤. 지시약 색 변화는 `liquid`를 단계마다 바꾼 그림으로.

### 5.9 전지·전기 분해 장치 `data-cell` (제안, 산화·환원 반응)

```html
<svg viewBox="0 0 560 320" data-cell='{
  "mode":"galvanic", "left":{"metal":"Zn","ion":"\\ce{Zn^2+}"}, "right":{"metal":"Cu","ion":"\\ce{Cu^2+}"},
  "bridge":"\\ce{KNO3}", "meter":"V", "show":["electron","ions","halfReactions"]
}'></svg>
```

- `mode`: `galvanic`(화학 전지: 산화 전극 = (−)극), `electrolysis`(전원 장치: 산화 전극 = (+)극), `plating`(도금).
- 전자 이동은 도선 위 `minus` 화살표, 이온 이동은 염다리·용액 안 화살표(D28), 전극 옆에 반쪽 반응식, 극 라벨에 산화/환원(`ox`/`rd`)을 함께.
- 표준 환원 전위 값을 주면 전지 전위 $E^\circ_\text{전지}=E^\circ_\text{환원 전극}-E^\circ_\text{산화 전극}$를 계산해 라벨로(교과서 식 꼴을 따름).

### 5.11 실험실 (Lab)

슬라이더 입력 → 계산 → 수치와 그림 갱신. 형식은 `<div class="lab" data-lab="이름">`이고, 동작은 덱의 `window.DECK_LABS.이름(root, API)`에 씁니다. 원칙은 다음과 같습니다.

- 슬라이더 옆에 **현재 값과 단위**를 항상 표시합니다(`output`). output 글자는 일반 글자(예: `0.10 M`)이고, 화학식 라벨이 바뀌어야 하면 HTML 겹침(`.ov`)에 `API.tex('\\ce{…}')`로 넣습니다.
- 결과 수치는 크게, 해석(산성/염기성, 정반응 우세, 자발적, 몇 배 빨라짐 등)은 문장으로 씁니다.
- 극단값에서도 그림이 칸 밖으로 나가지 않게 로그 척도(pH, 농도)나 상한을 둡니다.
- 슬라이드가 보일 때 다시 그립니다(`Harness.onShow`). 숨은 상태의 canvas는 크기를 잘못 잴 수 있어요.
- 상수와 부호 규약은 덱 메타 값을 씁니다(M11, M13). 계산은 교과서 식 그대로(예: 약산 pH는 $[\ce{H3O+}]\approx\sqrt{K_\mathrm{a}C}$ — 교과서가 근사를 쓰는 범위에서만).
- 입자 시뮬레이션(기체 분자 운동, 충돌, 평형 도달)은 `API.loop`로 고정 시간 간격 계산을 하고, 입자 수를 60–150개로 제한합니다. 무작위는 고정 시드로 재현 가능하게.

**필수 실험실 (S12)**: 아래 표에서 성취기준 <탐구 활동>에 해당하는 실험실은 **반드시** 만든다(굵게 표시). 실험실 하나가 탐구 활동 문장의 모든 동사를 덮어야 한다 — 예: "희석 시 몰 농도에 따른 pH 데이터를 수집하여 그래프로 표현하고 해석하기" → 희석 단계 슬라이더 + 측정값 표 누적 + pH–농도(로그) 그래프 + 해석 문장. "실험 설계하고 수행하기"는 변인(조작·종속·통제)을 학생이 고르는 단계를 넣고, 설계에 따라 결과가 달라지게 한다. 측정값에는 실제 실험처럼 작은 오차(고정 시드)를 넣어 데이터 해석 활동이 되게 할 수 있다(이론값과의 비교 탐구에서는 필수).

### 6.4 움직임 (2026-10 추가)
학생이 글만 읽다 지루해지지 않게, 화면이 '살아 있게' 하되 화학 이해를 돕는 움직임만 쓴다.

**엔진이 모든 덱에 자동으로 하는 것** (내용 파일에서 할 일 없음)
- 슬라이드가 보일 때 본문 덩어리가 차례로 떠오른다(h2는 왼쪽에서). 형광펜(`mark`)이 그어진다. 그림 속 `data-arw` 화살표가 꼬리→머리로 자란다.
- 단계(`.step`) 공개: 글은 아래에서 떠오르고, SVG 단계는 선이 그려지며, 정답(`.ans`)은 노랗게 한 번 반짝인다.
- 정지 모드: 인쇄·캡처·자동 점검(도구가 `window.__STILL`을 넣음)·`?still`·`?audit`·편집기·기기의 '동작 줄이기' 설정 → 움직임 없이 그린 그대로. `?motion`은 도구 안에서도 움직임을 켠다.

**그림 움직임 (`data-anim`) — 내용이 정한다**
- **원칙 M-A: 그린 모습 = 마지막 모습.** 움직임은 출발값(`data-from`)에서 그린 모습으로 온다. 그래서 인쇄·점검(D8 겹침 등)은 언제나 그린 모습으로 본다. 라벨 자리도 그린 모습 기준.
- **원칙 M-B: 화학적으로 맞게.** 입자는 반응 전 → 후로 원자를 보존하며 재배열(원자가 생기거나 사라지지 않음), 전자는 산화되는 쪽에서 환원되는 쪽으로, 이온은 반대 전하의 전극 쪽으로, 기체 분자는 무질서하게·고체는 제자리 진동, 평형에서는 정반응·역반응이 **동시에** 계속(멈추지 않음), 촉매는 경로만 낮춤. 장식용 무의미한 움직임은 넣지 않는다. 한 그림에 1–2개, 덱마다 15–25곳 정도.
- **원칙 M-C: 라벨은 움직이는 물체와 함께 묶을 때만 같이 움직인다.** 움직이는 동안 잠깐 닿는 것은 괜찮지만 끝 모습에서는 겹치지 않는다.

| 값 | 뜻 | 추가 속성 |
|---|---|---|
| `rot` | `data-from`(°, 시계 방향 +)만큼 돌려 놓은 데서 그린 모습으로 | `data-o="cx,cy"` 회전 중심 |
| `move` | `data-from="dx,dy"`만큼 옮긴 데서 | |
| `scale` · `pop` | 배율 `data-from`(한 값 또는 `"가로,세로"` — `"1,0"`이면 세로로 자라는 막대)에서 / 작게서 튀어나옴 | `data-o` |
| `fade` · `draw` | 나타남 / 선을 그림 | |

공통: `data-dur`(초, 기본 1.2) `data-delay` `data-rep="once|alt|loop|damp|swing"`(alt 왕복, damp 양쪽으로 흔들리며 줄어 그린 모습에 섬, swing 그린 모습을 가운데로 ±출발값 사이를 계속 흔들림 — 진자·용수철, dur = 반 주기) `data-ease="io|out|lin|in|soft|back|bounce"`(in = 정지에서 등가속 — 낙하·출발, out = 등감속해 정지 — 제동·던져 올림, soft = 부드럽게 멈춤, sine = 단진동 모양 — `alt`와 함께 진동) `data-on="step"`(가까운 `.step`이 켜질 때 시작 — 단계 밖이면 슬라이드가 보일 때) · `data-on="g:이름"`(그 `data-g` 단계가 켜질 때 시작 — 단계 밖 그림을 특정 단계에 맞출 때). 기본은 슬라이드가 보일 때. 점선 요소의 `draw`는 점선을 지키려고 나타남(fade)으로 바뀐다. `fade`는 요소의 원래 `opacity`(속성)까지만 나타나고, `draw`를 `<g>`에 걸면 그 안의 선들을 함께 그린다. `scale`의 출발값은 음수도 된다(정상파: `data-from="1,-1" data-rep="alt" data-ease="sine"`, 기준점 `data-o` = 평형선 위의 점, `data-dur` = 반 주기).
보통 `<g data-anim="rot" data-from="24" data-o="340,160" data-dur="1.8" data-ease="out">…</g>`처럼 움직일 부분을 `<g>`로 묶는다. 이미 `transform`이 있는 요소에도 쓸 수 있다(움직임이 앞에 붙는다). 한 요소에 두 움직임이 필요하면 `<g>`를 두 겹 쌓는다.
- **화학 덱의 쓰임 예**: 반응 전 분자에서 원자 묶음이 떨어져 나와 생성물로 다시 모임(`move`, 원자 수 보존) · 기체 분자의 무작위 운동(`move` + `alt`, 실험실이면 `API.loop`) · 고체 입자의 제자리 진동(`swing`, 작은 진폭) · 전자가 도선을 따라 이동(`dash` + `data-flow`, 방향 = 산화 전극 → 환원 전극) · 이온이 염다리·용액에서 이동(`move`) · 극성 분자가 대전체 쪽으로 돌아섬(`rot`, $\delta^-$ 쪽이 (+)대전체를 향하도록) · 평형 화살표 ⇌의 두 반쪽이 번갈아 깜빡이지 않고 함께 유지(평형에서도 반응은 계속) · 에너지 도표에서 활성화 에너지 언덕을 넘는 점(`draw` 경로) · 적정에서 뷰렛 액면이 내려감(`scale` `"1,0"` 반대 방향) · 지시약 색 변화(`fade`로 겹친 색 층).
- 자동으로 자라는 `data-arw` 화살표: 움직이는 묶음(`data-anim`) 안에 있으면 그 움직임을 따르고, 경로 `draw` 끝에 화살표를 맞추려면 그 `data-arw` 요소에 `data-delay`(초)를 준다.
- **작용점 규칙(M-D, 2026-10 추가 — 물리에서 온 규칙, 화학에서는 "움직이는 입자에 붙은 화살표·라벨"로 읽는다: 이동하는 이온의 전하 라벨, 분자에 붙은 쌍극자 화살표, 전자에 붙은 $e^-$)**: 움직이는 물체에 붙은 화살표(그 물체가 받는 힘, 그 물체의 속도·가속도·운동량)는 꼬리(작용점)가 움직이는 내내 물체에 붙어 있어야 한다 — 끝 위치에 고정된 화살표로 물체가 '다가가는' 모습은 물리 오류다. ① 평행 이동이면 화살표·라벨을 물체와 같은 `data-anim` 묶음에 넣는다. ② 방향도 물체와 함께 돌아야 하면(바퀴 접선력, 원운동 속도) 같은 회전 묶음. ③ 물체는 돌지만 방향은 고정(중력 등)이면 바깥 묶음 = 물체와 같은 회전, 안쪽 묶음 = 같은 시간의 반대 회전(`data-o` = 화살표 꼬리)으로 방향을 유지하거나, 한 번 움직임이면 화살표에 `data-delay`(움직임 끝 이후). ④ 움직임 중에만 있는 힘(유도 전류가 만드는 힘 등)을 움직임이 끝난 뒤에 나타나게 하면 안 된다. 접촉해야 생기는 힘은 접촉 뒤에. 공간에 고정된 것(장의 방향, 치수선, 경로·궤적 표시, 회전 방향 호, 정지 물체의 힘)은 그대로 둔다. 점검: `node tools/force_check.mjs`(후보를 뽑아 줌 — 그림을 보고 판단).
- 움직임이 있는 그림은 누르면 다시 움직인다(넘기지 않음). 슬라이드에 다시 들어올 때도 다시 움직인다.
- 점검: `node tools/motion_check.mjs`(움직임 켜고 모든 단계를 넘기며 콘솔 오류), 중간 프레임은 `?motion#N`으로 열어 `Harness.show(N-1,'reset')` 뒤 0.3·0.9·2초에 캡처해 방향·순서를 눈으로 본다.

### 6.5 질문 먼저, 답은 다음 누름에 (2026-10 추가)
발표자 미리보기가 없으므로, 답 단계 직전에 **한 번 누르면 질문을 강조**(빈칸은 노랗게 깜빡, 질문 문장은 노란 테 깜빡, 개념 지도 점선 빈칸 상자는 테가 굵게 깜빡)하고 **다음 누름에 답**을 연다. 뒤로 가기는 강조부터 끈다.
- 엔진이 '답'으로 보는 단계: `.blank` 안의 단계 · `.ans`/`.answer`(를 품은) 단계 · `→`로 시작하는 단계(끝이 '?'면 질문으로 봄) · SVG에서 점선(`stroke-dasharray`) 빈칸 상자 위의 글 단계 · `data-ask`가 있는 단계.
- 강조할 질문: 인라인 답이면 그 문장(문단·표 칸), 블록 답이면 바로 앞 형제 요소. 그것이 무대의 30%보다 크면 그 안의 마지막 질문 줄('?'가 있거나 'Q'로 시작)만. 앞 형제가 없으면(답 묶음 `.answers`의 첫 답 등) 바깥으로 올라가며 앞쪽의 질문 문장(제목 h2 포함)을 찾는다. 질문을 못 찾으면 강조 없이 바로 답(헛누름 없음).
- 작성 규칙: 질문 문장에는 '?'를 쓰거나 'Q'로 시작한다. 결론·요약 상자처럼 질문이 없는 `.answer`는 강조 없이 열린다. 강조를 빼려면 단계에 `data-ask="no"`, 강조하게 하려면 `data-ask`. 문장에 '?'가 없는 질문(빈칸 채우기 지시문 등)은 문장은 그대로 두고 그 요소에 `data-q`를 붙이면 엔진이 질문으로 본다 — 답 앞쪽에서 가장 가까운 `data-q`가 먼저 강조된다(그 사이에 '?' 질문이 있으면 그것이 우선).
- 평가 문항 덱(`.pf-key`)은 '풀이 공간 → 정답'이 이미 있으므로 하지 않는다.
- 점검: `node tools/ask_check.mjs`(헛누름·너무 큰 강조·숨은 요소 강조 0건).

웹앱이라면 **발표자 보기**(다음 슬라이드 미리보기, 메모, 타이머)를 두 번째 창으로 제공하는 것을 권장합니다.

### 7.3 편집 기능 요구사항

1. **수식·화학식 편집기**: KaTeX 실시간 미리보기. `H2O`처럼 쓴 화학식은 `\ce{H2O}`로(C1), 가운뎃점(·)은 `\cdot`(M2), 유니코드 첨자(₂)는 `\ce{}` 또는 `_2`(M1), 알파벳 x 곱셈은 `\times`(M8), `\text{}` 없는 단위는 감싸기(M9)를 제안. 반응식은 원자 수·전하 검산 결과를 옆에 표시(C5).
2. **컴포넌트 편집기**: 컴포넌트마다 끌어 놓기 편집기를 둡니다.
   - 입자 모형: 원소 팔레트(원자 색 표), 분자 묶음 복사, 반응 전후 원자 수 자동 비교(D21)
   - 루이스 전자점식: 원자를 고르면 원자가 전자 수만큼 점 자동 배치, 결합 만들기, 옥텟 점검(D22)
   - 분자 구조: 중심 원자·결합 원자·비공유 전자쌍 수 → 구조·결합각 자동(D23), 쌍극자 표시
   - 그래프: 표에 값을 붙여 넣거나 식 입력, 평형 구간·접선·반감기·중화점 도구(D25)
   - 에너지 도표·실험 기구·전지: 매개변수 패널 + 미리보기
3. **단계 편집**: 블록마다 공개 순서를 지정하고, 미리보기에서 단계별로 확인합니다. 컴포넌트 안 하위 그룹(비공유 전자쌍, 쌍극자 화살표, 평형 구간 음영, 반쪽 반응식)도 단계 지정 가능.
4. **슬라이드 분할/병합**: 분할하면 이후 번호가 바뀐다는 알림을 띄웁니다(S4).
5. **PDF 학습지 가져오기 (제안)**: 텍스트, 수식, 그림을 추출하고, 절 번호로 슬라이드 초안을 만듭니다. 핵심 정의(노란 형광펜 부분)는 `<mark>`로 옮깁니다. 교과서 그림은 저작권 때문에 **직접 그린 도식이나 컴포넌트로 대체**하도록 안내하고, 그림 종류(입자 모형/루이스/분자 구조/그래프/에너지 도표/실험 장치/전지…)를 추정해 해당 컴포넌트 초안을 제안합니다. 교과서의 반응식·화학식은 `\ce{}`로 옮깁니다.
6. **단원 팩 불러오기 (제안)**: 새 덱을 만들 때 영역을 고르면 템플릿, 컴포넌트, 매크로, 상수, 점검 항목이 함께 설정됩니다(10장).
7. **되돌리기/다시 하기**, 자동 저장(IndexedDB), 버전 기록.
8. **내보내기**: 단일 HTML 두 가지(가벼운 파일 / **교실용 오프라인 파일**, 4.2.1절), PDF(인쇄 CSS, 학습지 모드), JSON(백업).

- 모든 반응식은 원자 수·전하 보존을 검산해 plan.md에 남긴다. 계수는 가장 간단한 정수비.
- 물질 이름·기호·상수는 교과서 그대로(대한화학회 명명), 처음 나올 때 이름(화학식).
- 단위는 \text{} 안에, 수와 단위 사이 한 칸. 단위 곱은 \cdot, 수의 곱은 \times.
- 평형 상수식에 고체·순수한 액체를 넣지 않는다. 농도는 [\ce{A}], K·Q·K_\mathrm{w}·K_\mathrm{a}.
[도식]
- 원자 모형은 data-atom(원소별 고정 색, 같은 원소 같은 크기, 반응 전후 원자 수 같게).
- 루이스 전자점식은 네 자리 대칭 배치, 옥텟 확인. 분자 구조는 쐐기 결합 또는 공-막대 + 결합각(교과서 값).
- 쌍극자 모멘트 화살표는 + 꼬리, δ+ 쪽에서 전기 음성도 큰 원자 쪽으로.
- 에너지 도표: ΔH 화살표는 반응물 → 생성물, Ea는 치수선, 촉매 경로는 점선.
- 화학 전지·전기 분해: 전자는 도선 위(minus), 이온은 용액·염다리 안. 극 라벨과 산화(ox)/환원(rd)을 함께.
- 색은 HARNESS_COL 이름(ink, plus, minus, field, equi, bfield, ox, rd, grav, muted)으로 지정하고 hex를 새로 만들지 않는다.
  한 슬라이드 안에서 같은 색이 두 뜻을 갖지 않게 한다. 그림 라벨은 화면 기준 18px 이상.
- 그래프 축은 "기호 [단위]". 교과서 그림·사진은 베끼지 않고 직접 그린다.
[수업 흐름]
- 정답·풀이는 .step으로 숨긴다. 그림과 설명은 같은 .step 또는 같은 data-g.
- 새 현상은 현상(거시) → 입자 모형(미시) → 화학식(기호) 순서로 공개.
- 계산 풀이는 주어진 것 → 구할 것 → 관계식 → 계산 → 단위·유효 숫자 확인. 몰 환산은 사다리로 한 줄씩.
- 연습 문제는 한 장에 하나, 판서 공간 확보, 정답 가운데 정렬.
- 개념 도입 전 "왜 필요한가" 연결 슬라이드. 오개념 주제는 예측 → 관찰 → 설명.
- 실험 슬라이드에는 보호 장구·주의 사항·폐수 처리를 적는다.
- 성취기준 <탐구 활동>(덱목록의 requiredInquiry)은 필수: 담당 덱에서 실험실 + 탐구 슬라이드로 반드시 이행하고,
  교과서 활동이 일부만 다루면 덱이 채운다.
- 교육과정 범위 제한을 지킨다(예: 「화학」은 중화 적정 곡선·압력 평형 상수 ✗, 쌍극자 모멘트는 정성적).
- 원본 덱은 _소스/content를 고치고 tools/build.py로 다시 빌드. 완성 후 자동 점검 0건까지 고친다.

### 8.3 화학적 정확성 점검 (사람이 확인)

자동 점검으로 잡기 어려운 항목은 배포 전 교사가 확인합니다. 도구는 이 목록을 슬라이드별 체크 상자로 보여 줍니다.

- 모든 반응식의 원자 수·전하 보존, 계수가 가장 간단한 정수비인가 (plan.md 검산 기록과 대조)
- 풀이의 수치를 다시 계산하면 답과 같은가, 유효 숫자·로그 자릿수가 교과서와 같은가 (실험실 계산 함수로 재검산)
- 화학식·물질 이름·상태 기호가 교과서와 같은가 (아이오딘/요오드, 메테인/메탄 같은 옛 이름 금지)
- 그림의 방향(전자 이동, 이온 이동, 쌍극자 모멘트, $\Delta H$, 평형 이동 방향)이 본문 설명과 같은가
- 평형 상수식에 고체·순수한 액체가 들어가지 않았는가, $K$와 $Q$를 바꿔 쓰지 않았는가
- **성취기준 <탐구 활동>이 모두 이행되었는가** — 덱의 `requiredInquiry` 하나하나가 실험실과 탐구 슬라이드로 들어갔고, 탐구 활동 문장의 모든 동사(측정·그래프·해석·설계·비교·만들기)가 화면에서 실제로 일어나는가 (S12)
- 교육과정 범위를 넘지 않았는가 (10장 각 과목의 "범위 제한" — 예: 「화학」에서 중화 적정 곡선, 압력 평형 상수 ✗)

## 9. 접근성, 성능, 호환성

- 그림 SVG에는 `aria-label`을, 장식용 그림에는 `aria-hidden="true"`를 붙입니다. 컴포넌트는 JSON에서 설명문을 자동 생성합니다(예: "암모니아 분자. 중심 원자 질소에 공유 전자쌍 3개, 비공유 전자쌍 1개. 삼각뿔형, 결합각 107°.").
- 키보드 포커스를 눈에 보이게 합니다(`:focus-visible`).
- `prefers-reduced-motion`이면 단계 전환 애니메이션과 자동 재생 시뮬레이션을 끕니다.
- 입자 시뮬레이션은 슬라이드가 보일 때만 돌리고(`API.loop`), 끌기 중에는 입자 수를 줄입니다.
- 대상 브라우저는 최신 Chrome, Edge, Safari, 교실 PC의 Whale입니다.
- 사이트 덱은 KaTeX를 넣지 않으므로 가볍게 유지하고, **교실용 파일은 KaTeX·mhchem을 넣어도 2 MB 안쪽**을 목표로 합니다.

| 역동적인 화학 반응 | 순수한 물의 전기 전도성 → 물의 자동 이온화와 $K_\mathrm{w}$ → 몰농도와 표준 용액 만들기 → pH·pOH → 희석과 pH(데이터 그래프) → 중화 반응(알짜 이온 반응식) → 양적 관계($nMV=n'M'V'$) → 혼합 용액의 이온 수 변화 → 중화 적정과 식초의 아세트산 함량 | 중화 반응의 양적 관계는 **강산과 강염기의 반응**으로 제한. **중화 적정 곡선은 다루지 않음** | pH가 1 줄면 $[\ce{H3O+}]$가 1 늘어난다고 생각, 희석하면 pH가 7을 넘는다고 생각, 중화점이 항상 중성이라고 생각, 구경꾼 이온도 반응한다고 생각 | "pH 3인 염산을 물로 1000배 묽히면 pH는 6일까? 계속 묽히면?" |

- 상수(M11): $N_\mathrm{A}=6.02\times10^{23}$, 0 °C·1 기압 기체 1 몰 = 22.4 L, $K_\mathrm{w}=1.0\times10^{-14}$(25 °C), 원자량(몰질량)은 교과서 부록·문항 단서 값.
- 매크로·표기: `\ce{}`, `K`, `Q`, `K_\mathrm{w}`, `\text{pH}=-\log[\ce{H3O+}]`(교과서가 $[\ce{H+}]$로 쓰면 그대로).

### 10.2 물질과 에너지 (진로 선택) — [12물에01]–[12물에04]

| 영역 | 표준 슬라이드 흐름 | 범위 제한(교육과정) | 자주 생기는 오류·오개념 |
|---|---|---|---|
| 물질의 세 가지 상태 | 보일·샤를·아보가드로 법칙 → 이상 기체 방정식 $PV=nRT$와 활용(몰질량) → 부분 압력과 몰 분율(돌턴) → 분자 간 상호작용(쌍극자·쌍극자 힘, 분산력, 수소 결합) → 끓는점 비교(수소 화합물) → 증기압과 동적 평형 → 온도·압력과 상태 → 결정·비결정 → 결정성 고체의 분류(이온·분자·공유·금속 결정) | 결정 구조(단위 세포)는 다루지 않고 **화학 결합의 종류에 따라 분류**하는 수준. 모의실험으로 기체 관계 파악 | 섭씨 온도로 샤를 법칙 계산, 분자 간 힘과 공유 결합 혼동, 증기압이 액체 양에 따라 다르다고 생각 |
| 용액의 성질 | 물의 특이한 성질(비열, 밀도와 얼음, 표면 장력, 모세관 현상)과 수소 결합 → 증기 압력 내림(라울) → 끓는점 오름·어는점 내림(몰랄 농도) → 삼투 현상과 삼투압 → 생활 사례 | 끓는점 오름·어는점 내림은 **몰랄 농도 또는 몰 분율**로 | 용질 종류에 따라 다르다고 생각(비휘발성·비전해질에서는 입자 수), 삼투 방향 반대 |
| 화학 변화의 자발성 | 엔탈피와 반응 엔탈피 → 열화학 반응식 → 열량계 → 헤스 법칙(경로와 무관) → 엔트로피(정성) → 엔탈피·엔트로피 변화와 자발성 | 화학 반응의 열 출입으로 제한, **열역학 함수로서의 엔탈피는 다루지 않음**. **깁스 자유 에너지는 다루지 않으며 엔트로피는 정성적** | 발열 반응은 모두 자발적이라고 생각, $\Delta H$ 부호와 열 출입 방향 혼동, 헤스 법칙 경로를 거꾸로 할 때 부호를 안 바꿈 |
| 반응 속도 | 반응 속도 정의와 측정(센서) → 반응 속도식과 반응 차수(자료 해석) → 1차 반응의 반감기와 활용(방사성 연대 측정·의약품) → 유효 충돌과 활성화 에너지 → 농도·온도·촉매(효소)의 영향, 분자 운동 에너지 분포 | **적분 속도식은 유도하지 않고**, 자료 해석으로 반감기를 찾음 | 반응 차수를 계수로 정함, 촉매가 $\Delta H$를 바꾼다고 생각, 온도가 오르면 활성화 에너지가 낮아진다고 생각 |

- 상수(M11): $R=0.082\ \text{atm}\cdot\text{L/mol}\cdot\text{K}$(교과서 표기 순서를 따름), $T(\text{K})=t({}^\circ\text{C})+273$, 1 atm = 760 mmHg, 물의 $K_\mathrm{b}$·$K_\mathrm{f}$는 교과서 값.
- S6 예측 질문 후보: "높은 산에서 라면이 잘 안 익는 까닭은?", "얼음 위에 소금을 뿌리면?", "흡열 반응도 저절로 일어날 수 있을까?", "온도를 10 °C 올리면 반응 속도가 얼마나 빨라질까?"

### 10.3 화학 반응의 세계 (진로 선택) — [12반응01]–[12반응03]

| 영역 | 표준 슬라이드 흐름 | 범위 제한(교육과정) | 자주 생기는 오류·오개념 |
|---|---|---|---|
| 산 염기 평형 | 아레니우스 정의의 한계 → 브뢴스테드·라우리 산 염기와 짝산·짝염기 → 양쪽성 물질 → 이온화 상수 $K_\mathrm{a}$, $K_\mathrm{b}$와 상대적 세기 → 약산·약염기 수용액의 pH → 0.1 M 수용액 pH 측정과 이론값 비교 → 중화 적정 곡선(데이터 시각화) → 염의 가수 분해와 염 수용액의 액성 → 완충 용액과 생체 내 완충 작용 | 완충 작용은 **복잡한 pH 계산을 지양**하고 생체 내 완충의 중요성 중심. 브뢴스테드·라우리 정의의 확장성·유용성 | 강산과 진한 산 혼동, 짝산·짝염기 쌍을 잘못 짝지음, 중화점 = 중성이라고 생각(약산–강염기), 완충 용액은 pH가 전혀 안 변한다고 생각 |
| 산화·환원 반응 | 전자 이동과 산화·환원 → 산화수와 산화수 규칙 → 산화제·환원제(상대적 세기로 결정) → 반쪽 반응식으로 반응식 완성 → 화학 전지의 발전(볼타 → 다니엘 → 실용 전지) → 화학 전지의 원리와 표준 환원 전위, 전지 전위 → 전기 분해(용융·수용액)와 도금·제련 → 생명 현상(광합성·호흡)과 전지 속 산화·환원 | 산화·환원은 **동시에** 일어남. 산화제·환원제는 정해져 있지 않고 **상대적 세기**로. 화학 에너지 → 전기 에너지 전환 원리 | 산화수와 이온 전하 혼동, 표준 환원 전위에 계수를 곱함, 전지와 전기 분해의 (+)/(−)극 반응을 바꿔 씀, 전자가 용액을 지나간다고 그림 |
| 탄소 화합물과 반응 | 탄소 화합물이 다양한 까닭 → 탄화수소 → 작용기(알코올, 알데하이드, 카복실산)와 성질 → 작용기의 변화로 반응 설명(산화: 에탄올 → 아세트알데하이드 → 아세트산, 에스터화, 은거울 반응) → 단위체와 중합 반응(첨가·축합) → 천연·합성 고분자 → 신물질과 과학·기술·사회 | 작용기는 **알코올, 알데하이드, 카복실산만**, "작용기가 바뀌면 성질도 바뀐다" 수준. 고분자는 단위체의 반복 결합 이해 수준. **반응의 종류 암기보다 유용한 물질 개발**에 중점 | 작용기 이름과 화합물 이름 혼동, 구조식에서 탄소 원자가 4개 결합을 넘김, 고분자를 단위체의 혼합물로 생각 |

- 상수(M11): $K_\mathrm{w}=1.0\times10^{-14}$(25 °C), 이온화 상수·표준 환원 전위는 **교과서 부록 표 값만**(덱 plan.md에 출처 쪽과 함께).
- 표기: 반쪽 반응식은 전자를 `e-`로(`\ce{Cu^2+ + 2e- -> Cu}`), 표준 환원 전위 $E^\circ$ [V], 산화수는 C10.
- S6 예측 질문 후보: "0.1 M 아세트산과 0.1 M 염산의 pH는 같을까?", "아세트산 나트륨 수용액은 중성일까?", "레몬 전지에서 전자는 어느 금속에서 나올까?", "에탄올이 산화되면 무엇이 될까?"
